<h2 align="center">论述型作文·亮点句式——名词性从句</h2>

> **本讲核心**：陈述事实、表达观点、提出问题 → 用**名词性从句**（主语从句、宾语从句、表语从句、同位语从句）。亮点有二：**what 双从框架**（What...is that...）与**形式主语句式**（It is + a. + 从句/to do），后者可多层嵌套，是论述文"建议、要求"类语句的高级载体。

### （一）为什么是名词性从句

语义逻辑决定句式选择：**陈述事实 / 表达观点 / 提出问题**这三类语义，对应句式工具就是名词性从句——一个"大句子套小句子"的结构，小句子（从句）整体充当大句子的一个名词性成分。

**四种从句**（按从句充当的成分命名）：

| 从句类型 | 充当成分 | 典型场景 |
|:---|:---|:---|
| 主语从句 | 大句子的主语 | What we lack is ... |
| 宾语从句 | vt. 或介词后 | We can see that ... |
| 表语从句 | be / 半系动词后 | The problem is that ... |
| 同位语从句 | 解释说明名词 | a problem that ... / the conclusion that ... |

### （二）引导词与四种常用结构

**常用结构形式（4 种）**：

| 序号 | 结构 | 说明 |
|:---|:---|:---|
| 1 | **that / whether + 完整句子** | that 无实义不作成分；whether 表"是否" |
| 2 | **what / which / who + 非完整句子** | 连接代词在从句中作成分；what = the thing that |
| 3 | **when / where / why / how + 完整句子** | 连接副词作状语 |
| 4 | **how + adj./adv. + 主 + 谓** | 表感叹程度："多么好/坏/大/重要" |

**两条注意**：

1. **主语从句的引导词不能省略**（That he came is true. 的 that 不可丢）
2. **特殊疑问词引导从句，语序一律用陈述语序**（不是疑问语序）

> **考点**：主语从句作主语时，谓语用**单数**（主谓一致）——What we lack **is** the awareness of environmental protection.

### （三）形式主语句式（亮点句式）

形式主语句式表**建议、要求**类语义，两套模板：

1. **It is + a. + (for/of) sb to do sth.**
2. **It is + a. + 主语从句**（eg. that sb (should) do sth.）

> **易错点**：表人的品质的形容词（kind、shortsighted、wise...）用 **of sb**；一般形容词用 **for sb**。
> **虚拟语气**：necessary/essential/advisable 等"建议要求"类形容词后的 that 从句用 **(should) + 动词原形**，should 可省。

### （四）写作例题精讲（8 例）

#### 一、图表/图画描述句

**例 1**：从这个表格中，我们可以看出国产车品牌所占市场份额大幅度增加。

- 拆解：中文是"大句子套小句子"——主干谓语"看出"（see vt.），"份额大幅增加"是陈述事实 → 宾语从句（that + 句子）
- 词块：市场份额 **market share**（share 持有 → shareholder 股东）；国产品牌车 **cars of national/domestic brands**；大幅度（地）**dramatically/greatly**
- 基础版：From the table, we can see **that** the market share of cars of national brands has increased dramatically.
- what 升级版（主从 + 表从）：**What we can see from the table is that** the market share of cars of national brands has increased dramatically.
- 再嵌套定从（"所占"份额）：What we can see from the table is that the market share **that cars of national brands take** has increased dramatically.（take share 占份额）

> **技巧**："我们可以看出"两种写法——宾从版（we can see that）与主从+表从版（What ... is that ...），后者句首即亮点。

**例 2**：这幅画显然在说中国正面临着性别比例失衡的问题。

- 词转换："说" → "**反映/体现**" reflect（板书补充 indicate）
- 句式 1（主谓宾 + 同位语从句）：**Obviously, the picture reflects a problem that** China **is faced with** the imbalance of **sex/gender ratio**.
- 句式 2（形式主语）：**It is obvious that** the picture reflects a problem that China is faced with the imbalance of sex/gender ratio.

**例 3**：我们应该采取措施保持生态平衡。

- It is necessary/essential **that we (should) take measures to maintain ecological balance**.
- 要点："应该" → that 从句 + **(should)** 虚拟语气。

#### 二、观点/哲理句

**例 4**：因此，生活中重要的是我们为别人做了什么。

- **What(主语从句) is important in life is what(表语从句) we have done for others**.
- 词升级：be important = **count** (vi.)（如 Every minute counts. 分秒必争）

> **技巧**：一句话装两个名词性从句——主语从句 + 表语从句，"……的是……"类哲理句的固定框架。

**例 5**：我们可以得出这样的结论：那些认为他们的成功可以以对手的失败为代价而获得的人是目光短浅的。

- 拆主干：We can come to the conclusion: ....；从句主干：那些……的人是目光短浅的（those people are shortsighted）
- 基础版：We can **come to / draw** the conclusion **that(同位语从句)** those **who think (that)(宾语从句)** their success can be **gained/achieved at the cost of** rivals' failure **are shortsighted**.
- 形式主语升级版：We can come to the conclusion that **it(形式主语)** is shortsighted **of** some people to believe **that(宾语从句)** they can achieve success **at the expense of** rivals' failure.
- 词块：**at the cost of = at the expense of**（以……为代价）；**shortsighted** 目光短浅的

> **技巧**：同位语从句里再嵌形式主语 it is + a. + **of** sb to do（品质形容词配 of），一句三层从句。

**例 6**：当我们制定目标时，我们应该考虑到是否能够完成它。

- 版本 1（宾语从句）：When we **set a goal**, we should consider **whether** we can **achieve** it.
- 版本 2（形式主语嵌套）：When we set a goal, **it** is preferable **that(主语从句)** we (should) consider **whether(宾语从句)** we can achieve it.
- 版本 3：**It is preferable/necessary (for us) to consider** whether we can achieve it.

**例 7**：看到图画中的情景，我们不禁怀疑这位父亲的行为是否能让孩子领悟"孝顺"的真正含义。

- After/When we see the scene in the picture, we **can't help wondering whether(宾语从句)** the father's behavior can help his children understand the true meaning of **filial piety**.
- 词块：孝顺 **filial piety**（= respecting and loving parents）；不禁怀疑 **can't help wondering**

**例 8**：我们需要理性分析是否行业分配不公以及待遇悬殊是引起这个变化的主要原因。

- 基础版：We should **analyze/analyse in a rational way whether** ... **are the main reasons for this change**.
- 形式主语版（亮点）：**It is necessary for us to rationally analyze whether** the unfair distribution of industries and the disparate payment are the main reasons **that(定语从句) trigger/cause** this change.
- 词块：行业分配不公 **the unfair distribution of industries**；待遇悬殊 **the disparate payment / payment of distinct difference**

#### 三、主语从句基础两例

**例 A**：我们所缺少的是环保意识。

- **What we lack is** the **awareness of environmental protection**.（what 从句作主语，谓语单数 is）

**例 B**：他们经常把现在该做的事往后推。

- They often **put off what they should do now**.（what = the thing that；介词后接宾语从句；陈述语序）

### （五）本章总结

**知识结构**：

```
亮点句式·名词性从句
├─ 语义定位：陈述事实/表达观点/提出问题 → 名词性从句（大句子套小句子）
├─ 四分类：主语从句 / 宾语从句 / 表语从句 / 同位语从句（按充当成分命名）
├─ 引导词四种结构
│   ├─ that/whether + 完整句
│   ├─ what/which/who + 非完整句（what = the thing that）
│   ├─ when/where/why/how + 完整句
│   └─ how + adj./adv. + 主谓（多么……）
├─ 三条硬规则
│   ├─ 主语从句引导词不能省
│   ├─ 特殊疑问词引导 → 陈述语序
│   └─ 主语从句作主语 → 谓语单数（主谓一致）
├─ 亮点句式：形式主语
│   ├─ It is + a. + (for/of) sb to do sth.
│   ├─ It is + a. + that sb (should) do sth.（建议要求类 → 虚拟 should 可省）
│   └─ 品质形容词配 of sb（shortsighted of some people）
└─ 升级套路
    ├─ we can see that → What ... is that（主从+表从）
    ├─ "说" → reflect/indicate（图画句专用动词）
    ├─ be important → count (vi.)（Every minute counts）
    └─ at the cost of = at the expense of
```

**高频考点速记**：

| 考点 | 一句话记忆 |
|:---|:---|
| 名词性从句四分类 | 按充当成分命名：主/宾/表/同位 |
| what 从句 | what = the thing that，从句必须缺主语或宾语 |
| 陈述语序 | 特殊疑问词引导从句一律陈述语序 |
| 主谓一致 | 主语从句作主语，谓语用单数（What we lack **is**...） |
| 引导词省略 | 宾语从句 that 可省，主语从句 that 不可省 |
| 形式主语模板 | It is + a. + (for/of) sb to do / that sb (should) do |
| of vs for | 品质形容词（shortsighted/kind）用 of sb |
| 虚拟语气 | necessary/essential 类 + that 从句 → (should) 动词原形 |
| 图表句框架 | What we can see from the table is that... |
| 图画句动词 | "说"不用 say → reflect / indicate |
| 是否 | 从句中只用 whether（不用 if 更正式） |
| 同位语从句 | conclusion/problem/phenomenon/news + that + 完整句 |
| 孝顺 | filial piety = respecting and loving parents |
| 以…为代价 | at the cost of = at the expense of |

**话题词块备份**：market share（市场份额，shareholder 股东）、cars of national/domestic brands（国产品牌车）、dramatically/greatly（大幅度地）、the imbalance of sex/gender ratio（性别比例失衡）、take measures to maintain ecological balance（采取措施保持生态平衡）、can't help wondering（不禁怀疑）、the unfair distribution of industries（行业分配不公）、the disparate payment（待遇悬殊）、trigger/cause this change（引发变化）、put off（推迟）。
