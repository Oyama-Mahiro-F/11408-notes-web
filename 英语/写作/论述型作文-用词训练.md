<h2 align="center">论述型作文·用词训练</h2>

> **本讲核心**：考研论述型作文的用词有三层要求——**正确**（保底）、**准确**（及格线）、**丰富**（高分要求）。词汇升级 ≠ 生僻大词，而是**贴切、形象**的同义替换。

### （一）用词三要求总览

| 层级 | 要求 | 说明 |
|:---|:---|:---|
| 1 | 正确 | 拼写、语法、搭配不出错 |
| 2 | 准确 | 语义搭配恰当：搭配对象 + 情感色彩 |
| 3 | 丰富 | 高分要求：同义替换、贴切形象、善用短语 |

### （二）用词正确——语法正确

#### 一、词性正确：根据语法功能确定词性

一个词用什么词性，不由中文意思决定，而由它在句子里**充当的成分**决定。

**例**：Emerging from the chart is a noticeable phenomenon ~~with relate to~~ the change of population.

- ✗ with relate to → ✓ **in relation to / related to**
- 句式点评：本句用了**完全倒装**（介词短语/分词短语/形容词短语 + 谓语 + 主语），Emerging from the chart 是分词短语提前，真正的主语是 a noticeable phenomenon。

**句法功能 ↔ 词性对照表**（判断词性的唯一依据）：

| 句法功能 | 位置 | 性质 | 形式 |
|:---|:---|:---|:---|
| 主语 | 正常句：谓语前<br>倒装句：谓语后 | n. | 名词/代词/动名词/不定式/主语从句 |
| 谓语 | —— | v. | ①时态：v. / v-(e)s / be v-ing / will v. / have(has/had) v-ed<br>②被动语态：be + v-ed<br>③否定形式<br>④情态动词 + v. |
| 宾语 | ①vt. 之后<br>②介词后 | n. | 名词/代词/动名词/不定式/宾语从句 |
| 表语 | ①be 后<br>②半系动词后 | n./a. | 名词/代词/动名词/不定式/形容词/介词短语/表语从句 |
| 宾补 | 名词后 | n./a. | 名词/形容词/不定式/分词 |
| 定语 | 名词前/后 | a. | 名词/形容词/介词短语/分词短语/不定式短语/定语从句 |
| 状语 | ①动词前/后<br>②句子前/后 | adv. | 副词/介词短语/不定式短语/分词短语/状语从句 |
| 同位语 | —— | n. | 名词短语/同位语从句 |

#### 二、单词语法变形

各词类最容易漏检的变形点：

- **名词**：① 冠词 ② 可数/不可数 ③ 复数变形
- **动词**：时态、三单、被动语态
- **形容词/副词**：比较级和最高级

**例 1**：他下定决心今年通过考试。

- ✗ He **make** determination to pass the exam. → ✓ He **makes** determination to pass the exam.（主语三单，动词加 -s）

**例 2**：问题得到了解决。

- ✗ Problem solved.（光秃秃的 v-ed 不是谓语）→ ✓ **The problem has been solved.**（被动语态，be + v-ed 才完整）

**例 3**：People are ~~more happier~~ than the past.

- ✗ more + happier → 比较级重复，**二选一**：People are **happier** than in the past.

> **易错点**：v-ed 单独放在主语后不构成谓语；more 不能修饰比较级。

### （三）用词正确——搭配正确（语义 & 用法）

#### 一、动词搭配：一个中文动作，多种英文句型

**例 1**：年轻人花太多时间上网。

- Young men **spend** much time **(in) surfing** on the Internet.（人 + spend + 时间 + (in) doing）
- Surfing on the Internet **takes/costs/wastes/consumes** young men much time.（事作主语 + 花费动词 + 人 + 时间）
- = **It takes** young men much time **to surf** on the Internet.（It takes sb time to do）

**例 2**：提高人们的生活水平。

- ✗ ~~rise people's living level~~ —— rise 是**不及物动词**（vi.），不能带宾语
- ✓ **raise** people's living level（raise 是及物动词 vt.，"提高"带宾语）
- ✓ People's living level **has been rising**.（自身上升用 rise）

> **易错点**：rise (vi.) vs. raise (vt.)——有没有宾语，决定用哪个。

**例 3**：做志愿者。

- ✗ ~~do volunteers~~
- ✓ **be a volunteer** / **work (serve) as a volunteer**

**例 4**：压力大。

- ✗ ~~big pressure~~
- ✓ **heavy / overwhelming pressure / stress**（压力的固定搭配是 heavy）

#### 二、语义准确：搭配的两个考察维度

1. **搭配对象**：语义上跟谁连用（如 pressure 搭 heavy 不搭 big）
2. **情感色彩**：褒贬、正式度是否与语境一致

### （四）用词丰富（高分要求：贴切、形象）

丰富 ≠ 堆砌难词，而是 **varied / diverse**——同义表达轮换，且每个词都**贴切、形象**。

#### 一、高频话题词升级表

| 中文 | 可选表达 |
|:---|:---|
| 社会发展 | social development / progress |
| 经济繁荣/向好 | economic boom / prosperity / thriving / blooming |
| 科技进步 | technological advancement |
| 个人成长 | personal growth |
| 好的社会环境 | healthy social environment / climate / atmosphere |
| 好的政策 | favorable policies |
| 好的心态 | positive mind |
| 好的能力 | outstanding abilities / competence / capability |
| 好的工作 | highly-paid / decent（体面的）/ stable jobs |
| 好的前程 | a promising future |

#### 二、善用短语替换基础词

**① "出现/存在"**：exist

- → **come into existence / come into being**（"开始出现、形成"）

**② "认为"**：think

- → Sb **argue / maintain / insist / believe**...
- → **From my perspective**, ...
- → **As far as ... is concerned**, ...

**③ "很多"**：many / much

- → **a good/great/large number of** + 可数复数
- → **a good deal of** + 不可数
- → **a variety of**（形形色色）
- → **a multitude of**（大量的）

**④ "让某人做某事"**：make / let（按语义强度分层）

| 语义 | 表达 |
|:---|:---|
| 促使/使……能够 | enable / encourage / empower / allow sb to do sth |
| 造成（结果） | lead / cause sb to do sth; result in sb doing sth |
| 迫使（强制） | force sb to do sth |

**⑤ "对……有好处" = "有利于" = "促进"**

- **do good to**
- **be beneficial / helpful to**
- **play a positive role in**
- **drive ... forward**
- **promote / fuel / boost sth.**（promote 与 mote 同根，fuel/boost 更形象）

### （五）本章总结

**知识结构**：

```
用词训练
├─ 1 正确（保底）
│   ├─ 拼写
│   ├─ 语法正确
│   │   ├─ 词性正确 ← 由句法功能决定（主谓宾表补/定状同位对照表）
│   │   └─ 语法变形：名词（冠词/可数/复数）、动词（时态/三单/被动）、形副（比较级最高级）
│   └─ 搭配正确（语义&用法）：spend/take/cost、rise vs raise、heavy pressure…
├─ 2 准确（及格线）
│   └─ 语义搭配两要素：搭配对象 + 情感色彩
└─ 3 丰富（高分要求：贴切、形象）
    ├─ 话题词升级：社会发展/经济繁荣/科技进步/个人成长/好的环境政策心态能力工作前程
    └─ 善用短语替换：exist→come into being、think→argue/maintain、
        many→a multitude of、make→enable/empower、有利于→promote/fuel/boost
```

**高频易错点速记**：

| 考点 | 一句话记忆 |
|:---|:---|
| 谓语完整性 | v-ed 单独不作谓语，被动必须 be + v-ed |
| 比较级 | more 与 -er 不共存 |
| rise vs. raise | rise 不及物（自身升），raise 及物（抬高宾语） |
| 压力大 | heavy/overwhelming pressure，不是 big |
| 做志愿者 | work/serve as a volunteer，不是 do volunteers |
| 花时间句型 | 人 spend 时间 doing；It takes sb time to do；事作主语用 take/cost/waste/consume |
| 词性判断 | 先定句法功能，再定词性——对照句法功能表 |
| "很多"替换 | number of 接可数，a good deal of 接不可数 |
| "让某人做" | enable/empower（赋能）、lead/cause（导致）、force（迫使），按语义强度选 |
| "促进"替换 | promote / fuel / boost / play a positive role in |
