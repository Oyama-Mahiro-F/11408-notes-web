<h2 align="center">论述型作文·亮点句式——定语从句</h2>

> **本讲核心**：写作句式两大要求——**语法正确**（基本句型 + 成分形式）与**句式结构丰富**。定语从句是"从句之首"的亮点句式：既能把零散短句合并升级，又能用 *which* 指代整句承载**隐含逻辑**（因果、递进）。

### （一）写作句式的底层框架

#### 一、语法正确的两块基石

**1. 基本句型（5 种）**

| 句型 | 结构 | 谓语动词 |
|:---|:---|:---|
| 主谓 | S + V | vi. |
| 主谓宾 | S + V + O | vt. |
| 主谓双宾 | S + V + O(人) + O(物) | vt. |
| 主谓宾宾补 | S + V + O + C | vt. |
| 主系表 | S + 系 + P | be / 半系动词 |

**2. 成分形式（三级）**：同一个成分可以由 **词 → 短语 → 从句** 三种形式充当，句式升级的本质就是把低级形式换成高级形式。

#### 二、句子成分一览

**主干成分（5 种）**：

| 成分 | 语义 | 典型词性 |
|:---|:---|:---|
| 主语 | 谓语动作的发出者 | n. |
| 谓语 | 表示主语"干什么、是什么" | v. |
| 宾语 | 谓语动作的承受者 | n. |
| 表语 | 表示主语的性质/状态 | n. / adj. |
| 补语 | 补充说明宾语的性质状态 | n. / adj. |

**修饰语成分（3 种）**：

| 成分 | 语义 | 典型词性 |
|:---|:---|:---|
| 定语 | 修饰名词 | adj. |
| 状语 | 修饰 adj./v./adv. | adv. |
| 同位语 | 解释说明名词 | n. |

#### 三、句式选择的两依据与六种语义逻辑

句式选择看两点：**语义需要** + **逻辑关系**。论述文常用的 6 种语义逻辑，各有一类句式工具与之对应：

| 语义逻辑 | 对应句式工具 |
|:---|:---|
| 陈述事实 | 5 种基本句型（句式正确） |
| 表达观点 | 名词性从句 |
| 提出问题 | 名词性从句 |
| 逻辑推导 | 状语结构（修饰、逻辑） |
| 修饰润色 | 后置定语（修饰限定、解释说明） |
| 客观存在 | there be 句式 |
| 突出强调 | 倒装 / 强调句 |

### （二）定语从句：语义功能与引导词

#### 一、两大语义功能

| 类型 | 功能 | 标点 |
|:---|:---|:---|
| 限制性定从 | 译作"……的"，限定先行词 | 无逗号 |
| 非限制性定从 | 解释补充说明；which 可**指代前面整个句子** | 逗号隔开 |

#### 二、使用特征与注意点

**何时想到用定从**（两个信号）：

1. 中文出现"**……的**"修饰结构
2. 修饰语中**包含动作**（如"生活在舒适环境中**的**"→ who live in ...）

**两个注意**：

1. **引导词的选择**（看先行词 + 从句缺什么成分）
2. 定语从句的**谓语与先行词保持一致**（先行词决定从句主谓的单复数）

#### 三、引导词清单

| 先行词 | 引导词 |
|:---|:---|
| sb. | who / that |
| sth. | that / which |
| sb. / sth.（所属） | whose |
| 前面整个句子 | , which（非限制性） |
| 时间 | when |
| 地点 | where |
| reason(s) | why |
| 方式 | whereby |
| 介词 + which / whom | 正式书面（介词前置） |

#### 四、名词修饰语的位置总览

**前置定语**（放在名词前）：a/an/the、物主代词、名词所有格、形容词、单个分词、a + 数量/种类 + of

**+ 名词 +**

**后置定语**（放在名词后）：形容词短语、介词短语、不定式短语、分词短语、**定语从句**

> **考点**：定语从句是最长的后置定语——当修饰内容超出短语承载力（含完整动作、有自己的宾语状语）时，升级为定从。

### （三）写作例题精讲（6+2 例）

#### 一、限制性定从：修饰"……的人/物"

**例 1**：生活在舒适环境中的人们不能经受生活中的困难。

- 拆主干：人们不能经受困难（主谓宾）
- 参考表达：People cannot **withstand / weather** difficulty / hardship.（板书补充：face / cope with）
- 定从升级：People **who live in a comfortable / cozy environment** cannot withstand difficulties in life.

> **技巧**：先写主干，再把"……的"修饰部分用定从挂到名词上。

**例 2**：俗话说：世上无难事，只怕有心人。

- 固定句式：**As the saying goes**, ...
- 拆译：世上没有困难的事 → There is nothing difficult in the world. = Nothing in the world is difficult.
- "有心人"三连：who **has determination** = who **is determined** = who **sets his mind** (to do it)
- 参考：As the saying goes, nothing in the world is difficult for one **who sets his mind to do it**.

#### 二、并列句 → 定语从句的升级

**例 3**：独立带来很多好处，其中最重要的是自我决定（self-determination）。

- 并列句版：Independence **brings / leads to** many / various advantages, **and** the most important **one** is self-determination.
- 定从版（亮点）：Independence brings / leads to many / various advantages, the most important **of which** is self-determination.

> **技巧**："...，其中最……" → **the + 最高级 + of which**，比 and 接并列分句高一个档次。

#### 三、非限制性 which 指代整句

**例 4**：图片表明，一个国家的文化可能会成为国际的文化，这有利于所有的人类。

- 陈述句版：The picture **indicates / shows** that ...
- as 从句版：**As the picture indicates**, ...（as 也可指代整句，放句首）
- 参考：A kind of national culture may become an international one, **which benefits all the humans**.
- 要点：①非限制性定从 ②引导词指代**前面的整个句子**（"这有利于"的"这"）

**例 5**：普遍存在的虚假广告破坏了企业和顾客之间的信任，长此以往，这最终将阻碍我们国家的经济迅速发展。

- 词块：普遍存在的 common / widespread（板书补充 fake / misleading）；虚假广告 false and deceptive advertisement / advertising；破坏 destroy；阻碍 hinder
- 参考：The widespread false and deceptive advertising destroys the trust **between enterprises and customers / consumers**, **which in the long run will hinder the rapid economic development of our country**.
- 要点：**which in the long run will...** —— 用一个 which 从句同时装下"长此以往 + 阻碍发展"两层信息。

**例 6**：和谐的邻里关系是必要的，因为这能够让人们日常生活的环境更平和。

- 词块：和谐的 harmonious（harmony n.）；邻里关系 harmonious neighborhood（= the relationship between neighbors）；必要的 necessary / essential；**be of necessity** = is necessary（介词短语表性质，主系表的高级形式）
- 参考：Harmonious neighborhood relation **is of necessity**, **which can make people's common living environment more peaceful**.
- 要点：***定语从句承载语义隐含逻辑（如因果）**——中文用"因为"明示，英文用 which 从句隐含。

#### 四、介词 + which/whom

**例 7**：我们盼望已久的机会终于到来了。

- 基础版：The opportunity / chance has finally come.（期盼 expect / long for）
- 定从版：The opportunity **which / that we have been longing for** has finally come.
- 介词前置版（亮点）：= The opportunity **for which we have been longing** has finally come.

> **技巧**：短语动词里的介词（long **for**）可提到 which 前 → **for which**，书面感立刻拉满。

**例 8**：图中描绘了两位残疾人，只有一条腿。

- ✗ The picture depicts two handicapped men, ~~who have only one leg~~.（两人共用一条腿？语义错位）
- ✓ The picture depicts two handicapped men, **each of whom has only one leg**.（"各自"一条腿 → each of whom；谓语随之用单数 has）

> **易错点**："每者/各自"类语义用 **each of whom / each of which**；引导词作从句主语时谓语数随 each 变单数。

### （四）本章总结

**知识结构**：

```
亮点句式·定语从句
├─ 底层框架
│   ├─ 语法正确 = 基本句型(5种) + 成分形式(词/短语/从句)
│   ├─ 主干 5 成分(主谓宾表补) + 修饰语 3 成分(定状同位)
│   └─ 句式选择 = 语义需要 + 逻辑关系 → 6 种语义逻辑各配一类句式
├─ 定语从句本体
│   ├─ 语义功能：限制性("的") / 非限制性(补充说明, which 指代整句)
│   ├─ 使用信号："……的" + 修饰语含动作
│   ├─ 引导词清单：who/that·which/whose/when/where/why/whereby/介词+which(whom)
│   └─ 两个注意：引导词选择；从句谓语与先行词一致
├─ 写作升级套路
│   ├─ 并列句 → 定从：..., and the most important one → the most important of which
│   ├─ 因果隐含："因为这" → , which can make...
│   ├─ 整句指代："这/长此以往" → , which (in the long run) will...
│   ├─ 介词前置：longing for → for which
│   └─ 各自语义：各自一条腿 → each of whom has...
└─ 话题词块：withstand/weather hardship、false and deceptive advertising、
    harmonious neighborhood、be of necessity、self-determination、in the long run hinder
```
