<h2 align="center">论述型作文·写作句式（按功能分类）</h2>

> **本文定位**：汇总《用词训练》《亮点句式——定语从句》《亮点句式——名词性从句》《亮点句式——状语从句》《亮点句式——非谓语动词》五篇笔记的**句式**内容。
> **编排方式**：按**语义类别与写作功能**归类（不按讲义章节），每条句式后标注**句法归属**与**用途**，再给例句。

### （一）怎么用这份文件

#### 一、两条读法

1. **写作时（主线）**：从（三）～（十三）的**功能分类**入手——先定位这句话的功能（开篇？论证？建议？），再挑句式。
2. **语法遗忘时（反查）**：翻到（十五）**按句法归属反查**——想知道"定语从句能干什么"，从那里找到它出现在哪几个功能里。

#### 二、写作功能总览

| 功能 | 在作文中的作用 | 主要句式 | 一句话示例 |
|:---|:---|:---|:---|
| 零 句式正确 | 全部功能的地基 | 5 种基本句型 + 成分形式 | People cannot withstand hardship. |
| 一 开篇描述 | 第一段，图表/图画/谚语引入 | 宾从、主从+表从、同位从、As 定从 | What we can see from the table is that ... |
| 二 陈述事实与数据 | 描述现象、列举数据、描摹细节 | 基本句型、同位语从句、there be、**动名词作主语**、**分词表伴随** | The picture reflects a problem that ... / ..., sweating but smiling. |
| 三 表达观点与态度 | 第二段表态、立论 | 宾从（argue/believe）、介词短语框架 | Sb argue that ... / From my perspective, ... |
| 四 因果论证 | 分析原因、推导后果 | because 状从、so that / so...that、which 定从、**分词作状语（原因/结果）** | ..., which in the long run will hinder ... / **Spoiled by their parents**, some children have no opportunity to ... |
| 五 条件与假设 | 提出前提、推演结果 | if 状从（主将从现） | If we get fully prepared, we can ... |
| 六 让步与对比 | 辩证表达、两方对照 | although/though、while | ..., while the goalkeeper is ready to defend. |
| 七 目的与手段 | 提对策、讲做法 | so that 状从、in order to | ... so that we can bring people into realization of ... |
| 八 修饰与限定 | 把短句挂到名词上、扩充信息 | 定语从句、后置定语、**不定式/分词作定语**、介词+which | People who live in a comfortable environment cannot ... / many elements **being boiled** in the hot pot |
| 九 强调与倒装 | 句首亮句、突出重点 | 完全倒装、形式主语（**长主语后置**） | Emerging from the chart is a noticeable phenomenon ... |
| 十 议论与疑问 | 提出议题、表达怀疑 | whether 宾从 | We should consider whether we can achieve it. |
| 十一 建议、呼吁与收尾 | 第三段给建议、升华结尾 | 形式主语 + (should) 虚拟、what 双从哲理句 | It is necessary that we (should) take measures ... |

> **记忆**：功能决定句式——写之前先问自己"这句话的功能是什么"，再回来查表。

### （二）功能零：句式正确（保底基本盘）

**用途**：所有功能的共同地基。基本句型写错、谓语不完整，再高级的从句也不得分。

#### 一、5 种基本句型

| 句型 | 结构 | 谓语动词 |
|:---|:---|:---|
| 主谓 | S + V | vi. |
| 主谓宾 | S + V + O | vt. |
| 主谓双宾 | S + V + O(人) + O(物) | vt. |
| 主谓宾宾补 | S + V + O + C | vt. |
| 主系表 | S + 系 + P | be / 半系动词 |

#### 二、句子成分

| 成分 | 属性 | 语义 | 典型词性 |
|:---|:---|:---|:---|
| 主语 | 主干 | 谓语动作的发出者 | n. |
| 谓语 | 主干 | 主语"干什么、是什么" | v. |
| 宾语 | 主干 | 谓语动作的承受者 | n. |
| 表语 | 主干 | 主语的性质 / 状态 | n. / adj. |
| 补语 | 主干 | 补充宾语的性质状态 | n. / adj. |
| 定语 | 修饰 | 修饰名词 | adj. |
| 状语 | 修饰 | 修饰 adj./v./adv. | adv. |
| 同位语 | 修饰 | 解释说明名词 | n. |

#### 三、三条保底规则

| 规则 | 一句话记忆 |
|:---|:---|
| 谓语完整 | v-ed 单独不作谓语，被动必须 be + v-ed（The problem **has been solved**.） |
| 主谓一致 | 主语三单动词加 -s；主语从句作主语，谓语用单数 |
| 比较级 | more 不与 -er 共存（more happy ✗ / happier ✓） |

#### 四、成分形式的三级升级

同一个成分可由 **词 → 短语 → 从句** 三级形式充当——**句式升级的本质就是把低级形式换成高级形式**：

1. **词**：the **tough** task
2. **短语**：the task **hard to complete**
3. **从句**：the task **that we cannot complete**

#### 五、谓语与非谓语（三类非谓语）

动词有两条路：作**谓语**（一句话只有 1 个；需要 ≥2 个时必须加连词），或降级为**非谓语**（不作谓语，让句子多装动作）。

| 非谓语 | 形式 | 性质 | 句法功能 |
|:---|:---|:---|:---|
| 动名词 | v-ing | 名词 | 主语 / 宾语 / 定语 / 表语 |
| 不定式 | to + v. | 名词 / 形容词 / 副词 | 主语 / 宾语 / 表语 / 宾补 / 定语 / 状语 |
| 分词 | 现在分词 v-ing<br>过去分词 v-ed | 形容词 / 副词 | 定语 / 状语 / 宾补 / 表语 |

> **记忆**：动名词 = 名词；不定式 = 多面手；分词 = 形容词副词（**主动用 -ing，被动用 -ed**）。

### （三）功能一：开篇描述（引入话题）

**用途**：作文第一段。图表作文描述数据、图画作文描述画面、议论开篇引谚语或研究结论——**功能是"引人入题"，让第一句就有亮点**。

1. **From the table, we can see that ...**（宾语从句 · 图表描述基础版）
    - From the table, we can see **that** the market share has increased dramatically.
2. **What we can see from the table is that ...**（主语从句 + 表语从句 · 图表描述亮点版，句首即亮点）
    - **What we can see from the table is that** the market share of cars of national brands has increased dramatically.
3. **Obviously, the picture reflects / indicates a problem that ...**（宾语从句 + 同位语从句 · 图画描述，"说"不用 say）
    - **Obviously, the picture reflects a problem that** China is faced with the imbalance of sex ratio.
4. **It is obvious that the picture reflects ...**（形式主语 + 主语从句 · 图画描述客观化）
    - **It is obvious that** the picture reflects a problem that ...
5. **As the picture indicates, ...**（As 定语从句，指代整句 · 图画描述，放句首）
    - **As the picture indicates**, a kind of national culture may become an international one.
6. **As the saying goes, ...**（固定句式 · 引谚语俗语）
    - **As the saying goes**, nothing in the world is difficult for one who sets his mind to do it.
7. **Researches have found that ...**（宾语从句 · 引研究结论基础版）
    - **Researches have found that** a positive attitude is beneficial to life.
8. **As researches have found, ...**（As 定语从句 · 引研究结论亮点版）
    - **As researches have found**, a positive attitude is beneficial to life.
9. **It has been found by researches that ...**（形式主语 + 主语从句 · 引研究结论客观化，最书面）
    - **It has been found by researches that** a positive attitude is beneficial to life.

> **技巧**：同一功能给三档句式（基础 / 亮点 / 客观化）——"我们可以看出""研究表明"都有三种说法。
> **易错点**：作为图表句的 `what` 从句，从句内部必须缺主语或宾语（see **what** → 不是 see that）。

### （四）功能二：陈述事实与数据

**用途**：描述现象、摆数据、讲客观情况——**不掺杂主观态度**。核心是"句子完整、事实清楚"，不必追求花哨。

1. **S + V + O / S + 系 + P**（基本句型 · 陈述最基础的事实）
    - People cannot **withstand** difficulty. / A positive attitude **is** beneficial to life.
2. **There is / are ...**（there be 句式 · 客观存在"有"）
    - **There is** nothing difficult in the world.
3. **... a problem that + 完整句**（同位语从句 · 解释抽象名词 problem / conclusion / phenomenon / news）
    - the picture reflects a problem **that China is faced with the imbalance of sex ratio**.
4. **... when / where / why / how + 完整句**（连接副词引导的名词性从句 · 陈述时间 / 地点 / 原因 / 方式）
    - We should consider **how** we can solve the problem.
5. **how + adj./adv. + 主 + 谓**（名词性从句，感叹程度 · 强调"多么……"）
    - We all know **how important** it is to protect the environment.
6. **动名词 / 不定式作主语**（非谓语 · 陈述"做某事意味着/是……"）
    - **Ensuring the continuous prosperity** of Chinese traditional drama **means making** great contribution to the conservation of the world culture.（动名词作主语，谓语用单数）
7. **..., 分词（表伴随）**（非谓语 · 描摹动作细节，一句装两个动作）
    - 同一主体（现在分词表主动）：The athlete finally reaches the finishing line, **sweating but smiling**.
    - 同一主体：Two tourists are chatting and eating on a boat, **throwing much rubbish into the lake**.
    - 不同主体（**独立主格**）：Two tourists are chatting and eating on a boat, **(with) much rubbish thrown into the lake**.

> **易错点**：同位语从句的 that 后是**完整句子**（that 不作成分）；定语从句的 that 后**缺成分**——两者的分水岭就在这里。
> **注意**：动名词作主语时谓语用**单数**；分词表伴随的前提是**逻辑主语与主句主语一致**，不一致要用**独立主格**——(with) + 名词 + 分词。

### （五）功能三：表达观点与态度

**用途**：第二段立论、表态——**功能是把"我认为"写得不像"我觉得"**。

1. **Sb argue / maintain / insist / believe that ...**（宾语从句 · 引他人或普遍观点）
    - Many people **maintain that** independence brings various advantages.
2. **From my perspective, ...**（介词短语框架 · 本人表态，放句首）
    - **From my perspective**, the advantages outweigh the disadvantages.
3. **As far as ... is concerned, ...**（介词短语框架 · 限定话题后表态）
    - **As far as** college students **are concerned**, independence matters most.
4. **... what is important / what we should do is what ...**（主语从句 + 表语从句 · 哲理式表态"……的是……"）
    - **What** is important in life **is what** we have done for others.
5. **be important → count**（动词替换 · 表态时的用词升级）
    - Every minute **counts**.

> **技巧**：观点句的三种人称视角——引他人（Sb argue that）、本人（From my perspective）、限定范围（As far as ... is concerned），轮换使用避免重复。

### （六）功能四：因果论证（本项最常用）

**用途**：分析原因、推导后果、论证利弊——**功能是把两个分句之间的逻辑讲清楚**，并用从句把"这"的指代关系显性化。

1. **Because + 句子, 主句**（原因状语从句 · 明示原因，最直接）
    - **Because** most children are having too much school work, they have no time to participate in social activities.
2. **主句, so that + 句子**（结果状语从句 · 陈述结果"以至于"）
    - Most children are having too much school work **so that** they have no time to participate in social activities.
3. **so + adj./adv. + that + 句子**（结果状语从句强化 · 强调"如此……以至于"）
    - Most children are having **so** much school work **that** they have no time to participate in social activities.
4. **主句, , which will ...**（非限制性定语从句 · 隐含因果，替换 because 实现句式升级）
    - A positive attitude is beneficial to life, **which** will help us solve tough problems.
5. **主句, , which in the long run will ...**（非限制性定语从句 · 长效推论"长此以往这会…"）
    - ... destroys the trust between enterprises and customers, **which in the long run will hinder** the rapid economic development of our country.
6. **主句, the most important of which is ...**（非限制性定语从句 · "其中最……"，替代 and 并列句）
    - Independence brings many advantages, **the most important of which** is self-determination.
7. **enable / encourage / empower / allow sb to do sth**（动词短语 · 表"促使 / 使……能够"）
    - Technology **enables** us to work more efficiently.
8. **lead / cause sb to do sth；result in sb doing sth**（动词短语 · 表"造成、导致"）
    - Peer pressure may **lead** teenagers to make wrong choices.
9. **force sb to do sth**（动词短语 · 表"迫使"）
    - Heavy workload **forces** students to give up hobbies.
10. **do good to / be beneficial to / play a positive role in / drive ... forward / promote / fuel / boost**（动词短语 · 表"有利于 / 促进"）
    - Volunteering **plays a positive role in** personal growth.
11. **分词作状语（表原因 / 结果）**（非谓语 · 用分词隐含因果，最"去模板化"）
    - 前 置 表 原 因：**Spoiled by their parents**, some children have no opportunity to understand what the hardship is.
    - 后 置 表 结 果：Some children are spoiled by their parents, **having no opportunity to understand what the hardship is**.
12. **Considering / Given sth., 主句**（分词短语作状语 · 表"考虑到……"）
    - **Considering the severity of the problem**, it is a must to take effective measures before the deterioration of the situation.
    - **Given** the current situation, we should take action immediately.

> **考点**：同一因果关系有五种写法——原因状从（because）、结果状从（so that）、结果强化（so...that）、定语从句隐含因果（, which）、**分词状语隐含因果**（Spoiled by... / ..., having no...），轮换使用避免通篇 because。
> **易错点**：`so that` 表结果时从句陈述既成事实；表目的时从句常带 can/could（见功能七）。
> **易错点**：分词状语的逻辑主语必须与主句主语一致（不一致要用独立主格，见功能二）。

### （七）功能五：条件与假设（推演前提）

**用途**：提出前提、假设情景、推演后果——**功能是为论点设置条件**，常见于论述利弊、给建议的段落。

1. **If + 句子, 主句**（条件状语从句，主将从现 · 提出前提并推演结果）
    - **If we get** fully prepared, we can embrace the future challenges and become winners in the new era.
2. **If + 句子, 主句 + so that**（条件 + 结果 · 前提与结果双挂，首尾呼应）
    - **If you can balance this relationship well**, you will definitely acquire enough knowledge and gain experience **so that** you can be prepared for the future success.
3. **When + 句子, 主句**（时间状语从句 · 以"当……时"引前提）
    - **When we set a goal**, we should consider whether we can achieve it.

> **易错点**：if 条件句"**主将从现**"——从句用现在时（If we **get**），主句才用将来时 / 情态动词（we **can**）。
> **技巧**：条件句适合放在第三段"提建议"的位置，比 we should 开头的祈使式更有推演感。

### （八）功能六：让步与对比（辩证表达）

**用途**：辩证论述、两方对照、欲扬先抑——**功能是体现思辨性**：让步句先承认对方合理之处，再用主句转折回自己的立场。

1. **Although / Though + 句子, 主句**（让步状语从句 · 先让后转）
    - **Although** the task is tough, the player still tries his best.
2. **主句, while + 句子**（对比状语从句 · 两方对照，中文"而"）
    - A player is about to shoot the ball, **while** the goalkeeper is ready to defend.
3. **While + 句子, 主句**（伴随/对比状语从句 · 从句前置更书面）
    - **While** a player is about to shoot the ball, the goalkeeper is ready to defend.

> **易错点**：although / though 的主句**不能再接 but**。
> **技巧**：while 一词两用——表**对比**（两事对照）与表**伴随**（同时发生），两种情况都译"而"。

### （九）功能七：目的与手段（给对策）

**用途**：提出措施、说明做法、讲目的——**功能是回答"该怎么办"**，是论述文第三段的主力句式。

1. **主句 + so that + 句子**（目的状语从句 · 说明目的"以便"）
    - It is necessary to expand advertising in communities as well as schools **so that** we can bring people into realization of the importance of protecting the environment.
2. **in order to do sth.**（目的状语短语 · 说明目的，简洁版）
    - We should take measures **in order to** maintain ecological balance.
3. **It is necessary to do sth.**（形式主语 + 不定式 · 引出对策，替代 we should）
    - **It is necessary to expand advertising** in communities as well as schools.
4. **主句 + by doing sth.**（方式状语 · 手段"通过……"）
    - We can raise awareness **by expanding advertising**.

> **技巧**："以便 / 从而" → `so that`；目的从句的主语常换成 **we / people**，让句子从"我"扩展到"社会"。
> **注意**：so that 表**目的**时常带 can / could；表**结果**时（功能四）直接陈述事实。

### （十）功能八：修饰与限定（扩充句内信息）

**用途**：把短句挂到名词上，让一句承载两层信息——**功能是"不另外起句就能补充说明"**，是句式丰富的核心手段。

1. **名词 + who / that + 句子**（限制性定语从句 · 修饰"……的人"）
    - People **who live in a comfortable environment** cannot withstand difficulties in life.
2. **名词 + that / which + 句子**（限制性定语从句 · 修饰"……的物"）
    - the market share **that cars of national brands take**
3. **, which + 句子**（非限制性定语从句 · 补充说明，可指代整句）
    - ..., **which benefits all the humans**.
4. **介词 + which / whom**（介词前置定语从句 · 正式书面，介词提到关系词前）
    - The opportunity **for which we have been longing** has finally come.
5. **each of whom / each of which**（定语从句"各自"语义 · 谓语用单数）
    - two handicapped men, **each of whom has** only one leg
6. **whose + 名词**（定语从句所属 · "……的"，人/物所属）
    - the students **whose goals** are clear
7. **when / where / why / whereby + 句子**（关系副词定语从句 · 修饰时间 / 地点 / 原因 / 方式）
    - the reason **why** they succeed
8. **名词 + 介词短语 / 分词短语 / 不定式**（后置定语短语 · 短语级修饰，比定从简洁）
    - the task **hard to complete** / people **living in cities**
9. **名词 + 不定式（作定语）**（非谓语 · 后置，"要做的事"）
    - the reason **to** solve the problem；the opportunity **to** succeed
10. **名词 + 分词（作定语）**（非谓语 · 前置 / 后置均可；**主动 -ing，被动 -ed**）
    - There are many cultural elements / ingredients **being boiled in the hot pot**.（被煮的 → 现在分词的被动式 being done）
    - **Spoiled** children are more likely to lack independence.（前置，被动）

> **判据一句话**：名词与分词是**主动关系** → 现在分词（-ing）；是**被动关系** → 过去分词（-ed）；"正在被……" → being done。

> **何时升级为定从**：中文出现"……的"，且修饰部分**包含动作**（有自己的宾语、状语）——短语装不下时就用定从。
> **两个注意**：①引导词按"先行词 + 从句缺什么成分"选；②从句谓语的数由**先行词**决定。

### （十一）功能九：强调与倒装（句首亮句）

**用途**：突出关键信息、制造句首亮点——**功能是让阅卷人第一眼看到重点**。

1. **介词短语 / 分词短语 / 形容词短语 + 谓语 + 主语**（完全倒装 · 强调状语，主语后置）
    - **Emerging from the chart is** a noticeable phenomenon related to the change of population.
2. **It is + a. + (for/of) sb + to do sth.**（形式主语 + 不定式后置 · ① 强调评价 ② **长主语后置**平衡句子）
    - It is **not difficult (for us) to find that** students who have a positive mind usually get good scores in exams.
    - **It is shortsighted of** some people **to believe that** they can achieve success at the expense of rivals' failure.（表人品质的形容词用 of）
    - 形容词词库：a must / necessary / essential / important / imperative（必须的）/ suggested / advised / preferable / difficult / shortsighted
3. **It is + a. / v-ed + that + 句子**（形式主语 + 主语从句后置 · 强调建议、要求）
    - **It is necessary that we (should) take measures** to maintain ecological balance.
4. **It takes sb time to do sth.**（形式主语 · 强调耗时）
    - **It takes** young men much time **to surf** on the Internet.
5. **It is a must to do sth.**（形式主语 · "必须做某事"的高级表达）
    - **Considering the severity of the problem, it is a must to take effective measures** before the deterioration of the situation.

> **技巧**：倒装把最长的修饰语提到句首、主语后置——图表句、原因句都适合用，瞬间"去模板化"。
> **技巧**：形式主语句式两条用途——① **表达建议 / 要求**（应该、必须）② **平衡句子结构：长主语后置**（动名词主语一长就改写成 It is ... to do）。

### （十二）功能十：议论与疑问（提出议题）

**用途**：提出待探讨的问题、表达怀疑与深思——**功能是引出论证的靶子**，让文章有"思考感"。

1. **... consider / analyze whether + 句子**（宾语从句 · 提出"是否"的议题）
    - We should consider **whether** we can achieve it.
2. **... can't help wondering whether + 句子**（宾语从句 · 表达怀疑"不禁怀疑"）
    - we **can't help wondering whether** the father's behavior can help his children understand the true meaning of filial piety
3. **... put off what they should do now**（宾语从句 what · 提出应做之事）
    - They often **put off what they should do now**.

> **注意**：从句里表"是否"只用 **whether**（正式文体不用 if）；what 从句中 what 作成分（= the thing that）。
> **技巧**：whether 从句常与"图片疑问型"作文搭配——画面中有争议行为时用 can't help wondering whether 引出思考。

### （十三）功能十一：建议、呼吁与收尾升华

**用途**：第三段给出建议、发出呼吁、升华结尾——**功能是收束全文并提升立意**。

1. **It is necessary / essential / important / imperative that sb (should) do sth.**（形式主语 + 主语从句虚拟 · 提建议或要求）
    - **It is necessary that we (should) take measures** to maintain ecological balance.
2. **It is necessary for us to do sth.**（形式主语 + 不定式 · 提建议简洁版）
    - **It is necessary for us to rationally analyze** whether ...
3. **It is a must to do sth.**（形式主语 · "必须做某事"，语气最重）
    - **It is a must to take effective measures** before the deterioration of the situation.
4. **What is important in life is what we have done for others.**（主语从句 + 表语从句 · 哲理式升华）
    - **What** is important in life **is what** we have done for others.
5. **We can come to / draw the conclusion that ...**（同位语从句 · 归纳结论）
    - **We can come to the conclusion that** those who think ... are shortsighted.
6. **We should take measures to do sth.**（基本句型 · 呼吁行动）
    - We should **take measures to maintain** ecological balance.

> **考点**：necessary / essential / imperative / preferable / advisable 等"建议要求"类形容词后的 that 从句用 **(should) + 动词原形**，should 可省。
> **技巧**：结尾三件套——形式主语给建议 + 同位语从句下结论 + what 双从升哲理，任选其二即可，不堆砌。

### （十四）中文信号 → 句式速查

**用途**：写作时看到中文提示词，直接反查可用的句式。

1. **"……的" + 动作** → 定语从句（功能八：修饰限定）
    - People **who live in ...** cannot ...
2. **"这（有利于/阻碍）"** → 非限制性 which 指代整句（功能四：因果论证）
    - ..., **which** benefits all the humans.
3. **"长此以往，这将…"** → which in the long run will（功能四）
    - ..., **which in the long run will hinder** ...
4. **"……，其中最……"** → the + 最高级 + of which（功能四）
    - ..., the most important **of which** is ...
5. **"各自的 / 每者"** → each of whom / each of which（功能八）
    - two men, **each of whom has** ...
6. **"被……的"** → 过去分词作定语 / being done（功能八：修饰限定）
    - many elements **being boiled** in the hot pot；**Spoiled** children ...
7. **"我们可以看出"** → 宾从 → What...is that（功能一：开篇描述）
    - **What we can see from the table is that** ...
8. **"这幅画在说"** → reflect / indicate + 同位从（功能一）
    - the picture **reflects a problem that** ...
9. **"俗话说"** → As the saying goes（功能一）
    - **As the saying goes**, ...
10. **"研究发现"** → ①that 宾从 ②As... ③It has been found that（功能一）
    - **Researches have found that** ...
11. **"……的是……"** → what 主从 + what 表从（功能三：观点 / 功能十一：收尾）
    - **What** is important **is what** we have done.
12. **"我认为"** → argue/believe 宾从；From my perspective（功能三）
    - **From my perspective**, ...
13. **"因为这"** → because / 或转 , which will（功能四）
    - ..., **because** it will help us solve tough problems.
14. **"以至于 / 如此…"** → so + adj./adv. + that（功能四）
    - ... **so** much school work **that** they have no time to ...
15. **"使 / 促使 / 有利于"** → enable / lead to / result in / be beneficial to（功能四）
    - **lead** teenagers to make wrong choices
16. **"如果"** → if（主将从现）（功能五：条件假设）
    - **If we get** fully prepared, we can embrace the challenges.
17. **"而"（伴随/对比）** → while（功能六：让步对比）
    - ..., **while** the goalkeeper is ready to defend.
18. **"尽管 / 虽然"** → although / though（不接 but）（功能六）
    - **Although** the task is tough, ...
19. **"以便 / 从而"** → so that + 句子（功能七：目的手段）
    - ... **so that** we can bring people into realization of ...
20. **"我们应该…"** → 形式主语 + (should) 虚拟（功能十一：建议呼吁）
    - **It is necessary that we (should) take measures** ...
21. **"是否…"** → whether 宾从（功能十：议论疑问）
    - consider **whether** we can achieve it
22. **"花时间做"** → spend / It takes / take-cost-consume（功能九：强调 / 功能二：陈述）
    - **It takes** sb time **to do** ...
23. **"盼望已久的"** → 介词 + which 前置（功能八）
    - the opportunity **for which** we have been longing
24. **"存在 / 出现"** → there be / come into being（功能二：陈述事实）
    - **There is** nothing difficult ...
25. **"做某事是 / 意味着…"** → 动名词 / 不定式作主语（功能二：陈述事实）
    - **Ensuring the continuous prosperity** of Chinese traditional drama **means making** great contribution to ...
26. **"一边……一边…"** → 现在分词表伴随；不同主体用独立主格（功能二）
    - ..., **sweating but smiling**. / ..., **(with) much rubbish thrown into the lake**.
27. **"考虑到…"** → Considering / Given sth.（功能四：因果论证）
    - **Considering the severity of the problem**, it is a must to take effective measures ...
28. **"必须做…"** → It is a must to do sth.（功能九：强调 / 功能十一：建议）
    - **It is a must to take effective measures** before the deterioration of the situation.

### （十五）附：按句法归属反查

**用途**：从语法侧查——某类从句在哪些功能里能派上用场。

1. **5 种基本句型** → 可承担：陈述事实、建议呼吁
    - 形式：S+V / S+V+O / S+V+O+O / S+V+O+C / S+系+P
2. **定语从句** → 可承担：修饰限定、开篇描述（As）、因果论证（, which）
    - 引导词：who / that / which / whose / when / where / why / whereby / 介词+which
3. **主语从句** → 可承担：开篇描述（What...is that）、观点哲理、建议（形式主语）
    - 引导词：what / that / whether / how + adj.
4. **宾语从句** → 可承担：开篇描述、表达观点、议论疑问
    - 引导词：that / whether / what / how
5. **表语从句** → 可承担：开篇描述（What...is that）、哲理句
    - 引导词：that / what
6. **同位语从句** → 可承担：陈述事实、开篇描述、收尾结论
    - 形式：that（后接完整句）
7. **状语从句** → 可承担：因果论证（because）、条件假设（if）、让步对比（although/while）、目的（so that）、时间（when）
    - 功能四～七各清单
8. **形式主语 it** → 可承担：强调、建议、客观化描述、**长主语后置**
    - 形式：It is + a. + (for/of) sb + to do / It is + a./v-ed + that + 句子
9. **完全倒装** → 可承担：强调、句首亮点
    - 形式：介词/分词/形容词短语 + 谓语 + 主语
10. **非谓语动词** → 可承担：陈述事实（动名词作主语）、修饰限定（不定式/分词作定语）、因果论证与伴随（分词作状语）
    - 形式：动名词 v-ing（名词性）/ 不定式 to+v.（名形副）/ 分词 v-ing·v-ed（形副；主动 -ing、被动 -ed；独立主格 (with)+n.+分词）

### （十六）句式使用三原则

1. **保底优先**：基本句型写对再谈亮点——谓语完整、主谓一致是所有从句句式的前提。
2. **一句一亮点**：定从、what 双从、形式主语分散到不同句子，功能错开使用，不堆砌。
3. **功能先行**：先定这句话的功能（开篇/论证/建议/收尾），再选句式；语义决定句式，不是中文逐字翻译。
