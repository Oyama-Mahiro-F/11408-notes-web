<h2 align="center">论述型作文·写作句式汇总</h2>

> **本文定位**：汇总《用词训练》《亮点句式——定语从句》《亮点句式——名词性从句》《亮点句式——状语从句》四篇笔记中的**句式**内容，按"选句式 → 用句式"的写作动线整理成速查手册。词汇升级见《用词训练》，例题详解见三篇亮点句式笔记。

### （一）句式选择总纲

#### 一、两大要求

写作句式两要求：**语法正确**（基本句型 + 成分形式）是保底；**句式结构丰富**是得分点。丰富的手段不是堆长句，而是：同一个成分用**词 → 短语 → 从句**三级形式轮换升级（句式升级的本质），并按语义逻辑选用不同句式工具。

#### 二、语义逻辑 → 句式工具对照（总 lookup 表）

| 语义逻辑 | 首选句式工具 | 一句话示例 |
|:---|:---|:---|
| 陈述事实 | 5 种基本句型 | People cannot withstand hardship. |
| 表达观点 | 名词性从句（宾从/主从） | We can see that ... / What ... is that ... |
| 提出问题 | 名词性从句（whether 宾从） | We should consider whether ... |
| 逻辑推导 | 状语从句（引导词 + 句子） | When we set a goal, we should ... |
| 修饰润色 | 后置定语 / 定语从句 | People who live in ... cannot ... |
| 客观存在 | there be 句式 | There is nothing difficult in the world. |
| 突出强调 | 倒装 / 强调句 | Emerging from the chart is a noticeable phenomenon ... |

> **记忆**：先想"这句话在干什么"（陈述/观点/修饰/强调），再套对应句式——语义决定句式，不是中文逐字翻译。

### （二）基本句型与句子成分（保底层)

**5 种基本句型**：

| 句型 | 结构 | 谓语动词 |
|:---|:---|:---|
| 主谓 | S + V | vi. |
| 主谓宾 | S + V + O | vt. |
| 主谓双宾 | S + V + O(人) + O(物) | vt. |
| 主谓宾宾补 | S + V + O + C | vt. |
| 主系表 | S + 系 + P | be / 半系动词 |

**主干成分**：主语（动作发出者，n.）、谓语（v.）、宾语（承受者，n.）、表语（主语性质/状态，n./adj.）、补语（补充宾语性质，n./adj.）。

**修饰语成分**：定语（修饰名词，adj.）、状语（修饰 adj./v./adv.，adv.）、同位语（解释名词，n.）。

> **保底规则**：谓语必须完整——v-ed 单独不作谓语，被动必须 be + v-ed；主语三单动词加 -s；more 不与 -er 共存。

**倒装句式**（强调工具之一）：介词短语/分词短语/形容词短语 + 谓语 + 主语（完全倒装）。

- Emerging from the chart **is** a noticeable phenomenon **related to** the change of population.（分词短语提前，真正主语在后）

**there be 句式**（客观存在）：There is nothing difficult in the world. = Nothing in the world is difficult.

### （三）亮点句式一：定语从句

#### 一、何时用（两个信号）

1. 中文出现"**……的**"修饰结构
2. 修饰语中**包含动作**（有自己的宾语/状语，短语装不下）——"生活在舒适环境中**的**人们" → People **who live in a comfortable environment**

#### 二、引导词清单

| 先行词 | 引导词 |
|:---|:---|
| sb. | who / that |
| sth. | that / which |
| sb./sth.（所属） | whose |
| 前面整个句子 | , which（非限制性） |
| 时间 / 地点 | when / where |
| reason(s) / 方式 | why / whereby |
| 介词 + which / whom | 正式书面（介词前置） |

> **两个注意**：从句谓语与**先行词**保持一致；"各自"语义用 **each of whom / each of which**（谓语随 each 用单数）。

#### 三、五个升级套路

| 套路 | 普通版 → 亮点版 | 例句 |
|:---|:---|:---|
| "其中最…" | and the most important one is... → **the most important of which** is... | Independence brings many advantages, the most important of which is self-determination. |
| 整句指代 | 另起一句 This... → **, which...** | ..., which benefits all the humans.（"这"= 前面整句） |
| 隐含因果 | because 明示 → **, which can make...** 隐含 | Harmonious neighborhood relation is of necessity, which can make people's living environment more peaceful. |
| 长效推论 | 长此以往这将… → **, which in the long run will...** | ..., which in the long run will hinder the rapid economic development of our country. |
| 介词前置 | which we have been longing for → **for which** we have been longing | The opportunity for which we have been longing has finally come. |

> **加分表语**：is necessary → **is of necessity**（介词短语表性质，主系表的高级形式）。

### （四）亮点句式二：名词性从句

#### 一、四分类与使用场景

| 从句 | 充当成分 | 触发场景 |
|:---|:---|:---|
| 主语从句 | 大句主语 | "……的是……"、形式主语 |
| 宾语从句 | vt./介词后 | "看出/认为/考虑/怀疑 + 内容" |
| 表语从句 | be/半系动词后 | "问题是/重要的是……" |
| 同位语从句 | 解释名词 | conclusion / problem / phenomenon / news + that + 完整句 |

#### 二、引导词四种结构

| 结构 | 说明 |
|:---|:---|
| **that / whether + 完整句** | that 无实义；whether 表"是否"（正式文体不用 if） |
| **what / which / who + 非完整句** | 连接代词作成分；**what = the thing that** |
| **when / where / why / how + 完整句** | 连接副词作状语 |
| **how + adj./adv. + 主谓** | "多么好/坏/大/重要" |

> **三条硬规则**：①主语从句引导词**不可省**；②特殊疑问词引导从句用**陈述语序**；③主语从句作主语，谓语用**单数**（What we lack **is** ...）。

#### 三、what 双从框架（两个模板）

**模板 1——图表/认知句**（主语从句 + 表语从句）：

- **What we can see from the table is that** the market share of cars of national brands has increased dramatically.
- 普通版对照：From the table, we can see that ...（宾从版；what 版句首即亮点）
- 可再嵌定从：the market share **that cars of national brands take** has increased dramatically.

**模板 2——哲理句**（主语从句 + 表语从句）：

- **What is important in life is what we have done for others**.（"……的是……"固定框架）
- 升级词：be important = **count** (vi.)——Every minute counts.

#### 四、形式主语句式（建议、要求类专用）

**两套模板**：

1. **It is + a. + (for/of) sb to do sth.** —— It is necessary **for us** to rationally analyze whether ...
2. **It is + a. + that sb (should) do sth.** —— It is necessary/essential **that we (should) take measures** to maintain ecological balance.

**三个要点**：

- 品质形容词（kind / wise / shortsighted / careless...）配 **of sb**，一般形容词配 **for sb**：it is shortsighted **of** some people to believe that ...
- "建议要求"类形容词（necessary / essential / preferable / advisable）后的 that 从句用 **(should) + 动词原形**，should 可省
- 可多层嵌套：We can come to the conclusion that **it** is shortsighted of some people to believe that they can achieve success at the expense of rivals' failure.（同位从 + 形式主语 + 宾从，一句三层）

### （五）亮点句式三：状语从句

**构成**：引导词 + 句子；句法功能是修饰**动作或整个句子**。写法不变式：**先判句内语义逻辑，再据逻辑选引导词**。

**六大写作状语类型**：

| 类型 | 引导词 | 要点 |
|:---|:---|:---|
| 时间 | when / while / since（自从）/ as（随着）/ before / after | 注意主从句时态 |
| 条件 | if | 主将从现 |
| 原因 | because | —— |
| 结果 / 目的 | so that | 表目的"以便"；表结果"以至于" |
| 让步 | although / though | 主句不再用 but |
| 对比 | while | 中文"而" |

**升级套路**：

| 套路 | 普通版 → 亮点版 | 例句 |
|:---|:---|:---|
| "而"（伴随/对比） | and 另起 → **while** | A player is about to shoot the ball, **while** the goalkeeper is ready to defend. |
| 因果三写 | 只会 because → **so that / so...that** 轮换 | Most children are having **so** much school work **that** they have no time to participate in social activities. |
| 多层叠加 | 单层因果 → **because + while + so...that** | The player sees the task tough **because** ..., **while** the goalkeeper feels himself **so** smaller **that** ... |
| 目的 | to do → **so that + 句子** | It is necessary to expand advertising ... **so that** we can bring people into realization of ... |
| 条件 | —— | **If we get** fully prepared（主将从现）, we can embrace the future challenges. |

> **注意**：`so that` 表目的时从句常带 can/could；表结果时直接陈述既成事实。

### （六）功能句式速查（按写作功能分组）

**① 引谚语/俗语**：**As the saying goes**, nothing in the world is difficult for one who sets his mind to do it.

**② 描述图表**（"从……可以看出"）：

- From the table/chart, we can see that ...
- = **What we can see from the table is that** ...（亮点版）

**③ 描述图画**（"这幅画在说……"）：

- **Obviously, the picture reflects / indicates a problem that** ...（"说"不用 say → reflect/indicate）
- = **It is obvious that** the picture reflects a problem that ...
- = **As the picture indicates**, ...（as 指代整句放句首；which 从句放句尾）

**④ 表建议/要求**（"我们应该……"）：

- It is necessary/essential/preferable that we (should) take measures to maintain ecological balance.
- It is necessary (for us) to consider whether we can achieve it.
- When we set a goal, we should consider whether we can achieve it.（宾从基础版）

**⑤ 花时间/花费**（"某人花多少时间做某事"）：

- 人作主语：Young men **spend** much time **(in) surfing** on the Internet.
- 事作主语：Surfing on the Internet **takes / costs / wastes / consumes** young men much time.
- 形式主语：**It takes** young men much time **to surf** on the Internet.

**⑥ 表使役/推动**（"使/促使/有利于"）：

- 促使/使能够：**enable / encourage / empower / allow** sb to do sth
- 导致：**lead / cause** sb to do sth；**result in** sb doing sth
- 迫使：**force** sb to do sth
- 有利于/促进：**do good to / be beneficial to / play a positive role in / drive ... forward / promote / fuel / boost**

**⑦ 表因果结果的从句三写**（"因为/以至于"）：

- 原因状从：**Because** most children are having too much school work, they have no time to ...
- 结果状从：... **so that** they have no time to ...
- 结果强化：... **so** much school work **that** they have no time to ...

**⑧ 表目的 / 条件 / 对比**（"以便/如果/而"）：

- 目的：It is necessary to expand advertising ... **so that** we can ... / **in order to** do sth.
- 条件：**If we get** fully prepared（主将从现）, we can embrace the future challenges.
- 对比/伴随：A player is about to shoot the ball, **while** the goalkeeper is ready to defend.

**⑨ 表观点**（"我认为"）：

- Sb **argue / maintain / insist / believe** that ...
- **From my perspective**, ... / **As far as ... is concerned**, ...

**⑩ 表怀疑/是否**：we **can't help wondering whether** ... / we should **analyze whether** ...（从句表"是否"只用 whether）

### （七）总结：中文信号 → 句式速查表

| 中文信号 | 句式 | 例句 |
|:---|:---|:---|
| "……的"+动作 | 定语从句 | People **who live in ...** cannot ... |
| "这（有利于/阻碍）" | 非限制性 which 指代整句 | ..., **which** benefits all the humans. |
| "长此以往，这将…" | which in the long run will | ..., **which in the long run will hinder** ... |
| "……，其中最……" | the + 最高级 + of which | ..., the most important **of which** is ... |
| "各自的/每者" | each of whom / each of which | two men, **each of whom has** ... |
| "我们可以看出" | 宾从 → What...is that | **What we can see from the table is that** ... |
| "这幅画在说" | reflect/indicate + 同位从 | the picture **reflects a problem that** ... |
| "……的是……" | what 主从 + what 表从 | **What** is important **is what** we have done. |
| "我们应该…" | 形式主语 + (should) 虚拟 | **It is necessary that we (should) take measures** ... |
| "是否…" | whether 宾从 | consider **whether** we can achieve it |
| "俗话说" | As the saying goes | **As the saying goes**, ... |
| "花时间做" | spend / It takes / take-cost-consume | **It takes** sb time **to do** ... |
| "使某人能做" | enable/empower/allow sb to do | **enable** sb to do sth |
| "对…有好处" | be beneficial to / promote / fuel / boost | **play a positive role in** ... |
| "盼望已久的" | 介词 + which 前置 | the opportunity **for which** we have been longing |
| "存在/出现" | there be / come into being | **There is** nothing difficult ... |
| "而"（伴随/对比） | while | ..., **while** the goalkeeper is ready to defend. |
| "因为这" | because / 或转 , which will | ..., **because** it will help us solve tough problems. |
| "以至于/如此…" | so + adj./adv. + that | ... **so** much school work **that** they have no time to ... |
| "以便/从而" | so that + 句子 | ... **so that** we can bring people into realization of ... |
| "如果" | if（主将从现） | **If we get** fully prepared, we can embrace the challenges. |
| "尽管/虽然" | although / though（不接 but） | **Although** the task is tough, ... |
| "研究发现" | ①that 宾从 ②As... ③It has been found that | **Researches have found that** ... / **As researches have found**, ... |

**句式使用三原则**：

1. **保底优先**——基本句型写对再谈亮点；谓语完整、主谓一致是从句句式的前提
2. **一句一亮点**——定从、what 双从、形式主语分散到不同句子，不堆砌
3. **语义先行**——先定这句话的语义逻辑（陈述/观点/修饰/强调），再选句式工具
