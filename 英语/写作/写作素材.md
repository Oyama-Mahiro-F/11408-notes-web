### （一）怎么用这份文件

#### 一、三条读法

1. **写作时（主线）**：先判主题——题干落在文化教育 / 经济生活 / 环境保护哪一类，翻到对应主题节，按「主题词汇 → 论述角度 → 建议措施」三步取材组段。
2. **中文已想好、英文卡壳（反查）**：翻到（九）**按论述功能反查**——想知道"表归因、表意义、表建议"分别有哪些表达，从那里找。
3. **只要句式不要主题**：直接走（六）跨主题通用论述句式，或翻 `写作句式.md`（按功能分类的完整句式库）。

#### 二、主题总览

### （二）素材通用框架

#### 一、素材的两大落点

1. **宏观社会**：经济、科技、环境资源、文化、道德伦理
2. **微观个人**：知识、能力、品质、人际关系、健康、思想、生活——落到**工作 / 学习 / 生活**三个场景

#### 二、从组词到造句

**组词**（同一中文义备多个英文表达，写作时轮换）→ **造句**（注意内容逻辑与句式）。

例：**经济繁荣**

- 组词：economic **boom / prosperity / thriving**
- 造句：我们国家经济正在经历持续的繁荣。
    - Now our national economy **is witnessing / enjoying continuous prosperity**.

#### 三、三种论述角度（按话题性质选）

| <nobr>话题性质</nobr> | <nobr>论述角度</nobr> | 适用主题 | <nobr>段落骨架</nobr> |
| :--- | :--- | :--- | :--- |
| <nobr>正面（好事物）</nobr> | 意义价值分析 | 文化教育 | 事物属性 → 宏观意义 → 微观意义 |
| <nobr>中性趋势</nobr> | 影响分析 | 经济生活 | 趋势判断 → 影响 → 落到个人生活 |
| <nobr>负面问题</nobr> | 问题归因 | 环境保护 | 现象罗列 → 内因 / 外因 → 建议 |

**建议措施是所有话题的收尾段**——不论用哪种角度，末段都要落到"应该怎么做"（见（七）建议措施总库）。

### （三）主题一：文化教育

#### 一、主题词汇

**（1）文化类**

| 中文 | 英文 |
| :--- | :--- |
| <nobr>文化传播</nobr> | cultural **transmission / promotion** |
| <nobr>文化融合</nobr> | cultural **integration** |
| <nobr>文化交流</nobr> | cultural **exchange** |
| <nobr>文化多元化</nobr> | cultural **diversity** |
| <nobr>文化传承</nobr> | cultural **inheriting** |
| <nobr>文化遗产</nobr> | **cultural heritage** |

**（2）教育类**

| 中文 | 英文 |
| :--- | :--- |
| <nobr>家庭教育</nobr> | family education |
| <nobr>学校教育</nobr> | school education / schooling |
| <nobr>高等教育</nobr> | high education |
| <nobr>职业教育</nobr> | vocational education |
| <nobr>素质教育</nobr> | quality-oriented education |
| <nobr>远程教育</nobr> | tele-education |

#### 二、论述角度：意义价值分析（文化类）

**（1）事物本身属性（"文化是……"四句）**

1. **文化是人类文明的结晶。**
    - Culture is the **crystallization** of human civilization.
2. **中国文化是世界文化的重要部分。**
    - Chinese culture is an **essential part** of the world culture.
3. **世界和民族文化遗产是人类共同的财富。**
    - The world and national cultural heritage is the **common / shared wealth or treasure** of humans.
4. **中国历史悠久，文化灿烂。**
    - Chinese history is **time-honored** and its culture **(is) brilliant**.

**（2）宏微观意义（含高频句式）**

1. **文化多样性对国家的发展和繁荣至关重要。**
    - 句式：**… be vital to …**（对……至关重要）
    - Cultural diversity **is vital to** a country's development and prosperity.
    - Multi-cultures **are extremely vital in ensuring** a community's future development and prosperity.
2. **文化交流有利于社会和谐。**
    - 句式：**… be beneficial to … // do good to**（有利于）
    - Cultural exchange or communication **is beneficial to social harmony**.
3. **通过文化交流，世界不同的人们可以体验丰富的文化生活。**
    - 句式：**Through / By + 名词, 主句**（通过……）
    - **Through cultural communication**, people from different countries of the world can enjoy a rich cultural life.
4. **我们交流越多，文化越有活力。**
    - 句式：**The + 比较级, the + 比较级**（越……越……）
    - **The more** we communicate, **the more vigorous** the culture is.

#### 三、论述角度：教育的目的（教育类）

**总纲**：教育培养"人"——**知识、品德、技能 / 能力**三方面，最终**满足个人需求与社会需求**。

**（1）三方面的词库**

1. **知识**：universal / practical / professional knowledge
    - 学习知识 **acquire knowledge**
2. **品德**：moral / qualities（诚实、守信、责任感、乐于助人、勤奋、独立、积极向上、乐观、自信、坚持不放弃、毅力……）
    - 形容词链：**be honest / reliable = trustworthy / responsible / helpful / diligent = hardworking / independent / aggressive / optimistic / confident / perseverant / resilient …**
3. **技能 / 能力**（沟通、合作、解决问题、管理时间、规划、设定目标……）
    - **the ability to** communicate / collaborate / solve problems / manage time / make plans / set goals …
    - 培养：**develop / cultivate / foster**

**（2）满足需求**

1. **满足某人的需求**：**meet one's need**；**satisfy**
2. **适应社会发展**：**adapt to social development**

**（3）个人层面（六条）**

1. **自我提升** improve oneself
2. **获得机会** have an access to opportunities
3. **实现目标** reach one's goal
4. **取得成功** achieve success
5. **拥有好的工作 / 生活** enjoy satisfying jobs and life
6. **自我价值实现** fulfill oneself

**（4）社会层面（四条）**

1. **富强** powerful and rich
2. **文明** civilized
3. **和谐** harmonious
4. **可持续发展** sustainable

#### 四、建议措施

**（1）文化：态度三条**

1. **欢迎文化交流**：to **embrace** cultural exchange（take in）
2. **对待他国文化：取其精华，去其糟粕**：to **absorb the essence and discard the gross** of alien cultures
3. **认同民族文化**：to **identify with** national culture

**（2）文化：行动两条**

1. **积极参加文化交流活动**：to **participate in activities related to cultural exchange in a positive way**
2. **积极弘扬民族文化**：to **actively promote national culture**
    - 例（用外语讲好中国故事）：to **tell good stories of China** or **introduce China and Chinese people in foreign languages**

**（3）教育：外部环境**

1. **良好的家庭环境** favorable / pleasant family environment
    - 例：父母为孩子树立好榜样。**Parents set a good model for children.**
2. **健康的学校与社会氛围** healthy school and social atmosphere / climate
    - 例：提供帮助与支持。**provide help and support**

**（4）教育：个人**

1. **追求终生学习** pursue life-long learning
    - Learning is not only our daily experience but also our lifetime mission.
2. **持续努力** make constant effort
3. **不断奋斗** keep striving

#### 二、论述角度：经济对生活的影响

**（1）总起句式：如何表达"影响"**

1. **have a/an … effect / influence / impact on people's life**（对人们的生活有……影响）
    - 正向形容词：**positive**; **significant**; **great**; **dramatic**
    - 负向形容词：**negative**
2. **影响 → 促进 / 提升**：**promote / improve / boost**（由"影响"落到"变好"）
3. **people 的替换词**（轮换使用，避免全篇 people）
    - **residents**（居民）; **citizens**（公民）; **customers**（顾客）; **consumers**（消费者）

**（2）落点一：就业与收入**

| <nobr>雇主</nobr> | **employer** |
| <nobr>雇员</nobr> | **employee / worker / staff** |
| <nobr>工作满意度</nobr> | **satisfaction level of work** |
| <nobr>收入增加</nobr> | **the increase of incomes** |
| <nobr>薪酬</nobr> | **salary / compensation** |
| <nobr>高薪</nobr> | **high salary** |
| <nobr>薪酬制度</nobr> | **compensation scheme** |

**（4）落点三：消费**

| 中文 | 英文 |
| :--- | :--- |

| <nobr>出行</nobr> | **transportation** |

> **落点顺序**：就业 → 收入 → 生活水平 → 消费 → 旅游 / 出行 / 休闲……（由"工作"到"生活"逐层展开，可任取两三个落点组段）。

**（5）例题：经济对生活的影响**

> **中文原句**：随着我国经济不断增长，居民收入增加，进而生活水平极大地提高。此外，消费者的购买力增强，因此，在消费中更注重舒适、享受和独特的体验。

- **第一层「随着」两式**：
    1. **As** our national economy **grows continuously**,
    2. **With** the continuous economic growth in our country,
- **主干「收入增加 → 生活水平提高」**：
    - the incomes of residents **have greatly increased**, **thus leading to** dramatic rise of living level.
    - 句式：**thus / thereby + doing**（进而……）
- **第二层「此外」**：
    - **Besides**, consumers now have **increased purchasing power**,
- **第三层「因此」两式**：
    1. **Therefore**, when they shop or spend money, they pay more attention to comfort, enjoyment and unique experiences.
    2. …**as a result of which** when they shop or spend money, they pay more attention to comfort, enjoyment and unique experiences.

> **要点**：同段三处因果若全用 therefore / so 会单调，宜 **Therefore、thus、as a result of which** 交替。

1. **政策支持**

    - **favorable / privileged policies**（优惠政策）
2. **科技创新**
    - **technological innovation**
    - **Science and technology constitute a primary productive force.**（科学技术是第一生产力）
3. **人才培养**
    - **talent training**

### （五）主题三：环境保护

#### 一、考查方向

环境污染（大气 / 水）、气候变化、环境保护（垃圾分类）、资源节约（自然资源、水、海洋资源）、新能源（电车）、生物多样性。

#### 二、主题词汇：环境问题

| 中文 | 英文 |
| :--- | :--- |
| <nobr>环境污染</nobr> | **environmental pollution** |
| <nobr>沙漠化</nobr> | **desertification** |
| <nobr>资源短缺</nobr> | **the shortage of resources** |
| <nobr>粮食短缺</nobr> | **food shortage** |
| <nobr>能源紧缺</nobr> | **energy pinch** |
| <nobr>全球变暖</nobr> | **global warming** |
| <nobr>生物灭绝</nobr> | **the extinction of species** |

> 以上可统称 **crisis**（危机）——environmental crisis、energy crisis。

#### 三、论述角度：问题归因（内因 / 外因）

**（1）内因：意识与行为**

| 中文 | 英文 |
| :--- | :--- |
| <nobr>意识缺失</nobr> | **the lack** of awareness |
| <nobr>意识不足</nobr> | **insufficient** consciousness |
| <nobr>不负责任</nobr> | **irresponsibility** |
| <nobr>不道德</nobr> | **immorality** |
| <nobr>随意排放大量污染气体或废水</nobr> | **casual emission** of a large amount of polluted gases or water（carbon dioxide 二氧化碳） |

> 板书补充：**throw rubbish casually**（随手扔垃圾）——"casual"（随意的）是本组核心副词。

**（2）外因：制度与管理**

| 中文 | 英文 |
| :--- | :--- |
| <nobr>宣传 / 教育不足</nobr> | **insufficient** advertising / promotion / education |
| <nobr>缺乏适当的监督与监管</nobr> | **the lack** of proper supervision / regulation |
| <nobr>管理与执行不力</nobr> | **incompetent** management / implementation |
| <nobr>相关法律法规缺失</nobr> | **the absence** of related laws or rules |

**（3）归因例题**

> **例 1**：资源短缺的一个原因是人们对节约资源的意识不足。

- The shortage of resources **can be partly attributed to** the **insufficient awareness of conservation of resources** among the public.
- 句式：**A can be partly attributed to B**（A 可以部分归因于 B）——结果作主语，**partly** 使论断不过绝对。

> **例 2**：工业产生大量的二氧化碳和热，造成全球变暖。

1. 原因作主语（**cause / lead to** 路线）：
    - **A great deal of** carbon dioxide and heat **produced / emitted by** factories / plants **leads to** global warming.
2. 结果作主语（**be because of** 路线）：
    - Global warming **is mainly because of** a great deal of carbon dioxide and heat produced by factories or plants.

- **要点**：同一因果关系主客可颠倒，按前后句衔接挑一种；长主语 "A great deal of + 不可数名词" 谓语用单数 **leads**；**produced / emitted by** 是分词短语作后置定语（表被动，比定语从句简洁）。

#### 四、建议措施

**（1）企业 / 社会（六条）**

1. **减少污染与碳排放**：**reduce** pollution / carbon emission
2. **利用新能源**：**make more use of renewable energy**
    - **solar / wind energy**（太阳能 / 风能）
    - **battery-powered electric vehicles**（电动车，板书 **EV**）
3. **增加 / 扩大宣传引导**：**increase / expand** advertising / propagandas
4. **加强监管**：**strengthen / enhance** supervision and management
5. **完善法律制度**：**improve / perfect** laws and regulations
6. **政策支持**：**provide policy support**
    - We need **progressive policies that shape collective action**, alongside **engaged citizens pushing for change**.

**（2）个人：意识与责任感**

1. **raise the awareness of** sth.（提高对……的意识）
2. **be more conscious of** sth.（对……更有意识）
3. **assume the responsibility as a citizen**（承担作为公民的责任）

**（3）个人：日常行动（六条）**

| 中文 | 英文 |
| :--- | :--- |
| <nobr>垃圾分类</nobr> | **trash sorting / garbage classification** |
| <nobr>循环利用</nobr> | use **recyclable and environment-friendly products** like shopping bags or **straw**（吸管） |
| <nobr>搭乘公共交通</nobr> | take **public transports** |
| <nobr>节约资源</nobr> | **save resources** such as water and electricity |
| <nobr>减少消费</nobr> | **reduce / restrain consumption** |
| <nobr>可持续消费</nobr> | **shop sustainably** |

> 板书补充：**fast fashion**（快时尚）——"减少消费"最好用的具体靶子。

### （六）跨主题通用论述句式（按功能）

> 以下句式**三个主题通用**；更完整的句式库（定语从句、名词性从句、状语从句、非谓语、倒装、强调句等）见 `写作句式.md`。

1. **表"是什么"（属性判断）**——A is the crystallization of … / A is an essential part of … / A is the common wealth of …
2. **表"重要、有利于"（意义评价）**——**… be vital to …**（对……至关重要）／**… be beneficial to … // do good to**（有利于）
3. **表"影响"**——**have a/an effect / influence / impact on …**（正向 positive·significant·great·dramatic ／ 负向 negative）
4. **表"促进、提升"**——**promote / improve / boost / enhance**
5. **表"原因"（后接原因）**——**be due to / result from / be attributed to / be mainly because of**
6. **表"结果"（后接结果）**——**cause / lead to / result in / thus + doing / as a result of which + 从句**
7. **表"通过……（手段）"**——**Through / By + 名词, 主句**
8. **表"越……越……"**——**The + 比较级, the + 比较级**
9. **表"举例、包括"**——**such as / like / including**（用于把主题词汇挂到论点上）
10. **表"建议、呼吁"**——**It is necessary that we (should) … ／ We need … ／ Only in this way can we …**

### （七）建议措施总库（按主体）

**1. 国家 / 政府**

1. **国家政策的支持** the support from national policies
2. **优惠政策** favorable / privileged policies
3. **政策支持** provide policy support

### （十）素材使用三原则

1. **同一中文义轮换用词**——"经济繁荣"备 boom / prosperity / thriving，一篇之内不重复同一个词。
2. **角度要齐、不单打一**——正面话题给"属性 + 宏观意义 + 微观意义"，负面话题给"内因 + 外因"；只写一个角度会显得单薄。
3. **素材与句式分头取材**——内容（主题词汇、论述角度）看本文，句法（从句、非谓语、倒装、强调）看 `写作句式.md`；两者配合才能既**有话说**又**说得好**。
