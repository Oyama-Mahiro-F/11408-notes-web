## 添加笔记

1. 用 Typora 导出 HTML 到 `考研/` 对应目录
2. 运行 `python push.py`（或双击 `push.bat`）

脚本会自动：
- 复制 HTML 到 `site/`
- 生成顶部导航栏、左侧目录树、右侧页内目录
- 提交并推送到 GitHub
- GitHub Pages 自动部署

## 导航

每个页面包含三栏布局：

- **顶部**：首页 | 408 | 数学 | 英语 | 政治 标签
- **左侧**：完整目录树（自动扫描 HTML 文件生成，▼ 点击折叠）
- **右侧**：当前页面标题目录（自动提取 h3/h4，默认折叠，点击展开）

## 搜索

- 全站客户端搜索，支持中文 bigram 分词
- 支持单个中文字符搜索
- 索引在首次输入搜索时按需加载，并缓存到 `sessionStorage`
- 结果按标题/正文相关度排序，显示关键词高亮和上下文摘要
- 搜索入口：
  - 首页搜索框
  - 顶部导航栏搜索框
  - `Ctrl+K` 快速聚焦导航搜索框
  - 独立搜索结果页 `search-results.html`
- 搜索索引由 `add_nav.py` 自动生成到 `search/{科目}.json`，推送时自动更新
