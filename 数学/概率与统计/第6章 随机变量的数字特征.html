第六章 随机变量的数字特征

（一）随机变量的数学期望

数学期望是概率论中最核心的数字特征。它不仅是直观上的“加权平均”或概率分布的“重心”，在面对具有一定深度的综合性题目时，它往往是解开复杂分布或极限定理的“钥匙”。

下面我们从严格的定义、极其重要的定理（LOTUS）以及实战性质三个维度来彻底梳理它，帮你避开理论推导和计算中的常见陷阱。

1. 严格定义与“绝对收敛”陷阱

计算数学期望并不只是套用公式，在严谨的数学分析中，期望存在是有严格前提条件的。

  • 离散型：

    设随机变量 X 的分布律为 P(X=xi)=pi，则：

    E(X)=∑ixipi

    关键陷阱： 必须满足级数绝对收敛，即 ∑i|xi|pi<∞。如果该级数仅条件收敛或发散，则认为该随机变量的数学期望不存在。

  • 连续型：

    设连续型随机变量 X 的概率密度为 f(x)，则：

    E(X)=∫−∞+∞xf(x)dx

    关键陷阱： 广义积分必须绝对收敛，即 ∫−∞+∞|x|f(x)dx<∞。最经典的例子是标准柯西分布，其密度函数关于 y 轴对称，但由于积分不绝对收敛，它的数学期望是不存在的（不能直接由对称性得出期望为 0）。

2. 随机变量函数的数学期望（LOTUS）

无意识统计学家法则 (Law of the Unconscious Statistician, LOTUS) 是计算大题中出现频率极高的核心工具。它的最大价值在于：求 Y=g(X) 的期望时，不需要费力先求出 Y 的分布律或密度函数，直接用 X 的分布即可计算。

  • 一维情况：

    若 X 为连续型，密度为 f(x)，则对于连续函数 g(X)：

    E(g(X))=∫−∞+∞g(x)f(x)dx

  • 二维情况（常结合二重积分考查）：

    若 (X,Y) 的联合概率密度为 f(x,y)，对于函数 g(X,Y)：

    E(g(X,Y))=∫−∞+∞∫−∞+∞g(x,y)f(x,y)dxdy

    实战提示： 当遇到求 E(X+Y)、E(XY) 甚至 E(max(X,Y)) 或 E(min(X,Y)) 时，如果无法直接利用性质拆分，直接套用此二重积分公式，配合图形划分积分区域，是万能的通用解法。

3. 核心运算性质与实战技巧

熟练掌握运算性质可以大幅跳过繁琐的积分或求和步骤，是提高解题速度的关键。

  • 绝对的线性性（最常用）：

    E(aX+bY+c)=aE(X)+bE(Y)+c

    注意： 这条性质不需要 X 和 Y 相互独立！无论两者关系多么复杂，期望的线性可加性永远成立。利用这一点，复杂的随机变量（如二项分布）往往可以拆解为多个简单的指示变量之和来求期望。

  • 独立的乘积性：

    如果 X 与 Y 相互独立，则：

    E(XY)=E(X)E(Y)

    逆否命题与易错点： 如果 E(XY)≠E(X)E(Y)，则 X 与 Y 必定不独立。但这只是判断“不相关”的条件；如果 E(XY)=E(X)E(Y)，只能说明它们不相关，绝对不能反推它们独立（除非已知它们服从二维正态分布）。

  • 全期望公式（进阶框架）：

    在处理多阶段随机过程或复杂的联合分布时，条件期望的期望等于无条件期望：

    E(X)=E[E(X|Y)]

    这是降维拆解复杂概率模型的一大利器，通过先固定变量 Y 的取值，能把复杂问题转化为简单问题的叠加。

（二）随机变量的方差

方差 (Variance) 是概率论与数理统计中极为核心的数字特征。

如果说“数学期望（均值）”刻画了随机变量取值的“重心”或“平均位置”，那么“方差”刻画的就是随机变量取值的“离散程度”或“波动大小”。

一、 核心定义

设随机变量 X 的数学期望为 E(X)。我们把 X 与其期望的偏差的平方 (X−E(X))2 的数学期望，称为随机变量 X 的方差，记作 D(X) 或 Var(X)。

定义式：

D(X)=E[(X−E(X))2]
  • 物理意义： 方差越大，说明随机变量的取值越分散，波动越大；方差越小，说明取值越集中在期望值附近，波动越小。
  • 标准差 (Standard Deviation)： 方差的量纲（单位）是原变量的平方（比如原变量是米，方差就是平方米）。为了在同一量纲下比较，我们对方差开算术平方根，得到标准差，记作 σ(X)=D(X)。

二、 最常用的计算公式（考场必用）

虽然定义式很有物理意义，但在实际做题计算时，我们极少使用定义式，而是使用它展开后的计算公式：

D(X)=E(X2)−[E(X)]2

无论是离散型还是连续型随机变量，求方差的标准化流程永远是：

  1. 先求 E(X)。
  2. 再求 E(X2) （把分布律或密度函数里的 x 换成 x2 再求和或积分）。
  3. 两者套用上述公式相减。

三、 方差的核心性质（选择填空高频考点）

这些性质在化简复杂随机变量函数的方差时极其有用，必须熟记：

  1. 常数的方差为 0： D(C)=0 （常数没有波动）。

  2. 线性变化的方差（平方提取）： 对于常数 a,b，有：

    D(aX+b)=a2D(X)

    (注意：平移 b 不会改变数据的波动程度，所以 b 直接消失；而缩放 a 会导致方差放大 a2 倍。)

  3. 独立变量的方差可加性： 如果 X 和 Y 相互独立，则：

    D(X±Y)=D(X)+D(Y)

    (⚠️ 致命易错点：即使是 X−Y，方差也是相加的！因为两个独立变量相减，其波动程度是叠加的，只会更乱，不会抵消。)

  4. 一般情况下的加减法： 如果 X 和 Y 不独立，则需要引入协方差 Cov(X,Y)：

    D(X±Y)=D(X)+D(Y)±2Cov(X,Y)
    Cov(X,Y)=[X−E(X)][Y−E(Y)]
