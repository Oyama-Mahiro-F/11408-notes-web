## 第1章 函数的极限与连续

### 1.1 自查清单

- [ ] 能写出数列极限的 $\varepsilon$-$N$ 定义，并说明**极限与前有限项无关**（增删改有限项不改变极限）
- [ ] 能说出函数极限存在的充要条件：**左极限 = 右极限**；会用等价写法 $\lim\limits_{x \to x_0} f(x) = A \iff f(x) = A + \alpha$（$\alpha$ 为无穷小）
- [ ] 能一眼认出**必须分左右极限**的信号：$e^{\frac{1}{x}}$、$\arctan\frac{1}{x}$、取整函数 $[x]$、分段函数的分段点
- [ ] 能复述局部有界性（**去心邻域**内有界）与局部保号性，并知道由 $f(x) > 0$ 反推只能得 $A \ge 0$
- [ ] 能默写两个重要极限，并会用 $1^\infty$ 型公式 $\lim [f(x)]^{g(x)} = e^{\lim [f(x) - 1]g(x)}$（前提是 $f(x) \to 1$ 且在去心邻域内 $f(x) > 0$，否则不能取对数）
- [ ] 能默写 $x \to 0$ 的基础等价无穷小：$\sin x \sim \tan x \sim \arcsin x \sim \arctan x \sim x$、$\ln(1+x) \sim e^x - 1 \sim x$、$1 - \cos x \sim \frac{x^2}{2}$、$(1+x)^a - 1 \sim ax$
- [ ] 能默写**差值型**等价无穷小：$x - \sin x \sim \frac{x^3}{6}$、$\tan x - x \sim \frac{x^3}{3}$、$x - \arctan x \sim \frac{x^3}{3}$、$x - \ln(1+x) \sim \frac{x^2}{2}$
- [ ] 能说明等价无穷小替换**只对乘除因子安全**，加减场合必须改用泰勒展开保留足够阶数
- [ ] 会判断无穷小的阶（由 $\lim \frac{\alpha}{\beta^n} = c \ne 0$ 定 $n$）；变限积分、根式型会用泰勒或求导法定阶
- [ ] 能说清无穷大与无界的关系：**无穷大必无界，无界不必为无穷大**（反例 $x\sin x$）
- [ ] 会用夹逼准则处理 $n$ 项和与放缩题，并知道两端极限必须**存在且相等**
- [ ] 会用单调有界准则处理递推数列：先证有界与单调，再令 $n \to \infty$ 解方程求极限
- [ ] 会用定积分定义求 $n$ 项和极限：$\lim\limits_{n \to \infty} \frac{1}{n}\sum\limits_{i=1}^{n} f\left(\frac{i}{n}\right) = \int_0^1 f(x)\,dx$
- [ ] 能按"**先找点、再算左右极限**"判断间断点类型，区分第一类（可去、跳跃）与第二类（无穷、振荡）
- [ ] 能复述闭区间连续函数四大定理（最值、有界、介值、零点）及各自的前提条件
- [ ] 会用 $f(x) = A + \alpha$ 的等价写法处理"已知极限反求参数/函数值"的题

### 1.2 易错点 · 高频陷阱

- 等价无穷小**在加减法中直接替换会丢阶**：$\lim\limits_{x \to 0}\frac{\tan x - \sin x}{x^3}$ 若替换成 $\frac{x - x}{x^3} = 0$ 就错了，正确结果是 $\frac{1}{2}$。
- 洛必达法则三前提缺一不可；**导数之比的极限不存在，推不出原极限不存在**——如 $\lim\limits_{x \to \infty}\frac{x + \sin x}{x}$ 用洛必达得 $1 + \cos x$ 振荡，但原极限为 $1$。
- 局部保号性不能倒着用：由 $f(x) > 0$ 只得到 $A \ge 0$（等号可能取到）；反过来由 $A < 0$ 才能断言邻域内 $f(x) < 0$。
- **无穷大 ≠ 无界**：$x\sin x$ 在 $x \to \infty$ 时无界，却不是无穷大（存在趋于 0 的子列）。
- 只算单侧极限必失分：$\arctan\frac{1}{x}$ 在 $x \to 0$ 处左右极限为 $-\frac{\pi}{2}$ 与 $\frac{\pi}{2}$，属**第一类跳跃间断点**。
- 零点定理前提是"**闭区间连续 + 两端点异号**"，缺一不可；开区间或端点同号时结论不成立。
- $1^\infty$ 型（尤其抽象函数）直接套 $e^{\lim[f-1]g}$，**不必硬凑第二个重要极限**；若 $\lim[f-1]g$ 不存在则此法失效。
- 用夹逼准则时两端极限必须存在且相等，"一端有界、一端发散"推不出任何结论。

### 1.3 自测问答

**Q1. 求 $\lim\limits_{x \to 0}\dfrac{\tan x - \sin x}{x^3}$。**

<details><summary>▶ 展开答案</summary>

$\tan x - \sin x = \sin x\left(\frac{1}{\cos x} - 1\right) = \sin x \cdot \frac{1 - \cos x}{\cos x}$。
$x \to 0$ 时 $\sin x \sim x$，$1 - \cos x \sim \frac{x^2}{2}$，$\cos x \to 1$，故原式 $\sim \dfrac{x \cdot \frac{x^2}{2}}{x^3} = \dfrac{1}{2}$。

（用泰勒同样可验：$\tan x = x + \frac{x^3}{3} + o(x^3)$，$\sin x = x - \frac{x^3}{6} + o(x^3)$，相减得 $\frac{x^3}{2} + o(x^3)$。）
</details>

**Q2. 求 $\lim\limits_{x \to 0}\left(\dfrac{\sin x}{x}\right)^{\frac{1}{x^2}}$。**

<details><summary>▶ 展开答案</summary>

属 $1^\infty$ 型。先算 $\dfrac{\sin x}{x} - 1 = \dfrac{\sin x - x}{x} \sim \dfrac{-\frac{x^3}{6}}{x} = -\dfrac{x^2}{6}$，
于是 $\lim\limits_{x \to 0}\left(\dfrac{\sin x}{x} - 1\right)\cdot\dfrac{1}{x^2} = -\dfrac{1}{6}$，原式 $= e^{-\frac{1}{6}}$。
</details>

**Q3. 指出 $f(x) = \arctan\dfrac{1}{x}$ 在 $x = 0$ 处的间断点类型。**

<details><summary>▶ 展开答案</summary>

$x \to 0^-$ 时 $\frac{1}{x} \to -\infty$，$f(x) \to -\frac{\pi}{2}$；$x \to 0^+$ 时 $\frac{1}{x} \to +\infty$，$f(x) \to \frac{\pi}{2}$。
左右极限都存在但不相等，故为**第一类跳跃间断点**。（无穷间断点指的是 $\frac{1}{x}$ 这类极限为 $\infty$ 的情形，别混。）
</details>

**Q4. 设 $a_1 = \sqrt{2}$，$a_{n+1} = \sqrt{2 + a_n}$，证明 $\{a_n\}$ 收敛并求其极限。**

<details><summary>▶ 展开答案</summary>

**有界**：$a_1 = \sqrt{2} < 2$；若 $a_n < 2$，则 $a_{n+1} = \sqrt{2 + a_n} < \sqrt{4} = 2$，故 $a_n < 2$ 对一切 $n$ 成立。
**单调**：$a_{n+1}^2 - a_n^2 = 2 + a_n - a_n^2 = -(a_n - 2)(a_n + 1) > 0$（因 $0 < a_n < 2$），故 $a_{n+1} > a_n$。
由单调有界准则极限 $L$ 存在，对递推式两边取极限得 $L = \sqrt{2 + L}$，即 $L^2 - L - 2 = 0$，解得 $L = 2$（舍去 $-1$）。
</details>

## 第2章 一元函数微分学

### 2.1 自查清单

- [ ] 能写出导数定义的**两种等价形态**（增量式 $\lim\limits_{\Delta x \to 0}\frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$ 与差商式），并识别"增量与点必须严格对应"的广义化写法
- [ ] 能说清关系链：**可导 ⟹ 连续，连续 ⇏ 可导**（反例 $y = |x|$ 在 $x = 0$）；可导 $\iff$ 左导数 = 右导数；且**可微 $\iff$ 可导**，$\Delta y = f'(x_0)\Delta x + o(\Delta x)$、$dy = f'(x)\,dx$
- [ ] 会判断分段函数分界点的可导性——**必须回定义**，不能先求导函数再代入
- [ ] 能默写基本导数表（含 $\tan$、$\cot$、$\sec$、$\csc$ 与四个反三角函数的导数）
- [ ] 熟练链式法则（由外向内、层层相乘、最内层别漏）；会求幂指函数（取对数或写成 $u^v = e^{v\ln u}$）
- [ ] 会求反函数二阶导 $\dfrac{d^2x}{dy^2} = -\dfrac{y''}{(y')^3}$（负号与三次方都别丢）；会参数方程求导 $\dfrac{dy}{dx} = \dfrac{\psi'(t)}{\varphi'(t)}$ 及其二阶导
- [ ] 会隐函数求导（两边对 $x$ 求导，$y$ 视为 $x$ 的函数）；二阶导**对原方程连求两次**并边求边代值
- [ ] 能默写高阶导数公式（$e^{kx}$、$\sin(kx)$ 的相位 $\frac{n\pi}{2}$、$\ln(1+x)$、$\frac{1}{x+a}$、$(x+a)^\mu$）与莱布尼茨公式
- [ ] 能复述洛必达法则的三个前提，并知道**导数之比不存在时不能反推原极限不存在**
- [ ] 能默画中值定理链条（费马 → 罗尔 → 拉格朗日 → 柯西 → 泰勒）与每步的"降维"关系，会用构造辅助函数证等式：$f' + f = 0 \Rightarrow F = e^xf$、$xf' + nf = 0 \Rightarrow F = x^nf$
- [ ] 能说出泰勒两种余项的用途（**皮亚诺求极限、拉格朗日做证明**），并默写 8 个麦克劳林展开：$e^x$、$\sin x$、$\cos x$、$\ln(1+x)$、$(1+x)^\alpha$、$\frac{1}{1-x}$、$\frac{1}{1+x}$、$\arctan x$
- [ ] 能说出极值的必要条件与两个充分条件，以及**驻点 ≠ 极值点**、**$f''(x_0) = 0$ ≠ 拐点**；会讨论方程根的个数（单调区间分段 + 端点极限 + 零点定理）
- [ ] 能判断凹凸与拐点（拐点答**坐标点**）、会求三类渐近线、会算曲率 $K = \frac{|y''|}{(1 + (y')^2)^{\frac{3}{2}}}$

### 2.2 易错点 · 高频陷阱

- **可导 ⇏ 导函数连续**：$f(x) = x^2\sin\frac{1}{x}\ (x \ne 0)$、$f(0) = 0$ 在 $x = 0$ 可导（$f'(0) = 0$），但 $f'(x) = 2x\sin\frac{1}{x} - \cos\frac{1}{x}$ 在 $x \to 0$ 时无极限，导函数在 0 处不连续。
- 洛必达用前必验三条件；**若导数之比因周期振荡而不存在，只能说洛必达失效，不能由此推出原极限不存在**。
- 驻点 ≠ 极值点（$y = x^3$ 在 $x = 0$）；$f''(x_0) = 0$ ≠ 拐点（$y = x^4$ 在 $x = 0$）——充分条件必须验证**左右变号**。
- 极值点答**横坐标** $x = x_0$，拐点答**坐标点** $(x_0, f(x_0))$；区间端点既不能作极值点，也不能作拐点。
- 泰勒展开**阶数必须够**：算 $\frac{\sin x - x}{x^3}$ 只展到一阶得 0 是错的，须展到 $x^3$ 项得 $-\frac{1}{6}$。
- 隐函数二阶导**别对一阶公式硬用商法则**（$F_x, F_z$ 中含 $z$，展开极庞大），应对原方程连求两次导。
- $f'(x) \ge 0$ 且等号只在**离散个别点**成立时 $f$ 仍严格单调递增（如 $y = x^3$）；相邻单调区间在分界点连续时**可以合并**。
- 用拉格朗日证"$f'(x) \equiv 0 \Rightarrow f$ 为常数"需要区间上连续、区间内可导，两个前提都要交代。

### 2.3 自测问答

**Q1. 设 $f(x) = x^2\sin\frac{1}{x}\ (x \ne 0)$，$f(0) = 0$。求 $f'(0)$，并判断 $f'$ 在 $x = 0$ 处是否连续。**

<details><summary>▶ 展开答案</summary>

用定义：$f'(0) = \lim\limits_{x \to 0}\dfrac{x^2\sin\frac{1}{x} - 0}{x} = \lim\limits_{x \to 0} x\sin\dfrac{1}{x} = 0$（无穷小乘有界），故 $f'(0) = 0$ 存在。
而当 $x \ne 0$ 时 $f'(x) = 2x\sin\frac{1}{x} - \cos\frac{1}{x}$，其中 $\cos\frac{1}{x}$ 在 $x \to 0$ 时振荡无极限，故 $\lim\limits_{x \to 0}f'(x)$ 不存在，$f'$ 在 $x = 0$ 处**不连续**。
这说明**函数可导推不出导函数连续**。
</details>

**Q2. 求 $\lim\limits_{x \to 0}\dfrac{e^x - 1 - x}{x^2}$。**

<details><summary>▶ 展开答案</summary>

$e^x = 1 + x + \dfrac{x^2}{2} + o(x^2)$，故分子 $= \dfrac{x^2}{2} + o(x^2)$，原式 $= \dfrac{1}{2}$。

（用差值型等价无穷小 $e^x - 1 - x \sim \frac{x^2}{2}$ 直接得同结果；此题为 $\frac{0}{0}$ 型，洛必达两次亦可。）
</details>

**Q3. 求 $f(x) = x^3 - 3x$ 的极值点、极值与拐点。**

<details><summary>▶ 展开答案</summary>

$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$，驻点 $x = \pm 1$；$f''(x) = 6x$。
$f''(-1) = -6 < 0$ ⟹ $x = -1$ 为极大值点，极大值 $f(-1) = -1 + 3 = 2$；
$f''(1) = 6 > 0$ ⟹ $x = 1$ 为极小值点，极小值 $f(1) = 1 - 3 = -2$。
$f''(x) = 6x$ 在 $x = 0$ 左右变号，故拐点为 $(0, f(0)) = \mathbf{(0, 0)}$。
（注意：极值点答横坐标，拐点答坐标点。）
</details>

**Q4. 证明：当 $x > 0$ 时 $\ln(1+x) > x - \dfrac{x^2}{2}$。**

<details><summary>▶ 展开答案</summary>

令 $F(x) = \ln(1+x) - x + \dfrac{x^2}{2}$，则 $F(0) = 0$，且
$F'(x) = \dfrac{1}{1+x} - 1 + x = \dfrac{1 - (1+x) + x(1+x)}{1+x} = \dfrac{x^2}{1+x} > 0\ (x > 0)$。
故 $F$ 在 $[0, +\infty)$ 上严格递增，当 $x > 0$ 时 $F(x) > F(0) = 0$，即 $\ln(1+x) > x - \dfrac{x^2}{2}$。
</details>

## 第3章 不定积分

### 3.1 自查清单

- [ ] 能说清原函数与不定积分的定义：$\int f(x)\,dx = F(x) + C$（全体原函数），**漏写 $C$ 是绝对失分点**
- [ ] 能说清互逆关系：$\frac{d}{dx}\int f\,dx = f$（先积后导不还原常数）；$\int F'(x)\,dx = F(x) + C$（先导后积必须补 $C$）
- [ ] 能复述原函数存在定理：$f$ 连续必有原函数；含**第一类间断点或无穷间断点**则区间内无原函数；含**振荡间断点可能有**
- [ ] 能默写基本积分公式表（幂函数、$\frac{1}{x}$、指数、六个三角函数、反三角、$\frac{1}{a^2+x^2}$、$\frac{1}{\sqrt{a^2-x^2}}$、$\frac{1}{x^2-a^2}$、$\frac{1}{\sqrt{x^2 \pm a^2}}$）
- [ ] 熟练第一类换元（凑微分）五类常见凑法：幂、倒数与对数、指数、三角、反三角
- [ ] 会第二类换元的三类三角代换与适用根式：$\sqrt{a^2-x^2}$ 令 $x = a\sin t$、$\sqrt{a^2+x^2}$ 令 $x = a\tan t$、$\sqrt{x^2-a^2}$ 令 $x = a\sec t$
- [ ] 会用**画直角三角形**回代三角函数值，不硬背 $\cos t$、$\tan t$ 的表达式
- [ ] 会根式代换（令整个根式为 $t$）与倒代换（$x = \frac{1}{t}$，分母次数远高于分子时用）的适用特征
- [ ] 能默写分部积分公式 $\int u\,dv = uv - \int v\,du$ 与选 $u$ 口诀"**反对幂指三**"（排前者作 $u$）
- [ ] 会处理循环积分 $\int e^{ax}\sin bx\,dx$：连用两次分部后原积分回现，移项解出（别忘除以系数）
- [ ] 会有理函数积分三步：假分式先长除 → 分母因式分解 → 拆部分分式（单根、$k$ 重根、二次不可约因式各自拆法）
- [ ] 会用留数法（遮盖法）口算不重复一次因式的系数，不解方程组
- [ ] 会三角有理式：先试对称性代换（对 $\sin x$ 奇令 $u = \cos x$、对 $\cos x$ 奇令 $u = \sin x$、整体同奇令 $u = \tan x$），保底才用万能代换 $t = \tan\frac{x}{2}$
- [ ] 会简单无理函数：含 $\sqrt[n]{ax+b}$、$\sqrt[n]{\frac{ax+b}{cx+d}}$ 时令整个根式为 $t$，化为有理函数积分
- [ ] 能说出方法选用次序：凑微分 → 换元 → 分部 → 有理化（三类函数最终都归为有理函数积分）

### 3.2 易错点 · 高频陷阱

- 不定积分**必写 $+C$**；且 $\int\frac{dx}{x} = \ln|x| + C$（带绝对值），不是 $\ln x + C$，也不是把 $x^{-1}$ 套幂函数公式。
- $\int\frac{dx}{x^2-a^2} = \dfrac{1}{2a}\ln\left|\dfrac{x-a}{x+a}\right| + C$：**系数 $\frac{1}{2a}$ 与分子分母的顺序**两个都易错（写成 $\frac{1}{a}$ 或把 $x \pm a$ 写反）。
- 第二类换元积完**必须经反函数回代**；画直角三角形是最稳的回代方式，别把 $t$ 留在答案里。
- 假分式**必须先长除**再拆部分分式；$k$ 重根要拆足 $k$ 项（从一次到 $k$ 次），漏项则系数求不出。
- 三角代换要注意 $t$ 的取值范围：如 $x = a\sin t$ 时须保证 $\cos t \ge 0$，此时 $\sqrt{a^2 - x^2} = a\cos t$ 才能去掉绝对值。
- 分部积分 $u$ 选反会越积越复杂（$\int x\ln x\,dx$ 中 $u$ 必须取 $\ln x$，不能取 $x$）；循环积分移项后别忘除以系数。
- 万能代换计算量极大，动手前先检查对称性代换是否可行；$\int\frac{dx}{1+\cos x}$ 这类用恒等变形 $1 + \cos x = 2\cos^2\frac{x}{2}$ 更快。

### 3.3 自测问答

**Q1. 求 $\displaystyle\int \frac{x}{1+x^2}\,dx$。**

<details><summary>▶ 展开答案</summary>

凑微分：$x\,dx = \frac{1}{2}d(1+x^2)$，故原式 $= \dfrac{1}{2}\ln(1+x^2) + C$。

（验证：$\left[\frac{1}{2}\ln(1+x^2)\right]' = \frac{1}{2}\cdot\frac{2x}{1+x^2} = \frac{x}{1+x^2}$ ✓）
</details>

**Q2. 求 $\displaystyle\int \frac{dx}{x^2-4}$。**

<details><summary>▶ 展开答案</summary>

套公式 $\int\frac{dx}{x^2-a^2} = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C$，取 $a = 2$：
原式 $= \dfrac{1}{4}\ln\left|\dfrac{x-2}{x+2}\right| + C$。

（验证：$\frac{1}{4}\left(\frac{1}{x-2} - \frac{1}{x+2}\right) = \frac{1}{4}\cdot\frac{4}{x^2-4} = \frac{1}{x^2-4}$ ✓）
</details>

**Q3. 求 $\displaystyle\int e^x\sin x\,dx$。**

<details><summary>▶ 展开答案</summary>

记 $I = \int e^x\sin x\,dx$。分部：$I = -e^x\cos x + \int e^x\cos x\,dx$；再分部：$\int e^x\cos x\,dx = e^x\sin x - I$。
代回得 $I = -e^x\cos x + e^x\sin x - I$，移项 $2I = e^x(\sin x - \cos x)$，故

$$
I = \frac{e^x(\sin x - \cos x)}{2} + C.
$$

（验证：$\left[\frac{e^x(\sin x-\cos x)}{2}\right]' = \frac{e^x(\sin x-\cos x) + e^x(\cos x+\sin x)}{2} = \frac{2e^x\sin x}{2} = e^x\sin x$ ✓）
</details>

**Q4. 求 $\displaystyle\int \frac{dx}{1+\sqrt{x}}$。**

<details><summary>▶ 展开答案</summary>

令 $t = \sqrt{x}$，则 $x = t^2$，$dx = 2t\,dt$：

$$
\int \frac{2t}{1+t}\,dt = 2\int\left(1 - \frac{1}{1+t}\right)dt = 2\left(t - \ln(1+t)\right) + C.
$$

回代 $t = \sqrt{x}$ 得 $2\sqrt{x} - 2\ln(1+\sqrt{x}) + C$。
</details>

### 4.2 易错点 · 高频陷阱

- 变限积分求导**漏内层导数**是最高频失分点（上下限为函数时必须用推广式）；被积函数含 $x$ 时更要先换元，不能直接求导。
- 换元后不换限、或换限后又把 $t$ 代回 $x$——口诀是"**换元必换限、换限不回代**"；新下限可能大于新上限，**不许对调**。
- 见 $\int_{-1}^{1}\frac{dx}{x^2}$ 直接用牛顿–莱布尼茨得 $-2$ 是**完全错误**的：$x = 0$ 是瑕点，且 $p = 2 > 1$，该反常积分发散。
- 含内部瑕点或形如 $\int_{-\infty}^{+\infty}$ 的积分**必须拆段**，两段都收敛原积分才收敛；柯西主值存在不等于反常积分收敛。
- 极坐标面积公式 **$S = \frac{1}{2}\int_\alpha^\beta \rho^2\,d\theta$ 别漏 $\frac{1}{2}$**；柱壳法 $V_y = 2\pi\int_a^b x f(x)\,dx$ **别漏 $x$**。
- 华里士公式只对 $\int_0^{\frac{\pi}{2}}\sin^n x\,dx$、$\int_0^{\frac{\pi}{2}}\cos^n x\,dx$ 成立；其他区间先换元平移（如 $\int_0^{\pi}\sin^n x\,dx = 2\int_0^{\frac{\pi}{2}}\sin^n x\,dx$）。
- 抽水做功的积分限是**水所在的深度区间**（不是池深），提升距离是"到池口"的距离；必须切水平薄片。
- 分段函数（含绝对值、$\max$、$\min$）的定积分必须先求出分段点再逐段积，别硬积。

**Q1. 计算 $\displaystyle\int_0^{\frac{\pi}{2}}\sin^2 x\,dx$。**

（用降幂公式复核：$\int_0^{\frac{\pi}{2}}\frac{1-\cos 2x}{2}dx = \frac{1}{2}\left[\frac{\pi}{2} - 0\right] = \frac{\pi}{4}$ ✓）

**Q2. 求 $\dfrac{d}{dx}\displaystyle\int_{x^2}^{e^x}\ln(1+t)\,dt$。**

<details><summary>▶ 展开答案</summary>

由推广的变限积分求导公式，上限 $\varphi_2 = e^x$、下限 $\varphi_1 = x^2$：

\frac{d}{dx}\int_{x^2}^{e^x}\ln(1+t)\,dt = \ln(1+e^x)\cdot e^x - \ln(1+x^2)\cdot 2x.

</details>

**Q3. 讨论 $\displaystyle\int_0^1 \frac{dx}{x^p}$ 的敛散性（按 $p$ 分类）。**

<details><summary>▶ 展开答案</summary>

$x = 0$ 是瑕点。当 $p \ne 1$ 时 $\int_\varepsilon^1 x^{-p}dx = \frac{1 - \varepsilon^{1-p}}{1-p}$：
- $p < 1$ 时 $1 - p > 0$，$\varepsilon^{1-p} \to 0$，积分**收敛**且值为 $\dfrac{1}{1-p}$；
- $p > 1$ 时 $1 - p < 0$，$\varepsilon^{1-p} \to +\infty$，积分**发散**；
- $p = 1$ 时 $\int_\varepsilon^1\frac{dx}{x} = -\ln\varepsilon \to +\infty$，**发散**。

故 $p < 1$ 收敛，$p \ge 1$ 发散。
</details>

**Q4. 求由 $y = x$ 与 $y = x^2$ 围成的图形绕 $x$ 轴旋转所得旋转体的体积。**

<details><summary>▶ 展开答案</summary>

交点由 $x = x^2$ 得 $x = 0, 1$；在 $(0,1)$ 上 $x > x^2$，故 $y = x$ 为外、$y = x^2$ 为内，用垫圈法：

$$
V = \pi\int_0^1\left(x^2 - x^4\right)dx = \pi\left(\frac{1}{3} - \frac{1}{5}\right) = \frac{2\pi}{15}.
$$
</details>

## 第5章 微分方程

### 5.1 自查清单

- [ ] 能说清阶数、通解、特解、初始条件的概念，并知道**通解中独立任意常数的个数 = 方程的阶数**
- [ ] 能判断 $y = (C_1 + C_2)e^x$ 只含一个独立常数，不能作二阶方程的通解

- [ ] 会根据特征根写常系数齐次方程通解（单实根、$k$ 重实根、单对共轭复根三种情形）
- [ ] 会用待定系数法设 $f(x) = P_m(x)e^{\lambda x}$ 的特解 $y^* = x^kQ_m(x)e^{\lambda x}$，并按 $\lambda$ 是不是特征根定 $k = 0, 1, 2$
- [ ] 会设 $f(x) = e^{\lambda x}[P_l(x)\cos\omega x + P_n(x)\sin\omega x]$ 的特解：取 $m = \max(l,n)$，**必须同时设出 $\cos$ 与 $\sin$ 两组**，$k$ 按 $\lambda \pm \omega i$ 是否为特征根取 0 或 1

### 5.2 易错点 · 高频陷阱

- 分离变量时**除以 $g(y)$ 会丢常数解**：若 $g(a) = 0$，需检查 $y = a$ 能否被通解包含（取某个 $C$ 得到），不能包含就必须单独列出。
- 通解中的任意常数**必须独立且个数等于阶数**；$(C_1 + C_2)e^x$ 可合并成一个常数，不能作二阶方程的通解。
- **缺 $x$ 型误把 $y''$ 写成 $p'$** 是最经典的错误：缺 $x$ 时 $y'' = p\frac{dp}{dy}$；只有缺 $y$ 型才是 $y'' = p'$。
- 一阶线性方程没化标准型就提取 $P(x)$：$xy' + y = e^x$ 须先除以 $x$ 化为 $y' + \frac{1}{x}y = \frac{e^x}{x}$；且 $P(x)$ 要包含 $y$ 前面的**全部符号**（$y' - \frac{1}{x}y = x^2$ 的 $P = -\frac{1}{x}$）。
- 待定系数法的 $k$ 判错：$\lambda$ 恰为特征根时**必须乘 $x^k$**，否则猜出的特解与齐次通解"撞车"，代入左边恒为 0，系数解不出来。
- 三角型自由项**只设 $\cos$ 不设 $\sin$** 必错；多项式是几次就设几次的**一般**多项式（含全部低次项，如 $f$ 含 $x$ 就设 $Ax + B$）。
- 欧拉方程换元后解的是关于 $t$ 的常系数方程，**最后必须把 $t = \ln x$ 代回**，别把 $t$ 留在答案里。

**Q1. 求微分方程 $y' + y = e^{-x}$ 的通解。**

<details><summary>▶ 展开答案</summary>

标准型中 $P(x) = 1$、$Q(x) = e^{-x}$，$\int P\,dx = x$。代入通解公式：

$$
y = e^{-x}\left[\int e^{-x}\cdot e^{x}\,dx + C\right] = e^{-x}(x + C).
$$

（验证：$y' = e^{-x} - e^{-x}(x+C)$，$y' + y = e^{-x} - e^{-x}(x+C) + e^{-x}(x+C) = e^{-x}$ ✓）
</details>

**Q2. 写出 $y'' - 3y' + 2y = xe^x$ 的特解形式（不必求系数）。**

<details><summary>▶ 展开答案</summary>

特征方程 $r^2 - 3r + 2 = 0$，得 $r_1 = 1$、$r_2 = 2$。
自由项 $f(x) = xe^x$，即 $m = 1$ 的多项式乘 $e^{\lambda x}$，$\lambda = 1$ 恰为**单根**，故 $k = 1$：

$$
y^* = x(Ax + B)e^x.
$$

（若顺手求出系数：代为 $L[y]=(-2Ax+2A-B)e^x$，令其 $=xe^x$ 得 $A=-\frac12$、$B=-1$，即 $y^*=-\left(\frac{x^2}{2}+x\right)e^x$；题面只要求"形式"时写到 $x(Ax+B)e^x$ 即可。）
</details>

**Q3. 求微分方程 $yy'' - (y')^2 = 0$ 的通解。**

<details><summary>▶ 展开答案</summary>

方程含 $y, y', y''$ 而不含 $x$，属**缺 $x$ 型**。令 $y' = p$，则 $y'' = p\frac{dp}{dy}$，代入得

$$
y\,p\frac{dp}{dy} - p^2 = 0 \quad\Longrightarrow\quad p\left(y\frac{dp}{dy} - p\right) = 0.
$$

若 $p = 0$ 得 $y = C$（常数解）；若 $p \ne 0$，则 $\frac{dp}{p} = \frac{dy}{y}$，积分得 $p = C_1y$。
再由 $\frac{dy}{dx} = C_1y$ 分离变量积分得 $\ln|y| = C_1x + C_2$，即

$$
y = Ce^{C_1x},
$$

其中 $C = 0$ 已包含常数解 $y = 0$ 的情形，故通解即为 $y = Ce^{C_1x}$（$C, C_1$ 为任意常数）。
</details>

**Q4. 求欧拉方程 $x^2y'' - 2xy' + 2y = 0\ (x > 0)$ 的通解。**

<details><summary>▶ 展开答案</summary>

令 $x = e^t$（即 $t = \ln x$），记 $D = \frac{d}{dt}$，则 $xy' = Dy$、$x^2y'' = D(D-1)y$。代入原方程：

$$
D(D-1)y - 2Dy + 2y = 0 \;\Longrightarrow\; (D^2 - 3D + 2)y = 0.
$$

特征方程 $r^2 - 3r + 2 = 0$ 得 $r = 1, 2$，故 $y = C_1e^t + C_2e^{2t}$。回代 $e^t = x$ 得

$$
y = C_1x + C_2x^2.
$$

（验证：$y = x$ 时 $0 - 2x + 2x = 0$ ✓；$y = x^2$ 时 $2x^2 - 4x^2 + 2x^2 = 0$ ✓）
</details>

**Q1. 求过点 $(1, 0, -1)$ 且与平面 $x + 2y - z = 3$ 平行的平面方程。**

**Q2. 已知 $\boldsymbol{a} = (1, 2, 2)$、$\boldsymbol{b} = (2, -1, 0)$，求 $\boldsymbol{a} \times \boldsymbol{b}$ 及其模长。**

<details><summary>▶ 展开答案</summary>

$$
\boldsymbol{a} \times \boldsymbol{b} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ 1 & 2 & 2 \\ 2 & -1 & 0 \end{vmatrix} = (2\cdot0 - 2\cdot(-1),\ -(1\cdot0 - 2\cdot2),\ 1\cdot(-1) - 2\cdot2) = (2, 4, -5).
$$

$|\boldsymbol{a} \times \boldsymbol{b}| = \sqrt{4 + 16 + 25} = \sqrt{45} = 3\sqrt{5}$。
（交叉验证：$\boldsymbol{a} \cdot \boldsymbol{b} = 2 - 2 + 0 = 0$，两者垂直，故模长应等于 $|\boldsymbol{a}||\boldsymbol{b}| = 3\cdot\sqrt{5} = 3\sqrt{5}$ ✓）
</details>

**Q3. 判断四点 $A(1,0,0)$、$B(0,1,0)$、$C(0,0,1)$、$D(1,1,1)$ 是否共面。**

<details><summary>▶ 展开答案</summary>

以 $A$ 为起点构造三个向量：$\overrightarrow{AB} = (-1, 1, 0)$、$\overrightarrow{AC} = (-1, 0, 1)$、$\overrightarrow{AD} = (0, 1, 1)$。混合积

$$
[\overrightarrow{AB}, \overrightarrow{AC}, \overrightarrow{AD}] = \begin{vmatrix} -1 & 1 & 0 \\ -1 & 0 & 1 \\ 0 & 1 & 1 \end{vmatrix} = -1(0 - 1) - 1(-1 - 0) + 0 = 2 \ne 0,
$$

故四点**不共面**（它们构成一个正四面体）。
</details>

**Q4. 求直线 $\dfrac{x-1}{1} = \dfrac{y}{1} = \dfrac{z-1}{1}$ 与平面 $x + y + z = 0$ 的夹角。**

<details><summary>▶ 展开答案</summary>

直线方向向量 $\boldsymbol{s} = (1,1,1)$，平面法向量 $\boldsymbol{n} = (1,1,1)$，线面角用 $\sin\theta$：

$$
\sin\theta = \frac{|\boldsymbol{s} \cdot \boldsymbol{n}|}{|\boldsymbol{s}||\boldsymbol{n}|} = \frac{3}{\sqrt{3}\cdot\sqrt{3}} = 1 \;\Longrightarrow\; \theta = \frac{\pi}{2}.
$$

即该直线与平面**垂直**（方向向量平行于法向量）。
</details>

## 第7章 多元函数微分学

### 7.1 自查清单

- [ ] 能说清重极限"动点以**任何方式**趋近"的含义（比一元"左 + 右"严苛得多，路径有无穷多条）
- [ ] 会证重极限不存在：找两条路径（$y = kx$、$y = kx^2$）使极限不同或含 $k$
- [ ] 会用夹逼、极坐标代换（$r \to 0$ 时极限存在**且与 $\theta$ 无关**）、无穷小乘有界求重极限
- [ ] 能说清有界闭区域上连续函数必有最值、必有界
- [ ] 会按"对 $x$ 求偏导时把 $y$ 视为常数"计算偏导，并说出偏导的几何意义（截面曲线的切线斜率）
- [ ] 知道混合偏导相等定理：二阶混合偏导**连续**时求导顺序可换
- [ ] 能默写可微判定三步：用定义求 $f_x, f_y$ → 构造 $\Delta z - [f_x\Delta x + f_y\Delta y]$ → 验证 $\dfrac{\Delta z - (f_x\Delta x + f_y\Delta y)}{\sqrt{\Delta x^2 + \Delta y^2}} \to 0$

- [ ] 会用一阶全微分形式不变性（$dz = f_u\,du + f_v\,dv$）处理复合函数与隐函数，并按链式法则逐条相加 $\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial x}$
- [ ] 会隐函数公式 $\dfrac{\partial z}{\partial x} = -\dfrac{F_x}{F_z}$、$\dfrac{\partial z}{\partial y} = -\dfrac{F_y}{F_z}$（负号别丢），二阶导对原方程连求两次
- [ ] 会解方程组型隐函数（直接偏导法列线性方程组，或全微分法只令 $dy = 0$ 求 $u_x$）
- [ ] 会用 $A = f_{xx}$、$B = f_{xy}$、$C = f_{yy}$ 与 $\Delta = AC - B^2$ 判无条件极值，并知道 $\Delta = 0$ 时失效
- [ ] 会用拉格朗日乘数法求条件极值（两个约束时 $L = f + \lambda\varphi + \mu\psi$），消元前先讨论除式为零
- [ ] 会求有界闭区域最值三步：搜内（驻点）→ 搜边（参数化最推荐）→ 比大小，**别漏角点**
- [ ] 会求空间曲线切线/法平面（$\vec{T} = \nabla F \times \nabla G$）与曲面切平面/法线（显式 $z = f(x,y)$ 的法向量为 $(f_x, f_y, -1)$）
- [ ] 会算方向导数（方向向量**先单位化**）与梯度，并说出三条结论：沿梯度方向增长最快且最大值为 $|\nabla f|$、沿反方向下降最快、沿等值线方向方向导数为 0

### 7.2 易错点 · 高频陷阱

- **偏导数存在 ⇏ 连续**（多元特有陷阱）；只有可微才能同时推出连续与偏导存在，四条关系要背准。
- 分段函数在拼接点（如 $(0,0)$）求偏导、判可微**一律回定义**：$f_x(0,0) = \lim\limits_{x \to 0}\frac{f(x,0) - f(0,0)}{x}$，不能先求导函数再代入。
- $AC - B^2 = 0$ 时二阶判别法**失效**，不能下"不是极值"的结论，要回定义或用高阶泰勒判断。
- 拉格朗日乘数法消 $\lambda$ 时，两边同除含 $x$（或 $y$）的式子**必须先讨论该式为 0**，否则丢根、丢最值。
- 边界最值别漏**角点**（直线段交点）与端点函数值；求最值只需比大小，**不必**判极大极小、不必算 $\Delta$。
- 方向导数公式只对**单位**方向向量成立，先除以模长再代入；牢记方向导数是**数**、梯度是**向量**。
- 显式曲面 $z = f(x,y)$ 的法向量是 $(f_x, f_y, -1)$，**负号别丢**；隐式 $F(x,y,z) = 0$ 的才是 $(F_x, F_y, F_z)$。
- 用极坐标代换证重极限存在时，必须说明结果**与 $\theta$ 无关**——只证明沿每条射线极限存在是不够的。

### 7.3 自测问答

**Q1. 讨论 $f(x,y) = \dfrac{xy}{x^2+y^2}\ ((x,y) \ne (0,0))$、$f(0,0) = 0$ 在 $(0,0)$ 处的重极限。**

<details><summary>▶ 展开答案</summary>

沿路径 $y = kx$（$x \to 0$）逼近：$f(x, kx) = \dfrac{kx^2}{x^2 + k^2x^2} = \dfrac{k}{1+k^2}$。
该值随 $k$ 变化（$k = 1$ 得 $\frac{1}{2}$，$k = 0$ 得 $0$），故极限随路径不同而不同，**重极限不存在**。
</details>

**Q2. 设 $f(x,y) = \dfrac{xy}{\sqrt{x^2+y^2}}\ ((x,y) \ne (0,0))$、$f(0,0) = 0$。判断 $f$ 在 $(0,0)$ 处是否连续、偏导是否存在、是否可微。**

<details><summary>▶ 展开答案</summary>

记 $\rho = \sqrt{x^2+y^2}$。**连续**：$|f(x,y)| = \frac{|xy|}{\rho} \le \frac{\rho^2/2}{\rho} = \frac{\rho}{2} \to 0 = f(0,0)$ ✓
**偏导**：用定义 $f_x(0,0) = \lim\limits_{x \to 0}\frac{0 - 0}{x} = 0$，同理 $f_y(0,0) = 0$，均存在。
**可微**：考察 $\dfrac{\Delta z - [f_x\Delta x + f_y\Delta y]}{\rho} = \dfrac{xy/\rho}{\rho} = \dfrac{xy}{x^2+y^2}$，其极限随路径变化（沿 $y = x$ 得 $\frac{1}{2}$）不存在，故**不可微**。
本题说明：**连续 + 偏导存在 ⇏ 可微**。
</details>

**Q3. 求 $z = x^3 + y^3 - 3xy$ 的极值。**

<details><summary>▶ 展开答案</summary>

$z_x = 3x^2 - 3y = 0$、$z_y = 3y^2 - 3x = 0$，由 $y = x^2$ 与 $x = y^2$ 得 $x = x^4$，故驻点为 $(0,0)$ 与 $(1,1)$。
$A = z_{xx} = 6x$，$B = z_{xy} = -3$，$C = z_{yy} = 6y$，$\Delta = AC - B^2 = 36xy - 9$。
$(0,0)$ 处 $\Delta = -9 < 0$，非极值（鞍点）；$(1,1)$ 处 $\Delta = 36 - 9 = 27 > 0$ 且 $A = 6 > 0$，为**极小值**，$z(1,1) = 1 + 1 - 3 = \mathbf{-1}$。
</details>

**Q4. 求 $f(x,y) = x^2 + y^2$ 在点 $(1,1)$ 处沿方向 $\vec{l} = (1,1)$ 的方向导数，并指出该点处方向导数的最大值。**

<details><summary>▶ 展开答案</summary>

$\nabla f = (2x, 2y)$，在 $(1,1)$ 处 $\nabla f = (2,2)$，$|\nabla f| = 2\sqrt{2}$。
把方向向量**单位化**：$\vec{e} = \left(\frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}}\right)$，故

$$
\frac{\partial f}{\partial \vec{l}} = 2\cdot\frac{1}{\sqrt{2}} + 2\cdot\frac{1}{\sqrt{2}} = 2\sqrt{2}.
$$

方向导数最大值即 $|\nabla f| = 2\sqrt{2}$，取在**梯度方向** $(1,1)$ 上（正与本题方向相同）。
</details>

- [ ] 会算形心：$\bar{x} = \frac{1}{A}\iint_D x\,d\sigma$、$\bar{y} = \frac{1}{A}\iint_D y\,d\sigma$、$A = \iint_D d\sigma$

### 8.2 易错点 · 高频陷阱

- 极坐标**别漏雅可比因子 $r$**（$dxdy = r\,drd\theta$），漏掉则结果整体错误。
- 用奇偶对称性前必须确认**区域本身关于该轴对称**；"区域不对称 + 函数是奇函数"不能得 0。
- 交换积分次序**必须画图重新穿线**，不能只把两个积分号与上下限简单对调（上下限形式通常完全变了）。
- 圆心不在原点的圆域，极坐标下 $r$ 的上限含 $\theta$：如 $x^2+y^2 \le 2x$ 得 $-\frac{\pi}{2} \le \theta \le \frac{\pi}{2}$、$0 \le r \le 2\cos\theta$。
- 定限时**外层限必须是常数**，内层限才可以含外层变量；写反了积分无意义。
- 含绝对值 / $\max$ / $\min$ 时**分块边界要解对**：$|x-y|$ 用直线 $y = x$ 分块，$\max(x,y)$ 同理。
- 遇到内层积不出的原函数（$e^{x^2}$、$\frac{\sin x}{x}$ 等）要立刻考虑**交换次序**，别死磕。

### 8.3 自测问答

**Q1. 交换积分次序：$\displaystyle\int_0^1 dx\int_x^1 f(x,y)\,dy$。**

<details><summary>▶ 展开答案</summary>

原区域为 $0 \le x \le 1$、$x \le y \le 1$，即由 $y = x$、$y = 1$、$x = 0$ 围成的三角形。
改按 $y$ 为外层：$0 \le y \le 1$，$x$ 从 $0$ 到 $y$，故

$$
\int_0^1 dx\int_x^1 f(x,y)\,dy = \int_0^1 dy\int_0^y f(x,y)\,dx.
$$
</details>

**Q2. 计算 $\displaystyle\iint_D (x^2+y^2)\,d\sigma$，其中 $D: x^2+y^2 \le 1$。**

<details><summary>▶ 展开答案</summary>

用极坐标，$x^2+y^2 = r^2$，$d\sigma = r\,drd\theta$：

$$
\iint_D (x^2+y^2)\,d\sigma = \int_0^{2\pi}d\theta\int_0^1 r^2\cdot r\,dr = 2\pi\cdot\frac{1}{4} = \frac{\pi}{2}.
$$
</details>

**Q3. 计算 $\displaystyle\iint_D (x^3 + y^3 + 5)\,d\sigma$，其中 $D: x^2+y^2 \le 4$。**

<details><summary>▶ 展开答案</summary>

$D$ 关于两条坐标轴都对称，而 $x^3$、$y^3$ 分别是关于 $x$、$y$ 的奇函数，故两项积分均为 0。
剩下 $\iint_D 5\,d\sigma = 5\times(\text{面积}) = 5 \times 4\pi = \mathbf{20\pi}$。
</details>

**Q4. 计算 $\displaystyle\int_0^1 dy\int_y^1 e^{-x^2}dx$。**

<details><summary>▶ 展开答案</summary>

$e^{-x^2}$ 的原函数积不出，须交换次序。原区域：$0 \le y \le 1$、$y \le x \le 1$，改按 $x$ 为外层：$0 \le x \le 1$，$0 \le y \le x$，于是

$$
\int_0^1 dx\int_0^x e^{-x^2}dy = \int_0^1 x e^{-x^2}dx = \left[-\frac{1}{2}e^{-x^2}\right]_0^1 = \frac{1 - e^{-1}}{2}.
$$
</details>

### 9.2 易错点 · 高频陷阱

- 柱面坐标体积元素是 $\rho\,d\rho d\theta dz$、球面坐标是 $r^2\sin\varphi\,drd\varphi d\theta$，**漏掉因子全盘皆输**。
- 球面坐标的 $\varphi$ 是与 **$z$ 轴正向**的夹角（在 $[0,\pi]$ 上取），别与柱面/极坐标的 $\theta$ 混淆——这是最容易张冠李戴的一处。
- 球面坐标的上下限**不一定是常数**：$\varphi$ 的限可含 $\theta$，$r$ 的限可同时含 $\varphi$ 与 $\theta$，只有区域关于 $z$ 轴旋转对称（如球体）时才全是常数。
- 奇偶对称性判断口诀是"**关于哪个坐标面对称，就看哪个剩余变量**"：关于 $xOy$ 面对称要看 $z$ 的奇偶，别看成 $x$。
- 轮换对称性要求区域中 $x, y, z$ **地位完全对等**（如球体），否则"三分之一"技巧不成立。
- 投影法与截面法别用混：顶底曲面明确（$z_1(x,y)$ 到 $z_2(x,y)$）用投影法；水平截面面积易算（如 $D_z$ 是圆）用截面法。
- 用球坐标时"乘上 $r^2\sin\varphi$"与"把 $x^2+y^2+z^2$ 换成 $r^2$"是**两件独立的事**，两件都要做。

### 9.3 自测问答

**Q1. 计算 $\displaystyle\iiint_\Omega z\,dv$，其中 $\Omega: x^2+y^2+z^2 \le 1,\ z \ge 0$。**

<details><summary>▶ 展开答案</summary>

球面坐标：$\theta: 0 \to 2\pi$，$\varphi: 0 \to \frac{\pi}{2}$（上半球），$r: 0 \to 1$，$z = r\cos\varphi$。

$$
\iiint_\Omega z\,dv = \int_0^{2\pi}d\theta\int_0^{\frac{\pi}{2}}d\varphi\int_0^1 (r\cos\varphi)\cdot r^2\sin\varphi\,dr = 2\pi\cdot\frac{1}{4}\int_0^{\frac{\pi}{2}}\sin\varphi\cos\varphi\,d\varphi.
$$

其中 $\int_0^{\frac{\pi}{2}}\sin\varphi\cos\varphi\,d\varphi = \frac{1}{2}$，故结果 $= 2\pi\cdot\frac{1}{4}\cdot\frac{1}{2} = \dfrac{\pi}{4}$。
（校验：$\Omega$ 形心高度 $\bar{z} = \frac{3}{8}$，体积 $\frac{2\pi}{3}$，乘积恰为 $\frac{\pi}{4}$ ✓）
</details>

**Q2. 计算 $\displaystyle\iiint_\Omega (x^2+y^2+z^2)\,dv$，其中 $\Omega$ 为单位球 $x^2+y^2+z^2 \le 1$。**

<details><summary>▶ 展开答案</summary>

球面坐标下 $x^2+y^2+z^2 = r^2$，$dv = r^2\sin\varphi\,drd\varphi d\theta$：

$$
\iiint_\Omega r^2\,dv = \int_0^{2\pi}d\theta\int_0^{\pi}\sin\varphi\,d\varphi\int_0^1 r^4\,dr = 2\pi\cdot 2\cdot\frac{1}{5} = \frac{4\pi}{5}.
$$

（用轮换对称复核：$\iiint x^2 = \iiint y^2 = \iiint z^2$，三项之和为 $\frac{4\pi}{5}$，故每个为 $\frac{4\pi}{15}$ ✓）
</details>

**Q3. 求 $\Omega: z \ge x^2+y^2,\ z \le 1$ 的体积。**

<details><summary>▶ 展开答案</summary>

用柱面坐标，顶面 $z = 1$、底面 $z = \rho^2$，投影区域 $D: \rho \le 1$：

$$
V = \int_0^{2\pi}d\theta\int_0^1 \rho\,d\rho\int_{\rho^2}^{1} dz = 2\pi\int_0^1 \rho(1 - \rho^2)\,d\rho = 2\pi\left(\frac{1}{2} - \frac{1}{4}\right) = \frac{\pi}{2}.
$$

（截面法复核：高度 $z$ 处截面为圆 $\rho^2 \le z$、面积 $\pi z$，$V = \int_0^1 \pi z\,dz = \frac{\pi}{2}$ ✓）
</details>

**Q4. 计算 $\displaystyle\iiint_\Omega z\,dv$，其中 $\Omega: x^2+y^2 \le z \le 1$。**

<details><summary>▶ 展开答案</summary>

柱面坐标下 $x^2+y^2 = \rho^2$，故 $\rho^2 \le z \le 1$，且 $\rho$ 从 0 到 1（当 $\rho > 1$ 时下界已超过上界）：

$$
\iiint_\Omega z\,dv = \int_0^{2\pi}d\theta\int_0^1 \rho\,d\rho\int_{\rho^2}^{1} z\,dz = 2\pi\int_0^1 \rho\cdot\frac{1 - \rho^4}{2}\,d\rho = \pi\left(\frac{1}{2} - \frac{1}{6}\right) = \frac{\pi}{3}.
$$
</details>

## 第10章 无穷级数

### 10.1 自查清单

- [ ] 能说清级数收敛 = 部分和数列极限存在，并知道**敛散性只取决于"尾巴"**（增删改有限项不改变敛散性，但会改变和）
- [ ] 能默写收敛的必要条件 $\sum u_n$ 收敛 $\Rightarrow \lim u_n = 0$，会用它判发散，并知道 $u_n \to 0$ **不保证收敛**（调和级数反例）
- [ ] 能说出线性性质：收敛 ± 收敛 = 收敛；**收敛 ± 发散 = 发散**（反证法利器）；发散 ± 发散**不确定**
- [ ] 能说出加括号性质及其逆否：收敛级数加括号仍收敛且和不变；**加括号后发散 ⟹ 原级数发散**；加括号后收敛 ⇏ 原收敛（$1-1+1-\cdots$）
- [ ] 知道正项级数收敛 $\iff$ 部分和数列有上界（一切判别法的根源）
- [ ] 会用比较判别法及其极限形式（$0 < \lambda < +\infty$ 同敛散），并以 $p$ 级数为参照，用**等价无穷小**找参照
- [ ] 会用比值判别法（通项含 $n!$ 或 $a^n$）与根值判别法（通项带 $n$ 次根），并知道 $\rho = 1$ 时二者**失效**
- [ ] 会用积分判别法（经典：$\sum\frac{1}{n\ln n}$ 发散）
- [ ] 会用莱布尼茨判别法两个条件（$u_n$ 单调不增、$u_n \to 0$），并会用余项估计 $|r_n| \le u_{n+1}$
- [ ] 能区分绝对收敛与条件收敛，并知道**条件收敛级数的全体正项子级数与负项子级数都发散**
- [ ] 能复述阿贝尔定理，会用 $\rho = \lim\left|\frac{a_{n+1}}{a_n}\right|$ 求收敛半径 $R = \frac{1}{\rho}$，并会处理**缺项幂级数**
- [ ] 能区分收敛区间（开区间）与收敛域（区间 ∪ 收敛端点），**端点必须单独代入数项级数判敛**（端点可能绝对收敛，也可能只是条件收敛，如 $\sum\frac{x^n}{n}$ 在 $x = -1$ 处）
- [ ] 知道逐项求导、逐项积分后**收敛半径 $R$ 不变**，但端点敛散性可能改变（求导可能丢端点、积分可能得端点）
- [ ] 会求幂级数的和函数（先求收敛域 → 看系数形态 → 逐项求导/积分化为等比 → 逆运算还原 → **标注收敛域**），并记住 $\sum\limits_{n=1}^{\infty} nx^{n-1} = \frac{1}{(1-x)^2}$、$\sum\limits_{n=1}^{\infty}\frac{x^n}{n} = -\ln(1-x)$
- [ ] 会用间接法把函数展开成幂级数（代换、逐项求导/积分、拆项），并默写 $e^x$、$\sin x$、$\cos x$、$\ln(1+x)$、$\frac{1}{1-x}$、$\arctan x$、$(1+x)^\alpha$ 的展开式与收敛域
- [ ] 能默写傅里叶系数公式与狄利克雷收敛定理（**间断点与端点收敛于左右极限的平均值**），会用奇延拓/偶延拓求正弦级数、余弦级数，会做周期 $2l$ 的推广

### 10.2 易错点 · 高频陷阱

- $u_n \to 0$ 只是**必要**条件（$\sum\frac{1}{n}$ 发散）；比值、根值判别法出现 $\rho = 1$ 时一律**失效**，不能据此下敛散结论，须回比较判别法。
- **收敛区间 ≠ 收敛域**：端点必须单独代入判敛；求和函数、展开函数的答案**必须标注收敛域**（漏写端点扣分）。
- 逐项求导 / 逐项积分后 $R$ 不变，但**端点敛散性可能改变**——如 $\sum x^n$ 在 $x = \pm1$ 都发散，逐项积分后 $\sum\frac{x^n}{n}$ 在 $x = -1$ 收敛。
- **缺项幂级数**（如 $\sum\frac{(x-1)^{2n}}{n\cdot4^n}$）不能套系数公式，应直接对 $\left|\frac{u_{n+1}(x)}{u_n(x)}\right|$ 用比值法解出 $|x - x_0| < R$。
- 加括号性质的方向别搞反：收敛 ⟹ 加括号收敛；**加括号后发散 ⟹ 原级数发散**；加括号后收敛 ⇏ 原级数收敛。
- 莱布尼茨两条件是**充分不必要**："$u_n$ 不单调"不能推出发散，只能说该判别法失效。
- 傅里叶级数的和函数在**间断点与端点**处取左右极限的**平均值** $\frac{f(x^-) + f(x^+)}{2}$，不是 $f(x)$ 本身；求 $S(x_0)$ 先判 $x_0$ 是否间断点。
- 常用数项级数和别记错：$\sum\limits_{n=1}^{\infty}\frac{1}{n(n+1)} = 1$（裂项）、$\sum\limits_{n=1}^{\infty}\frac{(-1)^{n-1}}{n} = \ln 2$、$\sum\limits_{n=1}^{\infty}\frac{1}{n^2} = \frac{\pi^2}{6}$、$\sum\limits_{n=1}^{\infty}\frac{(-1)^{n-1}}{2n-1} = \frac{\pi}{4}$。

### 10.3 自测问答

**Q1. 判别 $\displaystyle\sum_{n=1}^{\infty}\frac{n}{2^n}$ 的敛散性。**

<details><summary>▶ 展开答案</summary>

通项含 $2^n$，用比值判别法：

$$
\rho = \lim_{n \to \infty}\frac{u_{n+1}}{u_n} = \lim_{n \to \infty}\frac{(n+1)/2^{n+1}}{n/2^n} = \lim_{n \to \infty}\frac{n+1}{2n} = \frac{1}{2} < 1,
$$

故级数**收敛**（其和恰为 2，可用 $\sum n x^{n-1}$ 在 $x = \frac{1}{2}$ 处取值得出）。
</details>

**Q2. 判别 $\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^{n-1}}{n}$ 的敛散类型，并写出其和。**

<details><summary>▶ 展开答案</summary>

取绝对值得调和级数 $\sum\frac{1}{n}$，**发散**，故不绝对收敛。
原级数为交错级数，$u_n = \frac{1}{n}$ 单调递减且趋于 0，由莱布尼茨判别法**收敛**。
故它是**条件收敛**，且和为 $\ln 2$（由 $\ln(1+x) = \sum\frac{(-1)^{n-1}x^n}{n}$ 取 $x = 1$）。
</details>

**Q3. 求幂级数 $\displaystyle\sum_{n=1}^{\infty}\frac{x^n}{n}$ 的收敛域与和函数。**

<details><summary>▶ 展开答案</summary>

$\rho = \lim\left|\frac{a_{n+1}}{a_n}\right| = \lim\frac{n}{n+1} = 1$，故 $R = 1$，收敛区间为 $(-1, 1)$。
端点：$x = 1$ 得调和级数 $\sum\frac{1}{n}$ **发散**；$x = -1$ 得交错级数 $\sum\frac{(-1)^n}{n}$ **收敛**。
故收敛域为 $[-1, 1)$。
和函数：设 $S(x) = \sum\limits_{n=1}^{\infty}\frac{x^n}{n}$，逐项求导得 $S'(x) = \sum\limits_{n=1}^{\infty}x^{n-1} = \frac{1}{1-x}$（$|x| < 1$），
再由 $S(0) = 0$ 积分得 $S(x) = -\ln(1-x)$。该式在 $x = -1$ 处也成立，故

$$
S(x) = -\ln(1-x), \quad x \in [-1, 1).
$$
</details>

**Q4. 设 $f$ 以 $2\pi$ 为周期，在 $[-\pi, \pi)$ 上 $f(x) = x$。求其傅里叶级数在 $x = \pi$ 处的和。**

<details><summary>▶ 展开答案</summary>

$x = \pi$ 是周期的端点（也是 $f$ 的跳跃间断点），由狄利克雷收敛定理，级数在此收敛于左右极限的平均值：

$$
S(\pi) = \frac{f(-\pi^+) + f(\pi^-)}{2} = \frac{-\pi + \pi}{2} = \mathbf{0}.
$$

（顺带结论：由该展开可得 $\sum\limits_{n=1}^{\infty}\frac{(-1)^{n-1}}{2n-1} = \frac{\pi}{4}$。）
</details>

## 第11章 曲线积分

### 11.1 自查清单

- [ ] 能分清两类曲线积分：含 $ds$ 的是第一类（**与方向无关**），含 $dx, dy$ 的是第二类（**有向**）
- [ ] 能说清定限规则的差异：第一类下限 < 上限（固定）；第二类**下限 = 起点参数、上限 = 终点参数**，可大可小、绝不许对调
- [ ] 会第一类"一投、二代、三定限"，并写出 $ds$ 的三种形式（参数式 $\sqrt{x'^2+y'^2}dt$、直角式 $\sqrt{1+y'^2}dx$、极坐标 $\sqrt{r^2+(r')^2}d\theta$）
- [ ] 会用第一类对称性与**轮换对称性**（$L$ 关于 $y = x$ 对称时 $\int_L x^2ds = \int_L y^2ds = \frac{1}{2}\int_L(x^2+y^2)ds$）
- [ ] 会第二类参数化通用公式 $\int_\alpha^\beta[P(x(t),y(t))x'(t) + Q(x(t),y(t))y'(t)]dt$，**严格从起点积到终点**
- [ ] 会显函数 $y = y(x)$ 情形：$dy = y'(x)dx$，化为 $\int_a^b[P + Qy'(x)]dx$
- [ ] 能复述格林公式前提（$L$ **封闭**且取正向、区域在左、$P, Q$ 在 $D$ 上有一阶连续偏导）
- [ ] 会补线法：补坐标轴平行线段闭合成圈再用格林，最后**减去**辅助线上的积分
- [ ] 会挖洞法：区域内有奇点时挖小圆，若 $\frac{\partial Q}{\partial x} \equiv \frac{\partial P}{\partial y}$ 则**大圈积分 = 同向小圈积分**
- [ ] 能说出路径无关条件（**单连通** + $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$）与六大等价命题
- [ ] 会用全微分求积找原函数 $u(x,y) = \int_{x_0}^{x}P(t,y_0)dt + \int_{y_0}^{y}Q(x,t)dt$，并用 $u$ 的端点差算积分
- [ ] 会用斯托克斯公式，并用**右手法则**把曲线方向与曲面侧别绑定
- [ ] 会算空间曲线积分（参数化）以及空间曲线在坐标面上的投影

### 11.2 易错点 · 高频陷阱

- 两类积分最本质的区别是方向性：第一类 $\int_{AB} = \int_{BA}$，第二类 $\int_{AB} = -\int_{BA}$；第二类**绝不许**为了"下小上大"而对调上下限。
- 格林公式要求 $L$ **封闭且取正向**（沿边界走区域在左侧，即逆时针）；方向取反则整体变号，不封闭则不能直接用。
- 补线法最后**必须减去**辅助线上的积分，漏减是最常见的失分点。
- 挖洞法内圈必须与外圈**同向**（都逆时针），移项时的负号要小心。
- 路径无关的前提是**单连通区域**：区域内有奇点（如原点）时"偏导相等"推不出路径无关，必须先把奇点挖掉。
- 第一类曲线积分的定限**必须下限小于上限**（因 $ds \ge 0$）；对称性化简前先确认**曲线本身**对称。
- 斯托克斯公式的方向绑定靠**右手法则**（四指沿曲线方向弯曲，大拇指指向曲面正侧法向），$dydz$、$dzdx$、$dxdy$ 前的正负号全由此决定。

### 11.3 自测问答

**Q1. 计算 $\displaystyle\oint_L x\,dy - y\,dx$，其中 $L$ 为圆周 $x^2+y^2 = a^2$ 取逆时针方向。**

<details><summary>▶ 展开答案</summary>

取 $P = -y$、$Q = x$，则 $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 1 - (-1) = 2$。由格林公式：

$$
\oint_L x\,dy - y\,dx = \iint_D 2\,d\sigma = 2\pi a^2.
$$

（这正是"二倍面积"公式：$A = \frac{1}{2}\oint_L x\,dy - y\,dx$。）
</details>

**Q2. 计算 $\displaystyle\int_L 2xy\,dx + x^2\,dy$，其中 $L$ 是从 $(0,0)$ 到 $(1,1)$ 沿 $y = x^2$ 的一段。**

<details><summary>▶ 展开答案</summary>

$P = 2xy$、$Q = x^2$，$\frac{\partial P}{\partial y} = 2x = \frac{\partial Q}{\partial x}$，且全平面单连通，故积分与路径无关。
取原函数 $u(x,y) = x^2y$（$du = 2xy\,dx + x^2dy$），于是

$$
\int_L 2xy\,dx + x^2\,dy = u(1,1) - u(0,0) = 1 - 0 = \mathbf{1}.
$$

（直接参数化复核：$y = x^2$、$dy = 2x\,dx$，$\int_0^1(2x\cdot x^2 + x^2\cdot 2x)dx = \int_0^1 4x^3dx = 1$ ✓）
</details>

**Q3. 计算 $\displaystyle\int_L (x^2+y^2)\,ds$，其中 $L$ 为圆周 $x^2+y^2 = a^2$。**

<details><summary>▶ 展开答案</summary>

在 $L$ 上被积函数恒等于 $a^2$，而 $L$ 的长度为 $2\pi a$，故

$$
\int_L (x^2+y^2)\,ds = a^2\cdot 2\pi a = 2\pi a^3.
$$

（也可用轮换对称：$\int_L x^2ds = \int_L y^2ds = \frac{1}{2}\int_L(x^2+y^2)ds = \pi a^3$，两者各占一半 ✓）
</details>

**Q4. 计算 $\displaystyle\oint_L \frac{x\,dy - y\,dx}{x^2+y^2}$，其中 $L$ 是包围原点的任一逆时针闭曲线。**

<details><summary>▶ 展开答案</summary>

取 $P = \frac{-y}{x^2+y^2}$、$Q = \frac{x}{x^2+y^2}$，直接计算得
$\frac{\partial P}{\partial y} = \frac{y^2-x^2}{(x^2+y^2)^2} = \frac{\partial Q}{\partial x}$（原点除外）。
原点为奇点，用**挖洞法**换成同向的单位圆 $x^2+y^2 = 1$：在被积函数分母化为 1，得

$$
\oint_L \frac{x\,dy - y\,dx}{x^2+y^2} = \oint_{x^2+y^2=1} (x\,dy - y\,dx) = 2\times\pi\times 1^2 = 2\pi.
$$

（对半径为 $\varepsilon$ 的小圆一般地有积分值 $2\pi$，与 $\varepsilon$ 无关。）
</details>

## 第12章 曲面积分

### 12.1 自查清单

- [ ] 能分清两类曲面积分：含 $dS$ 的是第一类（**与侧无关**，投影只看"影子"），含 $dydz + dzdx + dxdy$ 的是第二类（**换侧必变号**）
- [ ] 能写出两类互化式：$\iint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy = \iint_\Sigma(P\cos\alpha + Q\cos\beta + R\cos\gamma)\,dS$
- [ ] 拿到第二类题**先圈出"取外侧/上侧"**，明确法向量与坐标轴正向成锐角（正侧）还是钝角（负侧）
- [ ] 会用第一类对称性（关于 $xOy$ 面对称看 $z$ 的奇偶）与**轮换对称的 $\frac{1}{3}$ 技巧**处理高次项
- [ ] 会第一类"一投、二代、三算"：$dS = \sqrt{1 + z_x^2 + z_y^2}\,dxdy$（**伸缩因子别漏**）
- [ ] 会投影到 $yOz$、$zOx$ 面的处理：把曲面改写成 $x = x(y,z)$、$y = y(x,z)$，换成对应的两个偏导
- [ ] 会第二类"一投、二代、**三定号**"：法向量与 $z$ 轴正向成锐角（上侧）取正、钝角（下侧）取负
- [ ] 能复述高斯公式前提（曲面**封闭**、取**外侧**、$P, Q, R$ 在 $\Omega$ 内有一阶连续偏导）
- [ ] 会补面法：优先补在坐标面上（$z = 0$ 等使被积函数化简），原积分 = 高斯三重积分 **−** 补面积分
- [ ] 会挖洞法：挖小球面，夹层区域用高斯；**散度恒为 0 时大曲面通量 = 小球面通量**
- [ ] 知道点源场（分母含 $(x^2+y^2+z^2)^{\frac{3}{2}}$ 且过原点）的秒杀结论：包围奇点的任意闭曲面通量为常数（通常为 $4\pi$）
- [ ] 会算曲面面积（第一类中取 $f \equiv 1$）与利用对称性简化计算

### 12.2 易错点 · 高频陷阱

- 第二类曲面积分**换侧必变号**（$\iint_{\Sigma^+} = -\iint_{\Sigma^-}$），第一类则与侧无关——动笔前先把"外侧/上侧"圈出来。
- 第一类曲面积分**必须乘伸缩因子** $dS = \sqrt{1 + z_x^2 + z_y^2}\,dxdy$，漏掉结果必错。
- 直接投影法要"**每项各投各面、各定各号**"：$dxdy$ 看 $z$ 轴（上正下负）、$dydz$ 看 $x$ 轴、$dzdx$ 看 $y$ 轴。
- 高斯公式前提"**封闭 + 外侧**"缺一不可：曲面不封闭要先补面（**结果要减去补面积分**）；题目给内侧则整体先添负号。
- 补面时"原曲面的侧"与"补面的侧"要**各自独立判断**（高斯要求立体外侧），别把两者的正负号混用。
- 挖洞后内球面作为夹层立体的外侧**指向球心**；散度为 0 的场换小球面算通量，别在大曲面上硬算。
- 第一类曲面积分的对称性是第一反应，但前提是**曲面本身对称**；轮换对称要配 $\frac{1}{3}$ 技巧才有效。

### 12.3 自测问答

**Q1. 计算 $\displaystyle\iint_\Sigma (x^2+y^2)\,dS$，其中 $\Sigma$ 是单位球面 $x^2+y^2+z^2 = 1$ 的上半部分（$z \ge 0$）。**

<details><summary>▶ 展开答案</summary>

用球面坐标，单位球面上 $x^2+y^2 = \sin^2\varphi$、$dS = \sin\varphi\,d\varphi d\theta$（$r = 1$）：

$$
\iint_\Sigma (x^2+y^2)\,dS = \int_0^{2\pi}d\theta\int_0^{\frac{\pi}{2}}\sin^2\varphi\cdot\sin\varphi\,d\varphi = 2\pi\cdot\frac{2}{3} = \frac{4\pi}{3},
$$

其中 $\int_0^{\frac{\pi}{2}}\sin^3\varphi\,d\varphi = \frac{2!!}{3!!} = \frac{2}{3}$（华里士公式）。
（投影法复核：$dS = \frac{dxdy}{z}$ 且 $z = \sqrt{1-\rho^2}$，被积函数化为 $\frac{\rho^2}{\sqrt{1-\rho^2}}$，令 $\rho = \sin t$ 得 $2\pi\int_0^{\frac{\pi}{2}}\sin^3t\,dt = \frac{4\pi}{3}$，与球面坐标一致 ✓）
</details>

**Q2. 计算 $\displaystyle\iint_\Sigma x\,dydz + y\,dzdx + z\,dxdy$，其中 $\Sigma$ 为单位球面取外侧。**

<details><summary>▶ 展开答案</summary>

$P = x$、$Q = y$、$R = z$，散度 $\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z} = 3$。曲面封闭且取外侧，由高斯公式：

$$
\iint_\Sigma x\,dydz + y\,dzdx + z\,dxdy = \iiint_\Omega 3\,dV = 3\times\frac{4\pi}{3} = 4\pi.
$$

（几何复核：在单位球面上 $\vec{F}\cdot\vec{n} = (x,y,z)\cdot(x,y,z) = 1$，通量即球面积 $4\pi$ ✓）
</details>

**Q3. 计算 $\displaystyle\iint_\Sigma z\,dxdy$，其中 $\Sigma$ 是 $z = x^2+y^2$ 被 $z = 1$ 截得的部分，取下侧（法向量朝下）。**

<details><summary>▶ 展开答案</summary>

投影区域 $D: x^2+y^2 \le 1$。因取**下侧**（法向量与 $z$ 轴正向成钝角），定号为负：

$$
\iint_\Sigma z\,dxdy = -\iint_D (x^2+y^2)\,dxdy = -\int_0^{2\pi}d\theta\int_0^1 \rho^2\cdot\rho\,d\rho = -2\pi\cdot\frac{1}{4} = -\frac{\pi}{2}.
$$
</details>

**Q4. 计算 $\displaystyle\iint_\Sigma x\,dydz + y\,dzdx + z\,dxdy$，其中 $\Sigma$ 是上半球面 $z = \sqrt{1-x^2-y^2}$ 取上侧。**

<details><summary>▶ 展开答案</summary>

$\Sigma$ 不封闭，补上圆盘 $\Sigma_1: z = 0\ (x^2+y^2 \le 1)$ 取下侧（对上半球立体而言朝外）。
在封闭曲面（上半球面外侧 + 圆盘下侧）上用高斯公式，散度为 3，立体体积为 $\frac{1}{2}\cdot\frac{4\pi}{3} = \frac{2\pi}{3}$：

$$
\iint_{\Sigma+\Sigma_1} = 3\times\frac{2\pi}{3} = 2\pi.
$$

在 $\Sigma_1$ 上 $z = 0$，故 $\vec{F}\cdot\vec{n} = (x,y,0)\cdot(0,0,-1) = 0$，补面通量为 0。
于是 $\displaystyle\iint_\Sigma = 2\pi - 0 = \mathbf{2\pi}$。

（几何复核：单位球面上 $\vec{F}\cdot\vec{n} = 1$，上半球面面积 $2\pi$，通量即 $2\pi$ ✓）
