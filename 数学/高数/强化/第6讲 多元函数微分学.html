第6讲 多元函数微分学

第六讲 多元函数微分学及其应用

来源：27届考研强化阶段《高等数学》（主讲：崔怀垒） 题型：连续/偏导/全微分概念 | 偏导数计算 | 三大值计算

（一）多元函数连续、偏导数与全微分

一、二元函数极限

\[ \lim_{(x,y) \to (x_0, y_0)} f(x,y) = A \]

要求 \((x,y)\) 沿任意路径趋于 \((x_0, y_0)\) 时，极限都为 \(A\)。

1. 极限不存在的验证

选取不同路径得到不同极限值，即可证明极限不存在。

常用路径： - \(y = kx\)（不同斜率） - \(y = kx^2\) - \(x = ky^2\) - 沿坐标轴 \(x = 0\) 或 \(y = 0\)

2. 计算方法
  • 夹逼准则：无穷小量 \(\times\) 有界量 = 无穷小
  • 等价无穷小替换、泰勒公式（与一元类似）

【例】 \(\lim_{(x,y) \to (0,0)} \frac{xy}{x^2 + y^2}\)

沿 \(y = kx\)：极限 \(= \frac{k}{1+k^2}\)，与 \(k\) 有关 → 极限不存在

二、二元函数连续

\[ f(x,y) \text{ 在 } (x_0, y_0) \text{ 连续} \iff \lim_{(x,y) \to (x_0,y_0)} f(x,y) = f(x_0, y_0) \]

三、偏导数

\[ f'_x(x_0, y_0) = \lim_{x \to x_0} \frac{f(x, y_0) - f(x_0, y_0)}{x - x_0} \]

求偏导时：将另一个变量视为常数，按一元函数求导

分段函数在分段点的偏导数：用定义求

四、可微与全微分

\[ \Delta z = f'_x(x_0, y_0) \Delta x + f'_y(x_0, y_0) \Delta y + o(\rho) \]

其中 \(\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}\)

\[ dz = f'_x\,dx + f'_y\,dy \]

可微的判定
条件 结论
偏导数不存在 不可微
偏导数存在但不连续 不一定可微，需用定义
偏导数连续 一定可微

可微的定义法验证：

\[ \lim_{\rho \to 0} \frac{\Delta z - [f'_x \Delta x + f'_y \Delta y]}{\rho} = 0 \]

若极限为 \(0\) 则可微，否则不可微

关系总结
偏导连续 → 可微 → 连续
                → 偏导存在
可微 ⇏ 偏导连续
连续 ⇏ 偏导存在
偏导存在 ⇏ 连续

（二）偏导数的计算

一、复合函数求偏导

设 \(z = f(u, v)\)，\(u = u(x,y)\)，\(v = v(x,y)\)，则

\[ \frac{\partial z}{\partial x} = \frac{\partial f}{\partial u} \cdot \frac{\partial u}{\partial x} + \frac{\partial f}{\partial v} \cdot \frac{\partial v}{\partial x} \]

\[ \frac{\partial z}{\partial y} = \frac{\partial f}{\partial u} \cdot \frac{\partial u}{\partial y} + \frac{\partial f}{\partial v} \cdot \frac{\partial v}{\partial y} \]

链式法则：画出变量依赖关系图，沿路径求导再求和

抽象复合函数：用 \(f'_1, f'_2\) 等记号表示对各中间变量的偏导

【例6】 设 \(z = f(xy, x^2 - y^2) + g(x+y, x-y)\)，其中 \(f\) 二阶可导，\(g\) 有二阶连续偏导数，求 \(\frac{\partial^2 z}{\partial x \partial y}\)。

【例7】 设 \(f(x+1, e^x) = x(x+1)\)，\(f(x, x^2) = 2x^2 \ln x\)，求 \(df(1,1)\)。

方法：对已知等式两边关于 \(x\) 求导，代入特定点，解方程组求 \(f'_1(1,1)\) 和 \(f'_2(1,1)\)

二、隐函数求偏导

1. 方程法（两边同求偏导）

由 \(F(x, y, z) = 0\) 确定 \(z = z(x,y)\)：

两边对 \(x\) 求偏导（\(z\) 视为 \(x\) 的函数）：

\[ F_x + F_z \cdot \frac{\partial z}{\partial x} = 0 \implies \frac{\partial z}{\partial x} = -\frac{F_x}{F_z} \]

2. 公式法

\[ \frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \quad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z} \]

【例10】 设 \(x^2 + y^2 + z^2 = \int_0^{x+y} f(x+y-t)\,dt\)，求 \(\frac{\partial z}{\partial x}\) 和 \(\frac{\partial z}{\partial y}\)。

换元 \(u = x+y-t\) 化简积分后，再求偏导

三、高阶偏导数

若 \(f(x,y)\) 的二阶混合偏导数连续，则

\[ \frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x} \]

求高阶偏导：注意求导顺序，利用连续性简化

【例8】 已知 \(u = u(x,y)\) 满足方程，求常数 \(\alpha, \beta\)，使通过变换后方程化简。

方法：做变量替换 \(u = v \cdot e^{\alpha x + \beta y}\)，代入化简

【例9】 设 \(z = f(u,v)\)，\(u = x - 2y\)，\(v = x + 2y\)，且 \(\frac{\partial^2 z}{\partial x^2} + \frac{\partial^2 z}{\partial y^2} = 0\)，求 \(\frac{\partial^2 z}{\partial u \partial v}\)。

利用链式法则将 \(\frac{\partial^2 z}{\partial x^2}, \frac{\partial^2 z}{\partial y^2}\) 用 \(f\) 对 \(u, v\) 的偏导表示

（三）三大值的计算

一、一般极值

1. 必要条件

若 \((x_0, y_0)\) 为极值点且偏导存在，则

\[ f'_x(x_0, y_0) = 0, \quad f'_y(x_0, y_0) = 0 \]

即 \((x_0, y_0)\) 为驻点

2. 充分条件（\(A, B, C\) 判别法）

设 \(A = f''_{xx}\)，\(B = f''_{xy}\)，\(C = f''_{yy}\)，\(\Delta = AC - B^2\)

条件 结论
\(\Delta > 0\)，\(A > 0\) 极小值点
\(\Delta > 0\)，\(A < 0\) 极大值点
\(\Delta < 0\) 非极值点（鞍点）
\(\Delta = 0\) 不确定，用定义法

步骤： 1. 求驻点：\(f'_x = 0, f'_y = 0\) 2. 求 \(A, B, C\) 3. 计算 \(\Delta = AC - B^2\) 判定

二、条件极值

1. 代入消元法

由约束 \(\varphi(x,y) = 0\) 解出 \(y = y(x)\)，代入目标函数化为一元问题。

2. 拉格朗日乘数法

构造拉格朗日函数：

\[ L(x, y, \lambda) = f(x,y) + \lambda \varphi(x,y) \]

求偏导：

\[ \begin{cases} L_x = f_x + \lambda \varphi_x = 0 \\ L_y = f_y + \lambda \varphi_y = 0 \\ L_\lambda = \varphi(x,y) = 0 \end{cases} \]

消 \(\lambda\) 技巧：前两式相除或交叉相乘

两个约束条件：\(L = f + \lambda \varphi + \mu \psi\)

【例12】 求 \(u = x^2 + y^2 + z^2\) 在约束 \(x + y + z = 1\)，\(z = x^2 + y^2\) 下的最值。

构造 \(L = x^2+y^2+z^2 + \lambda(x+y+z-1) + \mu(z-x^2-y^2)\)，求解方程组

三、区域最值

步骤： 1. 内部：求驻点（无条件极值），计算函数值 2. 边界：用拉格朗日乘数法或参数化求条件极值 3. 比较所有候选点的函数值，确定最大值和最小值

【例13】 设 \(f''_{xx}(x,y) = 2\)，\(f'_x(x,0) = 2x-4\)，\(f(0,y) = -y\)

  1. 求 \(f(x,y)\)

  2. 求 \(f(x,y)\) 在区域 \(D = \{(x,y) \mid x+y \leq 4, y \geq 0, x \geq 0\}\) 上的最值

  1. 对 \(f''_{xx} = 2\) 积分两次，利用初始条件确定常数

  2. 内部驻点 + 三条边界分别讨论
