（三）一元函数积分学

来源：27届考研强化阶段《高等数学》（主讲：崔怀垒） 课时：7课时 | 题型：6种

一、题型总览

二、题型一：不定积分的计算

1. 概念

(1) 原函数

F′(x)=f(x)⟹F(x) 是 f(x) 的一个原函数
  • 同一区间上两个原函数只差一个常数
  • 特性：原函数在定义区间上连续

(2) 不定积分

f(x) 的所有原函数的全体 F(x)+C 为 f(x) 的不定积分：

∫f(x)dx=F(x)+C

注意：不要漏掉 +C

2. 性质
∫kf(x)dx=k∫f(x)dx
∫[f(x)±g(x)]dx=∫f(x)dx±∫g(x)dx

基本积分公式（部分）：

∫xαdx=xα+1α+1+C(α≠−1)
∫1xdx=ln⁡|x|+C
∫eaxdx=1aeax+C
∫11+x2dx=arctan⁡x+C
∫11−x2dx=arcsin⁡x+C
∫sec2⁡xdx=tan⁡x+C
∫sec⁡xtan⁡xdx=sec⁡x+C
∫sec⁡xdx=ln⁡|sec⁡x+tan⁡x|+C
∫csc⁡xdx=ln⁡|csc⁡x−cot⁡x|+C
∫1a2+x2dx=1aarctan⁡xa+C
∫1a2−x2dx=arcsin⁡xa+C
∫1x2±a2dx=ln⁡|x+x2±a2|+C
3. 计算方法（3种）
(1) 凑微分法（第一换元法）

核心：将被积表达式凑成 f(φ(x))d(φ(x)) 的形式

∫f(φ(x))φ′(x)dx=∫f(u)du=F(u)+C=F(φ(x))+C

常见凑微分：

xdx=12d(x2),cos⁡xdx=d(sin⁡x)
exdx=d(ex),1xdx=d(ln⁡x)
1cos2⁡xdx=d(tan⁡x),11+x2dx=d(arctan⁡x)
(2) 换元积分法（第二换元法）

适用：被积函数含根式

三角代换回代时，画直角三角形辅助

其他代换：

  • ax+bn：令 t=ax+bn
  • a2−(x−c)2：先配方再代换
  • 根式下为一次式：整体代换
  • 根式下为二次式：三角代换
(3) 分部积分法
∫udv=uv−∫vdu

选择原则（口诀：反对幂指三，靠前选作 u，靠后选作 v′）：

对于 eaxsin⁡bx 或 eaxcos⁡bx 型，分部两次后出现循环等式，解方程即可

典型例题

【例1】 求不定积分（凑微分 + 换元）

涉及 ex−1 等根式，令 t=ex−1

【例2】 求不定积分 ∫arccos⁡x1−x2dx

凑微分：dx1−x2=d(arcsin⁡x)

【例3】 已知 ln2⁡x 是 f(x) 的一个原函数，求 ∫xf(x)dx

分部积分：∫xf(x)dx=xf(x)−∫f(x)dx

f(x)=(ln2⁡x)′=2ln⁡xx

【例4】 设 f(t) 在 (1,+∞) 内可导，且 f(e)=0，又

xf′(x)={ln⁡x,0<x≤11x,x>1

求 f(x)

分段积分 + 利用连续性确定常数

【例5】（有理函数积分）求 ∫5x+6x2+5x+6dx

部分分式分解：5x+6(x+2)(x+3)=Ax+2+Bx+3

【例6】 求 ∫sin⁡xsin⁡x+cos⁡xdx

方法：分母同乘共轭，或利用 ∫sin⁡xsin⁡x+cos⁡xdx+∫cos⁡xsin⁡x+cos⁡xdx=x

有理函数积分补充

∫sinn⁡xcosm⁡xdx 的处理：

  1. n,m 中有一个奇数：将奇次的拆一个出来凑微分

    • 如 n 为奇：sinn⁡xcosm⁡xdx=sinn−1⁡xcosm⁡x⋅sin⁡xdx=−(1−cos2⁡x)n−12cosm⁡xd(cos⁡x)

  2. n,m 均为偶数：用倍角公式降幂

    • sin2⁡x=1−cos⁡2x2，cos2⁡x=1+cos⁡2x2
    • sin⁡xcos⁡x=12sin⁡2x

有理函数积分：

  • 若 Pn(x)Qm(x)，n<m（真分式）：部分分式分解
  • 若 n≥m（假分式）：先用多项式除法化为真分式
  • 分解后出现 1(ax+b)k 或 Ax+B(x2+px+q)k，分别用基本公式积分
