（三）一元函数积分学

来源：27届考研强化阶段《高等数学》（主讲：崔怀垒） 课时：7课时 | 题型：6种

一、题型总览

题型 考查形式 重要程度
题型一：不定积分的计算 小题/大题 必考
题型二：定积分的计算 小题 必考
题型三：积分等式与不等式的证明 大题 常考
题型四：变限积分的运算 小题 常考
题型五：反常积分的计算 小题 常考
题型六：定积分的应用 大题 常考

二、题型一：不定积分的计算

1. 概念

(1) 原函数

\[ F'(x) = f(x) \implies F(x) \text{ 是 } f(x) \text{ 的一个原函数} \]

  • 同一区间上两个原函数只差一个常数
  • 特性：原函数在定义区间上连续

(2) 不定积分

\(f(x)\) 的所有原函数的全体 \(F(x) + C\) 为 \(f(x)\) 的不定积分：

\[ \int f(x)\,dx = F(x) + C \]

注意：不要漏掉 \(+C\)

2. 性质

\[ \int k f(x)\,dx = k \int f(x)\,dx \]

\[ \int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx \]

基本积分公式（部分）：

\[ \int x^\alpha\,dx = \frac{x^{\alpha+1}}{\alpha+1} + C \quad (\alpha \neq -1) \]

\[ \int \frac{1}{x}\,dx = \ln|x| + C \]

\[ \int e^{ax}\,dx = \frac{1}{a}e^{ax} + C \]

\[ \int \frac{1}{1+x^2}\,dx = \arctan x + C \]

\[ \int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x + C \]

\[ \int \sec^2 x\,dx = \tan x + C \]

\[ \int \sec x \tan x\,dx = \sec x + C \]

\[ \int \sec x\,dx = \ln|\sec x + \tan x| + C \]

\[ \int \csc x\,dx = \ln|\csc x - \cot x| + C \]

\[ \int \frac{1}{a^2+x^2}\,dx = \frac{1}{a}\arctan\frac{x}{a} + C \]

\[ \int \frac{1}{\sqrt{a^2-x^2}}\,dx = \arcsin\frac{x}{a} + C \]

\[ \int \frac{1}{\sqrt{x^2 \pm a^2}}\,dx = \ln|x + \sqrt{x^2 \pm a^2}| + C \]

3. 计算方法（3种）
(1) 凑微分法（第一换元法）

核心：将被积表达式凑成 \(f(\varphi(x))\,d(\varphi(x))\) 的形式

\[ \int f(\varphi(x)) \varphi'(x)\,dx = \int f(u)\,du = F(u) + C = F(\varphi(x)) + C \]

常见凑微分：

\[ x\,dx = \frac{1}{2}d(x^2), \quad \cos x\,dx = d(\sin x) \]

\[ e^x\,dx = d(e^x), \quad \frac{1}{x}\,dx = d(\ln x) \]

\[ \frac{1}{\cos^2 x}\,dx = d(\tan x), \quad \frac{1}{1+x^2}\,dx = d(\arctan x) \]

(2) 换元积分法（第二换元法）

适用：被积函数含根式

根式类型 代换 恒等式
\(\sqrt{a^2 - x^2}\) \(x = a\sin t\) \(\sin^2 t + \cos^2 t = 1\)
\(\sqrt{x^2 + a^2}\) \(x = a\tan t\) \(1 + \tan^2 t = \sec^2 t\)
\(\sqrt{x^2 - a^2}\) \(x = a\sec t\) \(\sec^2 t - 1 = \tan^2 t\)

三角代换回代时，画直角三角形辅助

其他代换： - \(\sqrt[n]{ax+b}\)：令 \(t = \sqrt[n]{ax+b}\) - \(\sqrt{a^2 - (x-c)^2}\)：先配方再代换 - 根式下为一次式：整体代换 - 根式下为二次式：三角代换

(3) 分部积分法

\[ \int u\,dv = uv - \int v\,du \]

选择原则（口诀：反对幂指三，靠前选作 \(u\)，靠后选作 \(v'\)）：

函数类型 优先级
反三角函数 选 \(u\)
对数函数 选 \(u\)
幂函数 中间
指数函数 选 \(dv\)
三角函数 选 \(dv\)

对于 \(e^{ax}\sin bx\) 或 \(e^{ax}\cos bx\) 型，分部两次后出现循环等式，解方程即可

典型例题

【例1】 求不定积分（凑微分 + 换元）

涉及 \(\sqrt{e^x - 1}\) 等根式，令 \(t = \sqrt{e^x - 1}\)

【例2】 求不定积分 \(\int \frac{\arccos x}{\sqrt{1-x^2}}\,dx\)

凑微分：\(\frac{dx}{\sqrt{1-x^2}} = d(\arcsin x)\)

【例3】 已知 \(\ln^2 x\) 是 \(f(x)\) 的一个原函数，求 \(\int x f(x)\,dx\)

分部积分：\(\int x f(x)\,dx = x f(x) - \int f(x)\,dx\)

\(f(x) = (\ln^2 x)' = \frac{2\ln x}{x}\)

【例4】 设 \(f(t)\) 在 \((1,+\infty)\) 内可导，且 \(f(e) = 0\)，又

\[ x f'(x) = \begin{cases} \ln x, & 0 < x \leq 1 \\ \frac{1}{x}, & x > 1 \end{cases} \]

求 \(f(x)\)

分段积分 + 利用连续性确定常数

【例5】（有理函数积分）求 \(\int \frac{5x+6}{x^2+5x+6}\,dx\)

部分分式分解：\(\frac{5x+6}{(x+2)(x+3)} = \frac{A}{x+2} + \frac{B}{x+3}\)

【例6】 求 \(\int \frac{\sin x}{\sin x + \cos x}\,dx\)

方法：分母同乘共轭，或利用 \(\int \frac{\sin x}{\sin x + \cos x}\,dx + \int \frac{\cos x}{\sin x + \cos x}\,dx = x\)

有理函数积分补充

\(\int \sin^n x \cos^m x\,dx\) 的处理：

  1. \(n, m\) 中有一个奇数：将奇次的拆一个出来凑微分
    • 如 \(n\) 为奇：\(\sin^n x \cos^m x\,dx = \sin^{n-1} x \cos^m x \cdot \sin x\,dx = -(1-\cos^2 x)^{\frac{n-1}{2}} \cos^m x \, d(\cos x)\)
  2. \(n, m\) 均为偶数：用倍角公式降幂
    • \(\sin^2 x = \frac{1-\cos 2x}{2}\)，\(\cos^2 x = \frac{1+\cos 2x}{2}\)
    • \(\sin x \cos x = \frac{1}{2}\sin 2x\)

有理函数积分：

  • 若 \(\frac{P_n(x)}{Q_m(x)}\)，\(n < m\)（真分式）：部分分式分解
  • 若 \(n \geq m\)（假分式）：先用多项式除法化为真分式
  • 分解后出现 \(\frac{1}{(ax+b)^k}\) 或 \(\frac{Ax+B}{(x^2+px+q)^k}\)，分别用基本公式积分
