第2讲 一元函数微分学（续）

题型四：导数的几何应用

一、单调性

若 \(f'(x) > 0\)，\(x \in I\)，则 \(f(x)\) 在 \(I\) 上单调递增

若 \(f'(x) < 0\)，\(x \in I\)，则 \(f(x)\) 在 \(I\) 上单调递减

注意：\(f'(x) \geq 0\) 且 \(f'(x) = 0\) 只在孤立点处成立，仍为单调递增

二、极值

(1) 极值的定义

若 \(\forall x \in U(x_0)\) 有 \(f(x) < f(x_0)\)（或 \(f(x) > f(x_0)\)），则称 \(x_0\) 为极大（或极小）值点，\(f(x_0)\) 为极大（或极小）值。

口诀：可导极值点一定是驻点

可疑点（可能为极值点的位置）： - 驻点（\(f'(x_0) = 0\)） - 不可导点 - 分段点 - 无定义点（端点处不取极值，但有可能取到最值）

求最值：求所有极值点 + 端点，代入函数值比较大小

(2) 极值的必要条件

若 \(f(x)\) 在 \(x_0\) 处可导，且 \(x_0\) 为极值点，则

\[ f'(x_0) = 0 \quad (\text{即 } x_0 \text{ 为驻点}) \]

(3) 极值的充分条件

第一充分条件

若 \(f(x)\) 在 \(x = x_0\) 连续，且在 \(x_0\) 左右邻域内 \(f'(x)\) 符号相反，则 \(x_0\) 为极值点。

\(f'(x)\) 的符号变化 极值类型
\(+ \to -\) 极大值点
\(- \to +\) 极小值点
\(+ \to +\) 或 \(- \to -\) 非极值点

口诀：单调性发生改变的临界点就是极值点

第二充分条件

若 \(f'(x_0) = 0\) 且 \(f''(x_0) \neq 0\)，则 \(x_0\) 为极值点：

  • \(f''(x_0) > 0\)：\(x_0\) 为极小值点
  • \(f''(x_0) < 0\)：\(x_0\) 为极大值点

若 \(f''(x_0) = 0\)，第二充分条件失效，需回到第一充分条件

极值判断流程： 1. 找可疑点：驻点 + 不可导点 2. 判定：用第一或第二充分条件

三、凹凸性与拐点

(1) 凹凸性判定

\[ f''(x) > 0 \implies \text{凹（上凹）} \]

\[ f''(x) < 0 \implies \text{凸（上凸）} \]

口诀：大二小凸（\(f'' > 0\) 凹，\(f'' < 0\) 凸）

(2) 拐点

拐点：凹凸性发生改变的临界点 \((x_0, f(x_0))\)

注意：拐点是一个点 \((x_0, f(x_0))\)，不是 \(x_0\)

可疑点（可能为拐点的位置）： - \(f''(x) = 0\) 的点 - \(f''(x)\) 不存在的点 - \(f(x)\) 无定义的点

(3) 拐点的必要条件

若 \(f(x)\) 在 \(x_0\) 处二阶可导，且 \((x_0, f(x_0))\) 为拐点，则

\[ f''(x_0) = 0 \]

口诀：可导拐点一定是二阶驻点

(4) 拐点的充分条件

第一充分条件

若 \(f(x)\) 在 \(x_0\) 左右邻域内 \(f''(x)\) 符号相反，则 \((x_0, f(x_0))\) 为拐点。

第二充分条件

若 \(f''(x_0) = 0\) 且 \(f'''(x_0) \neq 0\)，则 \((x_0, f(x_0))\) 是拐点。

若 \(f'''(x_0) = 0\)，失效，回到第一充分条件

拐点判断流程： 1. 找可疑点：\(f''(x) = 0\) 的点 + \(f''(x)\) 不存在的点 2. 判定：用第一或第二充分条件

四、渐近线

(1) 铅直渐近线

若 \(\lim_{x \to a} f(x) = \infty\)，则 \(x = a\) 为铅直渐近线

找 \(f(x)\) 的无定义点

(2) 水平渐近线

若 \(\lim_{x \to +\infty} f(x) = A\)（或 \(x \to -\infty\)），则 \(y = A\) 为水平渐近线

(3) 斜渐近线

若 \(\lim_{x \to +\infty} f(x) = \infty\)，计算：

\[ k = \lim_{x \to +\infty} \frac{f(x)}{x}, \quad b = \lim_{x \to +\infty} [f(x) - kx] \]

若 \(k, b\) 均存在且 \(k \neq 0\)，则 \(y = kx + b\) 为斜渐近线

重要：相同趋向（如 \(x \to +\infty\)）下，水平渐近线与斜渐近线不可能同时存在

若 \(\lim_{x \to +\infty} f(x) = A\)（有限值），则 \(y = A\) 为水平渐近线，且该方向无斜渐近线

【例22】 曲线 \(y = x \ln\left|1 + \frac{1}{x}\right|\) 的渐近线有（ ）条

分析：铅直（\(x = 0\)）、水平/斜（\(x \to \pm\infty\)）

五、曲率（数一、数二）

曲率公式

\[ K = \frac{|y''|}{(1 + y'^2)^{3/2}} \]

曲率半径：\(R = \frac{1}{K}\)

曲率圆：在点 \((x_0, y_0)\) 处，圆心 \((x_0 - y'_0 \frac{1+y'^2_0}{y''_0},\; y_0 + \frac{1+y'^2_0}{y''_0})\)，半径 \(R\)

参数方程形式：若曲线由 \(x = x(t), y = y(t)\) 确定，在 \(t = t_0\) 处

\[ K = \frac{|x'(t_0)y''(t_0) - x''(t_0)y'(t_0)|}{[x'^2(t_0) + y'^2(t_0)]^{3/2}} \]

【例21】（数一、二）曲线 \(\begin{cases} x = \arctan t \\ y = \ln(1+t^2) \end{cases}\) 在 \(t=0\) 对应点处的曲率圆方程。

典型例题

【例20】 设 \(f(t)\) 连续且 \(f(t) > 0\)，\(f(-t) = f(t)\)，令

\[ F(x) = \int_{-a}^{a} |x - t| f(t)\,dt \quad (-a \leq x \leq a) \]

  1. 证明曲线 \(y = F(x)\) 在 \([-a, a]\) 上是凹的

  2. 当 \(x\) 为何值时，\(F(x)\) 取得最小值

  3. 若 \(F(x)\) 的最小值可表示为 \(f(a) - a^2 - 1\)，试求 \(f(t)\)

解法： (1) 去绝对值分段积分，求 \(F''(x) = 2f(x) > 0\) (2) \(F'(x) = 0 \Rightarrow x = 0\)（唯一极值点即最小值点） (3) 代入 \(F(0)\) 构造微分方程求解 \(f(t)\)

题型五：讨论方程根的个数

解题方法

问题：\(f(x) = 0\) 在区间 \(I\) 上有几个根？

方法一：研究 \(y = f(x)\) 的零点个数

  1. 求 \(f'(x)\)，找单调区间
  2. 在每个单调区间上用零点存在定理讨论

关键：区间端点代入函数值或求极限

方法二：将方程变形为 \(h(x) = k\)

即找 \(y = h(x)\) 与 \(y = k\)（水平线）的交点个数

步骤：求 \(h(x)\) 的单调区间 + 端点极值 → 画草图 → 数交点

典型例题

【例23】 设 \(k\) 为参数，确定方程 \(x^3 + 4x + 1 = ke^x\) 根的个数。

方法：变形为 \(k = (x^3 + 4x + 1)e^{-x}\)，研究 \(y = (x^3 + 4x + 1)e^{-x}\) 的图像

求导分析单调性和极值，与水平线 \(y = k\) 的交点： - \(k > 6e^{-2}\)：1个根 - \(k = 6e^{-2}\)：2个根 - \(0 < k < 6e^{-2}\)：3个根 - \(-e^{-1} < k \leq 0\)：2个根 - \(k = -e^{-1}\)：1个根 - \(k < -e^{-1}\)：无根

题型六：不等式证明

一、函数不等式证明

目标：证明 \(f(x) > g(x)\)，\(x \in (a,b)\)

步骤

  1. 化简：

    • 不等式两边有公因子 → 消去公因子
    • 不等式两边有分母 → 同乘分母

  2. 构造辅助函数：令 \(F(x) = f(x) - g(x)\)，证 \(F(x) > 0\)

  3. 证明：

    • 若 \(F(a) = 0\)（或 \(F(b) = 0\)）：利用单调性
      • \(F'(x) > 0\) 且 \(F(a) = 0 \implies F(x) > 0\)（\(x > a\)）
    • 若 \(F(a) = F(b) = 0\)：利用极值
      • 求导找极值点，求极值，证最小值 \(> 0\)

二、数值不等式证明

目标：证明 \(f(a,b) > g(a,b)\)，\(b > a\)

方法：将其中一个变量固定，转化为函数不等式

  • 令 \(F(x) = f(a,x) - g(a,x)\)，证 \(F(x) > 0\)（\(x \geq a\)）
  • 代入 \(x = b\) 即得结论

拉格朗日中值定理辅助：

若不等式中出现 \(f(b) - f(a)\)，利用

\[ f(b) - f(a) = f'(\xi)(b-a), \quad \xi \in (a,b) \]

再结合 \(f'(x)\) 的单调性放缩

【例24】 设 \(f(x)\) 是 \([0,1]\) 上二阶可导的正值函数，且 \(f(0)=1\)，\([f'(x)]^2 < f(x)f''(x)\)，判断：

  1. \(f(1) > f(0)\) → ✅

  2. \(f(1) < f(0)\) → ❌

  3. \(f'(1) > f'(0)\) → 需分析

  4. \(f'(1) < f'(0)\) → 需分析

方法：构造 \(G(x) = \frac{f'(x)}{f(x)}\)，利用 \(G'(x) > 0\)（单调递增）比较大小

【例25】 设 \(f(x)\) 在 \([0,a]\) 上二阶可导，且 \(|f''(x)| \leq M\)

  1. 若 \(f(0) = f(a) = 0\)，证明：\(\max|f(x)| \leq \frac{Ma^2}{8}\)

  2. 若 \(f(x)\) 在 \((0,a)\) 内取得极值，证明：\(|f'(0)| + |f'(a)| \leq Ma\)

方法：在 \(x=0\) 和 \(x=a\) 处泰勒展开

【例26】 设 \(x > 0\)，证明：\(\ln(1+x) + \frac{x}{1+x} > 1\)（\(x > 0\) 时某不等式）

方法：构造 \(F(x)\)，利用单调性 + 多次求导
