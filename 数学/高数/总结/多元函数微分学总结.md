一份全景式的"多元函数微分学核心概念与方法速查表"。在考场上，第一步永远是**辨析概念层级**（重极限？连续？偏导？可微？），第二步才是**套用计算框架**（链式法则、隐函数、拉格朗日乘数法）。

------

### （一）重极限与连续

- **定义核心**：动点以**任何方式**趋近于 $P_0$，函数值都趋于同一常数——比一元"左 + 右"严苛得多（路径有无穷多条）。
- **证不存在（极高频题型）**：找**两条路径**（$y = kx$、$y = kx^2$），沿路径极限不同、或极限含 $k$ ⟹ 重极限不存在。
- **求极限 / 证存在**：夹逼定理；**极坐标代换**（$x = r\cos\theta, y = r\sin\theta$，$r \to 0$ 时极限存在**且与 $\theta$ 无关**）；无穷小 × 有界。
- **连续**：$\lim\limits_{(x,y) \to (x_0,y_0)} f = f(x_0, y_0)$；多元初等函数在定义域内连续（无定义点外直接代值）；有界闭区域上连续 ⟹ 必有最值、必有界。

------

### （二）偏导数

- **计算本质**：对 $x$ 求偏导时**把 $y$ 视为常数**，完全按一元法则求导。
- **几何意义**：$f_x(x_0, y_0)$ = 截面曲线（$y = y_0$ 截曲面所得）在对应点的切线对 $x$ 轴的斜率。
- **混合偏导相等定理**：$\dfrac{\partial^2 z}{\partial x \partial y}$ 与 $\dfrac{\partial^2 z}{\partial y \partial x}$ **连续** ⟹ 相等（求导顺序可换，高阶求导化简利器）。
- **致命陷阱**：分段函数 / 绝对值函数在拼接点（如 $(0,0)$）的偏导**必须用定义** $\lim\limits_{x \to 0} \dfrac{f(x, 0) - f(0, 0)}{x}$，**不能**先求导函数再代入。

------

### （三）可微性与概念逻辑链（极高频考点）

#### 1. 可微的判定三步

1. 用定义求出 $f_x(x_0, y_0)$、$f_y(x_0, y_0)$；
2. 构造 $\Delta z - [f_x \Delta x + f_y \Delta y]$；
3. 验证极限：

$$
\lim_{(\Delta x, \Delta y) \to (0,0)} \frac{\Delta z - (f_x \Delta x + f_y \Delta y)}{\sqrt{\Delta x^2 + \Delta y^2}} \stackrel{?}{=} 0
$$

等于 $0$ ⟹ 可微；不为 $0$ 或不存在 ⟹ 不可微。

#### 2. 强弱关系（死记）

| 命题 | 真假 |
| --- | --- |
| 偏导数**连续** ⟹ 可微 | ✔（最强条件） |
| 可微 ⟹ 偏导数存在 | ✔ |
| 可微 ⟹ 连续 | ✔ |
| 偏导数存在 ⟹ 连续 | ✘（多元特有陷阱） |
| 连续 ⟹ 偏导数存在 | ✘ |
| 偏导数存在 ⟹ 可微 | ✘ |

> **口诀**：偏导连续必可微，可微必连续且偏导存在；连续与偏导存在互不推导。

- **一阶全微分形式不变性**：无论 $u, v$ 是自变量还是中间变量，$dz = f_u\,du + f_v\,dv$——隐函数、方程组求偏导的神技。
- 几何意义：可微 = 曲面在该点能被**切平面**平滑贴合（$dz$ 是切平面的纵坐标增量）。

------

### （四）复合函数与隐函数求导

#### 1. 链式法则

$$
\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial x}, \qquad \frac{\partial z}{\partial y} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial y} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial y}
$$

#### 2. 隐函数

- **单方程** $F(x, y, z) = 0$ 确定 $z = z(x, y)$：$\dfrac{\partial z}{\partial x} = -\dfrac{F_x}{F_z}$，$\dfrac{\partial z}{\partial y} = -\dfrac{F_y}{F_z}$（**负号别丢**）。
- **二阶偏导**：**不要**对 $-\dfrac{F_x}{F_z}$ 硬用商法则（$F_x, F_z$ 中含 $z$，展开极庞大）——**对原方程连求两次导**，边求边代已知点。
- **方程组** $\begin{cases} F = 0 \\ G = 0 \end{cases}$ 确定 $u = u(x,y), v = v(x,y)$：
  - **直接偏导法**：两边对 $x$ 求偏导——$y$ 是常数、$u, v$ 是 $x$ 的函数，得关于 $u_x, v_x$ 的线性方程组；
  - **全微分法**：两边求全微分，**只要求 $u_x$ 就令 $dy = 0$**，解出 $du$，系数即偏导数。

------

### （五）极值与最值

#### 1. 无条件极值（两步走）

- **找驻点**：$f_x = 0$ 且 $f_y = 0$（候选点还包括偏导数不存在的点）。
- **判别**：记 $A = f_{xx}$，$B = f_{xy}$，$C = f_{yy}$：

| $\Delta = AC - B^2$ | 结论 |
| --- | --- |
| $> 0$ | 有极值：$A > 0$ 极小值，$A < 0$ 极大值 |
| $< 0$ | 非极值（鞍点） |
| $= 0$ | **失效**，回定义或用高阶泰勒判断 |

#### 2. 条件极值（拉格朗日乘数法）

构造 $L(x, y, \lambda) = f(x, y) + \lambda\varphi(x, y)$（两个约束时 $L = f + \lambda\varphi + \mu\psi$），令 $L_x = L_y = L_\lambda = 0$ 解出全部候选点，最后比较函数值。
- **防丢根**：消 $\lambda$ 时两边同除含 $x$ 或 $y$ 的式子，**必须先讨论其 = 0** 的情况。
- **对称性**：$f$ 与 $\varphi$ 关于 $x, y$ 对称 ⟹ 候选点大概率在 $x = y$（或 $x = -y$）处，可作验算直觉。

#### 3. 闭区域最值（搜内 → 搜边 → 比大小）

- **搜内**：解 $f_x = f_y = 0$，算驻点函数值；
- **搜边**（三种武器）：① 拉格朗日乘数法；② **边界参数化**（圆 / 椭圆用 $x = R\cos\theta, y = R\sin\theta$ 降为一元，最推荐）；③ 直线段边界逐段代入化一元——**千万别漏角点（直线交点）的函数值**；
- **比大小**：全部候选函数值放一起，最大即最大值、最小即最小值（求最值**不必**判极大极小，不用算 $\Delta$）。

### （六）几何应用与场论（数一）

#### 1. 空间曲线的切线与法平面（核心：切向量 $\vec{T}$）

| 曲线形式 | 切向量 $\vec{T}$ |
| --- | --- |
| 参数式 $\begin{cases} x = x(t) \\ y = y(t) \\ z = z(t) \end{cases}$ | $(x'(t_0),\ y'(t_0),\ z'(t_0))$ |
| 面交式 $\begin{cases} F = 0 \\ G = 0 \end{cases}$ | $\vec{T} = \vec{n}_1 \times \vec{n}_2 = \nabla F \times \nabla G$ |

切线 = 点向式（方向 $\vec{T}$）；法平面 = 点法式（法向 $\vec{T}$）。

#### 2. 曲面的切平面与法线（核心：法向量 $\vec{n}$）

- 隐式 $F(x, y, z) = 0$：$\vec{n} = (F_x, F_y, F_z)$；
- 显式 $z = f(x, y)$：**移项**成 $f(x, y) - z = 0$，$\vec{n} = (f_x, f_y, -1)$——**别漏 $-1$**。

切平面 = 点法式（法向 $\vec{n}$）；法线 = 点向式（方向 $\vec{n}$）。

#### 3. 方向导数与梯度（一个数值、一个向量）

- **方向导数（数值）**：$\dfrac{\partial f}{\partial l} = f_x\cos\alpha + f_y\cos\beta + f_z\cos\gamma$——**方向向量必须先单位化**（除以模长）！
- **梯度（向量）**：$\nabla f = (f_x, f_y, f_z)$；等值面 $F = C$ 的法向量就是 $F$ 的梯度。
- **关系**：$\dfrac{\partial f}{\partial l} = \lvert \nabla f \rvert \cos\theta$，三条神级结论：
  1. 沿**梯度方向**增长最快，最大值为 $\lvert \nabla f \rvert$；
  2. 沿梯度**反方向**下降最快，最小值为 $-\lvert \nabla f \rvert$；
  3. 沿**等值面（等高线）**方向 $\theta = \frac{\pi}{2}$，方向导数为 $0$。

### （七）高频易错点清单

- **偏导数存在 ⇏ 连续**（多元特有！）；只有可微才同时推出连续与偏导存在。
- 分段点求偏导、判可微**一律回定义**，三步走别跳步。
- 隐函数二阶导：对原方程连求两次，别对一阶公式用商法则。
- 方程组求偏导先分清"谁是常数、谁是函数"；全微分法令 $dy = 0$ 提速。
- 拉格朗日消元先讨论除式为零防丢根；边界最值别漏角点；求最值不必判极大极小。
- $z = f(x, y)$ 的法向量 $(f_x, f_y, -1)$，负号别丢。
- 方向导数公式只对**单位**方向向量成立，先除模长再代入。
- $AC - B^2 = 0$ 时二阶判别法失效，**不能**下"不是极值"的结论。
- 极坐标代换证重极限存在时，必须说明结果**与 $\theta$ 无关**。
