一份全景式的"三重积分计算速查表"。在考场上，第一步永远是**看区域形状与被积函数特征选坐标系**，动手之前**先查对称性**。

------

### （一）概念与性质

- **定义**："分割、求和、取极限"的三维推广，$dv = dxdydz$（体积元素）。
- **物理与几何意义**：被积函数为**体密度** $\rho(x, y, z)$ 时积分 = 物体**总质量**；$f \equiv 1$ 时积分 = 区域**体积**：

$$
V = \iiint_\Omega 1\,dv
$$

- **性质**（与一元定积分、二重积分一脉相承）：线性、区域可加、比较保号、估值定理 $mV \le \iiint_\Omega f\,dv \le MV$、**中值定理** $\iiint_\Omega f\,dv = f(\xi, \eta, \zeta) \cdot V$（连续时）。

------

### （二）对称性（动手前必查的极速利器）

#### 1. 奇偶对称性

- 区域 $\Omega$ 关于 $xOy$ 面对称 ⟹ 看被积函数关于**剩余变量 $z$** 的奇偶：
  - $f(x, y, -z) = -f(x, y, z)$（奇）⟹ 积分直接为 **$0$**；
  - $f(x, y, -z) = f(x, y, z)$（偶）⟹ $= 2\times$ 半区（如 $z \ge 0$ 部分）积分。
- 关于 $yOz$ 面对称看 $x$，关于 $zOx$ 面对称看 $y$。

#### 2. 轮换对称性

- 区域表达式中 $x, y, z$ 地位完全对等（如球体 $x^2 + y^2 + z^2 \le R^2$）⟹

$$
\iiint_\Omega f(x)\,dv = \iiint_\Omega f(y)\,dv = \iiint_\Omega f(z)\,dv
$$

- **核心操作（凑三分之一）**：复杂被积函数用

$$
I = \frac{1}{3}\iiint_\Omega [f(x, y, z) + f(y, z, x) + f(z, x, y)]\,dv
$$

三项相加常能凑出 $(x^2 + y^2 + z^2)^n$ 型 ⟹ 立刻转**球面坐标**秒算。

------

### （三）三种坐标系（把"三重"降维成"三次"）

| **坐标系** | **代换** | **体积元素** | **适用场景** |
| --- | --- | --- | --- |
| 直角（**投影法**，先一后二） | — | $dxdydz$ | 顶底曲面明确（$z_1(x,y)$ 到 $z_2(x,y)$）：$\iint_{D_{xy}} dxdy \int_{z_1}^{z_2} f\,dz$ |
| 直角（**截面法**，先二后一） | — | $dxdydz$ | 水平截面 $D_z$ 规则且面积易算：$\int_a^b dz \iint_{D_z} f\,dxdy$ |
| **柱面坐标** | $x = \rho\cos\theta,\ y = \rho\sin\theta,\ z = z$ | $\rho\,d\rho d\theta dz$（**别漏 $\rho$**） | 圆柱体、旋转抛物面，被积函数含 $x^2 + y^2$ |
| **球面坐标** | $x = r\sin\varphi\cos\theta,\ y = r\sin\varphi\sin\theta,\ z = r\cos\varphi$ | $r^2\sin\varphi\,drd\varphi d\theta$（**牢记**） | 球体、圆锥面 $z = \sqrt{x^2 + y^2}$，被积函数含 $x^2 + y^2 + z^2$ |

- **柱面坐标本质**：$xy$ 面用极坐标 + $z$ 保持直角——通常"先 $z$ 后 $\rho, \theta$"。
- **球面坐标约定**：$r$ 为到原点距离；$\varphi$ 为连线与 $z$ 轴正向夹角（$0 \le \varphi \le \pi$）；$\theta$ 为 $xy$ 投影的极角（$0 \le \theta \le 2\pi$）。
- **球面坐标累次积分**（定限次序：先 $r$ → 再 $\varphi$ → 后 $\theta$；$\Omega$ 用 $\theta_1 \le \theta \le \theta_2$、$\varphi_1(\theta) \le \varphi \le \varphi_2(\theta)$、$r_1(\varphi,\theta) \le r \le r_2(\varphi,\theta)$ 描述）：

$$
\iiint_\Omega f\,dv = \int_{\theta_1}^{\theta_2} d\theta \int_{\varphi_1(\theta)}^{\varphi_2(\theta)} d\varphi \int_{r_1(\varphi,\theta)}^{r_2(\varphi,\theta)} f(r\sin\varphi\cos\theta,\ r\sin\varphi\sin\theta,\ r\cos\varphi)\, r^2 \sin\varphi\, dr
$$

  球体 $x^2 + y^2 + z^2 \le R^2$ 时退化为常数限特例：$\theta: 0 \to 2\pi$，$\varphi: 0 \to \pi$，$r: 0 \to R$（上半球 $\varphi: 0 \to \frac{\pi}{2}$，第一卦限 $\theta, \varphi$ 均为 $0 \to \frac{\pi}{2}$）。

------

### （四）坐标系选用流程（文字版流程）

1. **先查对称性**：奇函数部分直接划零；轮换对称用"三分之一"技巧化简。
2. 区域含**球面 / 锥面**，或被积函数含 $x^2 + y^2 + z^2$ ⟹ **球面坐标**。
3. 区域含**圆柱面 / 旋转抛物面**，或被积函数含 $x^2 + y^2$ ⟹ **柱面坐标**。
4. 水平截面规则（如某高度处截面是圆、面积好算）⟹ 直角坐标**截面法**（先二后一）最省力。
5. 其余 ⟹ 直角坐标**投影法**（先一后二）。

------

### （五）高频易错点清单

- 柱坐标体积元素 $\rho$、球坐标体积元素 $r^2\sin\varphi$——**漏掉全盘皆输**。
- 球面坐标的 $\varphi$、$\theta$ 上下限**不一定是常数**：$\varphi$ 的上下限可含 $\theta$，$r$ 的上下限可同时含 $\varphi, \theta$，只有区域关于 $z$ 轴旋转对称时才全为常数（如球体）。
- 球坐标的 $\varphi$ 是与 $z$ **轴**的夹角（从正向量起），别与柱坐标的 $\theta$ 混淆。
- 奇偶对称性："区域关于哪个坐标面对称，就看哪个**剩余变量**"的奇偶。
- 轮换对称性要求区域中 $x, y, z$ **地位对等**，不是任意区域都可用。
- 先一后二 vs 先二后一：投影好定用投影法，截面好算用截面法。
- $f \equiv 1$ 时三重积分 = 体积，可用于快速校验计算结果。

------

### （六）典型例题（考场实战）

以下 5 题对应前文"坐标系选用流程"：先查对称性，再按区域形状选坐标，截面规则时用先二后一。

#### 例1　柱面坐标：抛物面 $z = x^{2} + y^{2}$ 下方的积分

**【题目】** 计算

$$
I = \iiint_{\Omega}z\,dv,\qquad \Omega:\ x^{2} + y^{2} \le 1,\ 0 \le z \le x^{2} + y^{2}.
$$

**【解】** 区域含旋转抛物面、被积函数只含 $z$，用柱坐标 $x = r\cos\theta$、$y = r\sin\theta$、$z = z$，此时 $dv = r\,dr\,d\theta\,dz$。$\Omega$ 化为 $0 \le \theta \le 2\pi$、$0 \le r \le 1$、$0 \le z \le r^{2}$，先积 $z$：

$$
I = \int_{0}^{2\pi}d\theta\int_{0}^{1}r\,dr\int_{0}^{r^{2}}z\,dz
= 2\pi\int_{0}^{1}r\cdot\frac{r^{4}}{2}\,dr
= \pi\int_{0}^{1}r^{5}\,dr = \frac{\pi}{6}.
$$

**【结论】** $I = \dfrac{\pi}{6}$。

> **方法**：区域含圆柱面 / 旋转抛物面（或被积函数含 $x^{2} + y^{2}$）就用柱坐标；上顶面是 $z = r^{2}$ 时，$z$ 的上限写成 $r$ 的函数。
>
> **易错点**：体积元素漏乘 $\rho$（即 $r$）；把上顶面误当成常数限 $z = 1$——本区域没有平面 $z = 1$，上界随 $r$ 变化。

#### 例2　球面坐标：锥面 $z = \sqrt{x^{2} + y^{2}}$ 与球面

**【题目】** 计算

$$
I = \iiint_{\Omega}z\,dv,\qquad \Omega:\ x^{2} + y^{2} + z^{2} \le 1,\ z \ge \sqrt{x^{2} + y^{2}}.
$$

**【解】** 用球坐标 $x = r\sin\varphi\cos\theta$、$y = r\sin\varphi\sin\theta$、$z = r\cos\varphi$，此时 $dv = r^{2}\sin\varphi\,dr\,d\varphi\,d\theta$。球面为 $r = 1$；锥面 $z = \sqrt{x^{2} + y^{2}}$ 即 $\cos\varphi = \sin\varphi$，对应 $\varphi = \frac{\pi}{4}$。区域绕 $z$ 轴旋转对称，故 $0 \le \theta \le 2\pi$、$0 \le \varphi \le \frac{\pi}{4}$、$0 \le r \le 1$：

$$
I = \int_{0}^{2\pi}d\theta\int_{0}^{\pi/4}d\varphi\int_{0}^{1}r\cos\varphi\cdot r^{2}\sin\varphi\,dr
= 2\pi\cdot\frac{1}{4}\int_{0}^{\pi/4}\sin\varphi\cos\varphi\,d\varphi.
$$

$$
\int_{0}^{\pi/4}\sin\varphi\cos\varphi\,d\varphi = \frac{1}{2}\sin^{2}\varphi\Big|_{0}^{\pi/4} = \frac{1}{4},
$$

故 $I = 2\pi\cdot\dfrac{1}{4}\cdot\dfrac{1}{4} = \dfrac{\pi}{8}$。

**【结论】** $I = \dfrac{\pi}{8}$。

> **方法**：球体 + 锥面用球坐标；锥面 $z = \sqrt{x^{2} + y^{2}}$ 就是 $\varphi = \frac{\pi}{4}$，$\varphi$ 的上限取锥面的半顶角。
>
> **易错点**：体积元素漏 $r^{2}\sin\varphi$；把 $\varphi$ 的上限写成 $\frac{\pi}{2}$（那是上半球，区域更大）；$z = r\cos\varphi$ 别写成 $r\sin\varphi$。

#### 例3　对称性：奇偶消项 + 轮换"三分之一"

**【题目】** 计算

$$
I = \iiint_{\Omega}(xyz + x^{2} + 2y^{2} + 3z^{2})\,dv,\qquad \Omega:\ x^{2} + y^{2} + z^{2} \le 1.
$$

**【解】** ① 奇偶：$xyz$ 关于 $x$ 为奇函数，而球体 $\Omega$ 关于 $yOz$ 面对称，故

$$
\iiint_{\Omega}xyz\,dv = 0.
$$

② 轮换：$\Omega$ 中 $x$、$y$、$z$ 地位完全对等，故 $\iiint_{\Omega}x^{2}dv = \iiint_{\Omega}y^{2}dv = \iiint_{\Omega}z^{2}dv$。记该公共值为 $A$，则 $3A = \iiint_{\Omega}(x^{2} + y^{2} + z^{2})dv$，而球坐标下

$$
3A = \int_{0}^{2\pi}d\theta\int_{0}^{\pi}d\varphi\int_{0}^{1}r^{2}\cdot r^{2}\sin\varphi\,dr
= 2\pi\cdot 2\cdot\frac{1}{5} = \frac{4\pi}{5},
$$

所以 $A = \dfrac{4\pi}{15}$，$I = (1 + 2 + 3)A = 6\cdot\dfrac{4\pi}{15} = \dfrac{8\pi}{5}$。

**【结论】** $I = \dfrac{8\pi}{5}$。

> **方法**：球体对称先用奇偶划零；$x^{2}$、$y^{2}$、$z^{2}$ 的积分相等，可整体换成 $\frac{1}{3}(x^{2} + y^{2} + z^{2})$ 再转球坐标，即"轮换三分之一"。
>
> **易错点**：轮换对称要求 $x$、$y$、$z$ 地位对等（球体满足，长方体、圆柱体不满足）；$\int_{0}^{\pi}\sin\varphi\,d\varphi = 2$，别算成 $1$。

#### 例4　截面法（先二后一）：上半球的 $z^{2}$ 积分

**【题目】** 计算

$$
I = \iiint_{\Omega}z^{2}\,dv,\qquad \Omega:\ x^{2} + y^{2} + z^{2} \le 1,\ z \ge 0.
$$

**【解】** 用平面 $z = z$（$0 \le z \le 1$）截区域，截面 $D_{z}:\ x^{2} + y^{2} \le 1 - z^{2}$ 是半径 $\sqrt{1 - z^{2}}$ 的圆，面积为 $\pi(1 - z^{2})$。被积函数 $z^{2}$ 在 $D_{z}$ 上为常数，先算二重积分再对 $z$ 积分：

$$
I = \int_{0}^{1}z^{2}\left(\iint_{D_{z}}dxdy\right)dz
= \int_{0}^{1}z^{2}\cdot\pi(1 - z^{2})\,dz
= \pi\left(\frac{1}{3} - \frac{1}{5}\right) = \frac{2\pi}{15}.
$$

**【结论】** $I = \dfrac{2\pi}{15}$。

> **方法**：水平截面为圆、面积易算，且被积函数只含 $z$ 时用截面法（先二后一）：$\iiint_{\Omega}f\,dv = \int_{a}^{b}dz\iint_{D_{z}}f\,dxdy$。
>
> **易错点**：截面半径是 $\sqrt{1 - z^{2}}$、面积是 $\pi(1 - z^{2})$，不是常数 $\pi$；也可用球坐标互检：$2\pi\int_{0}^{\pi/2}\cos^{2}\varphi\sin\varphi\,d\varphi\int_{0}^{1}r^{4}dr = 2\pi\cdot\frac{1}{3}\cdot\frac{1}{5} = \frac{2\pi}{15}$。

#### 例5　综合：体积、质量与形心

**【题目】** 设 $\Omega$ 由旋转抛物面 $z = x^{2} + y^{2}$ 与平面 $z = 4$ 围成，体密度 $\rho = z$。求 $\Omega$ 的体积 $V$、质量 $M$ 与形心高度 $\bar z$。

**【解】** 柱坐标下 $\Omega:\ 0 \le r \le 2$、$r^{2} \le z \le 4$、$0 \le \theta \le 2\pi$。

① 体积：

$$
V = \iiint_{\Omega}dv = \int_{0}^{2\pi}d\theta\int_{0}^{2}r\,dr\int_{r^{2}}^{4}dz
= 2\pi\int_{0}^{2}r(4 - r^{2})\,dr
= 2\pi\left[2r^{2} - \frac{r^{4}}{4}\right]_{0}^{2} = 8\pi.
$$

② 质量：

$$
M = \iiint_{\Omega}z\,dv = \int_{0}^{2\pi}d\theta\int_{0}^{2}r\,dr\int_{r^{2}}^{4}z\,dz
= 2\pi\int_{0}^{2}r\cdot\frac{16 - r^{4}}{2}\,dr
= \pi\left[8r^{2} - \frac{r^{6}}{6}\right]_{0}^{2} = \frac{64\pi}{3}.
$$

③ 形心：由区域关于 $z$ 轴旋转对称、密度只与 $r, z$ 有关，知 $\bar x = \bar y = 0$；又

$$
\iiint_{\Omega}z^{2}\,dv = 2\pi\int_{0}^{2}r\cdot\frac{64 - r^{6}}{3}\,dr
= \frac{2\pi}{3}\left[32r^{2} - \frac{r^{8}}{8}\right]_{0}^{2} = 64\pi,
$$

故

$$
\bar z = \frac{1}{M}\iiint_{\Omega}z^{2}\,dv = \frac{64\pi}{64\pi/3} = 3.
$$

**【结论】** $V = 8\pi$，$M = \dfrac{64\pi}{3}$，$\bar z = 3$（且 $\bar x = \bar y = 0$）。

> **方法**：旋转体优先柱坐标；形心用 $\bar z = \frac{\iiint_{\Omega}z\rho\,dv}{\iiint_{\Omega}\rho\,dv}$，本题 $\rho = z$，故分子是 $\iiint_{\Omega}z^{2}dv$、分母是质量 $M$。
>
> **易错点**：$z$ 的下限是抛物面 $z = r^{2}$ 而不是 $0$；$\bar z$ 的分母是质量而不是体积；体积可快速验证：截面面积 $A(z) = \pi z$，$\int_{0}^{4}\pi z\,dz = 8\pi$。
