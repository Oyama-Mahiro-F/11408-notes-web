一份全景式的"不定积分核心方法速查表"。在考场上，拿到积分题的第一步永远是**识别被积函数形态**（能凑微分？带根号？两类函数相乘？有理式/三角式/无理式？），第二步才是**套用对应积分方法**。

### （〇）必须熟记的基本积分公式（所有积分的"锚点"）

| **代数、指数与反三角** | **三角函数** |
| --- | --- |
| $\int x^\mu dx = \dfrac{1}{\mu+1}x^{\mu+1} + C\ (\mu \ne -1)$ | $\int \sin x\,dx = -\cos x + C$；$\int \cos x\,dx = \sin x + C$ |
| $\int \dfrac{1}{x}dx = \ln \lvert x \rvert + C$ | $\int \sec^2 x\,dx = \tan x + C$；$\int \csc^2 x\,dx = -\cot x + C$ |
| $\int e^x dx = e^x + C$；$\int a^x dx = \dfrac{a^x}{\ln a} + C$ | $\int \sec x\tan x\,dx = \sec x + C$；$\int \csc x\cot x\,dx = -\csc x + C$ |
| $\int \dfrac{1}{1+x^2}dx = \arctan x + C$；$\int \dfrac{1}{\sqrt{1-x^2}}dx = \arcsin x + C$ | $\int \tan x\,dx = -\ln \lvert \cos x \rvert + C$；$\int \cot x\,dx = \ln \lvert \sin x \rvert + C$ |
| $\int \dfrac{1}{a^2+x^2}dx = \dfrac{1}{a}\arctan\dfrac{x}{a} + C$；$\int \dfrac{1}{\sqrt{a^2-x^2}}dx = \arcsin\dfrac{x}{a} + C$ | $\int \sec x\,dx = \ln \lvert \sec x + \tan x \rvert + C$ |
| $\int \dfrac{1}{x^2-a^2}dx = \dfrac{1}{2a}\ln \left\lvert \dfrac{x-a}{x+a} \right\rvert + C$ | $\int \csc x\,dx = \ln \lvert \csc x - \cot x \rvert + C$ |
| $\int \dfrac{1}{\sqrt{x^2 \pm a^2}}dx = \ln \left\lvert x + \sqrt{x^2 \pm a^2} \right\rvert + C$ | |

### （一）原函数与不定积分（概念辨析锚点）

- **原函数**：$F'(x) = f(x)$；**不定积分** = 全体原函数 $\int f(x)dx = F(x) + C$——**漏写 $C$ 是绝对失分点**。
- **互逆关系**：先积后导不还原常数（$\dfrac{d}{dx}\int f\,dx = f$）；先导后积**必须补 $C$**（$\int F'\,dx = F + C$）。
- **原函数存在定理（选择题陷阱）**：
  - $f$ 在区间上**连续** ⟹ 必有原函数；
  - 含**第一类间断点、无穷间断点** ⟹ 该区间内**没有**原函数；
  - 含**振荡间断点** ⟹ **可能**有原函数。

------

### （二）第一类换元法（凑微分法）

**核心思想**：认出 $f[g(x)] \cdot g'(x)$ 结构，把 $g'(x)dx$ 凑进微分号变成 $d[g(x)]$；积完**换回 $g(x)$**。

| **类别** | **凑微分公式** |
| --- | --- |
| 幂函数类 | $x\,dx = \dfrac{1}{2}d(x^2)$；$x^n dx = \dfrac{1}{n+1}d(x^{n+1})$ |
| 倒数与对数类 | $\dfrac{1}{x}dx = d(\ln \lvert x \rvert)$；$\dfrac{1}{2\sqrt{x}}dx = d(\sqrt{x})$ |
| 指数类 | $e^x dx = d(e^x)$；$e^{-x}dx = -d(e^{-x})$ |
| 三角类 | $\cos x\,dx = d(\sin x)$；$\sin x\,dx = -d(\cos x)$；$\sec^2 x\,dx = d(\tan x)$ |
| 反三角类 | $\dfrac{1}{1+x^2}dx = d(\arctan x)$；$\dfrac{1}{\sqrt{1-x^2}}dx = d(\arcsin x)$ |

> **破题诀窍**：找被积函数中"互为导数"的两部分——见到 $\ln x$ 与 $\dfrac{1}{x}$ 同现，立刻凑 $d(\ln x)$。

------

### （三）第二类换元法（变量代换法）

令 $x = \varphi(t)$（**单调**、$\varphi'(t) \ne 0$），算完**必须经反函数 $t = \varphi^{-1}(x)$ 回代**。

| **代换类型** | **适用特征** | **核心代换** |
| --- | --- | --- |
| 根式代换 | 含 $\sqrt[n]{ax+b}$ 或 $\sqrt[n]{\dfrac{ax+b}{cx+d}}$ | 令 $t = $ 整个根式 |
| 三角代换 | $\sqrt{a^2-x^2}$ | $x = a\sin t$（利用 $1-\sin^2 t = \cos^2 t$） |
| 三角代换 | $\sqrt{a^2+x^2}$ | $x = a\tan t$（利用 $1+\tan^2 t = \sec^2 t$） |
| 三角代换 | $\sqrt{x^2-a^2}$ | $x = a\sec t$（利用 $\sec^2 t - 1 = \tan^2 t$） |
| 倒代换 | 分母次数比分子高两次以上 | $x = \dfrac{1}{t}$（降分母次幂） |

> **回代保命技巧**：画直角三角形——如令 $x = a\sin t$，画对边 $x$、斜边 $a$、邻边 $\sqrt{a^2-x^2}$ 的三角形，其余三角函数值直接读出，绝不记错。

------

### （四）分部积分法

$$
\int u\,dv = uv - \int v\,du
$$

- **本质**："转移矛盾"——把难积的 $\int u\,dv$ 转移成好积的 $\int v\,du$。
- **选 $u$ 口诀**："**反对幂指三**"（或"反对幂三指"，指、三孰先孰后不影响实战）——排前者作 $u$（求导变简单），其余连同 $dx$ 作 $dv$。

| **题型** | **策略** | **典型例子** |
| --- | --- | --- |
| 对数/反三角 × 幂 | $u =$ 对数/反三角（求导后代数化） | $\int x\ln x\,dx$、$\int x\arctan x\,dx$ |
| 幂 × 指数/三角 | $u =$ 幂函数，连用降次 | $\int x^2 e^x\,dx$（连用两次）、$\int x\sin x\,dx$ |
| 指数 × 三角 | 谁作 $u$ 均可，**循环积分**：连用两次后原积分回现，移项解方程 | $\int e^x\sin x\,dx$ |

------

### （五）三类可积函数（统一思想：有理化）

#### 1. 有理函数 $\dfrac{P(x)}{Q(x)}$

1. **假分式先长除**：化为"多项式 + 真分式"；
2. **分母因式分解**：一次因式 $(x - a)$ 与二次不可约因式 $(x^2 + px + q)$；
3. **拆部分分式**：单根拆 $\dfrac{A}{x-a}$；$k$ 重根拆 $\dfrac{A_1}{x-a} + \dots + \dfrac{A_k}{(x-a)^k}$；二次因式拆 $\dfrac{Bx+C}{x^2+px+q}$。
- **提速**：分母为不重复一次因式时，用**留数法（遮盖法）**口算系数，别解方程组。

#### 2. 三角有理式 $R(\sin x, \cos x)$

- **高分首选——对称性代换**：
  - 对 $\sin x$ 是奇函数 ⟹ 提一个 $\sin x$，令 $u = \cos x$；
  - 对 $\cos x$ 是奇函数 ⟹ 提一个 $\cos x$，令 $u = \sin x$；
  - 对 $\sin x, \cos x$ 同为奇（整体不变号）⟹ 令 $u = \tan x$。
- **保底——万能代换**：$t = \tan\dfrac{x}{2}$，则 $\sin x = \dfrac{2t}{1+t^2}$、$\cos x = \dfrac{1-t^2}{1+t^2}$、$dx = \dfrac{2\,dt}{1+t^2}$——计算量极大，**走投无路再用**。

#### 3. 简单无理函数

- 含 $\sqrt[n]{ax+b}$、$\sqrt[n]{\dfrac{ax+b}{cx+d}}$：令**整个根式** $t$，反解 $x$、求 $dx$，根号消失 → 化为有理函数积分。

------

### （六）积分方法选用流程（文字版流程）

1. **先看能否凑微分**：找"互为导数"结构（$\frac{1}{x}$ 配 $\ln x$、$e^x$、三角）。
2. **带根号** → 第二类换元（根式 / 三角 / 倒代换）。
3. **两类不同函数相乘** → 分部积分（"反对幂指三"定 $u$）。
4. **有理式** → 长除 + 部分分式（留数法提速）；**三角有理式** → 先试对称性代换，保底万能代换；**无理式** → 根式代换。
5. 三类函数最终都化归为**有理函数积分**。

------

### （七）高频易错点清单

- 不定积分**必写 $+C$**；第一类换元积完换回 $g(x)$，第二类换元积完回代反函数。
- 原函数存在性：第一类间断点、无穷间断点 ⟹ **无**原函数；振荡间断点**可能有**（选择题陷阱）。
- 分部积分 $u$ 选错会越积越复杂——口诀排前者求导；指数 × 三角是循环积分，移项别忘除以系数。
- 三角代换回代**画直角三角形**，别硬背 $\cos t$、$\tan t$ 的表达式。
- 假分式**必须先长除**再拆部分分式；重根要拆足 $k$ 项。
- 万能代换计算量大，动手前先检查对称性代换是否可行。

### （八）典型例题（考场实战）

> 本节 6 道题对应前文（二）～（五）的方法：拿到积分先按（六）的流程判形态，再套对应方法；每题末尾给出**方法**与**易错点**。

#### 例1　凑微分：$\frac{\ln x}{x\sqrt{1+\ln x}}$

**【题目】** 求 $\displaystyle\int \frac{\ln x}{x\sqrt{1+\ln x}}\,dx$。

**【解】** 被积函数中 $\dfrac{1}{x}$ 与 $\ln x$ 互为导数，先凑微分：

$$
\int \frac{\ln x}{x\sqrt{1+\ln x}}\,dx = \int \frac{\ln x}{\sqrt{1+\ln x}}\,d(\ln x).
$$

再令 $u=\sqrt{1+\ln x}$（$u>0$），则 $\ln x=u^{2}-1$，$d(\ln x)=2u\,du$，于是

$$
\int \frac{u^{2}-1}{u}\cdot 2u\,du = 2\int (u^{2}-1)\,du = \frac{2}{3}u^{3}-2u+C.
$$

回代 $u=\sqrt{1+\ln x}$：

$$
\int \frac{\ln x}{x\sqrt{1+\ln x}}\,dx = \frac{2}{3}(1+\ln x)^{\frac{3}{2}}-2\sqrt{1+\ln x}+C.
$$

**【结论】** 原式 $= \dfrac{2}{3}(1+\ln x)^{\frac{3}{2}}-2\sqrt{1+\ln x}+C$。

> **方法**：凑微分（第一类换元法）——先由 $\dfrac{dx}{x}=d(\ln x)$ 把被积式整理成 $g(\ln x)\,d(\ln x)$，再令 $u=\sqrt{1+\ln x}$ 一次性去掉根式。
>
> **易错点**：漏掉 $d(\ln x)$ 这一步，把 $\ln x$ 当普通因子硬积；若只令 $u=1+\ln x$ 会留下 $\int\frac{u-1}{\sqrt{u}}du$，还要再拆项；回代后漏 $+C$。

#### 例2　三角代换：$\frac{x^{2}}{\sqrt{1-x^{2}}}$

**【题目】** 求 $\displaystyle\int \frac{x^{2}}{\sqrt{1-x^{2}}}\,dx$。

**【解】** 出现 $\sqrt{1-x^{2}}$，令 $x=\sin t$，$t\in\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)$，此时 $\cos t>0$，$dx=\cos t\,dt$，$\sqrt{1-x^{2}}=\cos t$。于是

$$
\int \frac{x^{2}}{\sqrt{1-x^{2}}}\,dx = \int \sin^{2}t\,dt = \int \frac{1-\cos 2t}{2}\,dt = \frac{t}{2}-\frac{\sin 2t}{4}+C.
$$

用 $\sin 2t=2\sin t\cos t$ 拆开：

$$
\int = \frac{t}{2}-\frac{\sin t\cos t}{2}+C.
$$

回代 $t=\arcsin x$、$\sin t=x$、$\cos t=\sqrt{1-x^{2}}$：

$$
\int \frac{x^{2}}{\sqrt{1-x^{2}}}\,dx = \frac{1}{2}\arcsin x-\frac{1}{2}x\sqrt{1-x^{2}}+C.
$$

**【结论】** 原式 $= \dfrac{1}{2}\arcsin x-\dfrac{1}{2}x\sqrt{1-x^{2}}+C$。

> **方法**：见 $\sqrt{a^{2}-x^{2}}$ 作三角代换 $x=a\sin t$，本题 $a=1$；开根号能取 $\cos t$ 的依据是限定 $t\in\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$。
>
> **易错点**：不限定 $t$ 的区间就写 $\sqrt{1-\sin^{2}t}=\cos t$（应为 $\lvert\cos t\rvert$）；回代时忘记 $\cos t$ 要换成 $\sqrt{1-x^{2}}$；最后漏 $+C$。

#### 例3　倒代换：$\frac{1}{x^{2}\sqrt{x^{2}+1}}$

**【题目】** 求 $\displaystyle\int \frac{dx}{x^{2}\sqrt{x^{2}+1}}$（$x>0$）。

**【解】** 分母次数远高于分子，用倒代换：令 $x=\dfrac{1}{t}$（$t>0$），则 $dx=-\dfrac{dt}{t^{2}}$，$\sqrt{x^{2}+1}=\dfrac{\sqrt{t^{2}+1}}{t}$，故

$$
x^{2}\sqrt{x^{2}+1} = \frac{1}{t^{2}}\cdot\frac{\sqrt{t^{2}+1}}{t} = \frac{\sqrt{t^{2}+1}}{t^{3}}.
$$

代入：

$$
\int \frac{dx}{x^{2}\sqrt{x^{2}+1}} = \int \left(-\frac{dt}{t^{2}}\right)\cdot\frac{t^{3}}{\sqrt{t^{2}+1}} = -\int \frac{t\,dt}{\sqrt{t^{2}+1}} = -\sqrt{t^{2}+1}+C.
$$

回代 $t=\dfrac{1}{x}$，并注意 $x>0$：

$$
-\sqrt{t^{2}+1} = -\sqrt{\frac{1}{x^{2}}+1} = -\frac{\sqrt{x^{2}+1}}{x}.
$$

**【结论】** 原式 $= -\dfrac{\sqrt{x^{2}+1}}{x}+C$（$x>0$）。

> **方法**：倒代换 $x=\dfrac{1}{t}$——分子为 $1$、分母含 $x$ 的高次幂与根式时，把 $x$ 换到分母上，根式阶数随之下降。
>
> **易错点**：$\sqrt{\frac{1}{t^{2}}+1}=\dfrac{\sqrt{t^{2}+1}}{\lvert t\rvert}$ 漏绝对值（$x<0$ 时须保留 $\lvert t\rvert$ 讨论，结果仍为 $-\dfrac{\sqrt{x^{2}+1}}{x}+C$）；回代后漏 $+C$。

#### 例4　分部积分（循环型）：$\sec^{3}x$

**【题目】** 求 $\displaystyle I=\int \sec^{3}x\,dx$。

**【解】** 把 $\sec^{3}x$ 拆成 $\sec x\cdot\sec^{2}x$，取 $u=\sec x$，$dv=\sec^{2}x\,dx=d(\tan x)$，分部积分得

$$
I = \sec x\tan x-\int \tan x\,d(\sec x) = \sec x\tan x-\int \sec x\tan^{2}x\,dx.
$$

用 $\tan^{2}x=\sec^{2}x-1$：

$$
I = \sec x\tan x-\int \sec x\,(\sec^{2}x-1)\,dx = \sec x\tan x-I+\int \sec x\,dx.
$$

移项得 $2I=\sec x\tan x+\ln\lvert \sec x+\tan x\rvert$，故

$$
I = \frac{1}{2}\left(\sec x\tan x+\ln\lvert \sec x+\tan x\rvert\right)+C.
$$

**【结论】** 原式 $= \dfrac{1}{2}\left(\sec x\tan x+\ln\lvert \sec x+\tan x\rvert\right)+C$。

> **方法**：循环型分部积分——拆出 $\sec^{2}x\,dx$ 作 $dv$、$\sec x$ 作 $u$，两次分部后原积分 $\int\sec^{3}x\,dx$ 重新出现，移项解出。
>
> **易错点**：移项得到 $2I$ 后忘记除以 $2$；$\int\sec x\,dx=\ln\lvert\sec x+\tan x\rvert+C$ 记错或漏绝对值。

#### 例5　有理函数部分分式：$\frac{x+1}{x^{3}+x}$

**【题目】** 求 $\displaystyle\int \frac{x+1}{x^{3}+x}\,dx$。

**【解】** 被积函数为真分式，分母 $x^{3}+x=x(x^{2}+1)$ 含一次因式与不可约二次因式，拆为

$$
\frac{x+1}{x(x^{2}+1)} = \frac{A}{x}+\frac{Bx+C}{x^{2}+1}.
$$

通分比较分子：

$$
x+1 = A(x^{2}+1)+(Bx+C)x = (A+B)x^{2}+Cx+A.
$$

比较系数得 $A=1$，$C=1$，$A+B=0$ 即 $B=-1$，故

$$
\frac{x+1}{x^{3}+x} = \frac{1}{x}+\frac{1-x}{x^{2}+1}.
$$

于是

$$
\int \frac{x+1}{x^{3}+x}\,dx = \int \frac{dx}{x}+\int \frac{dx}{x^{2}+1}-\frac{1}{2}\int \frac{2x\,dx}{x^{2}+1} = \ln\lvert x\rvert+\arctan x-\frac{1}{2}\ln(x^{2}+1)+C.
$$

**【结论】** 原式 $= \ln\lvert x\rvert+\arctan x-\dfrac{1}{2}\ln(x^{2}+1)+C$。

> **方法**：真分式拆部分分式——单根配 $\dfrac{A}{x-a}$，不可约二次因式配 $\dfrac{Bx+C}{x^{2}+px+q}$；系数用比较系数法，或对单个根用遮盖法先定 $A$。
>
> **易错点**：把二次因式拆成 $\dfrac{B}{x^{2}+1}$（漏 $x$ 项）；拆完不通分回验；$\int\dfrac{2x}{x^{2}+1}dx$ 前的 $\dfrac{1}{2}$ 系数漏写。

#### 例6　三角有理式：万能代换 $\frac{1}{1+\sin x+\cos x}$

**【题目】** 求 $\displaystyle\int \frac{dx}{1+\sin x+\cos x}$。

**【解】** 分母对 $\sin x$、$\cos x$ 既非奇也非偶，对称性代换失效，改用万能代换 $t=\tan\dfrac{x}{2}$：

$$
\sin x=\frac{2t}{1+t^{2}},\qquad \cos x=\frac{1-t^{2}}{1+t^{2}},\qquad dx=\frac{2\,dt}{1+t^{2}}.
$$

先化简分母：

$$
1+\sin x+\cos x = 1+\frac{2t}{1+t^{2}}+\frac{1-t^{2}}{1+t^{2}} = \frac{(1+t^{2})+2t+(1-t^{2})}{1+t^{2}} = \frac{2(1+t)}{1+t^{2}}.
$$

代入：

$$
\int \frac{dx}{1+\sin x+\cos x} = \int \frac{1+t^{2}}{2(1+t)}\cdot\frac{2\,dt}{1+t^{2}} = \int \frac{dt}{1+t} = \ln\lvert 1+t\rvert+C.
$$

回代 $t=\tan\dfrac{x}{2}$：

$$
\int \frac{dx}{1+\sin x+\cos x} = \ln\left\lvert 1+\tan\frac{x}{2}\right\rvert+C.
$$

**【结论】** 原式 $= \ln\left\lvert 1+\tan\dfrac{x}{2}\right\rvert+C$（在 $x\ne\pi+2k\pi$ 的区间内成立）。

> **方法**：三角有理式先试对称性代换（对 $\sin$ 为奇令 $u=\cos x$、对 $\cos$ 为奇令 $u=\sin x$、整体不变号令 $u=\tan x$），都不行再用万能代换 $t=\tan\frac{x}{2}$ 化为有理函数。
>
> **易错点**：万能代换三件套中 $dx=\dfrac{2dt}{1+t^{2}}$ 漏写；忘记 $\tan\frac{x}{2}$ 在 $x=\pi+2k\pi$ 无定义、需分区间讨论；回代后漏 $+C$。
