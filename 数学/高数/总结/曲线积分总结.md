一份全景式的"曲线积分核心方法速查表"。在考场上，第一步永远是**识别积分类型**（对弧长 $ds$？对坐标 $dx, dy$？），第二步才是**选计算路线**（参数化 → 格林 → 路径无关 → 斯托克斯）。

------

### （〇）两类曲线积分对比（先分清类型）

| **对比** | **第一类（对弧长）** | **第二类（对坐标）** |
| --- | --- | --- |
| 物理意义 | 曲线形构件的质量 $\int_L f\,ds$ | 变力沿曲线做功 $\int_L P\,dx + Q\,dy$ |
| 方向性 | **与方向无关**：$\int_{AB} = \int_{BA}$（$ds \ge 0$） | **有向**：$\int_{AB} = -\int_{BA}$（顺路正功、逆路负功） |
| 定限规则 | 下限 < 上限（固定不变） | **下限 = 起点参数，上限 = 终点参数**（可大可小，绝不许对调） |
| 核心微元 | $ds = \sqrt{x'^2 + y'^2}\,dt$ | $dx = x'(t)\,dt$，$dy = y'(t)\,dt$ |

------

### （一）第一类曲线积分

#### 1. 计算："一投、二代、三定限"——把 $ds$ 转化为具体微分

| 曲线形式 | $ds$ |
| --- | --- |
| 参数式 $x = x(t),\ y = y(t)$ | $\sqrt{[x'(t)]^2 + [y'(t)]^2}\,dt$ |
| 直角坐标 $y = y(x)$ | $\sqrt{1 + [y'(x)]^2}\,dx$（$x$ 即参数） |
| 极坐标 $r = r(\theta)$ | $\sqrt{r^2 + (r')^2}\,d\theta$ |

#### 2. 对称性化简（硬算前必查）

- 曲线 $L$ 关于 $y$ 轴对称：$f$ 关于 $x$ 为奇 ⟹ 积分 $= 0$；为偶 ⟹ $= 2\times$ 半边积分（关于 $x$ 轴对称同理看 $y$）。
- **轮换对称性（极为重要）**：$L$ 关于 $y = x$ 对称（圆周、正方形边界）⟹

$$
\int_L f(x, y)\,ds = \int_L f(y, x)\,ds = \frac{1}{2}\int_L [f(x, y) + f(y, x)]\,ds
$$

- 实战：$\int_L x^2 ds$ 与 $\int_L y^2 ds$ 相加后用 $x^2 + y^2 = R^2$ 化为常数 $R^2$，再除 2 各得一半。

------

### （二）第二类曲线积分

- **参数化（通用算法）**：设起点 $A$ 对应 $t = \alpha$、终点 $B$ 对应 $t = \beta$：

$$
\int_L P\,dx + Q\,dy = \int_\alpha^\beta [P(x(t), y(t))\,x'(t) + Q(x(t), y(t))\,y'(t)]\,dt
$$

完全不管 $\alpha, \beta$ 谁大谁小，严格**起点到终点**。
- 显函数 $y = y(x)$：$dy = y'(x)dx$，从起点 $x = a$ 积到终点 $x = b$：$\int_a^b [P + Q\,y'(x)]\,dx$。

------

### （三）格林公式（化线为面，封闭曲线 + 逆时针为正）

$$
\oint_L P\,dx + Q\,dy = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dxdy
$$

（前提：$L$ 封闭且取正向——沿边界走，**区域在左侧**；$P, Q$ 在 $D$ 上有一阶连续偏导。）

| **变型** | **场景** | **操作与细节** |
| --- | --- | --- |
| **补线法** | 曲线不封闭（上半圆弧、抛物线段） | 补简单辅助线 $L_1$（常为坐标轴平行线段，$dy = 0$ 极好算）闭合成圈 ⟹ 格林公式 ⟹ **减去** $\int_{L_1}$ |
| **挖洞法** | 区域内有奇点（$P, Q$ 偏导不连续，如原点） | 挖去小圆 $l$，在"带洞区域"用格林；若 $\frac{\partial Q}{\partial x} \equiv \frac{\partial P}{\partial y}$，则**大圈积分 = 小圈积分**（内圈取与 $L$ **相同环绕方向**） |

#### 路径无关与全微分求积（单连通区域内，$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$ 时）

- **换路径**：变态曲线积分直接换成"平行于坐标轴的折线"计算。
- **找原函数**：$du = P\,dx + Q\,dy$，则

$$
u(x, y) = \int_{x_0}^{x} P(t, y_0)\,dt + \int_{y_0}^{y} Q(x, t)\,dt + C, \qquad \int_{(x_1, y_1)}^{(x_2, y_2)} P\,dx + Q\,dy = u(x_2, y_2) - u(x_1, y_1)
$$

（牛顿–莱布尼茨公式的二元版。）
- **六大等价命题**（单连通 + 一阶偏导连续）：① 路径无关；② 闭环积分 $= 0$；③ 偏导相等；④ 存在原函数 $u$；⑤ $Pdx + Qdy = 0$ 是全微分方程；⑥ $(P, Q)$ 是某函数 $u$ 的梯度场。

------

### （四）斯托克斯公式（空间版格林：闭曲线 ↔ 张在其上的曲面）

$$
\oint_\Gamma P\,dx + Q\,dy + R\,dz = \iint_\Sigma (\nabla \times \vec{F}) \cdot \vec{n}\,dS
$$

- 坐标形式用三阶行列式记忆（首行 $dy\,dz,\ dz\,dx,\ dx\,dy$；次行 $\frac{\partial}{\partial x}, \frac{\partial}{\partial y}, \frac{\partial}{\partial z}$；末行 $P, Q, R$），展开后含 $\left(\frac{\partial R}{\partial y} - \frac{\partial Q}{\partial z}\right)dy\,dz$ 等三项。
- **右手法则绑方向**：四指沿 $\Gamma$ 积分方向弯曲，**大拇指 = 曲面正侧法向量 $\vec{n}$ 的方向**——它决定后面曲面积分取上侧还是下侧、各微元前的正负号（如"从 $z$ 轴正向看去逆时针"⟹ 拇指朝上 ⟹ $dxdy$ 前取正）。

------

### （五）计算决策流程（文字版流程）

1. **先分类型**：$ds$ 是第一类（与方向无关），$dx, dy$ 是第二类（有向）。
2. **第一类**：参数化 + 对称性 / 轮换对称性化简。
3. **第二类、平面曲线**：
   - 封闭 + 偏导连续 ⟹ **格林公式**；
   - 不封闭 ⟹ **补线**再用格林（记得减辅助线）；
   - 区域内有奇点 ⟹ **挖洞**（偏导相等时换小圈算）；
   - 偏导相等 + 单连通 ⟹ 换折线路径，或找原函数代端点。
4. **空间闭曲线** ⟹ **斯托克斯公式**（先用右手法则定向）。

------

### （六）高频易错点清单

- 两类积分最本质区别：**第一类与方向无关、第二类有向**——第二类上下限严格对应起终点，**绝不许**为"下小上大"而对调（符号就错在这）。
- 格林公式前提：**闭曲线 + 正向（区域在左）**；$P, Q$ 在 $D$ 内有一阶连续偏导。
- 补线法最后要**减去**辅助线积分；挖洞法内圈必须与外圈**同向**，移项时小心负号。
- 路径无关的前提是**单连通区域**——复连通域内"偏导相等"推不出路径无关（奇点必须挖掉）。
- 找原函数固定套路：先对 $x$ 积（$y$ 固定为 $y_0$），再对 $y$ 积。
- 斯托克斯的方向绑定靠**右手法则**：曲线方向决定曲面侧别，符号全部由此而来。
- 第一类曲线积分的定限必须**下限 < 上限**；对称性化简前先确认曲线本身的对称性。
