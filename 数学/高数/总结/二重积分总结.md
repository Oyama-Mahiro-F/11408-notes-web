一份全景式的"二重积分计算速查表"。在考场上，第一步永远是**观察对称性**（能省一半是一半），第二步才是**选坐标系、定积分次序**。

------

### （一）定义与性质

- **定义四步**：分割 → 取点 → 求和（黎曼和 $\sum f(\xi_i, \eta_i)\Delta\sigma_i$）→ 取极限（$\lambda$ 为小区域直径最大值，$\lambda \to 0$ 且与分法、取法无关）。连续函数必可积。
- **几何意义**：曲顶柱体体积；$f \equiv 1$ 时 $\iint_D d\sigma = \sigma$（**区域面积**）。
- **性质速查**（假设各积分存在）：

| 性质 | 内容 |
| --- | --- |
| 线性 | 常数可提、和差可拆 |
| 区域可加 | $D = D_1 \cup D_2$（内部不重叠）⟹ 积分相加 |
| 面积性质 | $\iint_D 1\,d\sigma = \sigma$ |
| 比较定理（保号性） | $f \le g \Rightarrow \iint_D f \le \iint_D g$；$\left\lvert \iint_D f \right\rvert \le \iint_D \lvert f \rvert$ |
| 估值定理 | $m\sigma \le \iint_D f\,d\sigma \le M\sigma$ |
| 中值定理 | $f$ 在 $D$ 上连续 ⟹ $\iint_D f\,d\sigma = f(\xi, \eta) \cdot \sigma$ |

------

### （二）直角坐标计算（穿线定限）

- **X 型区域（先 $y$ 后 $x$）**：竖线穿区域，**穿入点为下限、穿出点为上限**，外层 $x$ 限为常数：

$$
\iint_D f(x, y)\,d\sigma = \int_a^b dx \int_{f_1(x)}^{f_2(x)} f(x, y)\,dy
$$

- **Y 型区域（先 $x$ 后 $y$）**：横线穿区域，外层 $y$ 限为常数。

#### 核心考法：交换积分次序（$\int e^{x^2}dx$、$\int \frac{\sin x}{x}dx$ 等积不出的原函数必用）

1. 由原积分限**写不等式**（如 $0 \le y \le 1$，$y \le x \le 1$）；
2. **画区域草图**（最关键的一步）；
3. 换方向**重新穿线**定限；
4. 写出新次序的累次积分。

------

### （三）极坐标计算（圆、圆环、扇形，或含 $x^2 + y^2$、$\frac{y}{x}$ 时果断切换）

$$
\iint_D f(x, y)\,dxdy = \iint_{D'} f(r\cos\theta,\ r\sin\theta)\, r\,drd\theta
$$

**千万别漏雅可比面积元素 $r$。**

**射线法定限**（从极点引射线穿区域）：

| 极点位置 | 定限 |
| --- | --- |
| 在 $D$ 内部 | $0 \le \theta \le 2\pi$，$0 \le r \le r(\theta)$ |
| 在 $D$ 边界上 | $\alpha \le \theta \le \beta$，$0 \le r \le r(\theta)$ |
| 在 $D$ 外部 | $\alpha \le \theta \le \beta$，$r_1(\theta) \le r \le r_2(\theta)$ |

------

### （四）对称性（拿到题的第一反应）

| **对称性** | **条件** | **结论** |
| --- | --- | --- |
| 关于 $y$ 轴对称 | $f$ 关于 $x$ 为奇（$f(-x, y) = -f(x, y)$） | 积分 $= 0$ |
| | $f$ 关于 $x$ 为偶 | $= 2\iint_{D_{x \ge 0}}$（关于 $x$ 轴对称时看 $y$ 的奇偶，同理） |
| 关于原点对称 | $f(-x, -y) = -f(x, y)$ | 积分 $= 0$ |
| **轮换对称**（$D$ 关于 $y = x$ 对称） | $x, y$ 互换区域不变 | $\iint_D f(x, y) = \iint_D f(y, x)$，常"相加除 2"凑简单式（如 $\iint_D \frac{x}{x+y}dxdy$） |

------

### （五）特殊题型：含绝对值 / 最值的被积函数

$\lvert x - y \rvert$、$\max(x, y)$ 型：令绝对值内部 $= 0$ **画分界线**，把 $D$ 分块，逐块去绝对值（或取最值），用**区域可加性**分别计算。

------

### （六）计算流程（文字版流程）

1. **看对称性**：区域对称 + 函数奇偶 ⟹ 直接消项或减半；轮换对称换元化简。
2. **选坐标系**：圆 / 圆环 / 扇形，或被积函数含 $x^2 + y^2$、$\frac{y}{x}$ ⟹ 极坐标；否则直角坐标。
3. **定次序**：看哪种次序的内层好积（遇到积不出的内层立刻交换次序）。
4. **含 $\lvert\ \rvert$、$\max$**：先分块再去符号。

------

### （七）高频易错点清单

- 极坐标**别漏乘 $r$**；$r$、$\theta$ 的限按"极点在域内 / 边界 / 域外"三种情况讨论。
- 用奇偶性前先确认**区域对称**——"区域对称 + 函数奇偶"两者缺一不可。
- 交换次序必须**画图重新穿线**，不能只对调两个积分号。
- $\iint_D 1\,d\sigma$ = 区域面积，可用于反求参数、快速校验。
- 估值定理、中值定理常用于"不等式证明 / 定性比较"型选择题。
- 被积函数含绝对值 / 最值，先分块再积分，别直接硬积。
