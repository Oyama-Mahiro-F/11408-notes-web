一份全景式的“无穷级数核心判敛与求和速查表”。在考场上，第一步永远是**识别级数类型**（正项？交错？任意项？幂级数？），第二步才是**套用对应判别法或展开公式**。

------

### （〇）必须熟记的参照级数（所有判敛的“锚点”）

| **参照级数** | **敛散结论** |
| --- | --- |
| **等比（几何）级数** $\sum_{n=0}^{\infty} aq^n$ | $\|q\| < 1$ 时收敛，和为 $\frac{a}{1-q}$；$\|q\| \ge 1$ 时发散 |
| **$p$-级数** $\sum_{n=1}^{\infty} \frac{1}{n^p}$ | $p > 1$ 收敛；$p \le 1$ 发散 |
| **调和级数** $\sum_{n=1}^{\infty} \frac{1}{n}$ | 发散（$p = 1$ 的特例）；部分和 $S_n = \ln n + \gamma + o(1)$ |
| **交错 $p$-级数** $\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n^p}$ | $p > 1$ 绝对收敛；$0 < p \le 1$ 条件收敛；$p \le 0$ 发散 |

------

### （一）数项级数基础

#### 1. 定义与本质

- **部分和**：$S_n = \sum_{k=1}^{n} u_k$；**收敛** $\iff \lim\limits_{n \to \infty} S_n = S$ 存在，否则发散。
- **核心认知**：级数问题 = 部分和数列的极限问题；敛散性只取决于“尾巴”（增删改有限项不改变敛散性，但会改变和）。

#### 2. 基本性质（避坑高频）

- **线性**：$\sum (k_1 u_n + k_2 v_n)$：收敛 ± 收敛 = 收敛；**收敛 ± 发散 = 发散**（反证法利器）；发散 ± 发散 = **不确定**。
- **加括号**：收敛级数任意加括号仍收敛且和不变；**加括号后发散 ⟹ 原级数必发散**（判散利器）；加括号后收敛 ⇏ 原级数收敛（反例 $1-1+1-1+\cdots$）。

#### 3. 收敛的必要条件

$$
\sum_{n=1}^{\infty} u_n \ \text{收敛} \implies \lim_{n \to \infty} u_n = 0
$$

- 几乎只用来**判发散**：$\lim u_n \neq 0$ 或不存在 ⟹ 必发散。
- 避坑：$u_n \to 0$ **不保证**收敛（调和级数反例）——必要条件 ≠ 充分条件。

------

### （二）正项级数（$u_n \ge 0$）判别法

**基本定理**：正项级数收敛 $\iff$ 部分和数列 $S_n$ 有上界（一切判别法的祖宗）。

#### 1. 比较判别法及其极限形式

- **原始形式**：$0 \le u_n \le v_n$，则“大收 ⟹ 小收；小发 ⟹ 大发”。
- **极限形式**：设 $\lim\limits_{n \to \infty} \frac{u_n}{v_n} = \lambda$：
  - $0 < \lambda < +\infty$：$\sum u_n$ 与 $\sum v_n$ **同敛散**；
  - $\lambda = 0$：大收 ⟹ 小收；
  - $\lambda = +\infty$：小发 ⟹ 大发。
- **实战要领**：用**等价无穷小**找参照。$n \to \infty$ 时 $\sin\frac{1}{n} \sim \frac{1}{n}$、$\ln(1+\frac{a}{n}) \sim \frac{a}{n}$、$e^{\frac{1}{n}}-1 \sim \frac{1}{n}$、$1-\cos\frac{1}{n} \sim \frac{1}{2n^2}$，本质都是与 $p$-级数比（抓大头定 $p$）。

#### 2. 比值判别法（达朗贝尔）

$$
\rho = \lim_{n \to \infty} \frac{u_{n+1}}{u_n}：
\begin{cases}
\rho < 1, & \text{收敛} \\
\rho > 1, & \text{发散（且 } u_n \not\to 0\text{）} \\
\rho = 1, & \text{失效，改用比较判别法}
\end{cases}
$$

- 适用特征：通项含 **$n!$** 或 **$a^n$**。

#### 3. 根值判别法（柯西）

$$
\rho = \lim_{n \to \infty} \sqrt[n]{u_n}：\text{结论同比值判别法}
$$

- 适用特征：通项整体带 **$n$ 次根**，或形如 $[f(n)]^n$。

#### 4. 积分判别法

$f(x)$ 在 $[1, +\infty)$ 连续、非负、单调递减，则 $\sum f(n)$ 与 $\int_1^{+\infty} f(x)\,dx$ **同敛散**。经典应用：$\sum \frac{1}{n \ln n}$ 发散。

#### 5. 选用顺序

先看必要条件（$u_n \not\to 0$ 直接发散）→ 含 $n!$ / $a^n$ 用比值 → 含 $n$ 次根用根值 → 一般形式用等价无穷小 + 比较 → 都失效再用积分判别法、部分和定义、加括号技巧。

------

### （三）交错级数与任意项级数

#### 1. 莱布尼茨判别法（交错级数 $\sum (-1)^{n-1} u_n$，$u_n > 0$）

**两个条件**：① $u_n$ 单调不增（从某项起即可）；② $\lim\limits_{n \to \infty} u_n = 0$。满足 ⟹ 收敛，且**余项估计** $|r_n| \le u_{n+1}$。

- 避坑：两条件是**充分不必要**——“不单调”不能推出发散，只能说莱布尼茨失效，需另找办法。

#### 2. 绝对收敛与条件收敛

- $\sum |u_n|$ 收敛 ⟹ $\sum u_n$ 必收敛（**绝对收敛**）；收敛但不绝对 ⟹ **条件收敛**。
- **流程**：任意项级数先取绝对值按正项级数判；$\sum |u_n|$ 发散时，若原级数是交错级数再上莱布尼茨。
- 常考结论：条件收敛级数，其**全体正项子级数与全体负项子级数均发散**。

------

### （四）幂级数 $\sum_{n=0}^{\infty} a_n (x-x_0)^n$

#### 1. 阿贝尔定理与收敛半径

- **阿贝尔定理**：在 $x_1 \neq x_0$ 处收敛 ⟹ 对一切 $|x - x_0| < |x_1 - x_0|$ **绝对收敛**；在 $x_1$ 处发散 ⟹ 对一切 $|x-x_0| > |x_1-x_0|$ 发散。
- **收敛半径**：

$$
\rho = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right| \quad \left( \text{或 } \rho = \lim_{n \to \infty} \sqrt[n]{|a_n|} \right), \qquad R = \frac{1}{\rho}
$$

- $\rho = 0 \implies R = +\infty$；$\rho = +\infty \implies R = 0$（仅在 $x_0$ 收敛）。

#### 2. 收敛区间与收敛域

- **收敛区间**：$(x_0 - R,\ x_0 + R)$（开区间）；**收敛域** = 收敛区间 ∪ 收敛的端点，**端点必须单独代入数项级数判敛**。
- **缺项幂级数**（如 $\sum \frac{(x-1)^{2n}}{n \cdot 4^n}$）：不能套系数公式，直接对 $\left| \frac{u_{n+1}(x)}{u_n(x)} \right|$ 用比值法，解出 $|x - x_0| < R$。

#### 3. 幂级数的分析性质（求和函数的工具）

在收敛区间内部可**逐项求导**、**逐项积分**：收敛半径 $R$ 不变（收敛域端点可能改变：求导可能丢端点、积分可能得端点）。

$$
S'(x) = \sum_{n=1}^{\infty} n a_n x^{n-1}, \qquad \int_0^x S(t)\,dt = \sum_{n=0}^{\infty} \frac{a_n}{n+1} x^{n+1}
$$

#### 4. 求和函数套路（必先求收敛域）

1. **求收敛域**（第一步，不能省）。
2. **观察系数形态**：系数含 $n$、$n+1$ → 逐项求导消掉；系数含 $\frac{1}{n}$、$\frac{1}{n+1}$ → 先逐项积分生出来；目标是化成**等比级数**。
3. 下标对齐后用 $\sum x^n = \frac{1}{1-x}$，再逆运算（积分 / 求导）还原，**最后标注收敛域**。
4. 常用结果：

$$
\sum_{n=1}^{\infty} n x^{n-1} = \frac{1}{(1-x)^2}, \quad \sum_{n=1}^{\infty} \frac{x^n}{n} = -\ln(1-x) \ (-1 \le x < 1), \quad \sum_{n=1}^{\infty} \frac{(-1)^{n-1} x^n}{n} = \ln(1+x) \ (-1 < x \le 1)
$$

#### 5. 函数展开为幂级数（间接法为主）

思路：代换（把 $\frac{x}{2}$、$x^2$ 看成整体）、逐项求导 / 积分、先拆项，再套下表：

$$
e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!}, \quad x \in \mathbb{R}
$$

$$
\sin x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{(2n+1)!}, \quad \cos x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!}, \quad x \in \mathbb{R}
$$

$$
\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n, \quad \frac{1}{1+x} = \sum_{n=0}^{\infty} (-1)^n x^n, \quad |x| < 1
$$

$$
\ln(1+x) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1} x^n}{n}, \quad x \in (-1, 1]; \qquad \arctan x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{2n+1}, \quad x \in [-1, 1]
$$

$$
(1+x)^{\alpha} = 1 + \sum_{n=1}^{\infty} \frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!} x^n, \quad |x| < 1 \ (\text{端点随 } \alpha \text{ 讨论})
$$

### （五）傅里叶级数（数学一专属）

#### 1. 周期 $2\pi$ 的傅里叶级数

$$
f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} (a_n \cos nx + b_n \sin nx)
$$

$$
a_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \cos nx \, dx \ (n = 0, 1, 2, \cdots), \qquad b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \sin nx \, dx \ (n = 1, 2, \cdots)
$$

#### 2. 狄利克雷收敛定理（考“和函数在某点的值”，不必真展开）

若 $f(x)$ 在 $[-\pi, \pi]$ 上连续或只有有限个第一类间断点、只有有限个极值点，则傅里叶级数处处收敛于：

- **连续点**：$f(x)$ 本身；
- **间断点**：$\frac{f(x^-) + f(x^+)}{2}$（左右极限平均值）；
- **端点** $x = \pm\pi$：$\frac{f(-\pi^+) + f(\pi^-)}{2}$。

#### 3. 正弦级数与余弦级数（$[0, \pi]$ 上的展开）

- **奇函数** ⟹ 只含正弦项（$a_n = 0$）：$b_n = \frac{2}{\pi} \int_0^{\pi} f(x) \sin nx \, dx$；
- **偶函数** ⟹ 只含余弦项（$b_n = 0$）：$a_n = \frac{2}{\pi} \int_0^{\pi} f(x) \cos nx \, dx$（$a_0$ 同式取 $n=0$）。
- 仅在 $[0, \pi]$ 有定义：求正弦级数作**奇延拓**、求余弦级数作**偶延拓**——不必真延拓，直接套上式。

#### 4. 周期 $2l$ 的推广

把 $\pi$ 全部换成 $l$、$\cos nx / \sin nx$ 换成 $\cos \frac{n\pi x}{l} / \sin \frac{n\pi x}{l}$，系数相应变为 $\frac{1}{l} \int_{-l}^{l}$ 与 $\frac{2}{l} \int_0^{l}$。

------

### （六）判敛流程速查（文字版流程）

1. **必要条件**：$\lim u_n \neq 0$ 或不存在 ⟹ **发散**，结束。
2. **变号级数**？→ 先判 $\sum |u_n|$：收敛 ⟹ **绝对收敛**；发散 ⟹ 交错级数上**莱布尼茨**（得条件收敛），否则拆项 / 部分和定义。
3. **正项级数**：含 $n!$ 或 $a^n$ → **比值**；含 $n$ 次根 → **根值**；一般 → **等价无穷小 + 比较判别法**（对 $p$-级数）；仍失效 → 积分判别法 / 加括号 / 部分和定义。
4. 比值、根值出现 $\rho = 1$：一律**失效**，回到比较判别法。

------

### （七）高频易错点清单

- $u_n \to 0$ 只是**必要**条件（调和级数反例）；比值 / 根值 $\rho = 1$ 判别法**失效**。
- **收敛区间 ≠ 收敛域**：端点必须单独验证；求和函数、展开函数的答案**必须标注收敛域**。
- 逐项求导 / 积分：$R$ 不变，**端点敛散性可能改变**。
- 收敛 ± 发散 = 发散；发散 ± 发散不确定；增删改有限项不改变敛散性但**改变和**。
- 加括号：收敛 ⟹ 加括号仍收敛；**加括号后发散 ⟹ 原级数发散**；加括号后收敛 ⇏ 原级数收敛。
- 绝对收敛 ⟹ 收敛；条件收敛级数的正项、负项子级数**均发散**。
- 傅里叶和函数：间断点与端点收敛于**左右极限的平均值**——求 $S(x)$ 在某点的值先看该点是不是间断点。
- 数项级数求和常用结果备查：$\sum \frac{1}{n(n+1)} = 1$（裂项）、$\sum \frac{(-1)^{n-1}}{n} = \ln 2$、$\sum \frac{1}{n^2} = \frac{\pi^2}{6}$、$\sum \frac{(-1)^{n-1}}{2n-1} = \frac{\pi}{4}$。
