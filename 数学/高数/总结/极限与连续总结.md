一份全景式的"函数极限与连续核心考点速查表"。在考场上，拿到极限题的第一步永远是**识别题型**（未定式类型？要不要分左右极限？间断点分类？），第二步才是**套用对应工具**（等价无穷小、重要极限、夹逼、洛必达与泰勒）。

### （〇）必须熟记的等价无穷小（所有极限计算的"锚点"）

| **基础公式（$x \to 0$）** | **差值公式（$x \to 0$）** |
| --- | --- |
| $\sin x \sim x \sim \tan x \sim \arcsin x \sim \arctan x$ | $x - \sin x \sim \dfrac{1}{6}x^3$ |
| $\ln(1+x) \sim x$；$e^x - 1 \sim x$ | $x - \arcsin x \sim -\dfrac{1}{6}x^3$ |
| $1 - \cos x \sim \dfrac{1}{2}x^2$ | $x - \tan x \sim -\dfrac{1}{3}x^3$ |
| $(1+x)^a - 1 \sim ax$；$a^x - 1 \sim x\ln a$ | $x - \arctan x \sim \dfrac{1}{3}x^3$ |
| （"套壳"化简：$\ln\dfrac{\arcsin x}{x} = \ln\left(1 + \dfrac{\arcsin x - x}{x}\right) \sim \dfrac{\arcsin x - x}{x}$） | $x - \ln(1+x) \sim \dfrac{1}{2}x^2$ |

### （一）极限的概念与性质

#### 1. 定义与存在条件

- **数列极限**：$\lim\limits_{n \to \infty} a_n = L$；**与前有限项无关**（增删改有限项不改变极限）。
- **子列判别**：$\lim\limits_{n \to \infty} a_n = L \iff$ **任意**子列 $a_{n_k} \to L$；找一个子列发散、或两个子列极限不同 ⟹ 原极限不存在。
- **函数极限存在的充要条件**：

$$
\lim_{x \to x_0} f(x) = L \iff \lim_{x \to x_0^-} f(x) = \lim_{x \to x_0^+} f(x) = L
$$

- **必分左右极限的信号**：$e^{\frac{1}{x}}$、$\arctan\frac{1}{x}$、取整函数、分段函数的分段点（$x \to 0^+$ 与 $x \to 0^-$ 行为完全不同）。

#### 2. 极限的性质（存在则唯一）

- **局部有界性**：极限存在 ⟹ 某个**去心邻域**内有界。
- **局部保号性**：$A > 0$ ⟹ 邻域内 $f(x) > 0$；**反推时只能得 $A \ge 0$**（不等号变弱）。

------

### （二）极限的计算工具箱

#### 1. 四则与复合运算法则

- 四则：各极限**存在**才能拆；除法要求分母极限 $\ne 0$。
- 复合：$\lim\limits_{x \to x_0} f(g(x)) = f\left(\lim\limits_{x \to x_0} g(x)\right)$——外层在该点**连续**时，极限符号可以钻进函数内部。

#### 2. 两个存在准则

- **夹逼准则**：$g(x) \le f(x) \le h(x)$ 且两端同极限 ⟹ 中间同极限。适用：$n$ 项和、难以化简的式子（放缩抓大头）。
- **单调有界准则**：数列单调 + 有界 ⟹ 极限存在。适用：递推数列 $a_{n+1} = f(a_n)$ 证收敛（先证单调有界，再两边取极限解方程）。

#### 3. 两个重要极限

$$
\lim_{x \to 0} \frac{\sin x}{x} = 1 \qquad \qquad \lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e
$$

- **$1^\infty$ 型万能公式**：当 $\lim f(x) = 1$、$\lim g(x) = \infty$ 时，

$$
\lim [f(x)]^{g(x)} = e^{\lim [f(x) - 1]\,g(x)}
$$

### （三）无穷小、无穷大与无穷小的比较

#### 1. 无穷小的比较（设 $\lim \dfrac{\alpha}{\beta}$ 在同一过程中存在）

| 条件 | 结论 |
| --- | --- |
| $= 0$ | $\alpha$ 是 $\beta$ 的**高阶**无穷小，记 $\alpha = o(\beta)$ |
| $= \infty$ | $\alpha$ 是 $\beta$ 的**低阶**无穷小 |
| $= c \ne 0$ | **同阶**无穷小 |
| $= 1$ | **等价**无穷小 $\alpha \sim \beta$ |
| $\lim \dfrac{\alpha}{\beta^n} = c \ne 0$ | $\alpha$ 是 $\beta$ 的 **$n$ 阶**无穷小 |

#### 2. 等价替换定理

- $\lim \dfrac{\alpha}{\beta} = \lim \dfrac{\alpha_1}{\beta_1}$（$\alpha \sim \alpha_1$，$\beta \sim \beta_1$）；本质：$\alpha \sim \beta \iff \beta = \alpha + o(\alpha)$。
- **乘除因子可直接替换；加减中慎用**（易丢高阶项）——确需替换时改用泰勒展开保留足够阶数。
- $\lim f = a \iff f = a + \alpha$（$\alpha$ 为无穷小）——"极限值 = 函数 − 无穷小"。

#### 3. 无穷大量

- **倒数关系**（同一过程）：无穷大 ⟺ 倒数为无穷小。
- **无穷大 ⟹ 无界；无界 ⇏ 无穷大**（如 $x\sin x$ 在 $x \to \infty$ 时无界但非无穷大）。

### （四）连续与间断点

#### 1. 连续性

- 定义：$\lim\limits_{x \to x_0} f(x) = f(x_0)$（等价于 $\Delta y \to 0$）；连续 ⟺ **既左连续又右连续**。
- 闭区间 $[a, b]$ 上连续 = $(a, b)$ 内连续 + $a$ 右连续 + $b$ 左连续。
- 连续函数经四则（分母 $\ne 0$）、复合仍连续；初等函数在**定义区间**内处处连续。

#### 2. 间断点分类（先找点：初等函数的无定义点、分段函数的分段点）

| 大类 | 左右极限 | 类型 | 判断特征 | 典型例子（$x = 0$） |
| --- | --- | --- | --- | --- |
| **第一类** | **均存在** | 可去间断点 | 左 = 右 ≠ 函数值（或无定义） | $\dfrac{\sin x}{x}$ |
| **第一类** | **均存在** | 跳跃间断点 | 左 ≠ 右 | $\text{sgn}(x)$ |
| **第二类** | 至少一个不存在 | 无穷间断点 | 极限为 $\infty$ | $\dfrac{1}{x}$ |
| **第二类** | 至少一个不存在 | 振荡间断点 | 极限振荡不存在 | $\sin\dfrac{1}{x}$ |

------

### （五）闭区间上连续函数的四大定理

| 定理 | 条件 | 结论 / 用途 |
| --- | --- | --- |
| **最值定理** | $[a, b]$ 上连续 | 必有最大值与最小值 |
| **有界性定理** | $[a, b]$ 上连续 | 必有界（推广：开区间连续 + 两端点极限存在 ⟹ 有界） |
| **介值定理** | $[a, b]$ 上连续 | 可取到 $f(a)$、$f(b)$ 之间（即 $m$、$M$ 之间）的一切值 |
| **零点定理** | $[a, b]$ 上连续且 $f(a) \cdot f(b) < 0$ | 存在 $\xi \in (a, b)$ 使 $f(\xi) = 0$（证方程有根） |

### （六）极限计算流程（文字版流程）

1. **先化简**：乘除因子等价替换、提出非零极限因子、抓大头。
2. **定型**：$\frac{0}{0}$、$\frac{\infty}{\infty}$ → 洛必达或泰勒（见《一元函数微分学总结》）；$1^\infty$ → $e^{\lim[f-1]g}$；$0 \cdot \infty$、$\infty - \infty$ → 先通分/有理化化为分式。
3. **含 $e^{\frac{1}{x}}$、$\arctan\frac{1}{x}$、取整、分段点** → 左右极限分讨，相等才有极限。
4. **$n$ 项和** → 夹逼准则或定积分定义。
5. **递推数列** → 单调有界准则。

### （七）高频易错点清单

- 极限与**前有限项无关**，但与"尾巴"有关——子列判别找反例最快。
- 局部有界性强调**去心邻域**；保号性反推不等号变弱（$f \ge 0 \Rightarrow A \ge 0$）。
- 等价替换**只对乘除因子安全**，加减慎用（调和"$\arcsin x - \tan x$"类题必须上泰勒）。
- 无穷大必无界，无界未必无穷大。
- 判间断点两步走：先**找点**，再**算左右极限**；第一类/第二类的分界是"左右极限是否均存在"。
- 零点定理两前提缺一不可：**闭区间连续 + 端点异号**。
- $1^\infty$ 直接套 $e^{\lim[f-1]g}$，别硬凑第二个重要极限。
