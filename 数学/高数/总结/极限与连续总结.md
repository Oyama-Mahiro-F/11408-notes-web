一份全景式的"函数极限与连续核心考点速查表"。在考场上，拿到极限题的第一步永远是**识别题型**（未定式类型？要不要分左右极限？间断点分类？），第二步才是**套用对应工具**（等价无穷小、重要极限、夹逼、洛必达与泰勒）。

### （〇）必须熟记的等价无穷小（所有极限计算的"锚点"）

| **基础公式（$x \to 0$）** | **差值公式（$x \to 0$）** |
| --- | --- |
| $\sin x \sim x \sim \tan x \sim \arcsin x \sim \arctan x$ | $x - \sin x \sim \dfrac{1}{6}x^3$ |
| $\ln(1+x) \sim x$；$e^x - 1 \sim x$ | $x - \arcsin x \sim -\dfrac{1}{6}x^3$ |
| $1 - \cos x \sim \dfrac{1}{2}x^2$ | $x - \tan x \sim -\dfrac{1}{3}x^3$ |
| $(1+x)^a - 1 \sim ax$；$a^x - 1 \sim x\ln a$ | $x - \arctan x \sim \dfrac{1}{3}x^3$ |
| （"套壳"化简：$\ln\dfrac{\arcsin x}{x} = \ln\left(1 + \dfrac{\arcsin x - x}{x}\right) \sim \dfrac{\arcsin x - x}{x}$） | $x - \ln(1+x) \sim \dfrac{1}{2}x^2$ |

### （一）极限的概念与性质

#### 1. 定义与存在条件

- **数列极限**：$\lim\limits_{n \to \infty} a_n = L$；**与前有限项无关**（增删改有限项不改变极限）。
- **子列判别**：$\lim\limits_{n \to \infty} a_n = L \iff$ **任意**子列 $a_{n_k} \to L$；找一个子列发散、或两个子列极限不同 ⟹ 原极限不存在。
- **函数极限存在的充要条件**：

$$
\lim_{x \to x_0} f(x) = L \iff \lim_{x \to x_0^-} f(x) = \lim_{x \to x_0^+} f(x) = L
$$

- **必分左右极限的信号**：$e^{\frac{1}{x}}$、$\arctan\frac{1}{x}$、取整函数、分段函数的分段点（$x \to 0^+$ 与 $x \to 0^-$ 行为完全不同）。

#### 2. 极限的性质（存在则唯一）

- **局部有界性**：极限存在 ⟹ 某个**去心邻域**内有界。
- **局部保号性**：$A > 0$ ⟹ 邻域内 $f(x) > 0$；**反推时只能得 $A \ge 0$**（不等号变弱）。

------

### （二）极限的计算工具箱

#### 1. 四则与复合运算法则

- 四则：各极限**存在**才能拆；除法要求分母极限 $\ne 0$。
- 复合：$\lim\limits_{x \to x_0} f(g(x)) = f\left(\lim\limits_{x \to x_0} g(x)\right)$——外层在该点**连续**时，极限符号可以钻进函数内部。

#### 2. 两个存在准则

- **夹逼准则**：$g(x) \le f(x) \le h(x)$ 且两端同极限 ⟹ 中间同极限。适用：$n$ 项和、难以化简的式子（放缩抓大头）。
- **单调有界准则**：数列单调 + 有界 ⟹ 极限存在。适用：递推数列 $a_{n+1} = f(a_n)$ 证收敛（先证单调有界，再两边取极限解方程）。

#### 3. 两个重要极限

$$
\lim_{x \to 0} \frac{\sin x}{x} = 1 \qquad \qquad \lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e
$$

- **$1^\infty$ 型万能公式**：当 $\lim f(x) = 1$、$\lim g(x) = \infty$ 时，

$$
\lim [f(x)]^{g(x)} = e^{\lim [f(x) - 1]\,g(x)}
$$

### （三）无穷小、无穷大与无穷小的比较

#### 1. 无穷小的比较（设 $\lim \dfrac{\alpha}{\beta}$ 在同一过程中存在）

| 条件 | 结论 |
| --- | --- |
| $= 0$ | $\alpha$ 是 $\beta$ 的**高阶**无穷小，记 $\alpha = o(\beta)$ |
| $= \infty$ | $\alpha$ 是 $\beta$ 的**低阶**无穷小 |
| $= c \ne 0$ | **同阶**无穷小 |
| $= 1$ | **等价**无穷小 $\alpha \sim \beta$ |
| $\lim \dfrac{\alpha}{\beta^n} = c \ne 0$ | $\alpha$ 是 $\beta$ 的 **$n$ 阶**无穷小 |

#### 2. 等价替换定理

- $\lim \dfrac{\alpha}{\beta} = \lim \dfrac{\alpha_1}{\beta_1}$（$\alpha \sim \alpha_1$，$\beta \sim \beta_1$）；本质：$\alpha \sim \beta \iff \beta = \alpha + o(\alpha)$。
- **乘除因子可直接替换；加减中慎用**（易丢高阶项）——确需替换时改用泰勒展开保留足够阶数。
- $\lim f = a \iff f = a + \alpha$（$\alpha$ 为无穷小）——"极限值 = 函数 − 无穷小"。

#### 3. 无穷大量

- **倒数关系**（同一过程）：无穷大 ⟺ 倒数为无穷小。
- **无穷大 ⟹ 无界；无界 ⇏ 无穷大**（如 $x\sin x$ 在 $x \to \infty$ 时无界但非无穷大）。

------

### （四）连续与间断点

#### 1. 连续性

- 定义：$\lim\limits_{x \to x_0} f(x) = f(x_0)$（等价于 $\Delta y \to 0$）；连续 ⟺ **既左连续又右连续**。
- 闭区间 $[a, b]$ 上连续 = $(a, b)$ 内连续 + $a$ 右连续 + $b$ 左连续。
- 连续函数经四则（分母 $\ne 0$）、复合仍连续；初等函数在**定义区间**内处处连续。

#### 2. 间断点分类（先找点：初等函数的无定义点、分段函数的分段点）

| 大类 | 左右极限 | 类型 | 判断特征 | 典型例子（$x = 0$） |
| --- | --- | --- | --- | --- |
| **第一类** | **均存在** | 可去间断点 | 左 = 右 ≠ 函数值（或无定义） | $\dfrac{\sin x}{x}$ |
| **第一类** | **均存在** | 跳跃间断点 | 左 ≠ 右 | $\text{sgn}(x)$ |
| **第二类** | 至少一个不存在 | 无穷间断点 | 极限为 $\infty$ | $\dfrac{1}{x}$ |
| **第二类** | 至少一个不存在 | 振荡间断点 | 极限振荡不存在 | $\sin\dfrac{1}{x}$ |

------

### （五）闭区间上连续函数的四大定理

| 定理 | 条件 | 结论 / 用途 |
| --- | --- | --- |
| **最值定理** | $[a, b]$ 上连续 | 必有最大值与最小值 |
| **有界性定理** | $[a, b]$ 上连续 | 必有界（推广：开区间连续 + 两端点极限存在 ⟹ 有界） |
| **介值定理** | $[a, b]$ 上连续 | 可取到 $f(a)$、$f(b)$ 之间（即 $m$、$M$ 之间）的一切值 |
| **零点定理** | $[a, b]$ 上连续且 $f(a) \cdot f(b) < 0$ | 存在 $\xi \in (a, b)$ 使 $f(\xi) = 0$（证方程有根） |

### （六）极限计算流程（文字版流程）

1. **先化简**：乘除因子等价替换、提出非零极限因子、抓大头。
2. **定型**：$\frac{0}{0}$、$\frac{\infty}{\infty}$ → 洛必达或泰勒（见《一元函数微分学总结》）；$1^\infty$ → $e^{\lim[f-1]g}$；$0 \cdot \infty$、$\infty - \infty$ → 先通分/有理化化为分式。
3. **含 $e^{\frac{1}{x}}$、$\arctan\frac{1}{x}$、取整、分段点** → 左右极限分讨，相等才有极限。
4. **$n$ 项和** → 夹逼准则或定积分定义。
5. **递推数列** → 单调有界准则。

------

### （七）高频易错点清单

- 极限与**前有限项无关**，但与"尾巴"有关——子列判别找反例最快。
- 局部有界性强调**去心邻域**；保号性反推不等号变弱（$f \ge 0 \Rightarrow A \ge 0$）。
- 等价替换**只对乘除因子安全**，加减慎用（调和"$\arcsin x - \tan x$"类题必须上泰勒）。
- 无穷大必无界，无界未必无穷大。
- 判间断点两步走：先**找点**，再**算左右极限**；第一类/第二类的分界是"左右极限是否均存在"。
- 零点定理两前提缺一不可：**闭区间连续 + 端点异号**。
- $1^\infty$ 直接套 $e^{\lim[f-1]g}$，别硬凑第二个重要极限。

### （八）典型例题（考场实战）

#### 例1　等价无穷小与泰勒：$\frac{0}{0}$ 型

**【题目】** 求 $\displaystyle\lim_{x\to 0}\frac{e^{x}\sin x - x - x^{2}}{x^{3}}$。

**【解】** 这是 $\frac{0}{0}$ 型。分母是 $x^{3}$，故分子必须展开到 $x^{3}$；$e^{x}$ 与 $\sin x$ 的展开式相乘，只保留到 $x^{3}$ 项：

$$
e^{x}\sin x = \left(1 + x + \frac{x^{2}}{2} + \frac{x^{3}}{6} + o(x^{3})\right)\left(x - \frac{x^{3}}{6} + o(x^{3})\right)
= x + x^{2} + \frac{x^{3}}{3} + o(x^{3}).
$$

（$x^{3}$ 项来自 $1\cdot\left(-\dfrac{x^{3}}{6}\right)$ 与 $\dfrac{x^{2}}{2}\cdot x$ 的合并，其余乘积都是 $x^{4}$ 以上的高阶项。）于是

$$
\lim_{x\to 0}\frac{e^{x}\sin x - x - x^{2}}{x^{3}}
= \lim_{x\to 0}\frac{\dfrac{x^{3}}{3} + o(x^{3})}{x^{3}} = \frac{1}{3}.
$$

**【结论】** 原极限 $= \dfrac{1}{3}$。

> **方法**：加减与乘积混合的 $\frac{0}{0}$ 型，用泰勒公式把分子展开到与分母同阶，再逐项相消。
>
> **易错点**：把 $e^{x}$ 只取到 $1 + x$、$\sin x$ 只取到 $x$，乘出 $x(1 + x)$ 会丢掉 $x^{3}$ 项而错得 $0$——加减与乘积混合时展开阶数不够，是本题最大陷阱。

#### 例2　$1^{\infty}$ 型：幂指函数的极限

**【题目】** 求 $\displaystyle\lim_{x\to 0}\left(\frac{\sin x}{x}\right)^{\frac{1}{x^{2}}}$。

**【解】** 底数 $\frac{\sin x}{x}\to 1$、指数 $\frac{1}{x^{2}}\to +\infty$，属 $1^{\infty}$ 型。先用 $1^{\infty}$ 型公式化成 $e$ 的指数：

$$
L = \exp\left\{\lim_{x\to 0}\frac{1}{x^{2}}\left(\frac{\sin x}{x} - 1\right)\right\}
= \exp\left\{\lim_{x\to 0}\frac{\sin x - x}{x^{3}}\right\}.
$$

用泰勒公式 $\sin x = x - \dfrac{x^{3}}{6} + o(x^{3})$，得 $\sin x - x = -\dfrac{x^{3}}{6} + o(x^{3})$，故

$$
\lim_{x\to 0}\frac{\sin x - x}{x^{3}} = -\frac{1}{6},
\qquad L = e^{-\frac{1}{6}}.
$$

**【结论】** 原极限 $= e^{-\frac{1}{6}}$。

> **方法**：$1^{\infty}$ 型一律先化到 $\lim[f(x)]^{g(x)} = e^{\lim[f(x)-1]g(x)}$，再用等价无穷小或泰勒算出指数上的极限。
>
> **易错点**：不能由"底数 $\to 1$"直接写 $1^{\infty} = 1$；也不能对幂指函数直接洛必达，必须先取对数或写成 $e$ 的指数。

#### 例3　左右极限与间断点分类

**【题目】** 求函数 $f(x) = \dfrac{x^{2} - x}{|x|\,(x^{2} - 1)}$ 的间断点，并判断各间断点的类型。

**【解】** 无定义点 $x = 0, 1, -1$ 就是全部候选间断点。在 $x \ne 0, \pm 1$ 处约去公因子 $x - 1$，得简化式

$$
f(x) = \frac{x(x - 1)}{|x|(x - 1)(x + 1)} = \frac{x}{|x|(x + 1)}.
$$

- **$x = 0$**：左极限 $\lim\limits_{x\to 0^{-}}\dfrac{x}{|x|(x + 1)} = \lim\limits_{x\to 0^{-}}\dfrac{-1}{x + 1} = -1$，右极限 $\lim\limits_{x\to 0^{+}}\dfrac{x}{|x|(x + 1)} = \lim\limits_{x\to 0^{+}}\dfrac{1}{x + 1} = 1$。左右极限都存在但不等，为**跳跃间断点**（第一类）。
- **$x = 1$**：$\lim\limits_{x\to 1}f(x) = \dfrac{1}{1\cdot 2} = \dfrac{1}{2}$ 存在，而 $f(1)$ 无定义，为**可去间断点**（第一类）。
- **$x = -1$**：分子 $\to -1 \ne 0$，分母 $|x|(x + 1) \to 0$，故 $\lim\limits_{x\to -1}f(x) = \infty$，为**无穷间断点**（第二类）。

**【结论】** $x = 0$ 为跳跃间断点（左极限 $-1$、右极限 $1$）；$x = 1$ 为可去间断点（极限 $\dfrac{1}{2}$）；$x = -1$ 为无穷间断点。

> **方法**：判间断点两步走——先找无定义点（或分段点），再逐个算左右极限；第一类与第二类的分界是"左右极限是否都存在"。
>
> **易错点**：约分只在极限过程中成立，不能因此把 $x = 1$ 说成连续点；$x\to 0$ 时 $|x|$ 必须分左右，符号丢掉会把跳跃间断点误判成可去间断点。

#### 例4　夹逼准则：$n$ 项和的极限

**【题目】** 求 $\displaystyle\lim_{n\to\infty}\left(\frac{1}{\sqrt{n^{2} + 1}} + \frac{1}{\sqrt{n^{2} + 2}} + \cdots + \frac{1}{\sqrt{n^{2} + n}}\right)$。

**【解】** 记括号中的和为 $S_n$。和式共 $n$ 项，每项的分母介于 $\sqrt{n^{2} + 1}$ 与 $\sqrt{n^{2} + n}$ 之间，故每一项都介于这两个分母对应的分式之间：

$$
\frac{n}{\sqrt{n^{2} + n}} \le S_n \le \frac{n}{\sqrt{n^{2} + 1}}.
$$

两端分别求极限：

$$
\lim_{n\to\infty}\frac{n}{\sqrt{n^{2} + n}} = \lim_{n\to\infty}\frac{1}{\sqrt{1 + \frac{1}{n}}} = 1,
\qquad
\lim_{n\to\infty}\frac{n}{\sqrt{n^{2} + 1}} = 1.
$$

由夹逼准则，$\lim\limits_{n\to\infty}S_n = 1$。

**【结论】** 原极限 $= 1$。

> **方法**：$n$ 项和不能逐项取极限时，把每一项统一放缩（分母放大或缩小到同一形式），使两端都化成可求的简单极限。
>
> **易错点**：两端极限必须相等才能夹逼，只证一端无效；也不要把"$n$ 项之和"误当成"$n$ 乘每项的极限"。

#### 例5　单调有界准则：递推数列

**【题目】** 设 $a_1 = \sqrt{2}$，$a_{n + 1} = \sqrt{2 + a_n}$（$n = 1, 2, \dots$）。证明数列 $\{a_n\}$ 收敛，并求 $\lim\limits_{n\to\infty}a_n$。

**【解】** 先证有界：归纳证明 $0 < a_n < 2$。$a_1 = \sqrt{2} < 2$ 成立；若 $0 < a_n < 2$，则 $a_{n + 1} = \sqrt{2 + a_n} < \sqrt{4} = 2$，且 $a_{n + 1} > 0$，归纳完成。

再证单调递增。考察相邻两项的平方差：

$$
a_{n + 1}^{2} - a_{n}^{2} = (2 + a_n) - a_n^{2} = (2 - a_n)(1 + a_n) > 0,
$$

故 $a_{n + 1} > a_n$。由单调有界准则，$\lim\limits_{n\to\infty}a_n = A$ 存在。

对递推式两边取极限：$A = \sqrt{2 + A}$，即 $A^{2} - A - 2 = 0$，解得 $A = 2$ 或 $A = -1$。因 $a_n > 0$，故 $A \ge 0$，只能取 $A = 2$。

**【结论】** 数列 $\{a_n\}$ 收敛，且 $\lim\limits_{n\to\infty}a_n = 2$。

> **方法**：递推数列证收敛的固定套路——用归纳法证有界、再证单调（作差或作商），最后对递推式两边取极限解方程。
>
> **易错点**：极限方程可能有多余根，必须用有界范围舍去（$A = -1$ 被 $a_n > 0$ 排除）；"单调"要给出判号过程，不能只凭前几项观察下结论。

#### 例6　零点定理：方程实根的个数与位置

**【题目】** 证明方程 $x^{3} - 3x + 1 = 0$ 恰有三个实根，并指出它们所在的区间。

**【解】** 令 $f(x) = x^{3} - 3x + 1$，则 $f$ 在 $\mathbb{R}$ 上连续。计算若干关键点处的函数值：

$$
f(-2) = -1,\quad f(-1) = 3,\quad f(0) = 1,\quad f(1) = -1,\quad f(2) = 3.
$$

在三个端点异号的闭区间上分别用零点定理：

- $[-2, -1]$：$f(-2) < 0 < f(-1)$，存在 $\xi_1 \in (-2, -1)$ 使 $f(\xi_1) = 0$；
- $[0, 1]$：$f(1) < 0 < f(0)$，存在 $\xi_2 \in (0, 1)$ 使 $f(\xi_2) = 0$；
- $[1, 2]$：$f(1) < 0 < f(2)$，存在 $\xi_3 \in (1, 2)$ 使 $f(\xi_3) = 0$。

三个开区间 $(-2, -1)$、$(0, 1)$、$(1, 2)$ 两两不重叠，故方程至少有 $3$ 个实根；而三次方程至多有 $3$ 个实根，所以恰有 $3$ 个实根。

**【结论】** 方程恰有三个实根，分别位于区间 $(-2, -1)$、$(0, 1)$、$(1, 2)$ 内。

> **方法**：证"方程有几个根"= 找若干端点异号且互不重叠的区间（零点定理保底）+ 用方程次数封顶"至多几个"。
>
> **易错点**：零点定理只保证"至少一个"，不保证"恰好一个"；端点同号的区间不能下任何结论，重复使用同一区间也不能重复计数。
