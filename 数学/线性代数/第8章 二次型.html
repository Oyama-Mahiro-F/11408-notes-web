第八章 二次型

（一）二次型的基本概念

1. 核心定义与矩阵表示

二次型是一个只含有二次项的齐次多项式。对于 n 个变量 x1,x2,…,xn，二次型可以表示为：

f(x1,x2,…,xn)=∑i=1n∑j=1naijxixj

它的本质是将代数表达式转化为矩阵语言。通过令 aij=aji，任何二次型都可以唯一地用一个实对称矩阵 A 来表示：

f(x)=xTAx
  • 对称矩阵的优势： 实对称矩阵必然可以正交对角化（即存在正交矩阵 Q，使得 QTAQ=Λ），这为后续化简二次型提供了完美的理论支撑。

2. 化二次型为标准形

研究二次型的主要目的是通过坐标变换（x=Py），将其化为没有交叉项的标准形（Standard Form）：

f(y)=d1y12+d2y22+⋯+dnyn2=yT(PTAP)y

这里的 P 必须是可逆矩阵。常用的化简方法有两种：

  • 正交变换法（核心考点）：

    • 方法： 求解矩阵 A 的特征值 λi 和特征向量，将特征向量正交化、单位化后组成正交矩阵 Q。此时坐标变换为 x=Qy。
    • 结果： 标准形系数 di 严格等于矩阵 A 的特征值 λi。
    • 几何意义： 相当于对坐标轴进行了旋转，不改变几何体的形状和大小。

  • 配方法（Lagrange 方法）：

    • 方法： 通过代数上的凑完全平方，反复消去交叉项。对应的是合同变换。
    • 结果： 得到的标准形系数不一定是特征值，但正负号的个数是一致的。
    • 优势： 计算速度极快，适合用于快速判定二次型的正定性。

3. 惯性定理与规范形

惯性定理（Sylvester's Law of Inertia）： 无论使用什么可逆线性变换将二次型化为标准形，其标准形中正系数的个数（正惯性指数 p）和负系数的个数（负惯性指数 q）是绝对不变的。

对于实对称矩阵 A 及其对应的二次型 f(x)=xTAx：

  • 正惯性指数 (p)

    p=标准形中正平方项的个数=规范形中平方项系数为 +1 的个数=对称矩阵 A 的正特征值的个数

  • 负惯性指数 (q)

    q=标准形中负平方项的个数=规范形中平方项系数为 −1 的个数=对称矩阵 A 的负特征值的个数

  • 矩阵的秩 (r)

    r(A)=p+q=对称矩阵 A 的非零特征值的个数

进一步，如果令所有的系数变为 1,−1 或 0，就得到了规范形。规范形由秩（r=p+q）和符号差（p−q）唯一确定。

4. 正定性判定

一个二次型 f(x)=xTAx 如果对任意非零向量 x，都有 f(x)>0，则称其为正定二次型，矩阵 A 为正定矩阵。

判断正定矩阵 A 的等价条件（需熟记）：

  1. 特征值法： A 的所有特征值均大于 0（λi>0）。
  2. 顺序主子式法（Sylvester 判别法）： A 的所有各阶顺序主子式均大于 0（注意：如果是半正定，则要求所有主子式 ≥0，不仅是顺序主子式）。
  3. 合同法： A 与单位矩阵 I 合同（即存在可逆矩阵 P，使得 A=PTP）。
  4. 正惯性指数： A 的正惯性指数 p=n。

（二）化二次型为标准型

一、可逆线性变换

令列向量 x=[x1x2⋮xn]，列向量 y=[y1y2⋮yn]，系数矩阵 C=[c11c12…c1nc21c22…c2n⋮⋮⋱⋮cn1cn2…cnn]，则{x1=c11y1+c12y2+⋯+c1nynx2=c21y1+c22y2+⋯+c2nyn…xn=cn1y1+cn2y2+⋯+cnnyn

那么，线性变换可以简写为矩阵方程：

x=Cy
  • 若|C|≠0，则称x=Cy为可逆线性变换。
  • 若C为正交矩阵，则称x=Cy为正交变换。

二、矩阵合同

1. 合同矩阵的定义

设 A 和 B 是 n 阶方阵（在考研和高等代数中，通常限定为实对称矩阵）。如果存在一个可逆矩阵 P，使得：

B=PTAP

则称矩阵 A 与 B 合同，记作 A≃B。

  • 本质理解： 这个等式对应的正是二次型 f(x)=xTAx 经过可逆线性变换 x=Py 后的矩阵变化形式（yT(PTAP)y）。因此，研究矩阵的合同，本质上就是在研究同一个二次型在不同坐标系下的表现形式。
2. 合同的核心性质

若 A≃B（且 A,B 为实对称矩阵），则它们满足以下性质：

  1. 对称性保持： 若 A 是实对称矩阵，则 B=PTAP 必然也是实对称矩阵。
  2. 秩相同： r(A)=r(B)（因为乘以可逆矩阵不改变矩阵的秩）。
  3. 行列式同号： |B|=|PTAP|=|P|2|A|。由于 P 可逆， |P|2>0，所以 |B| 与 |A| 的正负号完全相同（若为 0 则同为 0）。
  4. 惯性指数相同（核心性质）： A 与 B 具有相同的正惯性指数 p 和负惯性指数 q。也就是说，它们化为标准形后，正平方项和负平方项的个数是严格相等的。

常见误区： 合同矩阵的特征值不一定相同。虽然特征值的正负个数（正负对角元素的符号）相同，但具体的具体数值通常会发生改变。

3. 实对称矩阵合同的充分必要条件

在做题时，判断两个实对称矩阵 A 和 B 是否合同，有以下等价条件：

A≃B⟺A 和 B 具有相同的正、负惯性指数 (p,q)
⟺A 和 B 具有相同的秩 r 且正惯性指数 p 相同
⟺A 和 B 具有相同的规范形
4. 三大矩阵关系的横向对比（考研命题重灾区）

在线性代数中，等价、相似、合同是三种最容易混淆的等价关系。必须清晰掌握它们的定义与强弱关系：

重要纽带（正交矩阵）：

如果可逆矩阵 P 恰好是一个正交矩阵（满足 P−1=PT），那么：

B=P−1AP=PTAP

此时，相似与合同达成统一。

  • 结论： 若实对称矩阵 A 与 B 相似，则它们一定合同；但反过来，若 A 与 B 合同，它们不一定相似（因为特征值具体数值不一定相等）。

三、正交变换法

1. 基本定理

定理： 对于任意一个 n 元二次型 f(x1,x2,…,xn)=xTAx（其中 A 为实对称矩阵），必定存在一个正交变换 x=Qy（其中 Q 为正交矩阵，满足 QT=Q−1），使得该二次型化为只含平方项的标准形：

f=(Qy)TA(Qy)=yT(QTAQ)y=yTΛy=λ1y12+λ2y22+⋯+λnyn2

其中，λ1,λ2,…,λn 是矩阵 A 的 n 个特征值。

2. 正交变换法的解题步骤

它的核心思想是：利用实对称矩阵的优良性质，寻找一个正交矩阵 Q（满足 QT=Q−1），通过坐标变换 x=Qy，将原二次型 f(x)=xTAx 化为只含平方项的标准形 λ1y12+λ2y22+⋯+λnyn2。

  1. 写出矩阵（建立标准）：

    写出二次型 f(x) 对应的实对称矩阵 A。

    • 注意： 主对角线是平方项系数，非对角线是交叉项系数除以 2。

  2. 求特征值（确定标准形系数）：

    解特征方程 |λI−A|=0，求出特征值 λ1,λ2,…,λn。

    • 此时已知终点： 标准形必然是 λ1y12+λ2y22+⋯+λnyn2。

  3. 求特征向量（寻找新基）：

    将每个特征值代入 (λiI−A)x=0，解齐次线性方程组，求出对应的基础解系（特征向量 αi）。

  4. 正交化与单位化（关键与易错点）：

    • 不同特征值对应的特征向量天然垂直，只需直接单位化：γi=αi||αi||。
    • 相同特征值（重根）对应的特征向量，必须先用施密特正交化（Gram-Schmidt）强行转为垂直，然后再单位化。

  5. 拼装矩阵（写出变换）：

    将单位正交后的列向量拼成正交矩阵 Q=[γ1,γ2,…,γn]。

    最终的正交变换方程组为 x=Qy。

四、配方法

配方法的计算量远远小于正交变换法。它不需要求特征值，也不需要解方程组和施密特正交化，完全依靠纯代数的凑完全平方。

当你遇到以下两种情况时，可以使用这种快速的计算方法：

  1. 题目只问“正负定性”或“惯性指数”（比如选择题、填空题）。
  2. 题目没有强制要求使用正交变换，只要求“求一个可逆变换化为标准形”。

配方法的核心思想是：通过提取公因式和添加常数项，强行把含有交叉项的多项式，凑成几个独立完全平方和的形式。

根据原二次型中“有没有平方项”，算法分为两种情况：

1. 存在平方项（例如有 x12）

这是最常见的情况

  1. 锁定目标： 找出一个平方项（比如 x12），把所有含有 x1 的项全部圈在一起。
  2. 强制配平： 提取 x12 的系数，利用公式 (a+b+c)2=a2+b2+c2+2ab+2ac+2bc 进行反向凑配，凑出一个大括号的完全平方 (x1+…)2。
  3. 多退少补： 把凑平方时多加进去的 x22,x32,x2x3 等项，在括号外面减掉。
  4. 循环往复： 此时 x1 已经被彻底“封印”在第一个平方项里了。剩下的尾巴里只有 x2 和 x3。对 x2 重复上述步骤，直到所有变量都被套进完全平方里。
2. 完全没有平方项（例如只有 x1x2+x2x3）

如果二次型连一个平方项都没有，配方法就无从下手。此时需要我们配出一个平方项：

  1. 挑出一个交叉项，比如 x1x2。
  2. 做一个极其简单的可逆线性变换：令 x1=y1+y2，x2=y1−y2，x3=y3。
  3. 代入原式后，x1x2 就会裂变成 y12−y22。
  4. 平方项构造完成。使用存在平方项的方法继续配方。
3. 注意
  1. 系数不是特征值 ：配方法得到的标准形，其前面的系数（如 2y12−3y22）绝对不等于矩阵 A 的特征值。配方法对应的是一般的合同变换（可逆变换），它只保证正负号的个数（惯性指数）与特征值一致。
  2. 结果不唯一： 根据你先配 x1 还是先配 x2，或者你提取公因式的方式不同，同一个二次型用配方法可以得出无数种不同的标准形和对应的可逆矩阵 P。只要正负惯性指数对得上就没问题。
  3. 写变换矩阵 P 要小心：配方最后得到的是 y1,y2,y3 用 x1,x2,x3 表示的方程，即 y=P−1x。题目通常要求的是 x=Py，所以你必须求一次逆矩阵（或者通过解一元一次方程组反解出 x）。
4. 实例
f(x1,x2,x3)=2x12+2x22+2x32+2x1x2+2x1x3−2x2x3

用配方法将其化为标准形，并写出所作的线性变换。

  1. 锁定 x1，强制凑完全平方

先把所有含有 x1 的项集中在一起，提取出平方项的系数 2：

f=2(x12+x1x2+x1x3)+2x22+2x32−2x2x3

现在对括号里的内容凑完全平方。利用公式 (a+b+c)2=a2+b2+c2+2ab+2ac+2bc，我们需要给 x1x2 和 x1x3 分别配上 12 的系数才能变回 2ab 的形式：

x12+x1x2+x1x3=(x1+12x2+12x3)2−14x22−14x32−12x2x3

将这个结果代回原式，并乘以外面的系数 2（注意多退少补）：

f=2(x1+12x2+12x3)2−12x22−12x32−x2x3+2x22+2x32−2x2x3
  1. 合并剩余项，处理 x2

整理上面式子中剩下的 x2,x3 相关项：

f=2(x1+12x2+12x3)2+32x22+32x32−3x2x3

现在，第一项已经配方完成，我们只需对后面的 32x22+32x32−3x2x3 继续配方。提取 x22 的系数 32：

32(x22−2x2x3)+32x32

对括号内凑完全平方：

32((x2−x3)2−x32)+32x32
=32(x2−x3)2−32x32+32x32
=32(x2−x3)2

非常巧合，x32 的项刚好被完全抵消了（这意味着该二次型的秩为 2）。

  1. 写出标准形与线性变换

综合以上两步，原二次型被化简为：

f=2(x1+12x2+12x3)2+32(x2−x3)2

令括号里的式子为新的坐标变量 y：

{y1=x1+12x2+12x3y2=x2−x3y3=x3

此时，标准形即为：

f=2y12+32y22

(注意：规范形为 f=z12+z22，正惯性指数 p=2，负惯性指数 q=0，该二次型是半正定的。)

  1. 注意求变换矩阵 P

题目要求“写出所作的线性变换”，这通常意味着你要写出 x=Py 的形式，而不是停留在上面的 y=P−1x。我们需要把 x 反解出来：

由第三式得：x3=y3

代入第二式得：x2=y2+y3

代入第一式得：x1=y1−12x2−12x3=y1−12(y2+y3)−12y3=y1−12y2−y3

所以，最终的可逆线性变换为：

(x1x2x3)=(1−12−1011001)(y1y2y3)

这个矩阵就是我们要找的可逆矩阵 P。可以用 PTAP 验算一下，结果必然是是对角矩阵 diag(2,32,0)。
