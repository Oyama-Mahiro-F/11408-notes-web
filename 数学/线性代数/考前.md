### 一、矩阵的秩的性质

#### 1. 基础与等价性质

| 性质         | 公式                                             |
| ------------ | ------------------------------------------------ |
| 初等变换不变 | 初等变换不改变矩阵的秩                           |
| 转置不变     | $r(A) = r(A^T)$                                  |
| 非零数乘不变 | $r(kA) = r(A)$（$k \neq 0$）                     |
| 乘可逆阵不变 | $r(PA) = r(AQ) = r(PAQ) = r(A)$                  |
| 满秩等价     | $r(A) = n \iff \lvert A\rvert \neq 0 \iff A$可逆 |

#### **2. 满秩与可逆的充要条件**

对 $n$ 阶方阵 $A$：

$$
r(A) = n \quad \iff \quad \lvert A \rvert \neq 0
$$

即 $r(A) = n$、$\lvert A \rvert \neq 0$、$A$ 可逆三者完全等价，这是连通矩阵的秩、行列式与逆矩阵三者的枢纽公式。

#### **3. 核心不等式**

| 不等关系           | 公式                                                         |
| ------------------ | ------------------------------------------------------------ |
| 加法（次可加性）   | $r(A+B) \le r(A) + r(B)$                                     |
| 乘法木桶效应       | $r(AB) \le \min\{r(A), r(B)\}$                               |
| 西尔维斯特不等式   | $r(AB) \ge r(A) + r(B) - n$（$n$ 为中间维度）；推论：若 $AB = O$，则 $r(A) + r(B) \le n$ |
| 弗罗贝尼乌斯不等式 | $r(ABC) \ge r(AB) + r(BC) - r(B)$                            |
| 加法下界           | $r(A+B) \ge \lvert r(A) - r(B) \rvert$                       |
| 实矩阵等秩         | $r(A^T A) = r(A)$                                            |

#### **4. 特殊矩阵的秩**

| 矩阵                   | 秩                                         | 依据                 |
| ---------------------- | ------------------------------------------ | -------------------- |
| 伴随矩阵 $A^*$         | $r(A^*) = n$、$1$、$0$（随 $r(A)$ 降两档） | 见（四）四           |
| $A^TA$（$A$ 为实矩阵） | $r(A^TA) = r(A)$                           | 与 $Ax = 0$ 恒同解   |
| 零矩阵                 | $r(O) = 0$                                 | 一阶子式已全为 $0$   |
| 幂等阵 $A^2 = A$       | $r(A) + r(A - E) = n$                      | 由 $E = A + (E - A)$ |

#### **5. 核心定理与推论**

1. **零矩阵的秩**：$r(O) = 0$。
2. **非零推断秩**：若存在一个 $k$ 阶子式 $\neq 0$，则 $r(A) \ge k$。
3. **全零推断秩**：若**所有** $k$ 阶子式全为 $0$，则 $r(A) < k$。
4. **满秩方阵**：$n$ 阶方阵本身就是唯一的 $n$ 阶子式，故 $\lvert A \rvert \neq 0 \iff r(A) = n$（满秩 / 可逆 / 非奇异）；$\lvert A \rvert = 0 \iff r(A) < n$（降秩 / 不可逆 / 奇异）。

> **备考提示**：求秩实战**永远用初等行变换化为阶梯形、数非零行行数**；子式定义法只用于理论证明与含参讨论。
