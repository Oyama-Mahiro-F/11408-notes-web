第五章 矩阵的特征值和特征向量

一、定义

在数学上，矩阵的特征值和特征向量有非常严谨的代数定义。以下是它们最核心的理论概念：

1. 严格代数定义

设 A 是一个 n 阶方阵。如果存在一个常数 和一个非零的 n 维列向量 x，使得等式：

Ax=λx

成立，那么：

  • 常数 称为矩阵 A 的特征值（Eigenvalue）。
  • 非零列向量 x 称为矩阵 A 对应于特征值 的特征向量（Eigenvector）。

2. 概念解析与常见陷阱

在理论推导和应用中，这个概念有三个必须高度关注的细节：

  1. 必须是方阵：特征值和特征向量的讨论仅限于 n×n 的方阵。非方阵没有这个概念（非方阵对应的是奇异值）。
  2. 特征向量绝不能为零向量：定义中严格要求 x≠0。因为如果 x=0，对于任意的 ，都有 A0=λ0，这样特征值就失去了唯一性和意义。
  3. 特征值可以为零：虽然 x 不能为 0，但 完全可以是 0。如果 λ=0，则有 Ax=0，这意味着矩阵 A 不可逆（因为方程组有非零解）。
  4. 一个特征向量只能个对应一个特征值：可通过反证法证明。

3. 概念的等价转换（方程组视角）

将定义式 Ax=λx 移项并提取 x，可以转化为纯粹的线性方程组问题：

(A−λE)x=0

（其中 E 是与 A 同阶的单位矩阵）

从这个等价形式可以看出：

  • 找特征值 ，本质上就是找一个标量，使得矩阵 (A−λE) 变成一个奇异矩阵（即行列式 |A−λE|=0）。
  • 找特征向量 x，本质上就是在 确定后，求解齐次线性方程组 (A−λE)x=0 的非零解。

二、求解方法

以一般形式的 n 阶方阵 An×n=(aij)n×n 为例，求解特征值和特征向量的过程，本质上是代数中多项式求根与求解齐次线性方程组的结合。

设矩阵 A 如下展开：

A=(a11a12…a1na21a22…a2n⋮⋮⋱⋮an1an2…ann)

求解过程严格分为两步：

第一步：求解特征方程（求特征值 ）

根据定义 (A−λE)x=0，且要求特征向量 x=(x1,x2,…,xn)T≠0，则系数矩阵 A−λE 的行列式必须为零。我们构造特征多项式：

|A−λE|=|a11−λa12…a1na21a22−λ…a2n⋮⋮⋱⋮an1an2…ann−λ|=0

将其完全展开，你会得到一个关于 的 n 次代数方程（称为特征方程）：

(−1)nλn+c1λn−1+c2λn−2+⋯+cn−1λ+cn=0

在复数域内，这个 n 次方程一定有 n 个根（包含重根）。解出这 n 个根 λ1,λ2,…,λn，它们就是矩阵 A 的全部特征值。

高阶考点洞察：

注意特征多项式的系数。展开行列式时，常数项 cn 正好等于 |A|（令 λ=0 即可看出）；而次高次项系数 c1 等于 (−1)n−1(a11+a22+⋯+ann)。这是证明“特征值之积等于行列式”、“特征值之和等于矩阵的迹”的最直接切入点。

第二步：求解齐次线性方程组（求特征向量 x）

求出特征值后，需要为每一个不同的特征值求出对应的特征向量。

假设我们取出了其中一个特征值 λi，将其代回原来的矩阵中，构造具体的齐次线性方程组 (A−λiE)x=0。展开为代数方程组形式：

{(a11−λi)x1+a12x2+⋯+a1nxn=0a21x1+(a22−λi)x2+⋯+a2nxn=0…an1x1+an2x2+⋯+(ann−λi)xn=0

此时，这个方程组的系数行列式已知为 0，说明它必定有非零解。接下来的标准操作是：

  1. 初等行变换： 将系数矩阵 A−λiE 化为行最简形矩阵。

  2. 求基础解系： 确定自由未知量，求出该齐次线性方程组的基础解系。假设解空间维数为 k（k=n−r(A−λiE)），得到基础解系 η1,η2,…,ηk。

  3. 写出全部特征向量： 对应于特征值 λi 的所有特征向量，就是这组基础解系的非零线性组合：

    x=k1η1+k2η2+⋯+kkηk

    （其中 k1,k2,…,kk 是不全为零的任意常数）

针对所有的特征值重复这第二步，就能求出矩阵 A 的所有特征向量。

三、性质

1. 特征值与矩阵元素的关系

设 n 阶方阵 A 的特征值为 λ1,λ2,…,λn（包含重根），则：

  • 迹定理（Trace）： n 个特征值之和等于矩阵主对角线元素之和（即矩阵的迹）。

    ∑i=1nλi=∑i=1naii=tr(A)

  • 行列式定理： n 个特征值之积等于矩阵的行列式。

    ∏i=1nλi=|A|

    (推论：矩阵 A 可逆 ⟺|A|≠0⟺A 的所有特征值均不为 0。)

  • 转置不变性： 矩阵 A 与其转置矩阵 AT 拥有完全相同的特征值。（但它们的特征向量通常不同）。

2. 特征向量的线性无关性

  • 不同特征值对应无关向量： 如果 λ1,λ2,…,λm 是矩阵 A 的互不相同的特征值，那么它们各自对应的特征向量 x1,x2,…,xm 一定是线性无关的。
  • 特征子空间的维数： 属于同一个特征值 的所有特征向量加上零向量，构成一个线性空间。这个空间的维数等于 n−r(A−λE)，它被称为 的几何重数。
  • 线性变换的性质：同一特征值对应的特征向量的线性组合（非零）仍是特征向量，不同特征值对应的特征向量的线性组合不再是特征向量。
