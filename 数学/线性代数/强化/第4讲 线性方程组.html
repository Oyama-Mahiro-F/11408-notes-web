第四讲 线性方程组

来源：27届考研强化阶段《线性代数》（主讲：许琦）

（一）方程组的形式

A 的列数 = 未知数个数 n，A 的行数 = 方程个数 m

（二）齐次方程组 Ax=0

一、解的判定

特例（n 阶方阵）：|A|=0⟺ 有非零解

二、解的性质

若 x1,x2 是 Ax=0 的解，则：

  • x1+x2 也是解
  • kx1 也是解（k 为任意常数）

解的集合构成向量空间（解空间），维数 = n−r(A)

三、基础解系

若 Ax=0 有非零解，则存在 n−r(A) 个线性无关的解 ξ1,ξ2,…,ξn−r，使得通解为：

x=k1ξ1+k2ξ2+⋯+kn−rξn−r

求法：

  1. 将 A 化为行最简形
  2. 确定自由变量（n−r(A) 个）
  3. 依次令一个自由变量为 1、其余为 0，得到基础解系

（三）非齐次方程组 Ax=b

一、解的判定

特例（n 阶方阵）：|A|≠0⟺ 有唯一解（x=A−1b）

二、解的结构

若 Ax=b 有解，设 η∗ 为一个特解，ξ1,…,ξn−r 为对应齐次方程组的基础解系，则通解为：

x=η∗+k1ξ1+k2ξ2+⋯+kn−rξn−r

三、解的性质

若 η1,η2 是 Ax=b 的解，则：

  • η1−η2 是 Ax=0 的解
  • η1+η2 不是 Ax=b 的解（除非 b=0）
  • kη1+(1−k)η2 是 Ax=b 的解（k 为任意常数）

（四）含参数的线性方程组

方法：

  1. 写出增广矩阵 (A,b)
  2. 初等行变换化为阶梯形
  3. 讨论参数取值对 r(A) 和 r(A,b) 的影响

【例】 已知线性方程组

{x1+x2+x3+x4+x5=a3x1+2x2+x3+x4−3x5=0x1+2x3+2x4+6x5=b5x1+4x2+3x3+3x4−x5=2

问 a,b 为何值时方程组有解？

对增广矩阵做行变换，令 r(A)=r(A,b) 解出参数

（五）典型例题

【例1】 设 A 是 m×n 矩阵，B 是 n×m 矩阵，则 (AB)x=0：

  • 当 m>n 时必有非零解

因为 r(AB)≤min(r(A),r(B))≤n<m，所以 r(AB)<m，有非零解

【例4】 设 A 是 m×n 矩阵，判断正确命题：

  • (A) 若 m<n，则 Ax=b 必有无穷多解 → ❌（r(A) 可能小于 r(A,b)，无解）
  • (B) 若 m>n，则 Ax=b 必有唯一解 → ❌（r(A) 可能小于 n）
  • (C) 若 r(A)=n，则 Ax=b 必有唯一解 → ❌（r(A,b) 可能大于 r(A)，无解）
  • (D) 若 r(A)=m，则 Ax=b 必有解 → ✅

(D) 正确：r(A)=m⇒r(A,b)=m（增广矩阵秩不增加）⇒ 有解

【例】 设 Am×nx=b，判断：

  • r(A)=m（行满秩）⇒ Ax=b 一定有解
  • r(A)=n（列满秩）⇒ Ax=0 只有零解，Ax=b 若有解则唯一

（六）核心公式速查

齐次 Ax=0：
  r(A) < n  → 有非零解，基础解系含 n-r(A) 个向量
  r(A) = n  → 只有零解
  |A| = 0   → 有非零解（n阶方阵）


非齐次 Ax=b：
  r(A) = r(A,b) = n  → 唯一解
  r(A) = r(A,b) < n  → 无穷多解
  r(A) ≠ r(A,b)       → 无解
  |A| ≠ 0             → 唯一解（n阶方阵），x = A⁻¹b


解的结构：
  x = η* + k₁ξ₁ + k₂ξ₂ + ... + k_{n-r}ξ_{n-r}
  特解 + 齐次通解
