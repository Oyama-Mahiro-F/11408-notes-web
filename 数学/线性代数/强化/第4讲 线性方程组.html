第四讲 线性方程组

来源：27届考研强化阶段《线性代数》（主讲：许琦） 题型：齐次线性方程组 | 非齐次线性方程组 | 公共解与同解

（一）齐次线性方程组

一、解的判定

Am×nx=0

推论（n 阶方阵 An×n）：

二、解的结构

1. 解的性质

若 ξ1,ξ2 是 Ax=0 的两个解，则 k1ξ1+k2ξ2（k1,k2 为任意常数）也是它的解。

解的集合构成解空间，维数 = n−r(A)

2. 基础解系

设 ξ1,ξ2,…,ξs 是 Ax=0 的解向量，若满足：

  1. 个数：s=n−r(A)
  2. 线性无关：ξ1,ξ2,…,ξs 线性无关
  3. 都是解：每个 ξi 都是 Ax=0 的解

则称 ξ1,ξ2,…,ξs 是 Ax=0 的一个基础解系。

等价定义：基础解系就是解空间的极大无关组

3. 通解

若 r(A)=r<n，设 ξ1,ξ2,…,ξn−r 是基础解系，则通解为：

x=k1ξ1+k2ξ2+⋯+kn−rξn−r(ki 为任意常数)

三、求解方法

1. 数值型

步骤：

  1. 将 A 化为行最简形
  2. 确定 r(A)，基础解系含 n−r(A) 个向量
  3. 令自由变量分别取 (1,0,…,0),(0,1,…,0),…，得到基础解系 ξ1,ξ2,…,ξn−r
  4. 写出通解
2. 抽象型

关键：验证基础解系的三个条件（个数、线性无关、是解）

【例2】 设 α1,α2,α3,α4 是 Ax=0 的基础解系，判断以下哪个也是基础解系：

  • (A) 与 α1,α2,α3,α4 等秩的向量组 → ❌（不一定是解）
  • (B) 与 α1,α2,α3,α4 等价的向量组 → ❌（个数可能不同）
  • (C) α1+α2,α2+α3,α3+α4,α4+α1 → 需验证三个条件

验证：都是解 ✅；个数 = 4 ✅；系数矩阵行列式 =0 ❌（线性相关）

（二）非齐次线性方程组

一、解的判定

Am×nx=b(b≠0)

特例（n 阶方阵）：

二、求唯一解（数值型）

  1. 初等行变换：(A∣b)→ 行最简形
  2. 克拉默法则：xi=DiD（D=|A|≠0）

三、解的结构

1. 解的性质
  • 若 η1,η2 是 Ax=b 的解，则 η1−η2 是 Ax=0 的解
  • 若 ξ 是 Ax=0 的解，η 是 Ax=b 的解，则 ξ+η 是 Ax=b 的解
2. 通解

若 Ax=b 有无穷多解，设 ξ1,…,ξn−r 是 Ax=0 的基础解系，η∗ 是 Ax=b 的一个特解，则通解为：

x=k1ξ1+k2ξ2+⋯+kn−rξn−r+η∗

口诀：非齐通 = 齐通 + 非齐特

四、求通解（数值型）

步骤：

  1. (A∣b)→ 行最简形（A 中包含 Er）
  2. 写出 Ax=0 的基础解系 ξ1,…,ξn−r（令自由变量分别取 (1,0,…),(0,1,…),…）
  3. 写出 Ax=b 的特解 η∗（令自由变量全为 0，代入 Ax=b）
  4. 写出通解：x=k1ξ1+⋯+kn−rξn−r+η∗

（三）含参数的线性方程组

方法：

  1. 写出增广矩阵 (A∣b)
  2. 初等行变换化为阶梯形
  3. 讨论参数对 r(A) 和 r(A,b) 的影响，判断解的情况

（四）抽象型方程组与矩阵方程

一、抽象型齐次方程组

关键：验证基础解系的三个条件

【例3】 设四维非零向量 ξ 既可由 α1,α2,α3 线性表示，也可由 β1,β2,β3 线性表示，求参数和通解。

方法：利用线性表示条件建立方程组

二、矩阵方程 AX=B

等价于求解多个非齐次方程组 Axi=bi（i=1,2,…）

方法：(A∣B)→ 行最简形，逐列求解

【例7】 已知 AX=B，求矩阵 X。

对 (A∣B) 做初等行变换

三、AC=B 型（存在性）

【例6】 设 A,B 已知，当 a,b 取何值时，存在矩阵 C 使得 AC=B？并求 C。

AC=B 有解 ⟺ r(A)=r(A,B)

对 (A∣B) 做行变换讨论参数

（五）公共解与同解

一、公共解

两个方程组 A1x=0 与 A2x=0 的公共解即同时满足两个方程组的解。

方法：联立 (A1A2)x=0，求通解

二、同解

A1x=0 与 A2x=0 同解 ⟺ 它们的解集完全相同

⟺r(A1)=r(A2)=r(A1A2)

三、综合题

【例8】 已知 A=(α1,α2,α3,α4) 是四阶矩阵，Ax=β 的通解是 x=(1,2,2,1)T+k(1,−2,4,0)T，又 B=(α3,α2,α1,β−α4)，求 Bx=α1−α2 的通解。

方法：从已知通解中提取 r(A),αi 之间的关系，重新构造方程组

（六）核心公式速查

齐次 Ax=0：
  r(A) < n  → 有非零解，基础解系含 n-r(A) 个向量
  r(A) = n  → 只有零解
  |A| = 0   → 有非零解（n阶方阵）
  通解：x = k₁ξ₁ + k₂ξ₂ + ... + k_{n-r}ξ_{n-r}


非齐次 Ax=b：
  r(A) ≠ r(A,b)       → 无解
  r(A) = r(A,b) = n   → 唯一解（克拉默法则 x_i = D_i/D）
  r(A) = r(A,b) < n   → 无穷多解
  通解：x = k₁ξ₁ + ... + k_{n-r}ξ_{n-r} + η*


解的结构：
  η₁ - η₂ 是 Ax=0 的解
  ξ + η* 是 Ax=b 的解（ξ为齐次解，η*为非齐次特解）


公共解：联立求解
同解：r(A₁) = r(A₂) = r(A₁; A₂)
