第二讲 矩阵

来源：27届考研强化阶段《线性代数》（主讲：许琦） 题型：矩阵的运算 | 初等变换与初等矩阵 | 矩阵的秩

（一）矩阵的概念

一、定义

A=(aij)m×n，m 行 n 列的矩阵。

二、特殊矩阵

零矩阵、单位阵 E、对角阵、上（下）三角矩阵、对称阵（AT=A）、反对称阵（AT=−A）、正交矩阵（AAT=E）

三、分块矩阵

将矩阵按行/列分成若干子块。

（二）矩阵的运算

一、加法

Am×n±Bm×n=(aij±bij)m×n

只有同型矩阵才可进行加法运算

二、数乘

kA=(kaij)m×n

注意：|kA|=kn|A|（不是 k|A|）

三、乘法

Am×n⋅Bn×s=Cm×s

cij=ai1b1j+ai2b2j+⋯+ainbnj

运算律：

  • 结合律：(AB)C=A(BC)
  • 数乘结合律：k(AB)=(kA)B=A(kB)
  • 左分配律：C(A+B)=CA+CB
  • 右分配律：(A+B)C=AC+BC

不满足交换律：AB≠BA（一般情况）

不满足消去律：AB=AC 且 A≠O 不能推出 B=C

向量的乘积：

αβT=(a1a2a3)(b1,b2,b3)=(a1b1a1b2a1b3a2b1a2b2a2b3a3b1a3b2a3b3)
βTα=b1a1+b2a2+b3a3=tr(A)(内积，一个数)

四、方阵的幂

Ak=A⋅A⋯A⏟k个，A0=E

运算律：AkAl=Ak+l，(Ak)l=Akl

(AB)k≠AkBk（因为 AB≠BA）

求法：

五、转置

运算律：

  • (AT)T=A
  • (A±B)T=AT±BT
  • (kA)T=kAT
  • (AB)T=BTAT（反序）
  • (A−1)T=(AT)−1

（三）伴随矩阵

一、定义

A∗=(Aji)n×n

注意：A∗ 的第 i 行第 j 列元素是 Aji（转置）

二、核心公式

AA∗=A∗A=|A|E

三、运算律

(A+B)∗ 没有简单展开式

四、求法

  1. 定义法：逐个计算代数余子式
  2. 利用逆矩阵：A∗=|A|A−1（|A|≠0 时）
  3. 利用核心公式：AA∗=|A|E

（四）逆矩阵

一、定义

若 AB=E（或 BA=E），则 B=A−1。

二、可逆的充要条件

A 可逆⟺|A|≠0⟺r(A)=n⟺A 的列向量组线性无关
⟺Ax=0 只有零解⟺Ax=b 有唯一解⟺A 的特征值都不为 0

三、运算律

(A+B)−1 没有简单展开式

四、求法

  1. 抽象型：用定义，凑出 A⋅(⋯)=E
  2. 2阶数值型：A=(abcd)⇒A−1=1ad−bc(d−b−ca)
  3. 3阶以上数值型：(A∣E)→初等行变换(E∣A−1)
  4. 分块对角阵：各块分别求逆

（五）矩阵运算题型

一、方阵的幂

【例1】 已知 A 是三阶矩阵，且所有元素都是 −1，求 A4+2A3。

A=−ααT（秩为1），Ak=[tr(A)]k−1A=(−3)k−1A

二、逆矩阵

【例2】 设 AB=A+B，判断命题正误。

AB−B=(A−E)B=A，(A−E)(B−E)=E

⇒A−E 与 B−E 互为逆矩阵

【例3】 设 A2+2A−3E=O，判断 A+2E 是否可逆。

凑出 (A+2E)⋅(⋯)=E

【例4】 设 A=E+αβT，αTβ=3，求 (A+2E)−1。

A2=E+8αβT，代入求 A2+A+4E=O，再凑逆

三、伴随矩阵

【例7】 已知 A 的伴随矩阵 A∗，且 ABA−1=BA−1+3E，求 B。

左乘 A∗：|A|B=A∗B+3|A|E，(|A|E−A∗)B=3|A|E

【例8】 设 A=(aij) 是3阶非零矩阵，aij+Aij=0，求 |A|。

A∗=−A，由 AA∗=|A|E 得 −A2=|A|E，|A|2=−|A|3

【例9】 已知 A 的所有元素的代数余子式之和。

所有 Aij 之和 = A∗ 所有元素之和，利用 |A∗|=|A|n−1 求解

（六）初等变换与初等矩阵

一、初等变换

二、初等矩阵

将单位矩阵做一次初等变换所得的矩阵。

核心关系（行左列右，先近后远）：

对 A 实施一次初等行变换 ⟺ 左乘相应的初等矩阵

对 A 实施一次初等列变换 ⟺ 右乘相应的初等矩阵

三、初等矩阵的运算律

四、矩阵的等价

A 经过有限次初等变换变到 B ⟺ 存在可逆阵 P,Q，使 PAQ=B

⟺r(A)=r(B)

（七）矩阵的秩

一、定义

矩阵 A 中存在一个 r 阶子式不为零，而所有 r+1 阶子式全为零，则 r(A)=r。

即：非零子式的最高阶数

二、性质

特别：

  • 若 P,Q 可逆，则 r(PA)=r(AQ)=r(PAQ)=r(A)
  • 若 r(Am×n)=n，则 r(AB)=r(B)

三、求法

  1. 抽象型：利用性质推导
  2. 数值型：初等行变换化为阶梯形，非零行数即为秩

（八）秩的综合考法

一、AB=O 且 A,B 均非零

Am×n⋅Bn×s=O,A≠O,B≠O
⇒r(A)<n,r(B)<n

即 A,B 都不可逆（非满秩）

二、AB=E（A 列满秩 / B 行满秩）

Am×n⋅Bn×m=Em⇒r(A)=m,r(B)=m

因为 r(Em)=m，且 r(AB)≤min(r(A),r(B))

三、r(Am×n)=m（行满秩）

r(A)=m⇒r(A,B)=m(增广矩阵秩不变)
⇒Ax=b 一定有解

四、r(Am×n)=n（列满秩）

r(A)=n⇒Ax=0 只有零解
r(AB)=r(B)(列满秩左乘不改变秩)

（九）秩的补充例题

一、已知秩求参数

【例12】 设矩阵 A,B 等价，求 a。

A,B 等价 ⟺ A,B 同型且 r(A)=r(B)

由 r(A)=r(B) 建立方程求参数

【例13】 设 A,B=αβT，若 r(A+AB)=2，判断命题。

A+AB=A(E+B)，利用秩的性质分析

二、证明题

【例14】 设 A 是 n 阶矩阵，且满足 A2=A，证明：r(A)+r(A−E)=n

证明：

  1. A2−A=A(A−E)=O ⇒ r(A)+r(A−E)≤n
  2. A−(A−E)=E ⇒ r(A)+r(A−E)≥r(A−(A−E))=r(E)=n
  3. 综上 r(A)+r(A−E)=n

推广：(A+kE)(A+lE)=O ⇒ r(A+kE)+r(A+lE)=n（k≠l）

【例15】 设 n 阶矩阵 A,B,C 满足 r(ABC)+2n=r(A)+r(B)+r(C)，判断正确选项。

利用 Sylvester 不等式链式放缩：

r(ABC)≥r(AB)+r(C)−n≥r(A)+r(B)+r(C)−2n

等号成立的条件分析

【例】 设 r(A,AB)=r(A)

因为 AB 的列向量是 A 的列向量的线性组合，所以 r(A,AB)=r(A)

（十）核心公式速查表

一、矩阵运算公式表

(kA)^T = kA^T           (kA)^{-1} = (1/k)A^{-1}     |kA| = k^n|A|
(kA)^* = k^{n-1}A^*     (kA)^m = k^m A^m


(AB)^T = B^T A^T        (AB)^{-1} = B^{-1}A^{-1}     |AB| = |A||B|
(AB)^* = B^* A^*


(A^T)^T = A             (A^T)^{-1} = (A^{-1})^T      |A^T| = |A|
(A^T)^* = (A^*)^T


(A^{-1})^{-1} = A       |A^{-1}| = |A|^{-1}          (A^{-1})^* = (A^*)^{-1}


(A^*)^* = |A|^{n-2}A    |A^*| = |A|^{n-1}


AA^* = A^*A = |A|E

二、秩的核心不等式

r(A) = r(A^T)
r(kA) = r(A)  (k≠0)
r(A±B) ≤ r(A) + r(B)
r(AB) ≤ min(r(A), r(B))
r(AB) ≥ r(A) + r(B) - n  (Sylvester)
AB = O  ⇒  r(A) + r(B) ≤ n
r(A*) = n (r(A)=n), 1 (r(A)=n-1), 0 (r(A)<n-1)
