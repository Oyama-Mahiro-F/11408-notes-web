## 第四讲 线性方程组

> 来源：27届考研强化阶段《线性代数》（主讲：许琦）
> 题型：齐次方程组 | 非齐次方程组 | 公共解与同解 | 矩阵方程

---

### （一）齐次线性方程组

#### 一、解的判定

$$
A_{m \times n} x = 0
$$

| 条件 | 结论 |
|------|------|
| $r(A) < n$ | 有非零解 |
| $r(A) = n$ | 只有零解 |

**推论**（$n$ 阶方阵）：$|A| = 0 \iff$ 有非零解

#### 二、解的结构

##### 1. 解的性质

若 $\xi_1, \xi_2$ 是 $Ax = 0$ 的解，则 $k_1\xi_1 + k_2\xi_2$ 也是它的解。

##### 2. 基础解系

$\xi_1, \xi_2, \ldots, \xi_s$ 是 $Ax = 0$ 的基础解系，当且仅当：

1. **个数**：$s = n - r(A)$
2. **线性无关**
3. **都是 $Ax = 0$ 的解**

##### 3. 通解

$$
x = k_1\xi_1 + k_2\xi_2 + \cdots + k_{n-r}\xi_{n-r}
$$

#### 三、求解

##### 1. 数值型

$A \to$ 行最简形 $\to$ 令自由变量分别取 $(1,0,\ldots), (0,1,\ldots), \ldots$ $\to$ 写出基础解系 $\to$ 写出通解

##### 2. 抽象型

验证基础解系的三个条件（个数、线性无关、是解）

---

### （二）非齐次线性方程组

#### 一、解的判定

| 条件 | 结论 |
|------|------|
| $r(A) \neq r(A, b)$ | 无解 |
| $r(A) = r(A, b) = n$ | 有唯一解 |
| $r(A) = r(A, b) < n$ | 有无穷多解 |

**克拉默法则**：$|A| \neq 0$ 时有唯一解，$x_i = \frac{D_i}{|A|}$

#### 二、解的结构

- $\eta_1 - \eta_2$ 是 $Ax = 0$ 的解（两个非齐次解之差是齐次解）
- $\xi + \eta^*$ 是 $Ax = b$ 的解（齐次解 + 非齐次特解）

**通解**：

$$
x = k_1\xi_1 + \cdots + k_{n-r}\xi_{n-r} + \eta^*
$$

> **口诀**：非齐通 = 齐通 + 非齐特

#### 三、求解

$(A \mid b) \to$ 行最简形 $\to$ 写齐次基础解系 $\to$ 写非齐次特解（自由变量全取0） $\to$ 写通解

---

### （三）矩阵方程

#### 一、$AX = B$

等价于 $A(x_1, x_2, \ldots, x_s) = (b_1, b_2, \ldots, b_s)$，逐列求解。

**方法**：$(A \mid B) \xrightarrow{\text{行变换}} (E \mid A^{-1}B)$

#### 二、$XA = B$

两边转置：$A^T X^T = B^T$，转化为 $AX = B$ 型。

#### 三、$AXB = C$

先求 $A^{-1}$ 和 $B^{-1}$，$X = A^{-1}CB^{-1}$

#### 四、$AC - CA = B$ 型

展开为线性方程组，对 $(A \mid B)$ 做行变换讨论参数

**【例6】** 当 $a, b$ 取何值时，存在矩阵 $C$ 使 $AC - CA = B$？并求 $C$。

> 设 $C = \begin{pmatrix} x_1 & x_2 \\ x_3 & x_4 \end{pmatrix}$，展开为4元线性方程组讨论

**【例8】** 已知 $A = (\alpha_1, \alpha_2, \alpha_3, \alpha_4)$，$Ax = \beta$ 的通解为 $x = (1,2,2,1)^T + k(1,-2,4,0)^T$，$B = (\alpha_3, \alpha_2, \alpha_1, \beta - \alpha_4)$，求 $Bx = \alpha_1 - \alpha_2$ 的通解。

> 从通解提取信息：$r(A) = 3$，$A\eta^* = \beta$，$A\xi = 0$
>
> 推导 $B$ 的列向量关系，确定 $r(B)$ 和基础解系

### （四）公共解

#### 一、定义

方程组 (I) 和 (II) 的**公共解**：同时满足两个方程组的解。

#### 二、求法

##### 情况1：已知两个方程组

**联立** $\begin{pmatrix} A_1 \\ A_2 \end{pmatrix} x = 0$，求解即可。

##### 情况2：已知一方程组 + 另一方的通解

1. 将含参通解代入另一方程组，建立新方程组
2. 求参数
3. 回代得到公共解

**【例】** 方程组 (I)：$x_1 + x_2 + x_3 = 0$，(II) 的通解为 $x = k_1(1,0,1)^T + k_2(1,1,0)^T$，求全部公共解。

> 将 $x = (k_1+k_2, k_2, k_1)^T$ 代入 (I)：$(k_1+k_2) + k_2 + k_1 = 0 \Rightarrow 2k_1 + 2k_2 = 0$
>
> 解得 $k_2 = -k_1$，公共解为 $k(0, -1, 1)^T$

##### 情况3：已知两个通解

1. 令两个通解相等，建立方程组
2. 求参数
3. 回代其中一个通解

**【例】** (I) 通解 $x = (1,1)^T + k(1,2)^T$，(II) 通解 $x = (3,4)^T + t(0,1)^T$，求公共解。

> 令 $(1+k, 1+2k)^T = (3, 4+t)^T$，解出 $k, t$

### （五）同解

#### 一、定义

(I) 的解都是 (II) 的解，且 (II) 的解都是 (I) 的解 $\iff$ 解集完全相同。

#### 二、判定

$$
Ax = 0 \text{ 与 } Bx = 0 \text{ 同解} \iff r(A) = r(B) = r\begin{pmatrix} A \\ B \end{pmatrix}
$$

$Ax = 0$ 的解都是 $Bx = 0$ 的解 $\iff r\begin{pmatrix} A \\ B \end{pmatrix} = r(A)$

#### 三、重要结论

1. $Ax = 0$ 与 $A^TAx = 0$ **同解**
2. $Bx = 0$ 的解**一定**是 $ABx = 0$ 的解（反之不一定）
3. 若 $r(A_{m \times n}) = n$（列满秩），则 $Bx = 0$ 与 $ABx = 0$ **同解**

#### 四、典型例题

**【例9】** 方程组 (I) 含参数 $a, b$，(II) 为另一方程组，讨论何时有/无公共解，何时有唯一/无穷多公共解。

> 联立为增广矩阵，行变换讨论 $r(A)$ 与 $r(A,b)$

**【例10】** 设 $A$ 已知，$Bx = 0$ 的解都是 $Ax = 0$ 的解，但 $Ax = 0$ 的解不都是 $Bx = 0$ 的解，求参数。

> $r\begin{pmatrix} A \\ B \end{pmatrix} = r(A)$ 且 $r(B) > r(A)$

**【例11】** 设 $A, B$ 为 $m \times n$ 矩阵，存在可逆矩阵 $P$ 使 $AP = B$，判断 $Ax = 0$ 与 $Bx = 0$ 的关系。

> $AP = B$，$P$ 可逆 $\Rightarrow$ $r(A) = r(B)$，但 $Ax = 0$ 与 $Bx = 0$ 不一定同解
>
> 实际上 $Bx = 0 \Rightarrow APx = 0 \Rightarrow Px$ 是 $Ay = 0$ 的解

### （六）核心公式速查

```
齐次 Ax=0：
  r(A) < n → 有非零解，基础解系含 n-r(A) 个向量
  r(A) = n → 只有零解

非齐次 Ax=b：
  r(A) ≠ r(A,b) → 无解
  r(A) = r(A,b) = n → 唯一解（克拉默法则）
  r(A) = r(A,b) < n → 无穷多解
  通解：x = 齐次通解 + 非齐次特解

矩阵方程：
  AX=B → (A|B) 行变换逐列求解
  XA=B → 转置为 AᵀXᵀ=Bᵀ
  AXB=C → X=A⁻¹CB⁻¹

公共解：联立求解
同解：r(A) = r(B) = r(A;B)
Ax=0 与 AᵀAx=0 同解
r(A)=n（列满秩）→ Bx=0 与 ABx=0 同解
```
