第三讲 向量

来源：27届考研强化阶段《线性代数》（主讲：许琦）

（一）向量的概念与运算

一、定义

n 维列向量：α=(a1,a2,…,an)T

n 维行向量：αT=(a1,a2,…,an)

二、线性运算

  1. 向量相等：α=β 当且仅当 ai=bi（i=1,2,…,n）
  2. 向量加法：α+β=(a1+b1,a2+b2,…,an+bn)T
  3. 数乘向量：kα=(ka1,ka2,…,kan)T

（二）线性相关性

一、定义

设 α1,α2,…,αm 是 m 个 n 维向量，如果存在不全为零的数 k1,k2,…,km，使得

k1α1+k2α2+⋯+kmαm=0

则称 α1,α2,…,αm 线性相关；否则称线性无关。

二、线性相关性的判别

特例：n 个 n 维向量线性无关 ⟺ |(α1,α2,…,αn)|≠0

三、线性相关性的性质

1. 部分与整体

部分相关则整体相关；整体无关则部分无关

若 α1,α2 相关，则 α1,α2,α3 也相关

2. 低维与高维

高维相关则低维相关；低维无关则高维无关

若向量组去掉某些分量后相关，则原向量组也相关

3. 个数与维数
  • m 个 n 维向量，当 m>n 时一定线性相关
  • n+1 个 n 维向量一定线性相关
4. 其他性质
  • 含零向量的向量组一定线性相关
  • 两个向量线性相关 ⟺ 对应分量成比例
  • α1,α2,…,αm 线性相关 ⟺ 其中至少有一个向量可由其余向量线性表示

（三）向量组的线性表示

一、定义

若 β=k1α1+k2α2+⋯+kmαm，则称 β 可由 α1,α2,…,αm 线性表示。

二、判别

β 可由 α1,α2,…,αm 线性表示

⟺(α1,α2,…,αm)x=β 有解
⟺r(α1,α2,…,αm)=r(α1,α2,…,αm,β)

唯一表示：方程组有唯一解 ⟺ 向量组线性无关且可表示

（四）向量组等价

一、定义

若向量组 (I) 与向量组 (II) 可以互相线性表示，则称两个向量组等价。

二、判别

(I)≅(II)⟺r(I)=r(II)=r(I,II)

（五）极大无关组与秩

一、极大无关组

向量组 α1,α2,…,αm 的部分组 αi1,αi2,…,αir 满足：

  1. 这 r 个向量线性无关
  2. 再添加任一向量都线性相关

则称 αi1,αi2,…,αir 为一个极大线性无关组，r 为向量组的秩。

二、求法

将向量组按列排成矩阵 A，用初等行变换化为阶梯形：

  • 非零行数 = 秩
  • 每行首个非零元素所在的列对应的原向量构成极大无关组

（六）典型例题

【例1】 判断下列向量组的线性相关性：

  • (A) α1=(1,2,3,4) → 1个非零向量，无关
  • (B) β1,β2,β3,β4 为4个3维向量 → m>n，相关
  • (C) 行列式 =0 → 相关
  • (D) 含零向量 → 相关

方法：个数与维数 / 秩 / 行列式

【例3】 设 A 是 n 阶矩阵，Aα1=α1+α2，Aα2=α2+α3，…

利用定义法证明线性无关：设 k1α1+k2α2+⋯=0，代入递推关系
