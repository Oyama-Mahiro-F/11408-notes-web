## 第七讲 数一专题

> 来源：27届考研强化阶段《线性代数》（主讲：许琦）
> 仅限数学一：向量空间 | 二次曲面 | 空间平面与直线

---

### （一）向量空间

#### 一、定义

设 $V$ 是 $n$ 维向量的集合，若 $V$ 非空，且对向量加法和数乘封闭，则称 $V$ 为**向量空间**。

#### 二、基与维数

- **基**：$V$ 的极大线性无关组 $\alpha_1, \alpha_2, \ldots, \alpha_r$
- **维数**：$\dim V = r$（基所含向量个数）

#### 三、坐标

设 $\alpha_1, \alpha_2, \ldots, \alpha_r$ 是 $V$ 的一个基，若

$$
\alpha = x_1\alpha_1 + x_2\alpha_2 + \cdots + x_r\alpha_r
$$

则 $(x_1, x_2, \ldots, x_r)$ 为 $\alpha$ 在基 $\alpha_1, \ldots, \alpha_r$ 下的**坐标**。

#### 四、基变换与过渡矩阵

设 $\alpha_1, \ldots, \alpha_n$ 与 $\beta_1, \ldots, \beta_n$ 都是 $V$ 的基，且

$$
(\beta_1, \beta_2, \ldots, \beta_n) = (\alpha_1, \alpha_2, \ldots, \alpha_n) C
$$

则 $C$ 为从基 $\{\alpha_i\}$ 到基 $\{\beta_i\}$ 的**过渡矩阵**。

**坐标变换**：若 $\alpha$ 在 $\{\alpha_i\}$ 下坐标为 $x$，在 $\{\beta_i\}$ 下坐标为 $y$，则

$$
x = Cy, \quad y = C^{-1}x
$$

**求过渡矩阵**：$(A \mid B) \to (E \mid A^{-1}B)$，其中 $A = (\alpha_1, \ldots, \alpha_n)$，$B = (\beta_1, \ldots, \beta_n)$

#### 五、规范正交基

若基 $\alpha_1, \ldots, \alpha_n$ 满足 $(\alpha_i, \alpha_j) = \delta_{ij}$，则称为**规范正交基**（标准正交基）。

**【例1】** 设 $\alpha_1 = (1,2,1)^T$，$\alpha_2 = (1,3,2)^T$，$\alpha_3 = (1,a,3)^T$ 为 $\mathbb{R}^3$ 的一个基，$\beta = (1,1,1)^T$ 在此基下坐标为 $(b,c,1)^T$

(1) 求 $a, b, c$

(2) 证明 $\alpha_2, \alpha_3, \beta$ 为 $\mathbb{R}^3$ 的一个基，并求到 $\alpha_1, \alpha_2, \alpha_3$ 的过渡矩阵

> (1) 由坐标定义 $(\alpha_1, \alpha_2, \alpha_3)(b,c,1)^T = \beta$ 建方程组
>
> (2) 证 $|\alpha_2, \alpha_3, \beta| \neq 0$

### （二）二次曲面（与二次型的对应）

二次型 $f(x_1, x_2, x_3) = c$（$c > 0$）对应的几何图形：

| 正负惯性指数 | 标准形 | 曲面类型 |
|:---:|:---:|:---:|
| $p=3, q=0$ | $y_1^2 + y_2^2 + y_3^2 = c$ | **椭球面** |
| $p=2, q=1$ | $y_1^2 + y_2^2 - y_3^2 = c$ | **单叶双曲面** |
| $p=1, q=2$ | $y_1^2 - y_2^2 - y_3^2 = c$ | **双叶双曲面** |
| $p=2, q=0$ | $y_1^2 + y_2^2 = c$ | **椭圆柱面** |
| $p=1, q=1$ | $y_1^2 - y_2^2 = c$ | **双曲柱面** |

> 正交变换 $x = Qy$ 不改变图形的类型

**【例2】** 设 $f = x^TAx$ 的正惯性指数 $p = 1$，$A$ 满足 $A^2 - 2A = 3E$，则 $f = 1$ 在空间中表示什么？

> $A^2 - 2A - 3E = O \Rightarrow (\lambda-3)(\lambda+1) = 0 \Rightarrow \lambda = 3$ 或 $-1$
>
> $p = 1 \Rightarrow$ 一个正特征值，两个负特征值 $\Rightarrow \lambda = 3, -1, -1$
>
> $q = 2 \Rightarrow$ **双叶双曲面**

### （三）空间平面方程

#### 一、点法式

$$
A(x - x_0) + B(y - y_0) + C(z - z_0) = 0
$$

法向量 $\vec{n} = (A, B, C)$，过点 $(x_0, y_0, z_0)$

#### 二、一般式

$$
Ax + By + Cz + D = 0
$$

#### 三、三个平面的位置关系

联立三个平面方程 $A_i x + B_i y + C_i z = d_i$（$i = 1,2,3$），即 $Ax = b$：

| $r(A)$ | $r(A, b)$ | 几何关系 |
|:---:|:---:|:---|
| 3 | 3 | 三平面交于**一点** |
| 2 | 2 | 三平面交于**一条直线** |
| 2 | 3 | 三平面**无公共点**（两两交线平行或其中两平面平行） |
| 1 | 1 | 三平面**重合** |
| 1 | 2 | 三平面**平行**（或两重合一平行） |

**【例】** 三张平面 $\pi_i: a_ix + b_iy + c_iz = d_i$，记 $\alpha_i = (a_i, b_i, c_i)^T$，$\beta_i = (a_i, b_i, c_i, d_i)^T$，若 $r(\alpha_1, \alpha_2, \alpha_3) = m$，$r(\beta_1, \beta_2, \beta_3) = n$，根据图形判断 $m, n$。

### （四）空间直线方程

#### 一、点向式（对称式）

$$
\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}
$$

方向向量 $\vec{s} = (m, n, p)$，过点 $(x_0, y_0, z_0)$

#### 二、参数方程

$$
\begin{cases} x = x_0 + mt \\ y = y_0 + nt \\ z = z_0 + pt \end{cases}
$$

#### 三、两条直线的位置关系

设 $L_1$ 方向向量 $\vec{s_1}$，$L_2$ 方向向量 $\vec{s_2}$，$L_1$ 上一点 $P_1$，$L_2$ 上一点 $P_2$：

| 条件 | 关系 |
|------|------|
| $\vec{s_1} \parallel \vec{s_2}$ 且 $\overrightarrow{P_1P_2} \parallel \vec{s_1}$ | **重合** |
| $\vec{s_1} \parallel \vec{s_2}$ 且 $\overrightarrow{P_1P_2} \nparallel \vec{s_1}$ | **平行** |
| $\vec{s_1} \nparallel \vec{s_2}$ 且 $(\vec{s_1}, \vec{s_2}, \overrightarrow{P_1P_2})$ 线性相关 | **相交** |
| $\vec{s_1} \nparallel \vec{s_2}$ 且 $(\vec{s_1}, \vec{s_2}, \overrightarrow{P_1P_2})$ 线性无关 | **异面** |

**【例】** 判断两直线 $L_1: \frac{x-1}{1} = \frac{y-2}{1} = \frac{z-3}{1}$ 与 $L_2: \frac{x-2}{1} = \frac{y-3}{2} = \frac{z-4}{3}$ 的位置关系。

> $\vec{s_1} = (1,1,1)$，$\vec{s_2} = (1,2,3)$，$\overrightarrow{P_1P_2} = (1,1,1)$
>
> 混合积 $(\vec{s_1}, \vec{s_2}, \overrightarrow{P_1P_2}) = 0 \Rightarrow$ **相交**

### （五）核心公式速查

```
向量空间：
  基变换 (β₁...βₙ) = (α₁...αₙ)C
  坐标变换 x = Cy, y = C⁻¹x
  求C：(A|B) → (E|A⁻¹B)

二次曲面 f=c (c>0)：
  p=3,q=0 → 椭球面
  p=2,q=1 → 单叶双曲面
  p=1,q=2 → 双叶双曲面
  p=2,q=0 → 椭圆柱面
  p=1,q=1 → 双曲柱面

三平面位置关系：
  r(A)=3,r(A,b)=3 → 交于一点
  r(A)=2,r(A,b)=2 → 交于一直线
  r(A)=2,r(A,b)=3 → 无公共点

两直线：
  异面 ⟺ (s₁,s₂,P₁P₂) 线性无关
  相交 ⟺ (s₁,s₂,P₁P₂) 线性相关 且 s₁∦s₂
```
