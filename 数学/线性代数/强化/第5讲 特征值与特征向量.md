## 第五讲 特征值与特征向量

> 来源：27届考研强化阶段《线性代数》（主讲：许琦）
> 题型：特征值与特征向量 | 相似对角化 | 实对称阵

---

### （一）特征值与特征向量

#### 一、定义

设 $A$ 为 $n$ 阶矩阵，若存在常数 $\lambda$ 和 $n$ 维非零列向量 $\alpha$，使得

$$
A\alpha = \lambda\alpha
$$

则称 $\lambda$ 为 $A$ 的**特征值**，$\alpha$ 是 $A$ 的属于特征值 $\lambda$ 的**特征向量**。

等价形式：$(\lambda E - A)\alpha = 0$，$\alpha \neq 0$

#### 二、求法

##### 1. 数值型

1. 解特征方程 $|\lambda E - A| = 0$，得全部特征值
2. 对每个 $\lambda_i$，求 $(\lambda_i E - A)x = 0$ 的基础解系 $\alpha_1, \ldots, \alpha_s$
3. 属于 $\lambda_i$ 的特征向量为 $k_1\alpha_1 + \cdots + k_s\alpha_s$（不全为0）

##### 2. 抽象型

利用已知 $A\alpha = \lambda\alpha$ 推导。

##### 3. 特殊矩阵的特征值

| 矩阵类型 | 特征值 |
|---------|--------|
| 秩1方阵 $A = \alpha\beta^T$ | $\lambda_1 = \beta^T\alpha = \text{tr}(A)$，其余为 $0$ |
| 上（下）三角矩阵 | 主对角线元素 |
| 分块上（下）三角矩阵 | 各对角块特征值的并集 |

#### 三、性质

##### 性质1：和与积

$$
\sum_{i=1}^n \lambda_i = \text{tr}(A), \quad \prod_{i=1}^n \lambda_i = |A|
$$

##### 性质2：矩阵运算对特征值的影响

| 矩阵 | 特征值 | 特征向量 |
|------|--------|---------|
| $kA$ | $k\lambda$ | $\alpha$ |
| $A^m$ | $\lambda^m$ | $\alpha$ |
| $f(A)$ | $f(\lambda)$ | $\alpha$ |
| $A^{-1}$ | $\lambda^{-1}$ | $\alpha$ |
| $A^*$ | $|A|/\lambda$ | $\alpha$ |
| $P^{-1}AP$ | $\lambda$ | $P^{-1}\alpha$ |

##### 性质3：特征向量的性质

1. 同一特征值的特征向量的非零线性组合仍是该特征值的特征向量
2. **不同特征值的特征向量线性无关**

##### 性质4：重数限制

$\lambda$ 是 $m$ 重特征值 $\Rightarrow$ 属于 $\lambda$ 的线性无关特征向量个数 $= n - r(\lambda E - A) \leq m$

#### 四、反用特征值条件

| 条件 | 含义 |
|------|------|
| $|A| = 0$ | $\lambda = 0$ 是特征值 |
| $|A - kE| = 0$ | $k$ 是特征值 |
| $(kE - A)x = 0$ 有非零解 | $k$ 是特征值 |
| $f(A) = O$ | $f(\lambda) = 0$（限定特征值范围） |
| $A$ 各行元素之和为 $k$ | $k$ 是特征值，特征向量 $(1,1,\ldots,1)^T$ |

**$A$ 可逆的等价条件**：$|A| \neq 0 \iff r(A) = n \iff$ 所有特征值 $\neq 0$

---

### （二）相似对角化

#### 一、定义

若存在可逆矩阵 $P$，使 $P^{-1}AP = \Lambda$（对角阵），则称 $A$ 可**相似对角化**，记 $A \sim \Lambda$。

$$
P = (\alpha_1, \alpha_2, \ldots, \alpha_n), \quad \Lambda = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)
$$

#### 二、可对角化的判定

| 条件 | 结论 |
|------|------|
| $A$ 有 $n$ 个线性无关的特征向量 | $\iff$ 可对角化 |
| 每个 $k_i$ 重特征值满足 $k_i = n - r(\lambda_i E - A)$ | $\iff$ 可对角化 |
| $A$ 有 $n$ 个不同特征值 | $\Rightarrow$ 可对角化 |
| $A$ 为实对称矩阵 | $\Rightarrow$ 可对角化 |

**判定步骤**：
1. 若 $A$ 是实对称 $\Rightarrow$ 可对角化
2. 求特征值，若互异 $\Rightarrow$ 可对角化
3. 对 $k$ 重特征值检验 $k = n - r(\lambda E - A)$

#### 三、对角化步骤

1. 求特征值 $\lambda_1, \lambda_2, \ldots$
2. 对每个特征值求基础解系（特征向量）
3. 令 $P = (\alpha_1, \alpha_2, \ldots, \alpha_n)$
4. $P^{-1}AP = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)$

#### 四、已知可对角化求参数

**关键**：$k$ 重特征值 $\lambda$ 的无关特征向量个数 $= n - r(\lambda E - A) = k$

**【例6】** 设 $A$ 有三个线性无关的特征向量，$\lambda = 2$ 是 $A$ 的二重特征值，求 $P$ 使 $P^{-1}AP$ 为对角阵。

> $\lambda = 2$ 为二重 $\Rightarrow n - r(2E - A) = 2 \Rightarrow r(2E - A) = 1$
>
> 由此确定参数，再求另一特征值和特征向量

#### 五、相似对角化的应用

1. **已知特征值、特征向量反求矩阵**：$P^{-1}AP = \Lambda \Rightarrow A = P\Lambda P^{-1}$
2. **求 $A^n$**：$A = P\Lambda P^{-1} \Rightarrow A^n = P\Lambda^n P^{-1}$
3. **求 $A^n\beta$**：将 $\beta$ 用特征向量线性表示 $\beta = c_1\alpha_1 + \cdots + c_n\alpha_n$

$$
A^n\beta = c_1\lambda_1^n\alpha_1 + c_2\lambda_2^n\alpha_2 + \cdots + c_n\lambda_n^n\alpha_n
$$

**【例8】** 已知方程组有无穷多解，矩阵 $A$ 的特征值是 $1, -1, 0$，对应特征向量为 $\alpha_1, \alpha_2, \alpha_3$，求 $A$ 和 $A^n\beta$。

> 先由无穷多解条件确定参数，再由 $A = P\Lambda P^{-1}$ 求矩阵

**【例7】** 设 $\alpha_1, \alpha_2, \alpha_3$ 线性无关，$A\alpha_1 = \alpha_1 + \alpha_2 + \alpha_3$，$A\alpha_2 = 2\alpha_2 + \alpha_3$，$A\alpha_3 = 2\alpha_2 + 3\alpha_3$

(I) 求 $B$ 使 $A(\alpha_1, \alpha_2, \alpha_3) = (\alpha_1, \alpha_2, \alpha_3)B$

(II) 求 $A$ 的特征值

(III) 求 $P$ 使 $P^{-1}AP$ 为对角阵

> $A$ 与 $B$ 相似，$B$ 的特征值就是 $A$ 的特征值

---

### （三）相似矩阵

#### 一、定义

存在可逆矩阵 $P$，使 $P^{-1}AP = B$，则 $A \sim B$。

#### 二、性质

若 $A \sim B$：
- $r(A) = r(B)$，$\text{tr}(A) = \text{tr}(B)$，$|A| = |B|$，$|\lambda E - A| = |\lambda E - B|$
- $A^T \sim B^T$，$A^{-1} \sim B^{-1}$，$A^* \sim B^*$，$A^m \sim B^m$，$f(A) \sim f(B)$

#### 三、矩阵相似的判定与应用

**已知 $A, B$ 相似求参数**：利用 $\text{tr}(A) = \text{tr}(B)$，$|A| = |B|$ 等

**特别**：若 $A$ 可对角化，则 $r(A) = $ 非零特征值的个数（按重数计）

**【例4】** 矩阵 $A, B$ 相似的充要条件 → 利用特征多项式相等

**【例5】** 判断与给定矩阵相似的矩阵 → 比较特征值、$r(\lambda E - A)$

**求 $P$ 使 $P^{-1}AP = B$**：分别对 $A, B$ 对角化，$A = P_1\Lambda P_1^{-1}$，$B = P_2\Lambda P_2^{-1}$，则 $P = P_1 P_2^{-1}$

### （四）实对称矩阵

#### 一、预备知识

##### 1. 向量的内积

$$
(x, y) = x^Ty = x_1y_1 + x_2y_2 + \cdots + x_ny_n
$$

##### 2. 模（长度）

$$
\|x\| = \sqrt{(x, x)} = \sqrt{x_1^2 + x_2^2 + \cdots + x_n^2}
$$

当 $\|x\| = 1$ 时，称 $x$ 为**单位向量**。任一非零向量 $x$ 可单位化为 $\frac{x}{\|x\|}$。

##### 3. 正交

当 $(x, y) = 0$ 时，称 $x$ 与 $y$ **正交**。

##### 4. Schmidt 正交化

设 $\alpha_1, \alpha_2, \ldots, \alpha_s$ 线性无关：

$$
\beta_1 = \alpha_1
$$

$$
\beta_2 = \alpha_2 - \frac{(\alpha_2, \beta_1)}{(\beta_1, \beta_1)} \beta_1
$$

$$
\beta_3 = \alpha_3 - \frac{(\alpha_3, \beta_1)}{(\beta_1, \beta_1)} \beta_1 - \frac{(\alpha_3, \beta_2)}{(\beta_2, \beta_2)} \beta_2
$$

则 $\beta_1, \beta_2, \ldots, \beta_s$ 两两正交，且与 $\alpha_1, \ldots, \alpha_s$ 等价。

**单位化**：$\eta_i = \frac{\beta_i}{\|\beta_i\|}$

##### 5. 正交矩阵

$$
Q^TQ = QQ^T = E \iff Q^{-1} = Q^T
$$

**性质**：
- $Q$ 的列（行）向量组为标准正交向量组
- $|Q| = 1$ 或 $-1$
- $Q$ 的实特征值为 $1$ 或 $-1$

#### 二、实对称阵的性质

**性质1**：特征值都是**实数**

**性质2**：不同特征值的特征向量**正交**

**性质3**：一定可相似对角化，且存在**正交矩阵** $Q$，使

$$
Q^{-1}AQ = Q^TAQ = \Lambda = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)
$$

#### 三、正交对角化步骤

1. **求特征值**：解 $|\lambda E - A| = 0$
2. **求特征向量**：对每个 $\lambda_i$，求 $(\lambda_i E - A)x = 0$ 的基础解系
3. **正交化**：对同一特征值的多个特征向量做 Schmidt 正交化（不同特征值的自动正交，不需处理）
4. **单位化**：$\eta_i = \frac{\beta_i}{\|\beta_i\|}$
5. **得正交矩阵** $Q = (\eta_1, \eta_2, \ldots, \eta_n)$，$Q^TAQ = \Lambda$

#### 四、典型例题

**【例9】** 设 $A = \begin{pmatrix} 2 & -1 & -1 \\ -1 & 2 & -1 \\ -1 & -1 & 2 \end{pmatrix}$，$B = \begin{pmatrix} 1 & 0 & 0 \\ 0 & b & 0 \\ 0 & 0 & 0 \end{pmatrix}$，$A$ 与 $B$ 相似

(I) 求 $a, b$ 的值

(II) 求正交矩阵 $Q$，使 $Q^TAQ$ 为对角阵

> (I) $A \sim B \Rightarrow \text{tr}(A) = \text{tr}(B)$，$|A| = |B|$
>
> $\text{tr}(A) = 6 = 1 + b + 0 \Rightarrow b = 5$？需具体计算特征值
>
> $|A| = 0 \Rightarrow$ 有一个特征值为 $0$

> (II) 求特征值和特征向量，对重根做 Schmidt 正交化，单位化得 $Q$

**【例10】** 已知 $A$ 是三阶实对称矩阵，特征值是 $1, 1, -1$，属于 $-1$ 的特征向量是 $\alpha_1 = (a, 1, 1)^T$，属于 $1$ 的特征向量是 $\alpha_2 = (1, b, (a+3))^T$，求 $Ax = 0$ 的通解并求矩阵 $A$。

> 实对称阵不同特征值特征向量正交 $\Rightarrow \alpha_1^T \alpha_2 = 0$
>
> $a + b + a + 3 = 0 \Rightarrow$ 确定 $a, b$
>
> $Ax = 0$ 的解即属于 $\lambda = 0$ 的特征向量（但此题 $\lambda$ 中没有 $0$），需重新分析

#### 五、第五章常见求参数条件

| 条件 | 利用方式 |
|------|---------|
| 已知一个特征值 | 代入 $|\lambda E - A| = 0$ |
| 已知一个特征向量 | 代入 $A\alpha = \lambda\alpha$ |
| 已知所有特征值 | $\text{tr}(A) = \sum\lambda_i$，$|A| = \prod\lambda_i$ |
| 已知两矩阵相似 | $\text{tr}$, $|A|$, 特征多项式相等 |
| 已知 $A$ 可对角化 | $k$ 重特征值：$n - r(\lambda E - A) = k$ |
| 已知 $A$ 为实对称阵 | 不同特征值特征向量正交 |

### （五）核心公式速查

```
特征方程：|λE - A| = 0
Σλᵢ = tr(A),  Πλᵢ = |A|

矩阵运算的特征值：
  kA→kλ, A^m→λ^m, A⁻¹→1/λ, A*→|A|/λ, f(A)→f(λ)
  P⁻¹AP 的特征值不变，特征向量变为 P⁻¹α

可对角化 ⟺ 有n个线性无关特征向量
  ⟺ 每个k重特征值有k个无关特征向量
  ⟺ n - r(λE-A) = k

A^n = PΛ^nP⁻¹
A^nβ = c₁λ₁ⁿα₁ + c₂λ₂ⁿα₂ + ... (β=Σcᵢαᵢ)

内积：(x,y) = xᵀy
正交：(x,y) = 0
Schmidt正交化：β₂ = α₂ - (α₂,β₁)/(β₁,β₁)·β₁
单位化：η = x/‖x‖

正交矩阵：QᵀQ = E, Q⁻¹ = Qᵀ, |Q| = ±1
实对称阵：不同特征值特征向量正交，一定可正交对角化
  QᵀAQ = Λ（Schmidt正交化 + 单位化）

相似性质：r, tr, |·|, |λE-·| 相同

常见求参数条件：
  已知特征值 → |λE-A|=0
  已知特征向量 → Aα=λα
  两矩阵相似 → tr, |A|, 特征多项式相等
  实对称阵 → 不同特征值特征向量正交
```
