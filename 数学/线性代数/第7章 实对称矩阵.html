第七章 实对称矩阵

一、向量的内积与施密特正交化

1. 向量的内积 (Inner Product)

在考研数学的线性代数中，内积是将几何概念（如长度、角度、垂直）引入抽象向量空间的基础。

定义：

设有 n 维向量 x=(x1,x2,…,xn)T 和 y=(y1,y2,…,yn)T，它们的标准内积定义为对应坐标乘积之和：

[x,y]=xTy=x1y1+x2y2+⋯+xnyn

性质与几何意义：

  • 模长（长度）： 向量 x 的长度为 ||x||=[x,x]。
  • 夹角： 两个向量的夹角余弦值为 cos⁡θ=[x,y]||x||⋅||y||。
  • 正交（垂直）： 若 [x,y]=0，则称向量 x 与 y 正交。

2. 规范正交向量组

在经历了施密特正交化之后，我们得到了相互垂直的向量。如果再进而在长度上做一次“标准化”，我们就会得到规范正交向量组（当向量个数等于空间维数时，也称为规范正交基）。

这是线性代数中非常完美的向量集合，在实对称矩阵对角化和化二次型为标准形等核心考点中扮演着基石的角色。

核心定义：

设 V 是一组向量 α1,α2,…,αr。如果这组向量满足以下两个条件，则称为规范正交向量组：

  1. 正交性： 向量之间两两正交。
  2. 规范性（单位化）： 每个向量的模长（长度）都为 1。

用内积的数学语言可以非常精炼地表达为（即克罗内克 δ 函数）：

[αi,αj]={1,i=j0,i≠j
为什么它如此重要？（三大核心性质）

规范正交基之所以好用，是因为它把复杂的计算极大地简化了。

1. 坐标计算极度简化

如果在普通的基底下，求一个向量 x 的坐标需要解一个复杂的线性方程组。但在规范正交基 η1,η2,…,ηn 下，向量 x 的第 i 个坐标直接就是 x 与 ηi 的内积！

x=[x,η1]η1+[x,η2]η2+⋯+[x,ηn]ηn

2. 构成了正交矩阵 (Orthogonal Matrix)

如果把 n 维空间中的 n 个规范正交向量作为列向量拼成一个矩阵 Q=(η1,η2,…,ηn)，那么 Q 就是一个正交矩阵。

正交矩阵有一个极其优美的性质：它的转置等于它的逆。

QTQ=E⟹QT=Q−1

3. 保距性与保角性

如果用正交矩阵 Q 对向量进行线性变换（比如 y=Qx），这种变换相当于在空间中对向量进行“旋转”或“反射”。它不会改变向量的长度，也不会改变向量之间的夹角。这就是为什么在处理二次型时，我们总是寻找正交变换，因为它只做坐标系的旋转，而不改变几何体的本质形状。

3. 正交矩阵

顺着我们刚才的思路：向量内积定义了长度和角度 → 施密特正交化帮我们找到了互相垂直的基 → 规范化让这组基的长度变成了 1。

现在，如果把这 n 个规范正交列向量拼在一起，构成一个 n 阶方阵 A=(η1,η2,…,ηn)，这个矩阵 A 就是正交矩阵。

在考研数学（特别是 11408 涉及的线代大题）中，正交矩阵是实对称矩阵对角化和二次型化标准形的核心工具。

核心定义与等价条件：

一个实方阵 A 是正交矩阵，当且仅当它满足：

ATA=AAT=E

(其中 E 是单位矩阵)

这个定义直接推导出了它最实用的计算性质：它的转置就等于它的逆。

A−1=AT

在解题时，求逆矩阵通常计算量极大，但如果是正交矩阵，只需要写出它的转置即可，极大简化了运算。

重要代数性质

  1. 行列式的值： |A|=1 或 |A|=−1。

    (证明思路：|ATA|=|AT||A|=|A|2=|E|=1)

  2. 封闭性： 两个正交矩阵的乘积仍然是正交矩阵；正交矩阵的逆矩阵（转置）也是正交矩阵。

  3. 特征值： 实正交矩阵的实特征值只能是 1 或 −1。

  4. 正交矩阵的列向量组，必定是一组规范正交基：若A=(α1,α2,…,αn) ，则(α1,α2,…,αn) 为一个规范正交向量组

几何意义：保距性与保角性

为什么我们在处理二次型时，必须用“正交变换”（即 x=Ay，其中 A 是正交矩阵）？

因为正交矩阵代表的是空间中的旋转（当 |A|=1）或反射（当 |A|=−1）。它在变换向量时，具有保距性和保角性：

  • 保长度： 变换前后向量的模长不变，即 ||Ax||=||x||。
  • 保内积（夹角）： 变换前后两个向量的内积不变，即 [Ax,Ay]=[x,y]。

这意味着，用正交矩阵去变换一个几何体（比如椭圆），它只会改变几何体的朝向（旋转），而绝对不会把椭圆拉长、压扁或扭曲。

为了直观展示这一点，我准备了一个 2D 变换交互演示。你可以对比一下“正交变换（旋转/反射）”与“非正交变换（拉伸）”对向量长度和夹角的影响。

2. 施密特正交化 (Gram-Schmidt Orthogonalization)

核心思想： 提取“纯粹”的新方向。把一个新向量投影到已有的正交基上，然后减去这些投影分量，剩下的部分自然就和已有的基正交了。

设有一组线性无关的向量 α1,α2,α3，我们要将其转化为一组两两正交的向量 β1,β2,β3。

推导步骤：

  1. 固定第一项： 直接取第一个向量作为基准。

    β1=α1

  2. 正交化第二项： 将 α2 在 β1 方向上的投影减去。

    β2=α2−[α2,β1][β1,β1]β1

  3. 正交化第三项： 将 α3 分别在 β1 和 β2 方向上的投影减去。

    β3=α3−[α3,β1][β1,β1]β1−[α3,β2][β2,β2]β2

(如果需要构造标准正交基，最后还需进行单位化：ηi=βi||βi||)

对于三维空间中的向量，正交化的过程本质上是不断的投影与相减。

二、实对称矩阵

1. 实对称矩阵定义

在线性代数的体系里，实对称矩阵可以说是性质最“完美”、在考场上出现频率最高的一类矩阵。它将我们前面讨论的特征值、正交性和对角化彻底串联在了一起。在冲击高分的过程中，无论是二次型还是矩阵相似对角化的解答题，基本上都围绕着它展开。

核心定义：

如果一个 n 阶实数矩阵 A 满足它的转置等于它本身，即：

AT=A

那么 A 就是实对称矩阵。

从矩阵元素来看，它以主对角线为对称轴，满足 aij=aji。

2. 四大核心性质

实对称矩阵之所以重要，是因为它拥有其他普通方阵求之不得的优良性质。以下四条在做大题时可以直接作为定理使用：

1. 特征值全为实数

普通矩阵的特征值可能是复数，但实对称矩阵的特征值必定全是实数。这就保证了我们在实数域内总能找到对应的特征向量，不会在考场上算出复数解（如果算出了复数，说明前面必定算错了）。

2. 属于不同特征值的特征向量必然正交

设 λ1,λ2 是 A 的两个不同的特征值，对应的特征向量分别为 α1,α2。那么必定有：

[α1,α2]=α1Tα2=0

实战意义：如果一道题的矩阵是实对称的，你求出了不同特征值对应的基础解系，它们天然就是互相垂直的，不需要再做施密特正交化！

3. 必然可以相似对角化（无条件）

普通方阵如果有重根（比如特征值是一个二重根），我们还需要验证它是否有两个线性无关的特征向量。

但实对称矩阵自带特权：对于 k 重特征根，它必定能求出恰好 k 个线性无关的特征向量。因此，实对称矩阵永远可以相似对角化。

即：(A−λ0E)x=0 的基础解系所含解向量个数为k，等价于k=n−r(A−λ0E)

4. 必存在正交矩阵实现对角化

结合性质 2 和 3，对于任意 n 阶实对称矩阵 A，必定存在一个正交矩阵 Q（即 QT=Q−1），使得：

QTAQ=Q−1AQ=Λ

其中 Λ 是由 A 的特征值构成的主对角矩阵。

考场上的避坑逻辑

在处理实对称矩阵的对角化大题时，很多人会因为步骤混乱而失分。记住这个铁律：

  • 不同特征值对应的特征向量 ⟹ 天然正交（无需施密特，直接单位化即可）。
  • 相同特征值（重根）对应的多个特征向量 ⟹ 不一定正交（必须先做施密特正交化，再单位化）。

这也就是为什么上一步我们在死磕施密特正交化的计算准确率——它专门用来对付实对称矩阵中的“重根”情况。
