<h2 align="center">线性代数总纲：从求解方程组的角度</h2>

> **本篇定位**：把八章线代压缩成一条主线——**解方程 $Ax = b$**。每一章都是这条主线上的一件工具：行列式是"体检指标"，矩阵与秩是"裁判"，向量是"翻译官"，特征值是"特殊方程组"，相似对角化与二次型是"终点应用"。复习时用这条线把知识串起来，而不是把八章当八门课。

### （一）总纲：整门线代就是围绕 $Ax = b$ 展开

#### 一、一个方程组，三种形式

$m$ 个方程、$n$ 个未知数的方程组，有三种等价写法，对应三种视角（详见第4章）：

$$
\underbrace{\begin{cases} a_{11}x_1 + \dots + a_{1n}x_n = b_1 \\ \dots \end{cases}}_{\text{代数形式：动手算}} \iff \underbrace{Ax = b}_{\text{矩阵形式：看变换}} \iff \underbrace{x_1\alpha_1 + \dots + x_n\alpha_n = b}_{\text{向量形式：看表出}}
$$

- **代数形式**：高斯消元的入口。
- **矩阵形式**：$A$ 是从 $\mathbb{R}^n$ 到 $\mathbb{R}^m$ 的线性变换，求解就是找被映射成 $b$ 的原像 $x$。
- **向量形式**："$Ax=b$ 有解" $\iff$ "$b$ 能由 $A$ 的列向量组线性表出"。理论证明题的核心语言。

#### 二、八章各自的角色

| <b><nobr>章节</nobr></b> | 在求解 $Ax = b$ 主线中的角色 |
|:---|:---|
| 第1章 行列式 | **方阵方程组的体检指标**：$|A| \neq 0$ 才配谈唯一解、克拉默法则；$|A| = 0$ 直判齐次有非零解 |
| 第2章 矩阵 | **消元的机器语言**：初等行变换 = 高斯消元；秩 $r(A)$ = 消元后独立方程数；$A^{-1}$ 给出 $x = A^{-1}b$ |
| 第3章 向量 | **翻译官**：把"有没有解"翻译成"能不能线性表出"；把"解的结构"翻译成"线性相关/无关" |
| 第4章 线性方程组 | **主战场**：解的存在性判定 + 通解结构 + 求解流程，全书的落脚点 |
| 第5章 特征值 | **另一类方程组**：$(A - \lambda E)x = 0$，特征向量就是它的非零解 |
| 第6章 相似矩阵 | **换坐标系解方程**：$A = P\Lambda P^{-1}$，用特征向量撑起新基，让矩阵方程退化成 $n$ 个数乘 |
| 第7章 实对称矩阵 | **最优坐标系**：必可正交对角化，$Q^T = Q^{-1}$，不同特征值的特征向量天然正交 |
| 第8章 二次型 | **终点应用**：$f = x^T Ax$ 经正交变换化为标准形，正定性本质上是"除零解外 $f$ 恒正"的方程组问题 |

#### 三、核心枢纽：秩

**整本书只有一个数字真正主宰解的命运——秩 $r(A)$**。它同时被三种工具刻画：

- **消元视角**：行阶梯形中非零行的个数。
- **子式视角**：最高阶非零子式的阶数。
- **向量视角**：列向量组中极大线性无关组所含向量个数（列秩 = 行秩 = $r(A)$）。

> **考点**：$r(A) = n$（列满秩）是"唯一解"的同义词；$r(A) < n$ 是"无穷多解 + 有自由变量"的同义词。所有判定都在比较 $r(A)$、$r(A, b)$、$n$ 三者。

### （二）工具箱：行列式与矩阵如何服务于求解

#### 一、行列式：只在方阵世界有效的"快判器"

行列式（第1章）牺牲了普适性换取速度——**只对 $n$ 阶方阵有效**，但一条行列式就能宣判决：

| 方程组 | $|A| \neq 0$ | $|A| = 0$ |
|:---|:---|:---|
| 齐次 $Ax = 0$ | 只有零解 | **有非零解** |
| 非齐次 $Ax = b$ | 唯一解（可用克拉默 $x_j = \dfrac{D_j}{D}$） | 解不定：无解或无穷多解，必须看秩 |

**克拉默法则的实战定位**：具体数字题**永远用高斯消元**（4 阶行列式要算 5 个，计算量爆炸）；它的真正战场是**含参方程组**——令 $|A| = 0$ 求参数是考研第一大题的固定套路。

#### 二、矩阵：把消元法" algebra 化"

第2章的一切都为求解服务：

1. **初等行变换 = 方程组的合法变形**（交换两方程、非零倍乘、倍加消元），且不改变解集。"左行右列"：行变换 = 左乘初等矩阵。
2. **求逆 = 解 $n$ 个方程组**：$(A \mid E) \to (E \mid A^{-1})$ 的本质是对 $A$ 的每一列常数项做高斯消元。
3. **可逆的八大等价刻画**（务必画等号）：

$$
A^{-1} \text{ 存在} \iff |A| \neq 0 \iff r(A) = n \iff Ax = 0 \text{ 只有零解} \iff \forall b,\ Ax = b \text{ 有唯一解}
$$

$$
\iff A^* \text{ 可逆} \iff A \cong E \iff A \text{ 的特征值全不为 } 0
$$

4. **秩的运算规则**（判定解时的常用武器）：
   - $r(A^T) = r(A)$；乘可逆阵不变：$r(PAQ) = r(A)$。
   - 木桶效应：$r(AB) \le \min(r(A), r(B))$。
   - **西尔维斯特推论**：$A_{m \times n}B_{n \times s} = O \implies r(A) + r(B) \le n$——它正是"$AB = O$ 时 $B$ 的列向量都是 $Ax = 0$ 的解，故 $r(B) \le n - r(A)$"的直接翻译。
   - 伴随：$r(A^*) = n, 1, 0$（对应 $r(A) = n, n-1, \le n-2$）。

### （三）主战场：解的判定、结构与求解（第4章浓缩）

#### 一、解的判定：三行看生死

对 $n$ 元方程组，增广矩阵消元后只需数秩：

| 情形 | 判定条件 | 消元后的长相 | 几何意义 |
|:---|:---|:---|:---|
| 无解 | $r(A) < r(A, b)$ | 出现 $0 = c$ 行 | $b$ 落在列空间之外，无法被列向量表出 |
| 唯一解 | $r(A) = r(A, b) = n$ | 满列秩，无自由变量 | $b$ 在列空间内且表出方式唯一 |
| 无穷多解 | $r(A) = r(A, b) < n$ | 有 $n - r$ 个自由变量 | $b$ 在列空间内但表出方式不唯一 |

> **易错点**：$m < n$（方程少未知数多）时齐次方程组**必有非零解**（$r(A) \le m < n$）；但非齐次方程组**可能无解**，别混。

#### 二、解的结构：通解的两层楼

**齐次 $Ax = 0$**：解集构成向量空间（解空间/零空间），维数严格等于 $n - r(A)$。

$$
x = k_1\xi_1 + k_2\xi_2 + \dots + k_{n-r}\xi_{n-r}
$$

基础解系三条件：是解、线性无关、能表出全部解。个数 $s = n - r(A)$ 是**填空题高频**——由特征值、$AB = O$ 等条件反推秩是常见考法。

**非齐次 $Ax = b$**：解集不是空间（对加法不封闭），但结构是"特解 + 齐次通解"：

$$
x = \underbrace{\eta^*}_{\text{特解（车架）}} + \underbrace{k_1\xi_1 + \dots + k_{n-r}\xi_{n-r}}_{\text{导出组的基础解系（轮子）}}
$$

**解的性质三连**（抽象题的全部弹药）：

1. **相减归零**：$\eta_1 - \eta_2$ 是 $Ax = 0$ 的解。
2. **偏移叠加**：$\eta^* + \xi$ 仍是非齐次解。
3. **系数和判别**（选择题秒杀）：$\sum k_i\eta_i$ 当且仅当 $\sum k_i = 1$ 时是 $Ax = b$ 的解，$\sum k_i = 0$ 时是 $Ax = 0$ 的解。

#### 三、求解流程：数值型 vs 抽象型

**数值型（增广矩阵行变换）**：

1. 写增广矩阵 $(A \mid b)$。
2. 只做**行变换**（列变换会打乱未知数顺序，禁用）化行最简形。
3. 数秩定生死：无解 / 唯一解（回代） / 无穷多解（分主元变量与自由变量）。
4. 自由变量轮流取单位值 $(1, 0, \dots), (0, 1, \dots)$，提出基础解系与特解，组装通解。

**抽象型（拼图游戏）**：

1. 由已知条件（解的个数、$AB = O$、特征值……）求出 $r(A)$，确定基础解系"坑位" $n - r(A)$。
2. 用已知解**两两相减**造出齐次解，验证线性无关且个数恰好达标 → 基础解系。
3. 用已知解（或系数和为 1 的组合）充当特解。
4. 套公式 $x = \eta^* + \sum k_i\xi_i$。

#### 四、公共解与同解

- **公共解**（两个方程组解集的交集）三法：

| 已知条件 | 推荐方法 | 要点 |
|:---|:---|:---|
| 两个矩阵 $A$、$B$ 都是具体的 | 联立矩阵法 | 拼 $\begin{bmatrix} A \\ B \end{bmatrix}$ 直接消元，最稳 |
| 第一问已求出某组通解 | 通解代入法 | 通解代入另一方程组，解出参数比例，计算量最小 |
| 给出两组基向量求交 | 通解相等法 | **两套独立参数字母**（$k$ 与 $l$），令两通解相等 |

- **同解**：$Ax = 0$ 与 $Bx = 0$ 同解 $\iff r(A) = r(B) = r\begin{bmatrix} A \\ B \end{bmatrix}$（行向量组等价）。

### （四）向量的视角：把求解问题翻译成表出问题（第3章）

第3章的存在意义，是给"解方程"配上几何语言：

| 方程组命题 | 向量语言翻译 |
|:---|:---|
| $Ax = b$ 有解 | $b$ 可由列向量组 $\alpha_1, \dots, \alpha_n$ 线性表出；$r(A) = r(A, b)$ |
| $Ax = b$ 解唯一 | 表出方式唯一 $\iff$ $\alpha_1, \dots, \alpha_n$ 线性无关 |
| $Ax = 0$ 有非零解 | $\alpha_1, \dots, \alpha_n$ **线性相关** |
| $Ax = 0$ 只有零解 | $\alpha_1, \dots, \alpha_n$ **线性无关** |
| 基础解系 | 零空间的一组基 |
| $n - r(A)$ 个自由变量 | 列向量组中"多余"向量的个数 |

**做题时最常用的转化**：判定相关性 / 求极大无关组，一律把向量按列拼矩阵做行变换——**行变换不改变列之间的线性关系**，主元列对应的**原向量**（不是化简后的列！）构成极大无关组。

> **高频结论**：$m > n$（向量个数大于维数）必相关；部分相关则整体相关；无关组添分量仍无关。

### （五）延伸一：特征值——另一类方程组（第5章）

特征值问题本质上还是解方程组，只是未知数多了一个：

$$
Ax = \lambda x \iff (A - \lambda E)x = 0
$$

**两步求解 = 一次行列式 + 一次齐次方程组**：

1. **求 $\lambda$**：令 $|A - \lambda E| = 0$（特征方程）。本质是找一个使 $(A - \lambda E)$ 奇异的 $\lambda$——与"$|A| = 0$ 则 $Ax = 0$ 有非零解"完全同构。
2. **求 $x$**：对每个 $\lambda_i$ 解齐次方程组 $(A - \lambda_i E)x = 0$ 的**非零解**，基础解系的非零线性组合就是全部特征向量。

**与主线的连接点**：

- $\lambda = 0$ 是 $A$ 的特征值 $\iff Ax = 0$ 有非零解 $\iff A$ 不可逆 $\iff r(A) < n$。
- $\lambda_i$ 的几何重数 $= n - r(A - \lambda_i E)$——就是齐次方程组基础解系的个数。
- $\sum \lambda_i = \text{tr}(A)$，$\prod \lambda_i = |A|$（由特征多项式系数读出；$\prod \lambda_i = 0 \iff$ 不可逆）。

### （六）延伸二：相似对角化——为解方程组选最好的坐标系（第6、7章）

#### 一、对角化 = 把矩阵方程退化成数乘

$P^{-1}AP = \Lambda \iff AP = P\Lambda$，按列拆开就是 $n$ 个 $A\xi_i = \lambda_i\xi_i$——**对角化的每一列，都是一次特征方程组求解**。

对角化后，一切矩阵方程都变简单：

$$
A^k = P\Lambda^kP^{-1}, \quad Ax = b \Rightarrow \Lambda y = P^{-1}b\ (x = Py)
$$

**可对角化判定（从方程组角度理解）**：

- 充要：每个特征值的**几何重数 = 代数重数**，即每个 $(A - \lambda_i E)x = 0$ 的基础解系个数恰好等于重根数。缺一个都凑不齐 $n$ 个线性无关特征向量，$P$ 不可逆。
- 充分：$n$ 个互异特征值（每个方程组至少一个非零解）；实对称（自带特权）。

#### 二、实对称矩阵：方程组的"豪华版"解法

- 特征值全为实数；**不同特征值的特征向量天然正交**（免施密特）；$k$ 重根必有 $k$ 个无关特征向量（必可对角化）。
- 存在正交矩阵 $Q$：$Q^TAQ = \Lambda$，$Q^T = Q^{-1}$。
- **考场铁律**：不同特征值的向量只单位化；**同一重根内部**的向量必须先施密特正交化再单位化。

### （七）终点应用：二次型（第8章）

二次型 $f = x^TAx$（$A$ 实对称）是"广义方程组"——问的不是 $x$ 具体是谁，而是 $x^TAx$ 恒正还是恒负。

**正交变换法化标准形 = 完整复用求解流水线**：写 $A$ → 解 $|A - \lambda E| = 0$ → 解各 $(A - \lambda_iE)x = 0$ 求特征向量 →（重根内施密特）单位化拼 $Q$ → 标准形系数就是特征值 $\sum \lambda_iy_i^2$。

**配方法**：快但不给特征值，只保正负惯性指数（惯性定理：$p$、$q$ 不随变换改变；$r(A) = p + q$ = 非零特征值个数）。注意最后要把 $y = P^{-1}x$ **反解**成 $x = Py$。

**正定性判定（四条等价）**：所有 $\lambda_i > 0$ $\iff$ 各阶顺序主子式全 $> 0$ $\iff$ $A \simeq E$（存在 $P$ 使 $A = P^TP$） $\iff$ $p = n$。

**三大关系对比**（命题重灾区）：

| <b><nobr>关系</nobr></b> | 定义式 | 保住什么 | 判定 |
|:---|:---|:---|:---|
| 等价 | $B = PAQ$ | 秩 | 秩相同即等价 |
| 相似 | $B = P^{-1}AP$ | 特征值、秩、迹、行列式 | 特征值相同且都能对角化 |
| 合同 | $B = P^TAP$ | 秩、正负惯性指数 | 实对称下 $p$、$q$ 相同即合同 |

正交矩阵是纽带：$P^T = P^{-1}$ 时相似与合同统一；实对称矩阵相似 $\Rightarrow$ 合同，反之不成立。

### （八）本章总结

**知识结构图**（一条主线串八章）：

```
解方程 Ax = b
├─ 判"有没有解 / 几个解"
│   ├─ 方阵特供快判：|A| ≠ 0（行列式 / 克拉默）
│   ├─ 通用裁判：r(A) vs r(A,b) vs n（矩阵 / 秩 / 初等行变换）
│   └─ 向量翻译：b 能否由列向量组线性表出（线性相关性 / 极大无关组）
├─ 有解后"解长什么样"
│   ├─ 齐次：解空间，维数 n − r(A)，基础解系 + 通解
│   ├─ 非齐次：特解 + 齐次通解（系数和判别秒杀选择题）
│   └─ 多组方程：公共解（联立/代入/通解相等）、同解（三秩相等）
├─ 工具升级
│   ├─ 特征值：(A − λE)x = 0 的非零解，几何重数 = n − r(A − λE)
│   ├─ 相似对角化：P 由特征向量拼成，几何重数 = 代数重数是充要条件
│   └─ 实对称：必可正交对角化，不同特征值向量天然正交
└─ 终点应用
    ├─ 二次型 f = xᵀAx 正交变换化标准形（系数 = 特征值）
    ├─ 惯性定理：p、q 不变；r(A) = p + q = 非零特征值个数
    └─ 正定 ⇔ λ 全正 ⇔ 顺序主子式全正 ⇔ A ≃ E ⇔ p = n
```
