<h2 align="center">线性代数总纲：从求解方程组的角度</h2>

> **本篇定位**：以解方程组 $Ax = b$ 为主线把八章内容串联起来。行列式给出方阵方程组的判定条件，矩阵与秩给出一般情形的判定方法，向量提供线性表出的语言，特征值对应另一类方程组，相似对角化与二次型是这条主线的延伸与应用。复习时按这条主线组织知识，而不是把八章当作互不相关的八部分。
>
> **配套**：第一部分为**主线总纲**（（一）～（八））；第二部分为**核心概念手册**（（九）～（十七）），按章给出每个概念的严格定义、等价刻画与易错辨析，可单独用于概念自测。公式结论汇总见 `公式.md`，题型与例题见 `题目.md` 与各章笔记。

### （一）总纲：整门线代围绕 $Ax = b$ 展开

#### 一、一个方程组，三种形式

$m$ 个方程、$n$ 个未知数的方程组，有三种等价写法，对应三种视角（详见第4章）：

$$
\underbrace{\begin{cases} a_{11}x_1 + \dots + a_{1n}x_n = b_1 \\ \dots \end{cases}}_{\text{代数形式：直接消元}} \iff \underbrace{Ax = b}_{\text{矩阵形式：线性变换}} \iff \underbrace{x_1\alpha_1 + \dots + x_n\alpha_n = b}_{\text{向量形式：线性表出}}
$$

- **代数形式**：直接对应高斯消元。
- **矩阵形式**：$A$ 是从 $\mathbb{R}^n$ 到 $\mathbb{R}^m$ 的线性变换，求解就是找被映射成 $b$ 的原像 $x$。
- **向量形式**："$Ax=b$ 有解" $\iff$ "$b$ 能由 $A$ 的列向量组线性表出"。理论证明题的主要表述方式。

#### 二、八章各自的作用

| <b><nobr>章节</nobr></b> | 在求解 $Ax = b$ 主线中的作用 |
|:---|:---|
| 第1章 行列式 | **方阵方程组的判定条件**：只有 $|A| \neq 0$ 才能判定唯一解，并给出克拉默法则；$|A| = 0$ 可判定齐次方程组有非零解 |
| 第2章 矩阵 | **消元的矩阵表示**：初等行变换 = 高斯消元；秩 $r(A)$ = 消元后独立方程数；$A^{-1}$ 给出 $x = A^{-1}b$ |
| 第3章 向量 | **线性表出的语言**：把"方程组是否有解"表述为"$b$ 能否由列向量组线性表出"；把解的结构问题转化为线性相关性问题 |
| 第4章 线性方程组 | **核心内容**：解的存在性判定 + 通解结构 + 求解流程，是全书内容最集中的一章 |
| 第5章 特征值 | **另一类方程组**：$(A - \lambda E)x = 0$，特征向量即该方程组的非零解 |
| 第6章 相似矩阵 | **通过换基简化运算**：$A = P\Lambda P^{-1}$，以特征向量构成新基，把矩阵运算化为对角矩阵的数乘 |
| 第7章 实对称矩阵 | **正交对角化**：必可正交对角化，$Q^T = Q^{-1}$，不同特征值的特征向量必正交 |
| 第8章 二次型 | **综合应用**：$f = x^T Ax$ 经正交变换化为标准形，正定性判定归结为二次型取值符号的判定 |

#### 三、核心：秩

**解的存在性与个数完全由秩 $r(A)$ 决定**。秩有三种等价刻画：

- **消元视角**：行阶梯形中非零行的个数。
- **子式视角**：最高阶非零子式的阶数。
- **向量视角**：列向量组中极大线性无关组所含向量个数（列秩 = 行秩 = $r(A)$）。

> **考点**：$r(A) = n$（列满秩）等价于"唯一解"；$r(A) < n$ 等价于"无穷多解 + 有自由变量"。所有判定都归结为比较 $r(A)$、$r(A, b)$、$n$ 三者。

### （二）基本工具：行列式与矩阵如何服务于求解

#### 一、行列式：仅适用于方阵的快速判定工具

行列式（第1章）只对 $n$ 阶方阵有效，但只需计算一个行列式即可作出判定：

| 方程组 | $|A| \neq 0$ | $|A| = 0$ |
|:---|:---|:---|
| 齐次 $Ax = 0$ | 只有零解 | **有非零解** |
| 非齐次 $Ax = b$ | 唯一解（可用克拉默 $x_j = \dfrac{D_j}{D}$） | 解不定：无解或无穷多解，必须看秩 |

**克拉默法则的适用范围**：具体数字题一律用高斯消元（4 阶行列式需计算 5 个，计算量大）；它主要用于**含参方程组**——令 $|A| = 0$ 求参数是考研大题中的常见思路。

#### 二、矩阵：消元法的矩阵表达

第2章的内容都服务于求解：

1. **初等行变换 = 方程组的同解变形**（交换两方程、非零倍乘、倍加消元），且不改变解集。"左行右列"：行变换 = 左乘初等矩阵。
2. **求逆 = 解 $n$ 个方程组**：$(A \mid E) \to (E \mid A^{-1})$ 的本质是对 $A$ 的每一列作为常数项做高斯消元。
3. **可逆的八大等价刻画**（必须熟练掌握）：

$$
A^{-1} \text{ 存在} \iff |A| \neq 0 \iff r(A) = n \iff Ax = 0 \text{ 只有零解} \iff \forall b,\ Ax = b \text{ 有唯一解}
$$

$$
\iff A^* \text{ 可逆} \iff A \cong E \iff A \text{ 的特征值全不为 } 0
$$

4. **秩的运算规则**（判定解时的常用结论）：
   - $r(A^T) = r(A)$；乘可逆阵不变：$r(PAQ) = r(A)$。
   - 乘积的秩：$r(AB) \le \min(r(A), r(B))$。
   - **西尔维斯特推论**：$A_{m \times n}B_{n \times s} = O \implies r(A) + r(B) \le n$——理由是：$AB = O$ 时 $B$ 的每一列都是 $Ax = 0$ 的解，故 $r(B) \le n - r(A)$。
   - 伴随：$r(A^*) = n, 1, 0$（对应 $r(A) = n, n-1, \le n-2$）。

### （三）核心内容：解的判定、结构与求解（第4章浓缩）

#### 一、解的判定：三种情形

对 $n$ 元方程组，增广矩阵消元后只需数秩：

| 情形 | 判定条件 | 消元后的形式 | 几何意义 |
|:---|:---|:---|:---|
| 无解 | $r(A) < r(A, b)$ | 出现 $0 = c$ 行 | $b$ 落在列空间之外，无法被列向量表出 |
| 唯一解 | $r(A) = r(A, b) = n$ | 满列秩，无自由变量 | $b$ 在列空间内且表出方式唯一 |
| 无穷多解 | $r(A) = r(A, b) < n$ | 有 $n - r$ 个自由变量 | $b$ 在列空间内但表出方式不唯一 |

> **易错点**：$m < n$（方程少未知数多）时齐次方程组**必有非零解**（$r(A) \le m < n$）；但非齐次方程组**可能无解**，两种情况不要混淆。

#### 二、解的结构：通解的组成

**齐次 $Ax = 0$**：解集构成向量空间（解空间/零空间），维数等于 $n - r(A)$。

$$
x = k_1\xi_1 + k_2\xi_2 + \dots + k_{n-r}\xi_{n-r}
$$

基础解系三条件：是解、线性无关、能表出全部解。个数 $s = n - r(A)$ 是**填空题常考点**——由特征值、$AB = O$ 等条件反推秩是常见考法。

**非齐次 $Ax = b$**：解集不是空间（对加法不封闭），但结构是"特解 + 齐次通解"：

$$
x = \underbrace{\eta^*}_{\text{特解}} + \underbrace{k_1\xi_1 + \dots + k_{n-r}\xi_{n-r}}_{\text{导出组的基础解系}}
$$

**解的三条性质**（抽象题的主要依据）：

1. **相减仍为齐次解**：$\eta_1 - \eta_2$ 是 $Ax = 0$ 的解。
2. **非齐次解加齐次解仍为非齐次解**：$\eta^* + \xi$ 仍是非齐次解。
3. **系数和判别**（选择题常用）：$\sum k_i\eta_i$ 当且仅当 $\sum k_i = 1$ 时是 $Ax = b$ 的解，$\sum k_i = 0$ 时是 $Ax = 0$ 的解。

#### 三、求解流程：数值型 vs 抽象型

**数值型（增广矩阵行变换）**：

1. 写增广矩阵 $(A \mid b)$。
2. 只做**行变换**（列变换会打乱未知数顺序，禁用）化行最简形。
3. 数秩定解的情况：无解 / 唯一解（回代） / 无穷多解（区分主元变量与自由变量）。
4. 自由变量轮流取单位值 $(1, 0, \dots), (0, 1, \dots)$，提出基础解系与特解，组装通解。

**抽象型（由已知解反推）**：

1. 由已知条件（解的个数、$AB = O$、特征值……）求出 $r(A)$，确定基础解系的个数 $n - r(A)$。
2. 用已知解**两两相减**造出齐次解，验证其线性无关且个数正好等于 $n - r(A)$ → 基础解系。
3. 用已知解（或系数和为 1 的组合）充当特解。
4. 套公式 $x = \eta^* + \sum k_i\xi_i$。

#### 四、公共解与同解

- **公共解**（两个方程组解集的交集）有三种方法：

| 已知条件 | 推荐方法 | 要点 |
|:---|:---|:---|
| 两个矩阵 $A$、$B$ 都是具体的 | 联立矩阵法 | 拼 $\begin{bmatrix} A \\ B \end{bmatrix}$ 直接消元，最稳定 |
| 第一问已求出某组通解 | 通解代入法 | 通解代入另一方程组，解出参数比例，计算量最小 |
| 给出两组基向量求交 | 通解相等法 | **两套独立参数字母**（$k$ 与 $l$），令两通解相等 |

- **同解**：$Ax = 0$ 与 $Bx = 0$ 同解 $\iff r(A) = r(B) = r\begin{bmatrix} A \\ B \end{bmatrix}$（行向量组等价）。

### （四）向量的视角：把求解问题转化为线性表出问题（第3章）

第3章的作用是用线性表出描述方程组的解：

| 方程组命题 | 向量表述 |
|:---|:---|
| $Ax = b$ 有解 | $b$ 可由列向量组 $\alpha_1, \dots, \alpha_n$ 线性表出；$r(A) = r(A, b)$ |
| $Ax = b$ 解唯一 | 表出方式唯一 $\iff$ $\alpha_1, \dots, \alpha_n$ 线性无关 |
| $Ax = 0$ 有非零解 | $\alpha_1, \dots, \alpha_n$ **线性相关** |
| $Ax = 0$ 只有零解 | $\alpha_1, \dots, \alpha_n$ **线性无关** |
| 基础解系 | 零空间的一组基 |
| $n - r(A)$ 个自由变量 | 列向量组中"多余"向量的个数 |

**做题时最常用的转化**：判定相关性 / 求极大无关组，一律把向量按列拼矩阵做行变换——**行变换不改变列之间的线性关系**，主元列对应的**原向量**（不是化简后的列）构成极大无关组。

> **高频结论**：$m > n$（向量个数大于维数）必相关；部分相关则整体相关；无关组添分量仍无关。

### （五）延伸一：特征值——另一类方程组（第5章）

特征值问题仍然是解方程组，只是多了一个参数 $\lambda$：

$$
Ax = \lambda x \iff (A - \lambda E)x = 0
$$

**两步求解 = 一次行列式 + 一次齐次方程组**：

1. **求 $\lambda$**：令 $|A - \lambda E| = 0$（特征方程）。本质是找一个使 $(A - \lambda E)$ 奇异的 $\lambda$，与"$|A| = 0$ 则 $Ax = 0$ 有非零解"是同一原理。
2. **求 $x$**：对每个 $\lambda_i$ 解齐次方程组 $(A - \lambda_i E)x = 0$ 的**非零解**，基础解系的非零线性组合就是全部特征向量。

**与主线的联系**：

- $\lambda = 0$ 是 $A$ 的特征值 $\iff Ax = 0$ 有非零解 $\iff A$ 不可逆 $\iff r(A) < n$。
- $\lambda_i$ 的几何重数 $= n - r(A - \lambda_i E)$——就是齐次方程组基础解系的个数。
- $\sum \lambda_i = \text{tr}(A)$，$\prod \lambda_i = |A|$（由特征多项式系数读出；$\prod \lambda_i = 0 \iff$ 不可逆）。

### （六）延伸二：相似对角化——通过换基简化矩阵运算（第6、7章）

#### 一、对角化把矩阵运算化为数乘

$P^{-1}AP = \Lambda \iff AP = P\Lambda$，按列拆开就是 $n$ 个 $A\xi_i = \lambda_i\xi_i$——**$P$ 的每一列都对应一次特征方程组的求解**。

对角化后，相关计算大为简化：

$$
A^k = P\Lambda^kP^{-1}, \quad Ax = b \Rightarrow \Lambda y = P^{-1}b\ (x = Py)
$$

**可对角化判定（从方程组角度理解）**：

- 充要：每个特征值的**几何重数 = 代数重数**，即每个 $(A - \lambda_i E)x = 0$ 的基础解系个数恰好等于重根数。只要有一个特征值不满足，就得不到 $n$ 个线性无关的特征向量，$P$ 不可逆。
- 充分：$n$ 个互异特征值（每个方程组至少有一个非零解）；实对称矩阵。

#### 二、实对称矩阵：可正交对角化的特殊情形

- 特征值全为实数；**不同特征值的特征向量必正交**（无需施密特正交化）；$k$ 重特征值必有 $k$ 个线性无关的特征向量（必可对角化）。
- 存在正交矩阵 $Q$：$Q^TAQ = \Lambda$，$Q^T = Q^{-1}$。
- **解题规则**：不同特征值对应的特征向量只需单位化；**同一重根内部**的特征向量必须先施密特正交化再单位化。

### （七）综合应用：二次型（第8章）

二次型 $f = x^TAx$（$A$ 实对称）研究的是 $x^TAx$ 的取值符号，而不是求出具体的 $x$。

**正交变换法化标准形与特征值求解流程完全一致**：写 $A$ → 解 $|A - \lambda E| = 0$ → 解各 $(A - \lambda_iE)x = 0$ 求特征向量 →（重根内施密特）单位化拼 $Q$ → 标准形系数就是特征值 $\sum \lambda_iy_i^2$。

**配方法**：计算较快，但不给出特征值，只保持正负惯性指数不变（惯性定理：$p$、$q$ 不随变换改变；$r(A) = p + q$ = 非零特征值个数）。注意最后要把 $y = P^{-1}x$ **反解**成 $x = Py$。

**正定性判定（四条等价）**：所有 $\lambda_i > 0$ $\iff$ 各阶顺序主子式全 $> 0$ $\iff$ $A \simeq E$（存在 $P$ 使 $A = P^TP$） $\iff$ $p = n$。

**三大关系对比**（常考）：

| <b><nobr>关系</nobr></b> | 定义式 | 保持不变的性质 | 判定 |
|:---|:---|:---|:---|
| 等价 | $B = PAQ$ | 秩 | 秩相同即等价 |
| 相似 | $B = P^{-1}AP$ | 特征值、秩、迹、行列式 | 特征值相同且都能对角化 |
| 合同 | $B = P^TAP$ | 秩、正负惯性指数 | 实对称下 $p$、$q$ 相同即合同 |

正交矩阵联系二者：$P^T = P^{-1}$ 时相似与合同统一；实对称矩阵相似 $\Rightarrow$ 合同，反之不成立。

│   ├─ 特征值：(A − λE)x = 0 的非零解，几何重数 = n − r(A − λE)

### （九）行列式 · 概念

#### 一、定义与几何意义

**1. $n$ 阶行列式（determinant）**：由 $n^2$ 个数排成 $n$ 行 $n$ 列所确定的一个算式

$$
D=\sum_{j_1j_2\cdots j_n}(-1)^{\tau(j_1j_2\cdots j_n)}a_{1j_1}a_{2j_2}\cdots a_{nj_n}
$$

其结果是一个**数**：每项从不同行、不同列各取一个元素相乘，共 $n!$ 项。

- **要点**：只有**方阵**才有行列式，记 $|A|$ 或 $\det A$；$A$ 与数 $|A|$ 一一对应，是方阵的数字特征。
- **易错辨析**：行列式是"数"、矩阵是"表"；$|A|$ 不可用于非方阵；$|A+B| \neq |A|+|B|$，而 $|AB|=|A||B|$。

**2. 逆序数与排列奇偶性（inversion number, parity）**：排列 $j_1j_2\cdots j_n$ 中"前面的数大于后面的数"的数对个数 $\tau$ 称逆序数，项的符号由 $(-1)^{\tau}$ 给出。

- **要点**：行下标已按自然顺序排定，**符号只看列下标的排列**；一次对换改变奇偶性。
- **易错辨析**：符号与元素数值大小无关。

**3. 几何意义（geometric meaning）**：$|A|$ 是线性变换的体积缩放率。二阶行列式的**绝对值**等于两向量张成的平行四边形面积，三阶对应平行六面体体积。

- **要点**：$|A|=0$ 表示变换把空间压成低维（列向量组线性相关）；$|A|<0$ 表示定向翻转。
- **易错辨析**：面积／体积取绝对值，负号只表示定向反转。

#### 二、行列式的基本性质

**4. 转置不变性（invariance under transposition）**：$|A^T|=|A|$。

- **要点**：行与列地位完全对等——凡对行成立的性质，对列同样成立。
- **易错辨析**：与"互换两行变号"是两条不同的性质，勿混。

**5. 互换变号（alternating property）**：互换两行（或两列），行列式**变号**。

- **要点**：推论——两行（列）完全相同 $\Rightarrow |A|=0$（既不变号又变号，只能为 $0$）。

**6. 倍乘性质（homogeneity）**：某一行（列）各元素同乘 $k$，等于用 $k$ 乘整个行列式；由此 $|kA|=k^n|A|$。

- **易错辨析**：一次只能提一行（列）的公因子；$|kA|=k^n|A|$，不是 $k|A|$；两行（列）对应元素成比例 $\Rightarrow |A|=0$。

**7. 可加性（additivity in one row）**：某一**行（列）**的元素为两组数之和时，可拆成两个行列式之和，其余各行不动。

- **易错辨析**：可加性只对单行（列）成立，不能"整体相加"。

**8. 倍加不变（invariance under row/column addition）**：某行（列）的 $k$ 倍加到另一行（列），行列式值**不变**。

- **要点**：这是"化三角型"等值变形的基本手段。三种初等行变换对行列式的效果：倍加不变、互换变号、倍乘提 $k$。

**9. 零值判据（criteria for a vanishing determinant）**：某行（列）全为 $0$、两行（列）完全相同、两行（列）成比例、某行（列）可由其余行（列）线性表示，均使 $|A|=0$。

- **等价刻画**：$|A|=0 \iff$ 行（列）向量组线性相关 $\iff r(A)<n \iff A$ 不可逆 $\iff A$ 有特征值 $0$。

#### 三、结构型行列式

**10. 三角行列式（triangular determinant）**：主对角线一侧全为 $0$ 时，值等于主对角线元素之积 $a_{11}a_{22}\cdots a_{nn}$；副三角（副对角线一侧全为 $0$）须带符号 $(-1)^{\frac{n(n-1)}{2}}$。

- **要点**：副三角化为标准三角需 $\frac{n(n-1)}{2}$ 次行（列）互换，符号由此产生。
- **易错辨析**：符号 $(-1)^{\frac{n(n-1)}{2}}$ 只属副三角；上三角与下三角结果相同。

**11. 范德蒙德行列式（Vandermonde determinant）**：第一行全为 $1$、以下各行是上一行的同底升幂，则 $V_n=\prod_{1 \le j < i \le n}(x_i-x_j)$。

- **等价刻画**：$V_n=0 \iff$ 存在 $i \neq j$ 使 $x_i=x_j$。
- **易错辨析**：连乘是"大下标减小下标"的**全部**差，共 $\frac{n(n-1)}{2}$ 项，不可漏项、不可写反。

**12. 爪型行列式（claw-shaped determinant）**：除主对角线及第一行、第一列外元素全为 $0$ 的结构型行列式。

- **要点**：属"经倍加化为三角型、再按一行展开"的稀疏结构。
- **易错辨析**：与"两线一星型""三对角线型"（仅三条对角线非零）是不同的结构类别。

**13. 分块行列式（determinant of a block matrix）**：$A$ 为 $m$ 阶、$B$ 为 $n$ 阶方阵时

$$
\begin{vmatrix} A & O \\ C & B \end{vmatrix}=\begin{vmatrix} A & C \\ O & B \end{vmatrix}=|A|\cdot|B|, \qquad \begin{vmatrix} O & A \\ B & C \end{vmatrix}=(-1)^{mn}|A|\cdot|B|
$$

- **要点**：拉普拉斯定理取全部行（列）的特例。
- **易错辨析**：副对角分块的符号是 $(-1)^{mn}$，不是 $(-1)^{\frac{(m+n)(m+n-1)}{2}}$。

**14. 秩 $1$ 扰动行列式（rank-one perturbation）**：$|E+\alpha\beta^T|=1+\beta^T\alpha$；一般地 $|cE+\alpha\beta^T|=c^{n-1}\left(c+\sum_{i=1}^{n}a_ib_i\right)$。

- **要点**：$\alpha\beta^T$ 的特征值为 $\beta^T\alpha$ 与 $n-1$ 个 $0$，公式由 $|cE+M|=\prod(c+\lambda_i)$ 得到。

#### 四、余子式与展开定理

**15. 余子式（minor）**：划去 $a_{ij}$ 所在的第 $i$ 行与第 $j$ 列，余下元素按原相对位置构成的 $n-1$ 阶行列式 $M_{ij}$。

- **要点**：$M_{ij}$ 只由位置 $(i,j)$ 决定，与 $a_{ij}$ 的数值无关，且**不带符号**。

**16. 代数余子式（algebraic cofactor）**：$A_{ij}=(-1)^{i+j}M_{ij}$，符号呈棋盘状交替（$(1,1)$ 位为正）。

- **易错辨析**：考研主考 $A_{ij}$；题目问 $M_{ij}$ 时须先化成 $A_{ij}=(-1)^{i+j}M_{ij}$ 再用定理——$M$ 与 $A$ 混用是高频失分点。

**17. 展开定理（expansion theorem）**：任一行（列）的元素与其对应代数余子式乘积之和等于 $|A|$，即 $D=\sum_{j=1}^{n}a_{ij}A_{ij}$。

- **要点**：对任意行（列）都成立，结果与所选行（列）无关；选含 $0$ 最多的行（列）展开最省力。
- **易错辨析**：必须"同一行（列）元素配同一行（列）的代数余子式"。

**18. 异乘变零定理（alien cofactors）**：$i \neq k$ 时 $\sum_{j=1}^{n}a_{ij}A_{kj}=0$。与展开定理合写为

$$
\sum_{j=1}^{n}a_{ij}A_{kj}=|A|\,\delta_{ik}=\begin{cases}|A|, & i=k \\ 0, & i \neq k\end{cases}
$$

- **易错辨析**：本质是"按第 $k$ 行展开一个第 $i$ 行与第 $k$ 行完全相同的行列式"；只有 $i=k$ 才等于 $|A|$。

**19. 拉普拉斯定理（Laplace expansion theorem）**：取定 $k$ 行（列），由这 $k$ 行（列）组成的**全部** $k$ 阶子式与其对应代数余子式乘积之和等于 $|A|$；$k=1$ 时退化为展开定理。

- **易错辨析**：必须遍历**全部** $k$ 阶子式；"对应"指删去子式所占行列后的余子式并带符号。

#### 五、行列式与矩阵运算

**20. 乘法性质（multiplicativity）**：同阶方阵 $|AB|=|A||B|$，由此 $|A^m|=|A|^m$、$|A^{-1}|=|A|^{-1}$、$|A^*|=|A|^{n-1}$。

- **易错辨析**：$|AB|=|BA|$ 恒成立（尽管 $AB \neq BA$）；$|A^*|=|A|^{n-1}$ 而非 $|A|^n$；$|A|\neq0$ 时上述逆与伴随的公式才有意义。

**21. 行列式与可逆性、秩**：$|A|=0 \iff r(A)<n \iff A$ 不可逆 $\iff Ax=0$ 有非零解 $\iff$ 行（列）向量组线性相关。

- **要点**：反向即 $|A| \neq 0 \iff r(A)=n \iff A$ 可逆 $\iff A \cong E$（这是第 1、2 两章之间的枢纽）。

**22. 行列式与特征值**：$|A|=\prod_{i=1}^{n}\lambda_i$，$|\lambda E-A|=\prod_{i=1}^{n}(\lambda-\lambda_i)$，且 $\text{tr}(A)=\sum_{i=1}^{n}\lambda_i$。

- **要点**：相似矩阵行列式相等，故 $|A|$ 是**相似不变量**；$\prod\lambda_i=0 \iff A$ 不可逆。
- **易错辨析**：$|A-\lambda E|=(-1)^n|\lambda E-A|$，二者只差一个符号，求根结论一致。

### （十）矩阵 · 概念

#### 一、矩阵与特殊矩阵

**1. 矩阵（matrix）**：由 $m \times n$ 个数排成的 $m$ 行 $n$ 列矩形数阵，记 $A=(a_{ij})_{m \times n}$，$a_{ij}$ 为第 $i$ 行第 $j$ 列元素。

- **等价刻画**：$A=B \iff$ **同型**（行数、列数相同）且 $a_{ij}=b_{ij}$ 对一切 $i,j$ 成立。
- **易错辨析**：同型是加、减与相等的前提；行数 $\neq$ 列数的矩阵无"阶"可言。

**2. 方阵（square matrix）**：行数与列数相等的矩阵。

- **要点**：只有方阵才有 $|A|$、$A^k$、$A^{-1}$、$A^*$、特征值；对**方阵**而言"满秩 $=$ 可逆 $=$ 非奇异"是同一件事，而非方阵另有"行满秩"（$r(A)=m$）、"列满秩"（$r(A)=n$）之说。

**3. 特殊矩阵一览**：

| <b><nobr>名称</nobr></b> | 定义 | 关键结论 |
|:---|:---|:---|
| 零矩阵 $O$ | 元素全为 $0$ | $r(O)=0$；$A=O \iff r(A)=0$ |
| 单位矩阵 $E$ | 主对角线为 $1$、其余为 $0$ | $AE=EA=A$，$\lvert E\rvert=1$，$r(E)=n$；规定 $A^0=E$ |
| 数量矩阵 $kE$ | 主对角线元素全为同一常数 $k$ | $A$ 与任意同阶矩阵可交换 $\iff A=kE$ |
| 对角矩阵 $\Lambda$ | 非对角元全为 $0$ | $\Lambda^k=\operatorname{diag}(\lambda_1^k,\dots,\lambda_n^k)$，$\lvert\Lambda\rvert=\prod\lambda_i$ |
| 三角矩阵 | 主对角线一侧全为 $0$ | $\lvert A\rvert=\prod a_{ii}$；同向三角阵之和、积仍为三角阵 |
| 对称矩阵 | $A^T=A$（即 $a_{ij}=a_{ji}$） | 任意方阵下 $A+A^T$ 对称、$A-A^T$ 反对称 |
| 反对称矩阵 | $A^T=-A$ | 主对角线元素**必全为 $0$**；奇数阶必 $\lvert A\rvert=0$ |
| 正交矩阵 | $AA^T=A^TA=E$ | $A^{-1}=A^T$，$\lvert A\rvert=\pm1$，列（行）为规范正交基 |
| 奇异矩阵 | $\lvert A\rvert=0$ | 奇异 $\iff$ 降秩 $\iff$ 不可逆 $\iff r(A)<n$ |
| 幂等阵 $A^2=A$ | 投影型 | 特征值只取 $1$（$r(A)$ 重）与 $0$（$n-r(A)$ 重），$r(A)+r(A-E)=n$ |
| 幂零阵 $A^k=O$ | 特征值全为 $0$ | 不可对角化（除非 $A=O$） |
| 对合阵 $A^2=E$ | 特征值只取 $1$ 与 $-1$ | 必可对角化 |

**4. 反对称与对称的判别**：$A$ 对称 $\iff a_{ij}=a_{ji}$；$A$ 反对称 $\iff a_{ij}=-a_{ji}$。

- **易错辨析**：对称与正交是两件事（$A^T=A$ vs $A^T=A^{-1}$）；"看起来稀疏"不等于对角阵——对角阵要求**非对角元全为 $0$**。

#### 二、矩阵的运算

**5. 加法与数乘（addition, scalar multiplication）**：同型矩阵对应元素相加得 $A+B=(a_{ij}+b_{ij})$；数 $k$ 乘 $A$ 得 $kA=(ka_{ij})$。

- **要点**：满足交换律、结合律、分配律。
- **易错辨析**：只有同型才能相加；$kA$ 是每个元素乘 $k$，而 $\lvert kA\rvert=k^n\lvert A\rvert$ 是每行提一个 $k$，二者数量级不同。

**6. 矩阵乘法（matrix multiplication）**：$A_{m \times s}B_{s \times n}=C_{m \times n}$，其中 $c_{ij}=\sum_{k=1}^{s}a_{ik}b_{kj}$（行乘列）。

- **要点**：满足结合律 $(AB)C=A(BC)$ 与分配律；$AB$ 的第 $j$ 列是 $A$ 的列向量组的线性组合——这正是"方程组 → 线性表出"语言的来源。
- **易错辨析**：**不满足交换律**（$AB \neq BA$，甚至不同阶）、**无消去律**（$AB=AC$ 且 $A \neq O$ 推不出 $B=C$）、**有零因子**（$AB=O$ 推不出 $A=O$ 或 $B=O$）；$(AB)^k \neq A^kB^k$，$(A+B)^2=A^2+2AB+B^2$ 需要 $AB=BA$。

**7. 矩阵的转置（transpose）**：$(A^T)_{ij}=a_{ji}$；$(A \pm B)^T=A^T \pm B^T$，$(kA)^T=kA^T$，$(AB)^T=B^TA^T$。

- **要点**：$r(A^T)=r(A)$，$\lvert A^T\rvert=\lvert A\rvert$。
- **易错辨析**：乘积的转置必须**反序**（穿脱原则）。

**8. 方阵的幂（power of a square matrix）**：$A^k$ 为 $k$ 个 $A$ 连乘，规定 $A^0=E$。

- **要点**：$A^mA^n=A^{m+n}$，$(A^m)^n=A^{mn}$；$A=P\Lambda P^{-1} \Rightarrow A^k=P\Lambda^kP^{-1}$；秩 $1$ 阵 $A=\alpha\beta^T \Rightarrow A^k=(\beta^T\alpha)^{k-1}A$。
- **易错辨析**：指数法则只对**同一个**矩阵成立。

**9. 方阵的行列式（determinant）**：见（九）20～22——$\lvert A^T\rvert=\lvert A\rvert$、$\lvert kA\rvert=k^n\lvert A\rvert$、$\lvert AB\rvert=\lvert A\rvert\lvert B\rvert$，但 $\lvert A+B\rvert \neq \lvert A\rvert+\lvert B\rvert$。

#### 三、分块矩阵

**10. 分块矩阵（block matrix）**：用若干横线与竖线把 $A$ 分成 $p \times q$ 个子块；块运算形式上与元素运算一致，但"元素"变成了小矩阵。

- **要点**：加法要求同型且**分块方式完全一致**；乘法要求左阵的列分块与右阵的行分块匹配，$C_{ij}=\sum_k A_{ik}B_{kj}$；转置时子块位置互换且**每块自身也要转置**。
- **易错辨析**：分块相乘 $\neq$ 对应子块分别相乘。

**11. 分块对角矩阵与分块三角矩阵**：$\operatorname{diag}(A_1,\dots,A_n)$ 的 $\lvert A\rvert=\prod\lvert A_i\rvert$、$A^k=\operatorname{diag}(A_1^k,\dots,A_n^k)$、$A^{-1}=\operatorname{diag}(A_1^{-1},\dots,A_n^{-1})$（各块均可逆）。

- **要点**：分块三角阵的逆含 Schur 补项，如 $\begin{pmatrix}A&O\\C&B\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&O\\-B^{-1}CA^{-1}&B^{-1}\end{pmatrix}$。
- **易错辨析**：分块求逆不是简单逐块取逆。

#### 四、伴随矩阵

**12. 伴随矩阵（adjugate matrix）**：$A^*=(A_{ji})_{n \times n}$，即代数余子式**按行求出、按列放置**（定义自带一次转置）。

- **易错辨析**：$A$ 第 $1$ 行的代数余子式构成 $A^*$ 的第 $1$ **列**——顺序反了整题皆错。

**13. 伴随恒等式与公式组**：$AA^*=A^*A=\lvert A\rvert E$（对任意方阵成立，这是伴随的**万能定理**）；$\lvert A^*\rvert=\lvert A\rvert^{n-1}$；$\lvert A\rvert \neq 0$ 时 $A^*=\lvert A\rvert A^{-1}$、$A^{-1}=\dfrac{1}{\lvert A\rvert}A^*$；$(A^T)^*=(A^*)^T$、$(A^*)^*=\lvert A\rvert^{n-2}A$、$(kA)^*=k^{n-1}A^*$、$(AB)^*=B^*A^*$。

- **易错辨析**：$(A^*)^{-1}=\dfrac{A}{\lvert A\rvert}$ 与 $(A^*)^*=\lvert A\rvert^{n-2}A$ 极易混淆；$n=2$ 时 $(A^*)^*=A$；$(A+B)^*$ 无简单展开式。

**14. 伴随矩阵的秩（rank of adjugate）**：$r(A)=n \Rightarrow r(A^*)=n$；$r(A)=n-1 \Rightarrow r(A^*)=1$；$r(A) \le n-2 \Rightarrow r(A^*)=0$。

- **要点**：$r(A^*)$ 只能取 $n$、$1$、$0$ 三个值，是"断崖式"跳变；仅当 $r(A)=n$ 时才有 $r(A^*)=r(A)$。

#### 五、可逆矩阵

**15. 可逆矩阵（invertible matrix）**：若存在同阶方阵 $B$ 使 $AB=BA=E$，则称 $A$ 可逆，$B$ 为 $A$ 的逆矩阵，记 $A^{-1}$。

- **可逆的八等价**（必须熟记）：

$$
A^{-1}\text{ 存在} \iff \lvert A\rvert \neq 0 \iff r(A)=n \iff A^*\text{ 可逆}\ (r(A^*)=n) \iff Ax=0\text{ 只有零解}
$$

$$
\iff \forall b,\ Ax=b\text{ 有唯一解} \iff A \cong E\ (\text{可经初等变换化为 } E) \iff A\text{ 的特征值全不为 } 0
$$

- **易错辨析**：必须是**方阵**；由 $AB=E$（单边）即可推出 $BA=E$；逆矩阵若存在必**唯一**。

**16. 逆矩阵的运算性质**：$(A^{-1})^{-1}=A$；$(A^T)^{-1}=(A^{-1})^T$；$\lvert A^{-1}\rvert=\lvert A\rvert^{-1}$；$(AB)^{-1}=B^{-1}A^{-1}$；$(kA)^{-1}=\dfrac{1}{k}A^{-1}$。

- **要点**：转置、逆、伴随三类运算对乘积一律**反序**（穿脱原则）。
- **易错辨析**：$(kA)^{-1}=\dfrac{1}{k}A^{-1}$ 与 $(kA)^*=k^{n-1}A^*$ 形式完全不同，不可互套；$(A+B)^{-1}$ 无简单展开式。

#### 六、初等变换与初等矩阵

**17. 初等变换（elementary operation）**：对换 $r_i \leftrightarrow r_j$、倍乘 $r_i \to kr_i\ (k \neq 0)$、倍加 $r_i \to r_i+kr_j$。

- **要点**：初等变换**不改变矩阵的秩**；可逆矩阵经初等变换仍可逆。
- **易错辨析**：倍乘的 $k$ 必须非零（否则破坏秩与可逆性）；初等变换**会改变行列式**（对换变号、倍乘提 $k$、倍加不变），但不改变秩——"变行列式"与"不变秩"要分开记。

**18. 初等矩阵（elementary matrix）**：由单位矩阵 $E$ 经过**一次**初等变换所得的矩阵，分对换阵 $E_{ij}$、倍乘阵 $E_i(k)$、倍加阵 $E_{ij}(k)$。

- **要点**：初等矩阵均可逆，且逆矩阵仍是**同类型**的初等矩阵：$E_{ij}^{-1}=E_{ij}$，$E_i(k)^{-1}=E_i(\frac{1}{k})$，$E_{ij}(k)^{-1}=E_{ij}(-k)$；行列式依次为 $-1$、$k$、$1$。
- **易错辨析**：倍加阵**逆是变号**（$E_{ij}(-k)$）、**转置是变位置**（$E_{ij}(k)^T=E_{ji}(k)$），两者不可混。

**19. 左行右列法则（left-row, right-column rule）**：对 $A$ 施行一次初等**行**变换 $\iff$ 左乘相应的初等矩阵（$EA$）；施行一次初等**列**变换 $\iff$ 右乘相应的初等矩阵（$AE$）。

- **要点**：连续行变换对应 $P_k\cdots P_1A=E$，故 $A^{-1}=P_k\cdots P_1$——这正是 $(A \mid E) \to (E \mid A^{-1})$ 的代数本质。
- **易错辨析**：左、右不可互换；**求逆只能用行变换**（用列变换会破坏右半块），求等价标准形才可左右并用。

**20. 矩阵等价（matrix equivalence）**：若 $A$ 经有限次初等变换化为 $B$，称 $A$ 与 $B$ 等价，记 $A \cong B$。

- **等价刻画**：$A \cong B \iff$ 存在可逆矩阵 $P$、$Q$ 使 $PAQ=B \iff$ $A$、$B$ 同型且 $r(A)=r(B)$；任何秩为 $r$ 的 $m \times n$ 矩阵等价于标准形 $\begin{pmatrix}E_r&O\\O&O\end{pmatrix}$；$n$ 阶方阵 $A$ 可逆 $\iff A \cong E_n$。
- **易错辨析**：等价只看"同型 + 同秩"，与**相似**、**合同**是三种不同的关系（对比见（十七））。

#### 七、矩阵的秩

**21. $k$ 阶子式（$k$-order minor）**：在 $m \times n$ 矩阵中任取 $k$ 行 $k$ 列，交叉处 $k^2$ 个元素按原相对位置构成的 $k$ 阶行列式。

- **要点**：共有 $C_m^k \cdot C_n^k$ 个，它是一个**数**而不是矩阵；$n$ 阶方阵的 $n$ 阶子式只有一个，就是 $\lvert A\rvert$。

**22. 矩阵的秩（rank）**：$A$ 中最高阶非零子式的阶数 $r(A)$，即"存在 $r$ 阶子式非零"且"所有 $r+1$ 阶子式全为零"。

- **等价刻画**：$r(A)=r(A^T)$；$r(A)=$ 行阶梯形中非零行的个数 $=$ 行秩 $=$ 列秩 $=$ 列（行）向量组极大无关组所含向量个数；$r(A)=0 \iff A=O$；$r(A)=1 \iff$ 各行（列）成比例 $\iff A=\alpha\beta^T$；$r(A) \le \min(m,n)$。
- **易错辨析**：定义中"存在 $r$ 阶非零子式"与"任意 $r+1$ 阶子式全零"两条**缺一不可**；子式法用于理论证明与含参讨论，实战一律用初等行变换数非零行。

**23. 秩的基本性质**：初等变换不改变秩；$r(kA)=r(A)\ (k \neq 0)$；$r(PA)=r(AQ)=r(PAQ)=r(A)$（$P$、$Q$ 可逆）；$r(A)=r(A^T)$。

- **要点**：**行满秩** $r(A)=m$ 时 $r(A,b)=r(A)$，$Ax=b$ 必有解；**列满秩** $r(A)=n$ 时 $Ax=0$ 只有零解，且 $r(AB)=r(B)$。
- **易错辨析**：$r(A) \le r(A,b)$（增广后秩不减），只有 $r(A)=r(A,b)$ 才是有解判据；乘可逆阵秩不变，乘一般矩阵秩只减不增。

**24. 秩的核心不等式**：

- $r(A \pm B) \le r(A)+r(B)$（次可加性）与 $r(A+B) \ge \lvert r(A)-r(B)\rvert$。
- $r(AB) \le \min\{r(A),r(B)\}$（木桶效应：乘积的秩不超过任一旁）。
- **西尔维斯特（Sylvester）不等式**：$r(AB) \ge r(A)+r(B)-n$（$n$ 为中间维度）；推论 $AB=O \Rightarrow r(A)+r(B) \le n$。
- **Frobenius 不等式**：$r(ABC) \ge r(AB)+r(BC)-r(B)$。
- **易错辨析**：Sylvester 中的 $n$ 是"$A$ 的列数 $=B$ 的行数"，不是任一方阵的阶数。

**25. 特殊矩阵的秩**：$r(A^*)=n,1,0$（依 $r(A)=n,n-1,\le n-2$）；实矩阵 $r(A^TA)=r(A)$（因 $Ax=0$ 与 $A^TAx=0$ 同解）；幂等阵 $A^2=A$ 有 $r(A)+r(A-E)=n$。

- **易错辨析**：$r(A^TA)=r(A)$ 要求 $A$ 是**实**矩阵；$r(A^*)$ 只在 $r(A)=n$ 时才与 $r(A)$ 相等。

### （十一）向量 · 概念

#### 一、向量与线性表出

**1. $n$ 维向量（$n$-dimensional vector）**：$n$ 个实数组成的有序数组 $\alpha=(a_1,\dots,a_n)^T$ 称 $n$ 维**列**向量，$\alpha^T=(a_1,\dots,a_n)$ 称行向量。

- **要点**：$\alpha=\beta \iff$ 各分量对应相等；维数 $=$ 分量个数；列向量即 $n \times 1$ 矩阵。
- **易错辨析**：列、行向量不可混用（转置才互换）；线性相关、秩等概念都建立在"列向量"约定上。

**2. 线性组合（linear combination）**：$k_1\alpha_1+\dots+k_m\alpha_m$ 称向量组 $\alpha_1,\dots,\alpha_m$ 的线性组合，$k_i$ 称组合系数。

- **要点**：全部线性组合的集合即张成空间 $\mathrm{span}\{\alpha_1,\dots,\alpha_m\}$（也就是以它们为列的矩阵的列空间）。

**3. 线性表示（linear representation）**：若存在 $k_1,\dots,k_m$ 使 $\beta=k_1\alpha_1+\dots+k_m\alpha_m$，则称 $\beta$ 可由该向量组线性表示。

- **等价刻画**：令 $A=(\alpha_1,\dots,\alpha_m)$，则可表示 $\iff Ax=\beta$ 有解 $\iff r(A)=r(A,\beta)$；表示**唯一** $\iff$ 该组线性无关且 $r(A)=r(A,\beta)=m$。
- **易错辨析**：秩相等只保证**有解**；解不唯一时表示法无穷多，此时向量组必线性相关。

**4. 向量组等价（equivalence of vector groups）**：两个同维向量组若能**互相**线性表示，则称等价。

- **等价刻画**：$A \cong B \iff r(A)=r(B)=r(A,B)$；若 $A$ 可由 $B$ 表示，则存在矩阵 $K$ 使 $A=BK$ 且 $r(A) \le r(B)$。
- **易错辨析**：仅 $r(A)=r(B)$ 推不出向量组等价；**矩阵等价 $\neq$ 向量组等价**（前者只要同型同秩，后者要求互相表出）。

#### 二、线性相关与线性无关

**5. 线性相关／线性无关（linear dependence / independence）**：若存在**不全为零**的 $k_1,\dots,k_m$ 使 $k_1\alpha_1+\dots+k_m\alpha_m=0$，称该向量组线性**相关**；若该式仅当 $k_1=\dots=k_m=0$ 时成立，称线性**无关**。

- **等价刻画**：令 $A=(\alpha_1,\dots,\alpha_m)$，则相关 $\iff Ax=0$ 有非零解 $\iff r(A)<m$；无关 $\iff$ 只有零解 $\iff r(A)=m$；$m=n$ 时相关 $\iff \lvert A\rvert=0$；相关 $\iff$ 至少有一个向量可由其余向量线性表示；无关 $\iff$ 任一向量都不能由其余向量表示。
- **易错辨析**："相关"要求系数**不全为零**；含零向量或含成比例向量的组必相关；单个向量相关 $\iff \alpha=0$。

**6. 相关性的基本性质**：

- **方向一**：部分相关 $\Rightarrow$ 整体相关；整体无关 $\Rightarrow$ 部分无关。
- **方向二**：低维无关 $\Rightarrow$ 添分量后仍无关；高维相关 $\Rightarrow$ 减分量后仍相关。
- **个数与维数**：$m$ 个 $n$ 维向量，若 $m>n$ 必相关（本质是 $r(A) \le n<m$）。
- **易错辨析**：四条方向都**不可逆**；"无关组添向量可能变相关"与"相关组减向量可能变无关"要分清。

**7. 极大线性无关组（maximal linearly independent set）**：向量组的部分组 $A_0$ 若自身线性无关，且原组中任一向量都可由 $A_0$ 线性表示（等价地，再添任一向量即相关），则称 $A_0$ 为一个极大线性无关组。

- **要点**：原组与其极大无关组等价、张成同一空间；极大无关组**不唯一**，但所含向量个数**唯一**。
- **易错辨析**：极大无关组只能取**原向量组**中的向量——行变换后主元列号对应**原矩阵**的列，化简后矩阵的列数值已经变了。

**8. 向量组的秩（rank of a vector group）**：极大线性无关组所含向量的个数，记 $r(\alpha_1,\dots,\alpha_m)$。

- **等价刻画**：秩 $=$ 张成空间的维数 $=$ 以该组为列构成的矩阵的秩；向量组无关 $\iff$ 秩 $=$ 向量个数；$r \le \min\{m,n\}$。
- **易错辨析**：只含零向量的组规定秩为 $0$；秩是"独立方向数"，不是向量个数。

#### 三、向量空间（数一）

**9. 向量空间与子空间（vector space / subspace）**：非空集合 $V$ 若对加法与数乘封闭（即任意线性组合仍属于 $V$），称向量空间；$V$ 中同样封闭的非空子集 $W$ 称子空间。

- **要点**：封闭性 $\Rightarrow$ 必含零向量；张成空间、齐次方程组的解空间都是 $\mathbb{R}^n$ 的子空间。
- **易错辨析**：不过原点的平面不是子空间；两子空间的**并**一般不是子空间，**交**是。

**10. 基、维数与坐标（basis, dimension, coordinates）**：$V$ 中线性无关且能表示 $V$ 中每个向量的向量组称基，基所含向量个数称维数 $\dim V$；若 $\alpha=x_1\varepsilon_1+\dots+x_n\varepsilon_n$，则系数列向量称 $\alpha$ 在该基下的坐标。

- **要点**：$n$ 维空间中任意 $n$ 个线性无关向量都构成基；基不唯一但个数固定，坐标由基唯一确定。
- **易错辨析**：坐标依赖基，同一向量在不同基下坐标不同；零空间的维数为 $0$、没有基。

**11. 过渡矩阵与坐标变换（transition matrix）**：设旧基 $A=(\alpha_1,\dots,\alpha_n)$、新基 $B=(\beta_1,\dots,\beta_n)$，由 $B=AP$ 定义的（必可逆的）$P$ 称由 $A$ 到 $B$ 的过渡矩阵。

- **要点**：**基变换**——新基 $=$ 旧基 $\cdot P$（$P$ 的列是新基向量在旧基下的坐标）；**坐标变换**——$X=PY$，即 $Y=P^{-1}X$（$X$ 为旧坐标、$Y$ 为新坐标）。
- **易错辨析**：基变换与坐标变换的矩阵**互逆**，写成 $Y=PX$ 是典型错误；求 $P$ 用 $(A \mid B) \to (E \mid A^{-1}B)$。

> **内积、正交、规范正交基、正交矩阵、施密特正交化** 属"实对称矩阵"一章的工具，集中于（十五）一。

### （十二）线性方程组 · 概念

#### 一、方程组的形式与同解变形

**1. 线性方程组的三种形式**：一般（代数）形式、矩阵形式 $Ax=b$（$\bar A=(A \mid b)$ 为增广矩阵）、向量形式 $x_1\alpha_1+\dots+x_n\alpha_n=b$。

- **要点**：三形式对应三种视角——高斯消元、线性变换求原像、列向量组的线性表出；向量形式直接给出有解判据"$b$ 可由列向量组线性表示"。
- **易错辨析**：求解只许用初等**行**变换（列变换会打乱未知数顺序）；系数矩阵 $A$ 与增广矩阵 $(A \mid b)$ 不可混。

**2. 同解变形（equivalent transformation）**：交换两个方程、某方程乘非零常数、某方程的 $k$ 倍加到另一方程，都不改变解集。

- **要点**：这三条正是方程组的同解变形，也正是矩阵的三种初等**行**变换——"初等行变换 = 方程组的同解变形"是第 2 章与第 4 章的接点。

#### 二、齐次线性方程组

**3. 齐次线性方程组（homogeneous system）**：常数项全为零的方程组 $Ax=0$。

- **要点**：$x=0$ 恒为解（零解），故齐次方程组**永远有解**；解集对加法、数乘封闭，构成 $\mathbb{R}^n$ 的子空间。

**4. 零解与非零解的判定**：$Ax=0$（$m \times n$）只有零解 $\iff r(A)=n$；有非零解 $\iff r(A)<n$（此时有无穷多解）。

- **等价刻画**：$A$ 为 $n$ 阶方阵时，只有零解 $\iff \lvert A\rvert \neq 0$，有非零解 $\iff \lvert A\rvert=0$；$m<n$ 时必有非零解；有非零解 $\iff$ 列向量组线性相关。
- **易错辨析**：判据中的 $n$ 是**未知数个数**，不是方程个数。

**5. 解空间（solution space / null space）**：$N(A)=\{x \mid Ax=0\}$。

- **等价刻画**：$N(A)$ 是子空间且 $\dim N(A)=n-r(A)$；$N(A)=\{0\} \iff r(A)=n$。
- **易错辨析**：维数 $n-r(A)$ 与秩 $r(A)$ 是两回事，填空题常在此设陷阱。

**6. 基础解系（fundamental system of solutions）**：解空间的一组基 $\xi_1,\dots,\xi_s$。

- **三条件**：都是 $Ax=0$ 的解、线性无关、任一解都可由它们线性表示——**缺一不可**。
- **等价刻画**：个数恒为 $s=n-r(A)$；任意 $n-r(A)$ 个线性无关的解都构成基础解系，基础解系**不唯一**。
- **易错辨析**：抽象题中给出若干解，必须验证其线性无关**且个数恰为 $n-r(A)$**，才能断言是基础解系。

**7. 齐次方程组的通解（general solution）**：$x=k_1\xi_1+\dots+k_{n-r}\xi_{n-r}$（$k_i$ 任意）。

- **要点**：独立任意常数的个数恰为 $n-r(A)$，它遍历解空间全部解；$r(A)=n$ 时通解退化为 $x=0$。
- **易错辨析**：常数的个数不等于 $n-r(A)$，说明基础解系取错了。

#### 三、非齐次线性方程组

**8. 非齐次线性方程组与解的判定（Kronecker-Capelli 定理）**：$b \neq 0$ 时 $Ax=b$ 称非齐次线性方程组。

| 情形 | 判定条件 | 消元后的形式 |
|:---|:---|:---|
| 无解 | $r(A)<r(A,b)$ | 出现 $0=c$ 行 |
| 唯一解 | $r(A)=r(A,b)=n$ | 满列秩，无自由变量 |
| 无穷多解 | $r(A)=r(A,b)<n$ | 有 $n-r$ 个自由变量 |

- **等价刻画**：有解 $\iff r(A)=r(A,b) \iff b$ 可由 $A$ 的列向量组线性表示；$A$ 为方阵时唯一解 $\iff \lvert A\rvert \neq 0$。
- **易错辨析**：秩相等只保证有解，达到 $n$ 才保证唯一；$m<n$ 时**齐次**必有非零解，但**非齐次**可能无解，两者不可混淆。

**9. 非齐次解的结构**：$x=\underbrace{\eta^*}_{\text{特解}}+\underbrace{k_1\xi_1+\dots+k_{n-r}\xi_{n-r}}_{\text{导出组 }Ax=0\text{ 的通解}}$。

- **解的三条性质**：$\eta$ 是 $Ax=b$ 的解 $\iff \eta-\eta^*$ 是 $Ax=0$ 的解（**相减为齐**）；非齐解 $-$ 非齐解 $=$ 齐次解；非齐解 $+$ 齐次解 $=$ 非齐解。
- **易错辨析**：非齐次解集**不是**子空间（不含零向量、对加法不封闭）；特解可以任取。

**10. 系数和判别（coefficient-sum criterion）**：若 $\eta_1,\dots,\eta_k$ 都是 $Ax=b$ 的解，则 $A(c_1\eta_1+\dots+c_k\eta_k)=(c_1+\dots+c_k)b$。

- **判据**：$\sum c_i=1 \Rightarrow$ 组合仍是 $Ax=b$ 的解；$\sum c_i=0 \Rightarrow$ 组合是 $Ax=0$ 的解；系数和既非 $0$ 也非 $1$ 时二者皆非。
- **易错辨析**：只看系数之**和**，与各系数的大小、与 $b$ 是否为零都无关。

**11. 克拉默法则（Cramer's rule）**：设 $A$ 为 $n$ 阶方阵且 $D=\lvert A\rvert \neq 0$，则 $Ax=b$ 有唯一解 $x_j=\dfrac{D_j}{D}$，其中 $D_j$ 是把 $A$ 的**第 $j$ 列**换成 $b$ 后所得矩阵的行列式。

- **等价刻画**：齐次情形 $\lvert A\rvert \neq 0 \iff$ 只有零解，$\lvert A\rvert=0 \iff$ 有非零解——这是第 1 章与第 4 章的直接联系。
- **易错辨析**：前提是**方阵且 $\lvert A\rvert \neq 0$**；替换的必须是第 $j$ 列；$\lvert A\rvert=0$ 时法则失效，不能据此断定无解（须回到秩）。

#### 四、公共解、同解与矩阵方程

**12. 公共解（common solution）**：同时满足两个（或多个）方程组的解，即各解空间的**交集**。

- **等价刻画**：$Ax=0$ 与 $Bx=0$ 的公共解集 $=N\begin{pmatrix}A\\B\end{pmatrix}$，即联立方程组 $\begin{pmatrix}A\\B\end{pmatrix}x=0$ 的解空间；非齐次情形联立 $\begin{pmatrix}A\\B\end{pmatrix}x=\begin{pmatrix}b\\d\end{pmatrix}$。
- **易错辨析**：公共解可能只有零解，也可能无穷多；用**两组通解相等**求交集时必须设**两套不同的参数字母**（如 $k$ 与 $l$），否则会漏解。

**13. 同解（equivalent systems）**：两个方程组的解集完全相同。

- **等价刻画**：齐次时 $Ax=0$ 与 $Bx=0$ **同解** $\iff r(A)=r(B)=r\begin{pmatrix}A\\B\end{pmatrix}$（即行向量组等价）；"$Ax=0$ 的解全是 $Bx=0$ 的解" $\iff r\begin{pmatrix}A\\B\end{pmatrix}=r(A)$；恒同解：$Ax=0$ 与 $A^TAx=0$；$P$ 可逆时 $Ax=0$ 与 $PAx=0$ 同解。
- **易错辨析**：同解 $\Rightarrow$ 同秩，**同秩 $\nRightarrow$ 同解**；$Bx=0$ 的解必是 $ABx=0$ 的解，反之不成立。

**14. 矩阵方程（matrix equation）**：以矩阵为未知量的方程 $AX=B$、$XA=B$、$AXB=C$。

- **要点**：$AX=B$ 按列分块即逐列解 $Ax_j=b_j$，有解 $\iff r(A)=r(A,B)$；$A$ 可逆时 $X=A^{-1}B$；$XA=B$ 转置化为 $A^TX^T=B^T$；$AXB=C$ 且 $A$、$B$ 可逆时 $X=A^{-1}CB^{-1}$。
- **易错辨析**：乘法不可交换，$AX=B$ 与 $XA=B$ 是两类问题；$A$ 不可逆时须按秩讨论解的存在性与个数。

### （十三）特征值与特征向量 · 概念

#### 一、定义与特征方程

**1. 特征值与特征向量（eigenvalue / eigenvector）**：设 $A$ 为 $n$ 阶方阵，若存在数 $\lambda$ 与**非零**列向量 $x$ 使 $Ax=\lambda x$，则称 $\lambda$ 为 $A$ 的特征值、$x$ 为属于 $\lambda$ 的特征向量。

- **等价刻画**：$(A-\lambda E)x=0$ 有非零解 $\iff \lvert A-\lambda E\rvert=0 \iff A-\lambda E$ 奇异 $\iff r(A-\lambda E)<n$。
- **易错辨析**：只对**方阵**定义；$x \neq 0$ 是硬性要求（$\lambda$ 可以为 $0$）；一个特征向量只能属于一个特征值。

**2. 特征多项式与特征方程（characteristic polynomial / equation）**：$f(\lambda)=\lvert A-\lambda E\rvert$ 称特征多项式，$\lvert A-\lambda E\rvert=0$ 称特征方程。

- **要点**：$f(\lambda)$ 是 $n$ 次多项式，在复数域内恰有 $n$ 个根（含重根），全部特征值即其全部根；展开后常数项为 $\lvert A\rvert$，$n-1$ 次项系数含 $\text{tr}(A)$——迹定理与行列式定理之源。
- **易错辨析**：$\lvert A-\lambda E\rvert$ 与 $\lvert\lambda E-A\rvert$ 只差 $(-1)^n$，根相同、结论通用；**特征多项式相同是相似的必要条件而非充分条件**。

**3. 特征子空间（eigenspace）**：属于同一 $\lambda$ 的全部特征向量再添上零向量，即 $(A-\lambda E)x=0$ 的解空间。

- **要点**：其维数为 $n-r(A-\lambda E)$，即该特征值的几何重数；同一特征值的特征向量的非零线性组合仍是特征向量。
- **易错辨析**：不同特征值的特征向量之线性组合一般**不是**特征向量。

#### 二、重数与谱性质

**4. 代数重数与几何重数（algebraic / geometric multiplicity）**：$\lambda$ 作为特征方程根的重数称**代数重数** $k$；特征子空间维数 $n-r(A-\lambda E)$ 称**几何重数** $g$。

- **核心不等式**：$1 \le g=n-r(A-\lambda E) \le k$，且各特征值的几何重数之和 $\le n$。
- **易错辨析**：$g<k$ 是**不可对角化的唯一来源**；含重根时必须逐个验算 $g=k$，不能只数不同特征值的个数。

**5. 特征值的和与积（迹定理、行列式定理）**：$n$ 阶方阵的 $n$ 个特征值（按重数计）满足 $\sum_{i=1}^{n}\lambda_i=\text{tr}(A)$、$\prod_{i=1}^{n}\lambda_i=\lvert A\rvert$。

- **要点**：$A$ 可逆 $\iff$ 所有特征值非零；相似矩阵的迹与行列式必相等。
- **易错辨析**：求和求积必须**按重数计**；这两式只提供必要条件，不能反推特征值分布。

**6. 矩阵多项式的谱（matrix polynomial）**：若 $\lambda$ 是 $A$ 的特征值，则 $kA$、$A^m$、$A^{-1}$、$A^*$、$f(A)$（$f$ 为多项式）分别以 $k\lambda$、$\lambda^m$、$\lambda^{-1}$、$\dfrac{\lvert A\rvert}{\lambda}$、$f(\lambda)$ 为特征值，且**特征向量 $x$ 不变**。

- **易错辨析**：$A^{-1}$、$A^*$ 的情形要求 $A$ 可逆（$\lambda \neq 0$）；$A+B$、$AB$ 没有此类简单传递。

**7. 转置、乘积与相似下的不变性**：$A^T$ 与 $A$ 特征值完全相同；$P^{-1}AP$ 与 $A$ 特征值相同（特征向量变为 $P^{-1}x$）；$AB$ 与 $BA$ 的非零特征值相同（$A$、$B$ 同阶时含重数完全相同）。

- **易错辨析**：转置不改变特征值，但通常改变特征向量。

**8. 特征向量的线性无关性**：属于互异特征值 $\lambda_1,\dots,\lambda_m$ 的特征向量 $x_1,\dots,x_m$ 必线性无关。

- **要点**：由此得"$n$ 个互异特征值 $\Rightarrow$ 有 $n$ 个线性无关特征向量 $\Rightarrow$ 可对角化"；不同特征值的特征子空间之和为直和。
- **易错辨析**：结论只对"互异特征值各取一个"成立；同一特征值下须取基础解系才保证无关。

**9. 反用特征值条件（求参数的入口）**：$\lvert A-kE\rvert=0 \iff k$ 是 $A$ 的特征值 $\iff (kE-A)x=0$ 有非零解；特别地 $\lvert A\rvert=0 \iff 0$ 是 $A$ 的特征值（即 $A$ 不可逆）。又 $f(A)=O \Rightarrow f(\lambda)=0$ 对每个特征值成立。

- **要点**：$A$ 各行元素之和为 $k$ $\iff$ $k$ 是特征值且 $(1,1,\dots,1)^T$ 为对应特征向量。
- **易错辨析**：$f(A)=O$ 只说明特征值都是 $f$ 的根（**限定取值范围**），不能反推 $f$ 的每个根都是特征值。

**10. 常见特殊矩阵的谱（spectra）**：上（下）三角阵、对角阵的特征值即主对角线元素；分块三角阵、分块对角阵的特征值是各对角块特征值的并集；秩 $1$ 阵 $A=\alpha\beta^T$ 的谱为 $\beta^T\alpha$ 与 $n-1$ 个 $0$。

- **要点**：幂等阵 $A^2=A$ 的谱为 $\{1\ (r(A)\text{ 重}),\ 0\ (n-r(A)\text{ 重})\}$；幂零阵的谱全为 $0$；对合阵 $A^2=E$ 的谱只取 $\pm1$。
- **易错辨析**：这些都是"特征值取值范围"型结论，反推矩阵类型不成立。

### （十四）相似矩阵 · 概念

#### 一、相似的定义与性质

**1. 相似矩阵（similar matrices）**：设 $A$、$B$ 为同阶方阵，若存在**可逆**矩阵 $P$ 使 $P^{-1}AP=B$（等价地 $AP=PB$），则称 $A$ 与 $B$ 相似，记 $A \sim B$，$P$ 称相似变换矩阵。

- **要点**：相似是等价关系（自反、对称、传递）；本质是**同一线性变换在不同基下的矩阵**，$P$ 的列向量即新基。
- **易错辨析**：$P$ 必须可逆；相似矩阵一般不相等；$P$ 不唯一。

**2. 相似的必要条件**：若 $A \sim B$，则 $\lvert A-\lambda E\rvert=\lvert B-\lambda E\rvert$（特征多项式相同、特征值含重数相同），且 $\lvert A\rvert=\lvert B\rvert$、$\text{tr}(A)=\text{tr}(B)$、$r(A)=r(B)$、可逆性相同。

- **易错辨析**：以上全部只是**必要**条件——特征值、迹、行列式全同仍可能不相似（如零矩阵与非零幂零阵）；判"不相似"优先找**秩或迹**的差异。

**3. 相似关系的运算封闭性**：若 $A \sim B$，则 $A^{-1} \sim B^{-1}$、$A^T \sim B^T$、$A^* \sim B^*$、$A^m \sim B^m$、$f(A) \sim f(B)$——见证矩阵依次为 $P$、$P^T$、$P^*$、$P$、$P$。

- **易错辨析**：只有 $A^{-1} \sim B^{-1}$ 要求 $A$ 可逆；$A^* \sim B^*$ 对**任意**相似矩阵都成立（由 $B=P^{-1}AP$ 得 $B^*=P^*A^*(P^*)^{-1}$，而 $P$ 可逆 $\Rightarrow P^*$ 可逆）。

#### 二、相似对角化

**4. 相似对角化（diagonalizable）**：若存在可逆矩阵 $P$ 与对角阵 $\Lambda$ 使 $P^{-1}AP=\Lambda$，则称 $A$ 可（相似）对角化，记 $A \sim \Lambda$。

- **要点**：$AP=P\Lambda$ 按列拆开即 $n$ 个 $A\xi_i=\lambda_i\xi_i$，故 $\Lambda$ 的对角元是 $A$ 的全部特征值，$P$ 的列是对应的线性无关特征向量，两者**次序严格一一对应**。
- **易错辨析**：$P$ 由特征向量**按列**拼成（不是按行）；$\Lambda$ 与 $P$ 的次序可以同时任意调换，但必须同步。

**5. 可对角化的充要条件**：$A$ 可对角化 $\iff A$ 有 $n$ 个线性无关的特征向量 $\iff$ 每个特征值的**几何重数 $=$ 代数重数**（$k$ 重根 $\lambda$ 满足 $n-r(A-\lambda E)=k$）。

- **等价刻画**：等价于几何重数之和恰为 $n$；等价于存在由特征向量构成的基。
- **易错辨析**：少一个向量都不可对角化（典型反例：$\lambda=1,1,2$ 而 $r(A-E)=2$，二重根只贡献 $1$ 个向量）；不可对角化的成因**只能是重根处 $g<k$**。

**6. 可对角化的充分条件**：$A$ 有 $n$ 个**互不相同**的特征值 $\Rightarrow$ 可对角化；$A$ 是实对称矩阵 $\Rightarrow$ 必可（正交）对角化。

- **易错辨析**：充分条件不满足 $\neq$ 不可对角化（有重根仍可能对角化，须验重数）。

**7. 判定与构造（求 $\Lambda$ 与 $P$）**：解 $\lvert A-\lambda E\rvert=0$ 得全部特征值 $\to$ 对每个 $\lambda$ 解 $(A-\lambda E)x=0$ 取基础解系 $\to$ 各基础解系按列拼成 $P$、特征值按同序写在对角线上得 $\Lambda$ $\to$ $P^{-1}AP=\Lambda$。

- **要点**：对 $k$ 重根只需验证 $n-r(A-\lambda_iE)=k$；"已知可对角化求参数"正是用这条等式定秩。
- **易错辨析**：$P$ 的列数必须凑够 $n$；次序错位即写出错误的相似关系。

**8. 两个矩阵相似的判定**：$A$、$B$ 均可对角化且特征值（含重数）相同 $\Rightarrow A \sim B$（各自对角化到同一个 $\Lambda$）；$A$、$B$ 同为实对称阵且特征值相同 $\Rightarrow$ 正交相似；都不可对角化时须比较若尔当标准型（超出考纲，仅作辨析）。

- **要点**：求 $P$ 使 $P^{-1}AP=B$：由 $A=P_1\Lambda P_1^{-1}$、$B=P_2\Lambda P_2^{-1}$ 得 $P=P_1P_2^{-1}$。
- **易错辨析**：只比特征值而不验"是否都可对角化"会误判。

**9. 相似与合同的区别**：**相似** $B=P^{-1}AP$（同一线性变换换基）；**合同** $B=C^TAC$（同一二次型换坐标）。

- **要点**：相似保持特征值（进而迹、行列式、秩）；合同保持秩与正负惯性指数，**不保持特征值数值**；当 $P$ 取正交矩阵时 $P^T=P^{-1}$，两种关系统一；实对称情形 $A \sim B \Rightarrow A \simeq B$，反之不成立。
- **易错辨析**：一般情形二者互不包含；"惯性指数相同"推不出相似（对比见（十六）与（十七））。

### （十五）实对称矩阵 · 概念

#### 一、内积与正交（工具）

**1. 内积（inner product）**：$n$ 维实向量 $\alpha$、$\beta$ 的内积 $(\alpha,\beta)=\alpha^T\beta=\sum_{i=1}^{n}a_ib_i$。

- **要点**：对称、双线性、$(\alpha,\alpha) \ge 0$ 且等号仅当 $\alpha=0$；$(\alpha,\beta)=0$ 时称 $\alpha$ 与 $\beta$ **正交**。
- **易错辨析**：$\alpha^T\beta$ 是**数**、$\alpha\beta^T$ 是**矩阵**；零向量与任何向量正交，但不能入选正交向量组。

**2. 长度与夹角（norm and angle）**：$\lVert\alpha\rVert=\sqrt{(\alpha,\alpha)}$ 称长度；$\cos\theta=\dfrac{(\alpha,\beta)}{\lVert\alpha\rVert\lVert\beta\rVert}$；柯西不等式 $\lvert(\alpha,\beta)\rvert \le \lVert\alpha\rVert\lVert\beta\rVert$。

- **易错辨析**：夹角只对两个**非零**向量有定义；$\lVert\alpha\rVert=0 \iff \alpha=0$。

**3. 正交向量组（orthogonal vector group）**：由两两正交的**非零**向量构成的向量组。

- **要点**：正交向量组**必线性无关**（比线性无关更强）。
- **易错辨析**：线性无关组未必正交；含零向量的组即使"两两正交"也不算正交向量组。

**4. 规范正交基（orthonormal basis）**：满足 $(\varepsilon_i,\varepsilon_j)=\delta_{ij}$ 的基（两两正交且每个向量长度为 $1$）。

- **要点**：$n$ 个规范正交**列**向量拼成 $Q$，则 $Q^TQ=E$；此时坐标由内积直接给出 $x_i=(\alpha,\varepsilon_i)$。
- **易错辨析**：正交组漏了单位化就不是规范正交组；单位化不破坏正交性。

**5. 正交矩阵（orthogonal matrix）**：满足 $A^TA=AA^T=E$ 的 $n$ 阶实方阵。

- **等价刻画**：$A^{-1}=A^T$；列（行）向量组是规范正交基；$\lvert A\rvert=\pm1$；实特征值只能为 $\pm1$；乘积与逆仍正交；保内积、保长度（$\lVert Ax\rVert=\lVert x\rVert$）。
- **易错辨析**：$\lvert A\rvert=\pm1$ 只是**必要**条件（如 $\operatorname{diag}(2,\frac{1}{2})$ 行列式为 $1$ 却非正交）；正交（$A^T=A^{-1}$）与对称（$A^T=A$）是两回事。

**6. 施密特正交化（Gram-Schmidt orthogonalization）**：把线性无关组 $\alpha_1,\dots,\alpha_r$ 化为正交组：$\beta_1=\alpha_1$，$\beta_k=\alpha_k-\sum_{i<k}\dfrac{(\alpha_k,\beta_i)}{(\beta_i,\beta_i)}\beta_i$，再单位化 $\varepsilon_k=\dfrac{\beta_k}{\lVert\beta_k\rVert}$。

- **要点**：$\mathrm{span}\{\beta_1,\dots,\beta_k\}=\mathrm{span}\{\alpha_1,\dots,\alpha_k\}$——改造不改变张成空间，所得规范正交组与原组等价。
- **易错辨析**：分母是 $(\beta_i,\beta_i)$ 而非 $(\alpha_i,\alpha_i)$；必须**先正交化、后单位化**；只有**同一重根内部**的多个特征向量才需要正交化。

#### 二、实对称矩阵

**7. 实对称矩阵（real symmetric matrix）**：满足 $A^T=A$（即 $a_{ij}=a_{ji}$）的实方阵。

- **四大性质**：① 特征值全为**实数**；② **不同**特征值的特征向量**必正交**；③ 必可对角化——$k$ 重特征值恰有 $k$ 个线性无关特征向量（$n-r(A-\lambda_0E)=k$）；④ 必存在正交矩阵 $Q$ 使 $Q^TAQ=\Lambda$。
- **易错辨析**：②只对**不同特征值**成立，重根对应的特征向量不一定正交，须先正交化；③是"无条件"的，普通矩阵要先验几何重数 $=$ 代数重数。

**8. 正交对角化（orthogonal diagonalization）**：存在正交矩阵 $Q$ 使 $Q^{-1}AQ=Q^TAQ=\Lambda$（$\Lambda$ 为特征值构成的对角阵）。

- **等价刻画**：实矩阵可正交对角化 $\iff$ 它是实对称矩阵。
- **要点**：$Q^T=Q^{-1}$ 使相似与合同在此统一。
- **易错辨析**：相似对角化只要求 $P$ 可逆，正交对角化要求 $P$ 的列是**规范正交**特征向量；口诀"**异根免施密特只单位化，重根内先施密特再单位化**"。

### （十六）二次型 · 概念

#### 一、二次型及其矩阵

**1. 二次型与二次型矩阵（quadratic form and its matrix）**：$n$ 元二次齐次多项式 $f(x_1,\dots,x_n)=\sum_{i=1}^{n}\sum_{j=1}^{n}a_{ij}x_ix_j=x^TAx$，其中 $A$ 为**实对称**矩阵，称二次型的矩阵。

- **要点**：$a_{ii}$ 取 $x_i^2$ 的系数，$a_{ij}=a_{ji}$ 取交叉项 $x_ix_j$ 系数的一半；二次型与实对称矩阵**一一对应**。
- **易错辨析**：交叉项系数必须**除以 2** 分放到对称位置（写错矩阵的重灾区）；若给出的 $A$ 不对称，须先对称化 $\dfrac{A+A^T}{2}$。

**2. 二次型的秩（rank of a quadratic form）**：规定 $r(f)=r(A)$。

- **等价刻画**：$r(f)=p+q=$ 非零特征值个数 $=$ 标准形中非零平方项的个数。
- **易错辨析**：秩只数**非零平方项的个数**，与各项系数的大小无关。

**3. 可逆线性变换与正交变换（invertible / orthogonal transformation）**：$x=Cy$ 且 $\lvert C\rvert \neq 0$ 称可逆线性变换；$C$ 为正交矩阵时称正交变换。

- **要点**：$f=x^TAx=y^T(C^TAC)y$——可逆线性变换把 $A$ 换成**合同**的 $C^TAC$。
- **易错辨析**：$\lvert C\rvert=0$ 的变换不可逆，不保证惯性指数不变，不能用来化标准形。

#### 二、标准形、规范形与惯性定理

**4. 标准形（canonical / standard form）**：只含平方项、无交叉项的二次型 $f=d_1y_1^2+d_2y_2^2+\dots+d_ny_n^2$。

- **要点**：任一二次型都可用可逆线性变换化为标准形；**正交变换**下 $d_i$ 恰为 $A$ 的特征值且（不计次序）唯一，**配方法**下 $d_i$ 不唯一。
- **易错辨析**：只有正交变换法的系数等于特征值；标准形不唯一而规范形唯一。

**5. 规范形（normal form）**：系数只取 $1$、$-1$、$0$ 的标准形 $f=z_1^2+\dots+z_p^2-z_{p+1}^2-\dots-z_{p+q}^2$。

- **等价刻画**：规范形由 $(p,q)$ 唯一确定，等价地由秩 $r=p+q$ 与符号差 $p-q$ 唯一确定。
- **易错辨析**：规范形唯一，但化到规范形的可逆变换不唯一。

**6. 惯性定理与惯性指数（law of inertia；positive / negative index of inertia）**：正惯性指数 $p$ 为标准形中正平方项（正特征值）的个数，负惯性指数 $q$ 为负平方项（负特征值）的个数；**惯性定理**断言 $p$、$q$ 与所用可逆线性变换无关。

- **等价刻画**：$p=\#\{\lambda_i>0\}$，$q=\#\{\lambda_i<0\}$，$r(A)=p+q$；特征值法与配方法算出的 $p$、$q$ 必一致。
- **易错辨析**：合同变换保持 $p$、$q$ 却**不保持特征值数值**，别把"正负个数相同"当成"特征值相同"。

**7. 二次型与二次曲面（数一）**：$f=x^TAx=c\ (c>0)$ 的图形类型由 $(p,q)$ 决定，且正交变换不改变图形类型。

| $(p,q)$ | 标准形 | 曲面类型 |
|:---|:---|:---|
| $(3,0)$ | $y_1^2+y_2^2+y_3^2=c$ | 椭球面 |
| $(2,1)$ | $y_1^2+y_2^2-y_3^2=c$ | 单叶双曲面 |
| $(1,2)$ | $y_1^2-y_2^2-y_3^2=c$ | 双叶双曲面 |
| $(2,0)$ | $y_1^2+y_2^2=c$ | 椭圆柱面 |
| $(1,1)$ | $y_1^2-y_2^2=c$ | 双曲柱面 |

- **易错辨析**：只看特征值的**符号个数**，与特征值具体大小无关。

#### 三、合同与三大关系

**8. 合同矩阵（congruent matrices）**：若存在**可逆**矩阵 $C$ 使 $B=C^TAC$，则称 $A$ 与 $B$ 合同，记 $A \simeq B$。

- **等价刻画**（实对称）：$A \simeq B \iff$ 有相同的正负惯性指数 $(p,q) \iff$ 有相同的规范形 $\iff$ 秩 $r$ 与正惯性指数 $p$ 分别相同。
- **易错辨析**：只要求 $C$ **可逆**、不要求正交；合同保持对称性、秩与正负惯性指数，但**不保持特征值**。

**9. 等价、相似、合同（equivalence / similarity / congruence）**：

| <b><nobr>关系</nobr></b> | 定义式 | 保持不变的性质 | 判定 |
|:---|:---|:---|:---|
| 等价 | $B=PAQ$（$P$、$Q$ 可逆） | 同型、秩 | 同型且 $r(A)=r(B)$ |
| 相似 | $B=P^{-1}AP$ | 特征值、秩、迹、行列式、可逆性 | 特征值相同且均可对角化 |
| 合同 | $B=C^TAC$（$C$ 可逆） | 秩、正负惯性指数、对称性 | 实对称下 $(p,q)$ 相同 |

- **要点**：正交矩阵使 $P^T=P^{-1}$，相似与合同在此**统一**；实对称情形相似 $\Rightarrow$ 合同，反之不成立。
- **易错辨析**：秩相同只能推出**等价**；"惯性指数相同"推不出相似。

#### 四、正定性

**10. 正定、负定、半正定与不定（definiteness）**：对任意 $x \neq 0$，$x^TAx>0$ 为正定，$<0$ 为负定，$\ge 0$ 为半正定，$\le 0$ 为半负定；既能取正值又能取负值则为不定。

- **等价刻画**：正定 $\iff p=n$；负定 $\iff q=n$（即 $-A$ 正定）；半正定 $\iff p=r(A)$；不定 $\iff p>0$ 且 $q>0$。
- **易错辨析**：判定永远只针对 $x \neq 0$（恒有 $f(0)=0$）；半正定允许存在非零 $x$ 使 $f(x)=0$，这正是它与正定的分界。

**11. 正定的判别（criteria for positive definiteness）**：设 $A$ 为实对称矩阵，下列条件彼此等价，任取其一即可判正定：

- ① 所有特征值 $>0$；
- ② 各阶**顺序主子式**全 $>0$（Sylvester 判别法：$\Delta_1>0,\ \Delta_2>0,\dots,\Delta_n=\lvert A\rvert>0$）；
- ③ $A \simeq E$（与单位矩阵合同）；
- ④ 存在可逆矩阵 $P$ 使 $A=P^TP$；
- ⑤ 正惯性指数 $p=n$。
- **易错辨析**：半正定要求**所有主子式** $\ge 0$，仅顺序主子式非负不够；负定要求**奇数阶**顺序主子式 $<0$、**偶数阶** $>0$。

**12. 正定矩阵的性质（properties of positive definite matrices）**：$\lvert A\rvert>0$ 且主对角元 $a_{ii}>0$；$A^{-1}$、$A^*$、$A^k\ (k \ge 1)$、$kA\ (k>0)$ 均正定；$A$、$B$ 正定 $\Rightarrow A+B$ 正定；$P$ 可逆 $\Rightarrow P^TAP$ 正定（合同保正定性）；$A$、$B$ 正定且 $AB=BA$ $\Rightarrow AB$ 正定。

- **易错辨析**：正定矩阵之和必正定，之积**未必**（且 $AB$ 未必对称）；正定必可逆，可逆未必正定。

### （十七）跨章易混概念辨析总表

> **用法**：把全书中**最容易混**的概念成对（成组）摆在一起——先看左列自述差别，再遮住右列核对判据与死因。

#### 一、矩阵与行列式

| 概念对 | 关键差别（一条判据定生死） |
|:---|:---|
| 矩阵 $A$ 与行列式 $\lvert A\rvert$ | $A$ 是数表（可非方阵），$\lvert A\rvert$ 是数（只对方阵）；$\lvert A\rvert=0$ 只说明**奇异**，绝不说明元素为 $0$ |
| 矩阵相等与矩阵等价 | 相等要求同型且元素全同；等价只要求同型且**秩相等**（$B=PAQ$） |
| 矩阵等价与向量组等价 | 前者只要秩同；后者要求两组能**互相线性表出**，条件更强 |
| 可逆、满秩与非奇异 | 对方阵而言三者是同一件事（$\lvert A\rvert \neq 0 \iff r(A)=n$） |
| 伴随 $A^*$ 与逆 $A^{-1}$ | $A^*$ 对任意方阵都有定义，$A^{-1}$ 只在 $\lvert A\rvert \neq 0$ 时存在；此时 $A^*=\lvert A\rvert A^{-1}$ |
| 余子式 $M_{ij}$ 与代数余子式 $A_{ij}$ | $A_{ij}=(-1)^{i+j}M_{ij}$，差一个符号；题目问 $M$ 要先转成 $A$ |
| 转置 $A^T$ 与逆 $A^{-1}$ | $(AB)^T=B^TA^T$ 与 $(AB)^{-1}=B^{-1}A^{-1}$ 都反序；但 $A^T$ 恒存在，$A^{-1}$ 未必 |
| 对称 $A^T=A$ 与正交 $A^T=A^{-1}$ | 前者管元素对应相等，后者管整体求逆；正交必可逆且 $\lvert A\rvert=\pm1$，对称未必 |

#### 二、向量与线性关系

| 概念对 | 关键差别（一条判据定生死） |
|:---|:---|
| 线性相关与线性无关 | 相关 $\iff$ 存在**不全为零**的系数使组合为零 $\iff r(A)<m$；无关 $\iff$ 只有零解 $\iff r(A)=m$ |
| 线性无关与正交 | **非零**向量组正交 $\Rightarrow$ 无关；无关 $\nRightarrow$ 正交 |
| 线性表示与线性相关 | 表示问"$\beta$ 能否由该组表出"（$Ax=\beta$ 有解）；相关问"该组自己零组合是否有非零解"（$Ax=0$） |
| 极大无关组与基础解系 | 前者是任意向量组的"代表"（个数 $=r$）；后者专指齐次**解空间**的基（个数 $=n-r$） |
| 向量组的秩与矩阵的秩 | 同一件事：以该组为列拼成矩阵，向量组的秩 $=$ 该矩阵的秩 |
| 向量组等价与矩阵等价 | 秩相同只是矩阵等价；向量组等价还要求**互相表出**（对比（十七）一、同名一行） |

#### 三、方程组

| 概念对 | 关键差别（一条判据定生死） |
|:---|:---|
| 齐次解集与非齐次解集 | 齐次解集是**子空间**（含零向量、对加法封闭）；非齐次解集**不是**子空间 |
| 通解与基础解系 | 基础解系是解空间的一组**基**（$n-r$ 个向量，不含任意常数）；通解 $=$ 基的任意线性组合 |
| 有解与唯一解 | 有解只要求 $r(A)=r(A,b)$；唯一解还要求该公共值 $=n$ |
| 公共解与同解 | 公共解是两个解集的**交集**（可能只有零解）；同解是两个解集**完全相同** |
| 特解与通解 | 特解是任意一个解；通解 $=$ 特解 $+$ 导出组的基础解系的任意组合 |

#### 四、特征值、相似与合同

| 概念对 | 关键差别（一条判据定生死） |
|:---|:---|
| 代数重数与几何重数 | 代数重数是特征根的**重数** $k$；几何重数是 $n-r(A-\lambda E)$；恒有 $g \le k$，$g=k$ 才可对角化 |
| 可逆与可对角化 | 两件无关的事：可逆看特征值是否全非零，可对角化看重根处 $g$ 是否 $=k$；$\begin{pmatrix}1&1\\0&1\end{pmatrix}$ 可逆不可对角化，$\begin{pmatrix}1&0\\0&0\end{pmatrix}$ 可对角化不可逆 |
| 相似与合同 | 相似保**特征值**（$P^{-1}AP$）；合同保**惯性指数**（$C^TAC$）；正交矩阵下二者统一 |
| 实对称与一般可对角化 | 实对称"无条件"可对角化（重根也给足向量）；普通矩阵必须逐个验 $g=k$ |
| 标准形与规范形 | 标准形系数是 $d_i$（**不唯一**）；规范形系数只取 $\pm1$、$0$（**唯一**，由 $p$、$q$ 决定） |
| 正定与半正定 | 正定 $p=n$（对一切 $x \neq 0$ 恒 $>0$）；半正定 $p=r(A)$（允许某些 $x \neq 0$ 使 $f=0$） |
| 顺序主子式与全部主子式 | 判**正定**用顺序主子式全 $>0$；判**半正定**必须所有主子式 $\ge 0$ |
| 惯性指数相同与特征值相同 | 前者只说明**合同**（实对称）；**特征值相同且均可对角化**才说明相似；实对称矩阵相似必有相同的惯性指数 |

#### 五、一句话自测清单

> **用法**：遮住右列，只看左列概念名自述定义，说完再核对。

| <b><nobr>概念</nobr></b> | 一句话自述定义 |
|:---|:---|
| 行列式 | 不同行不同列元素带符号乘积之和 |
| 余子式 / 代数余子式 | 划去所在行列所得的行列式 / 再加符号 $(-1)^{i+j}$ |
| 伴随矩阵 | 代数余子式按行求出、按列放置 |
| 矩阵等价 | 同型且秩相等（$B=PAQ$） |
| 矩阵的秩 | 最高阶非零子式的阶数 |
| 线性相关 | 存在不全为零的系数使组合为 $0$ |
| 极大无关组 | 自身无关且能表出全组（添任一向量即相关） |
| 基础解系 | 齐次解空间的一组基，个数 $n-r(A)$ |
| 特征值与特征向量 | 被 $A$ 作用后只伸缩、不变向（$Ax=\lambda x$，$x \neq 0$） |
| 几何重数 | $n-r(A-\lambda E)$，即特征子空间的维数 |
| 可对角化 | 每个特征值的几何重数 $=$ 代数重数 |
| 正交矩阵 | $A^T=A^{-1}$，列向量组为规范正交基 |
| 合同 | 存在可逆 $C$ 使 $B=C^TAC$ |
| 二次型的秩 | 其矩阵的秩 $=p+q=$ 非零特征值个数 |
| 正定 | 对一切 $x \neq 0$ 有 $x^TAx>0$ |
