<h2 align="center">线性代数总纲：从求解方程组的角度</h2>

> **本篇定位**：以解方程组 $Ax = b$ 为主线把八章内容串联起来。行列式给出方阵方程组的判定条件，矩阵与秩给出一般情形的判定方法，向量提供线性表出的语言，特征值对应另一类方程组，相似对角化与二次型是这条主线的延伸与应用。复习时按这条主线组织知识，而不是把八章当作互不相关的八部分。

### （一）总纲：整门线代围绕 $Ax = b$ 展开

#### 一、一个方程组，三种形式

$m$ 个方程、$n$ 个未知数的方程组，有三种等价写法，对应三种视角（详见第4章）：

$$
\underbrace{\begin{cases} a_{11}x_1 + \dots + a_{1n}x_n = b_1 \\ \dots \end{cases}}_{\text{代数形式：直接消元}} \iff \underbrace{Ax = b}_{\text{矩阵形式：线性变换}} \iff \underbrace{x_1\alpha_1 + \dots + x_n\alpha_n = b}_{\text{向量形式：线性表出}}
$$

- **代数形式**：直接对应高斯消元。
- **矩阵形式**：$A$ 是从 $\mathbb{R}^n$ 到 $\mathbb{R}^m$ 的线性变换，求解就是找被映射成 $b$ 的原像 $x$。
- **向量形式**："$Ax=b$ 有解" $\iff$ "$b$ 能由 $A$ 的列向量组线性表出"。理论证明题的主要表述方式。

#### 二、八章各自的作用

| <b><nobr>章节</nobr></b> | 在求解 $Ax = b$ 主线中的作用 |
|:---|:---|
| 第1章 行列式 | **方阵方程组的判定条件**：只有 $|A| \neq 0$ 才能判定唯一解，并给出克拉默法则；$|A| = 0$ 可判定齐次方程组有非零解 |
| 第2章 矩阵 | **消元的矩阵表示**：初等行变换 = 高斯消元；秩 $r(A)$ = 消元后独立方程数；$A^{-1}$ 给出 $x = A^{-1}b$ |
| 第3章 向量 | **线性表出的语言**：把"方程组是否有解"表述为"$b$ 能否由列向量组线性表出"；把解的结构问题转化为线性相关性问题 |
| 第4章 线性方程组 | **核心内容**：解的存在性判定 + 通解结构 + 求解流程，是全书内容最集中的一章 |
| 第5章 特征值 | **另一类方程组**：$(A - \lambda E)x = 0$，特征向量即该方程组的非零解 |
| 第6章 相似矩阵 | **通过换基简化运算**：$A = P\Lambda P^{-1}$，以特征向量构成新基，把矩阵运算化为对角矩阵的数乘 |
| 第7章 实对称矩阵 | **正交对角化**：必可正交对角化，$Q^T = Q^{-1}$，不同特征值的特征向量必正交 |
| 第8章 二次型 | **综合应用**：$f = x^T Ax$ 经正交变换化为标准形，正定性判定归结为二次型取值符号的判定 |

#### 三、核心：秩

**解的存在性与个数完全由秩 $r(A)$ 决定**。秩有三种等价刻画：

- **消元视角**：行阶梯形中非零行的个数。
- **子式视角**：最高阶非零子式的阶数。
- **向量视角**：列向量组中极大线性无关组所含向量个数（列秩 = 行秩 = $r(A)$）。

> **考点**：$r(A) = n$（列满秩）等价于"唯一解"；$r(A) < n$ 等价于"无穷多解 + 有自由变量"。所有判定都归结为比较 $r(A)$、$r(A, b)$、$n$ 三者。

### （二）基本工具：行列式与矩阵如何服务于求解

#### 一、行列式：仅适用于方阵的快速判定工具

行列式（第1章）只对 $n$ 阶方阵有效，但只需计算一个行列式即可作出判定：

| 方程组 | $|A| \neq 0$ | $|A| = 0$ |
|:---|:---|:---|
| 齐次 $Ax = 0$ | 只有零解 | **有非零解** |
| 非齐次 $Ax = b$ | 唯一解（可用克拉默 $x_j = \dfrac{D_j}{D}$） | 解不定：无解或无穷多解，必须看秩 |

**克拉默法则的适用范围**：具体数字题一律用高斯消元（4 阶行列式需计算 5 个，计算量大）；它主要用于**含参方程组**——令 $|A| = 0$ 求参数是考研大题中的常见思路。

#### 二、矩阵：消元法的矩阵表达

第2章的内容都服务于求解：

1. **初等行变换 = 方程组的同解变形**（交换两方程、非零倍乘、倍加消元），且不改变解集。"左行右列"：行变换 = 左乘初等矩阵。
2. **求逆 = 解 $n$ 个方程组**：$(A \mid E) \to (E \mid A^{-1})$ 的本质是对 $A$ 的每一列作为常数项做高斯消元。
3. **可逆的八大等价刻画**（必须熟练掌握）：

$$
A^{-1} \text{ 存在} \iff |A| \neq 0 \iff r(A) = n \iff Ax = 0 \text{ 只有零解} \iff \forall b,\ Ax = b \text{ 有唯一解}
$$

$$
\iff A^* \text{ 可逆} \iff A \cong E \iff A \text{ 的特征值全不为 } 0
$$

4. **秩的运算规则**（判定解时的常用结论）：
   - $r(A^T) = r(A)$；乘可逆阵不变：$r(PAQ) = r(A)$。
   - 乘积的秩：$r(AB) \le \min(r(A), r(B))$。
   - **西尔维斯特推论**：$A_{m \times n}B_{n \times s} = O \implies r(A) + r(B) \le n$——理由是：$AB = O$ 时 $B$ 的每一列都是 $Ax = 0$ 的解，故 $r(B) \le n - r(A)$。
   - 伴随：$r(A^*) = n, 1, 0$（对应 $r(A) = n, n-1, \le n-2$）。

### （三）核心内容：解的判定、结构与求解（第4章浓缩）

#### 一、解的判定：三种情形

对 $n$ 元方程组，增广矩阵消元后只需数秩：

| 情形 | 判定条件 | 消元后的形式 | 几何意义 |
|:---|:---|:---|:---|
| 无解 | $r(A) < r(A, b)$ | 出现 $0 = c$ 行 | $b$ 落在列空间之外，无法被列向量表出 |
| 唯一解 | $r(A) = r(A, b) = n$ | 满列秩，无自由变量 | $b$ 在列空间内且表出方式唯一 |
| 无穷多解 | $r(A) = r(A, b) < n$ | 有 $n - r$ 个自由变量 | $b$ 在列空间内但表出方式不唯一 |

> **易错点**：$m < n$（方程少未知数多）时齐次方程组**必有非零解**（$r(A) \le m < n$）；但非齐次方程组**可能无解**，两种情况不要混淆。

#### 二、解的结构：通解的组成

**齐次 $Ax = 0$**：解集构成向量空间（解空间/零空间），维数等于 $n - r(A)$。

$$
x = k_1\xi_1 + k_2\xi_2 + \dots + k_{n-r}\xi_{n-r}
$$

基础解系三条件：是解、线性无关、能表出全部解。个数 $s = n - r(A)$ 是**填空题常考点**——由特征值、$AB = O$ 等条件反推秩是常见考法。

**非齐次 $Ax = b$**：解集不是空间（对加法不封闭），但结构是"特解 + 齐次通解"：

$$
x = \underbrace{\eta^*}_{\text{特解}} + \underbrace{k_1\xi_1 + \dots + k_{n-r}\xi_{n-r}}_{\text{导出组的基础解系}}
$$

**解的三条性质**（抽象题的主要依据）：

1. **相减仍为齐次解**：$\eta_1 - \eta_2$ 是 $Ax = 0$ 的解。
2. **非齐次解加齐次解仍为非齐次解**：$\eta^* + \xi$ 仍是非齐次解。
3. **系数和判别**（选择题常用）：$\sum k_i\eta_i$ 当且仅当 $\sum k_i = 1$ 时是 $Ax = b$ 的解，$\sum k_i = 0$ 时是 $Ax = 0$ 的解。

#### 三、求解流程：数值型 vs 抽象型

**数值型（增广矩阵行变换）**：

1. 写增广矩阵 $(A \mid b)$。
2. 只做**行变换**（列变换会打乱未知数顺序，禁用）化行最简形。
3. 数秩定解的情况：无解 / 唯一解（回代） / 无穷多解（区分主元变量与自由变量）。
4. 自由变量轮流取单位值 $(1, 0, \dots), (0, 1, \dots)$，提出基础解系与特解，组装通解。

**抽象型（由已知解反推）**：

1. 由已知条件（解的个数、$AB = O$、特征值……）求出 $r(A)$，确定基础解系的个数 $n - r(A)$。
2. 用已知解**两两相减**造出齐次解，验证其线性无关且个数正好等于 $n - r(A)$ → 基础解系。
3. 用已知解（或系数和为 1 的组合）充当特解。
4. 套公式 $x = \eta^* + \sum k_i\xi_i$。

#### 四、公共解与同解

- **公共解**（两个方程组解集的交集）有三种方法：

| 已知条件 | 推荐方法 | 要点 |
|:---|:---|:---|
| 两个矩阵 $A$、$B$ 都是具体的 | 联立矩阵法 | 拼 $\begin{bmatrix} A \\ B \end{bmatrix}$ 直接消元，最稳定 |
| 第一问已求出某组通解 | 通解代入法 | 通解代入另一方程组，解出参数比例，计算量最小 |
| 给出两组基向量求交 | 通解相等法 | **两套独立参数字母**（$k$ 与 $l$），令两通解相等 |

- **同解**：$Ax = 0$ 与 $Bx = 0$ 同解 $\iff r(A) = r(B) = r\begin{bmatrix} A \\ B \end{bmatrix}$（行向量组等价）。

### （四）向量的视角：把求解问题转化为线性表出问题（第3章）

第3章的作用是用线性表出描述方程组的解：

| 方程组命题 | 向量表述 |
|:---|:---|
| $Ax = b$ 有解 | $b$ 可由列向量组 $\alpha_1, \dots, \alpha_n$ 线性表出；$r(A) = r(A, b)$ |
| $Ax = b$ 解唯一 | 表出方式唯一 $\iff$ $\alpha_1, \dots, \alpha_n$ 线性无关 |
| $Ax = 0$ 有非零解 | $\alpha_1, \dots, \alpha_n$ **线性相关** |
| $Ax = 0$ 只有零解 | $\alpha_1, \dots, \alpha_n$ **线性无关** |
| 基础解系 | 零空间的一组基 |
| $n - r(A)$ 个自由变量 | 列向量组中"多余"向量的个数 |

**做题时最常用的转化**：判定相关性 / 求极大无关组，一律把向量按列拼矩阵做行变换——**行变换不改变列之间的线性关系**，主元列对应的**原向量**（不是化简后的列）构成极大无关组。

> **高频结论**：$m > n$（向量个数大于维数）必相关；部分相关则整体相关；无关组添分量仍无关。

### （五）延伸一：特征值——另一类方程组（第5章）

特征值问题仍然是解方程组，只是多了一个参数 $\lambda$：

$$
Ax = \lambda x \iff (A - \lambda E)x = 0
$$

**两步求解 = 一次行列式 + 一次齐次方程组**：

1. **求 $\lambda$**：令 $|A - \lambda E| = 0$（特征方程）。本质是找一个使 $(A - \lambda E)$ 奇异的 $\lambda$，与"$|A| = 0$ 则 $Ax = 0$ 有非零解"是同一原理。
2. **求 $x$**：对每个 $\lambda_i$ 解齐次方程组 $(A - \lambda_i E)x = 0$ 的**非零解**，基础解系的非零线性组合就是全部特征向量。

**与主线的联系**：

- $\lambda = 0$ 是 $A$ 的特征值 $\iff Ax = 0$ 有非零解 $\iff A$ 不可逆 $\iff r(A) < n$。
- $\lambda_i$ 的几何重数 $= n - r(A - \lambda_i E)$——就是齐次方程组基础解系的个数。
- $\sum \lambda_i = \text{tr}(A)$，$\prod \lambda_i = |A|$（由特征多项式系数读出；$\prod \lambda_i = 0 \iff$ 不可逆）。

### （六）延伸二：相似对角化——通过换基简化矩阵运算（第6、7章）

#### 一、对角化把矩阵运算化为数乘

$P^{-1}AP = \Lambda \iff AP = P\Lambda$，按列拆开就是 $n$ 个 $A\xi_i = \lambda_i\xi_i$——**$P$ 的每一列都对应一次特征方程组的求解**。

对角化后，相关计算大为简化：

$$
A^k = P\Lambda^kP^{-1}, \quad Ax = b \Rightarrow \Lambda y = P^{-1}b\ (x = Py)
$$

**可对角化判定（从方程组角度理解）**：

- 充要：每个特征值的**几何重数 = 代数重数**，即每个 $(A - \lambda_i E)x = 0$ 的基础解系个数恰好等于重根数。只要有一个特征值不满足，就得不到 $n$ 个线性无关的特征向量，$P$ 不可逆。
- 充分：$n$ 个互异特征值（每个方程组至少有一个非零解）；实对称矩阵。

#### 二、实对称矩阵：可正交对角化的特殊情形

- 特征值全为实数；**不同特征值的特征向量必正交**（无需施密特正交化）；$k$ 重特征值必有 $k$ 个线性无关的特征向量（必可对角化）。
- 存在正交矩阵 $Q$：$Q^TAQ = \Lambda$，$Q^T = Q^{-1}$。
- **解题规则**：不同特征值对应的特征向量只需单位化；**同一重根内部**的特征向量必须先施密特正交化再单位化。

### （七）综合应用：二次型（第8章）

二次型 $f = x^TAx$（$A$ 实对称）研究的是 $x^TAx$ 的取值符号，而不是求出具体的 $x$。

**正交变换法化标准形与特征值求解流程完全一致**：写 $A$ → 解 $|A - \lambda E| = 0$ → 解各 $(A - \lambda_iE)x = 0$ 求特征向量 →（重根内施密特）单位化拼 $Q$ → 标准形系数就是特征值 $\sum \lambda_iy_i^2$。

**配方法**：计算较快，但不给出特征值，只保持正负惯性指数不变（惯性定理：$p$、$q$ 不随变换改变；$r(A) = p + q$ = 非零特征值个数）。注意最后要把 $y = P^{-1}x$ **反解**成 $x = Py$。

**正定性判定（四条等价）**：所有 $\lambda_i > 0$ $\iff$ 各阶顺序主子式全 $> 0$ $\iff$ $A \simeq E$（存在 $P$ 使 $A = P^TP$） $\iff$ $p = n$。

**三大关系对比**（常考）：

| <b><nobr>关系</nobr></b> | 定义式 | 保持不变的性质 | 判定 |
|:---|:---|:---|:---|
| 等价 | $B = PAQ$ | 秩 | 秩相同即等价 |
| 相似 | $B = P^{-1}AP$ | 特征值、秩、迹、行列式 | 特征值相同且都能对角化 |
| 合同 | $B = P^TAP$ | 秩、正负惯性指数 | 实对称下 $p$、$q$ 相同即合同 |

正交矩阵联系二者：$P^T = P^{-1}$ 时相似与合同统一；实对称矩阵相似 $\Rightarrow$ 合同，反之不成立。

### （八）本章总结

**知识结构图**（以 $Ax = b$ 为主线）：

```
解方程 Ax = b
├─ 判定"有没有解 / 有几个解"
│   ├─ 方阵判定：|A| ≠ 0（行列式 / 克拉默）
│   ├─ 一般判定：r(A) vs r(A,b) vs n（矩阵 / 秩 / 初等行变换）
│   └─ 向量刻画：b 能否由列向量组线性表出（线性相关性 / 极大无关组）
├─ 有解时解的结构
│   ├─ 齐次：解空间，维数 n − r(A)，基础解系 + 通解
│   ├─ 非齐次：特解 + 齐次通解（系数和判别）
│   └─ 多组方程：公共解（联立/代入/通解相等）、同解（三秩相等）
├─ 进一步推广
│   ├─ 特征值：(A − λE)x = 0 的非零解，几何重数 = n − r(A − λE)
│   ├─ 相似对角化：P 由特征向量拼成，几何重数 = 代数重数是充要条件
│   └─ 实对称：必可正交对角化，不同特征值向量必正交
└─ 综合应用
    ├─ 二次型 f = xᵀAx 正交变换化标准形（系数 = 特征值）
    ├─ 惯性定理：p、q 不变；r(A) = p + q = 非零特征值个数
    └─ 正定 ⇔ λ 全正 ⇔ 顺序主子式全正 ⇔ A ≃ E ⇔ p = n
```
