第六章 相似矩阵

（一）基础概念

一、严格代数定义

设 A,B 都是 n 阶方阵。如果存在一个可逆矩阵 P，使得：

P−1AP=B

或者等价地写成 AP=PB，那么我们就说矩阵 A 与矩阵 B 相似，记作 A∼B。其中，可逆矩阵 P 被称为相似变换矩阵。

二、核心几何直观（“同一种变换的不同语言”）

如果在应试或推导中只把 P−1AP=B 当作一个干瘪的公式，遇到综合题时很容易卡壳。必须从几何空间的角度去理解它：

相似矩阵的本质，是“同一个线性变换”在“不同坐标系（基）”下的不同表现形式。

  • 矩阵 A：在标准直角坐标系下，对空间进行的一种扭曲（比如拉伸、旋转）。

  • 矩阵 P：代表一个全新的坐标系（它的列向量就是新坐标系的基底）。

  • 矩阵 B：在 P 这个新坐标系下，描述完全相同的那种扭曲。

当你计算 P−1APx 时，整个过程其实是一个“翻译”游戏：

  1. Px：将新坐标系下的向量翻译回标准坐标系。

  2. A(Px)：在标准坐标系下执行真实的物理变换。

  3. P−1(APx)：将变换后的结果，再次翻译回新坐标系，这正是矩阵 B 直接做的事情。

三、相似矩阵的性质

既然 A 和 B 本质上是同一个空间变换，它们必然共享这个变换的所有“绝对属性”。如果 A∼B，它们拥有以下相同的核心特征：

1. 矩阵本身的特征

  1. 特征多项式相同： |A−λE|=|B−λE|。（这是推导其他性质的万恶之源）

  2. 特征值完全相同： λA=λB。（但注意，特征向量通常不同，关系为 xB=P−1xA）

  3. 行列式相同： |A|=|B|。

  4. 矩阵的迹相同： tr(A)=tr(B)（主对角线元素之和相等）。

  5. 矩阵的秩相同： r(A)=r(B)。

  6. 可逆性相同：A 可逆 ⟺B 可逆。

2. 矩阵变换的相似

  1. 可逆矩阵的相似： A∼B⟺A−1∼B−1

  2. 转置矩阵的相似： A∼B⟺AT∼BT

  3. 伴随矩阵的相似： A∼B⟺A∗∼B∗

  4. 多项式（包含高次幂与平移）相似： A∼B→f(A)∼f(B)

注意：

  • “性质相同”是相似的必要条件，但不是充分条件。也就是说，如果两个矩阵的特征值、行列式、迹全一样，它们未必相似（除非它们能对角化，或者属于同一类型的若尔当标准型）。

  • 利用相似求未知数是高频考法。如果题目告诉你 A∼B，且含有未知参数，第一反应应该是列出 tr(A)=tr(B) 和 |A|=|B|，这两个方程通常能直接秒杀参数。

（二）矩阵的相似对角化

矩阵的相似对角化是线性代数中将复杂问题“大道至简”的终极手段。它的本质是寻找一个完美的坐标系（基），在这个坐标系下，原本复杂的空间扭曲（矩阵变换）变成单纯的各个方向上的缩放（对角矩阵）。

1. 相似对角化的定义

设 A 是一个 n 阶方阵。如果存在一个可逆矩阵 P 和一个对角矩阵 Λ，使得：

P−1AP=Λ

那么，我们称矩阵 A 可相似对角化。

  • 对角矩阵 Λ：主对角线上的元素正是矩阵 A 的 n 个特征值 λ1,λ2,…,λn。

  • 可逆矩阵 P：它的 n 个列向量，正是对应于这 n 个特征值的线性无关的特征向量。

核心原则（一一对应）：矩阵 P 中的第 i 列（特征向量），必须与 Λ 中第 i 行主对角线上的特征值严格匹配，次序绝对不能错。

2. 矩阵可对角化的条件

在解题时，判断一个矩阵能否对角化，通常依赖以下几个层次的条件。请严格区分“充要条件”（等价条件）和“充分条件”（只要满足就一定行，但没满足也不代表不行）。

简要推导：

P−1AP=Λ⟺AP=PΛ
P=(ξ1,ξ2,…,ξn)

其中每一个 ξi 都是一个 n 维列向量。

Λ=(λ1λ2⋱λn)

现在，我们分别计算等式 AP=PΛ 的左边和右边：

  • 等式左边 (AP)：

    根据矩阵分块乘法的基本规则，矩阵 A 乘以 P 的每一列，等于把 A 分别乘到 P 的每个列向量上：

    AP=A(ξ1,ξ2,…,ξn)=(Aξ1,Aξ2,…,Aξn)

  • 等式右边 (PΛ)：

    一个矩阵乘以一个对角矩阵，相当于把对角线上的标量分别乘到该矩阵对应的列上：

    PΛ=(ξ1,ξ2,…,ξn)(λ1λ2⋱λn)=(λ1ξ1,λ2ξ2,…,λnξn)

由于 AP=PΛ，它们对应的每一列也必须完全相等。于是，我们得到了 n 个独立的向量方程：

Aξ1=λ1ξ1
Aξ2=λ2ξ2
⋮
Aξn=λnξn

简写为：

Aξi=λiξi(i=1,2,…,n)

这说明：λi 必须是矩阵 A 的特征值，而 ξi 必须是 A 对应于特征值 λi 的特征向量。

充要条件（完全等价，最根本的判断依据）

  1. 基本充要条件： n 阶矩阵 A 有 n 个线性无关的特征向量。

  2. 实战充要条件（重数相等定理）： 矩阵 A 的每一个特征值 λi 的几何重数等于其代数重数。

    • 翻译成人话：如果 λi 是一个 k 重特征根（代数重数为 k），那么把 λi 代入方程组 (A−λiE)x=0 后，求出的基础解系中必须恰好有 k 个线性无关的特征向量（即 n−r(A−λiE)=k）。少一个都不行！

充分条件（做题秒杀技巧）

如果矩阵满足以下条件之一，你可以直接断定它可对角化，甚至不需要去求特征向量：

  1. 无重根： 矩阵 A 有 n 个互不相同的特征值。（因为不同特征值对应的特征向量天然线性无关，凑齐 n 个互异特征值，就必然能凑齐 n 个线性无关的特征向量）。

  2. 实对称矩阵： 只要 AT=A，A 就一定能对角化。而且更强的是，它不仅能对角化，还能通过正交矩阵进行“正交对角化”（即 P−1=PT）。

3. 典型反例：什么时候“不能”对角化？

遇到含有重根的矩阵时，必须提高警惕。

例如，设矩阵 A 的特征值为 λ1=1,λ2=1,λ3=2。

  • λ3=2 是单根，肯定能贡献 1 个特征向量。

  • λ=1 是二重根（代数重数 = 2）。如果方程组 (A−E)x=0 的秩 r(A−E)=2，那么基础解系的个数（几何重数）为 3−2=1。

  • 此时，二重根只找到了 1 个特征向量（几何重数 1 < 代数重数 2）。总共只能拼凑出 2 个特征向量，凑不齐 3 个。

  • 结论： 该矩阵不可对角化。

4. 求解相似对角化

假设给定一个 n 阶方阵 A：

  1. 第一步：求特征值（特征方程）

    计算特征行列式 |A−λE|=0。将其展开为一个关于 λ 的 n 次多项式方程，解方程求出所有的特征值 λ1,λ2,…,λn。注意记录每个特征值的重数（代数重数）。

  2. 第二步：求特征向量（齐次方程组）

    对于每一个特征值 λi，代入齐次线性方程组 (A−λiE)x=0。通过初等行变换将系数矩阵化为行最简形，求出其基础解系。这些基础解系就是该特征值对应的线性无关特征向量。

  3. 第三步：可对角化判定（重数检验）

    检查特征向量的总数：

    • 如果所有特征值贡献的线性无关特征向量的总数恰好等于 n（即每个重根的几何重数都等于代数重数），则矩阵 A 可以对角化，继续下一步。

    • 如果总数小于 n，则矩阵 A 不可对角化，求解结束。

  4. 第四步：构造可逆矩阵 P

    将拼凑出的 n 个线性无关的特征向量作为列向量，横向排列组合成一个 n×n 的方阵 P：

    P=(ξ1,ξ2,…,ξn)

  5. 第五步：构造对角矩阵 Λ 并写出结论

    构造对角矩阵 Λ，将其特征值写在主对角线上：

    Λ=(λ1λ2⋱λn)

    最后写出结论： P−1AP=Λ（或 A=PΛP−1）。

    核心细节：Λ 中特征值的排列顺序必须与 P 中特征向量的列排列顺序严格一一对应。
