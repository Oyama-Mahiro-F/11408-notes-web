<h2 align="center">政治背诵手册</h2>

> **用法**：左列是提示，**先遮住右列回想**，想不起来再对照；打勾过一遍后考前仍要二刷。
> **收录规则**：只收**可背诵**条目——定义原话、原理表述、结论句、分类条目（"四条""三阶段""两个分化"）、答题模板/步骤。解释性论述留在对应笔记里，不重复搬运。
> **标题划分**：按**知识点**划分（不用"知识模块NNN"序号）；讲义标注的【必背考点】【总结考点】直接标在对应知识点标题后。
> **维护**：每次编写政治笔记、且提供了需要背诵的内容时，同步补录到对应知识点下（规则见 `AGENTS.md` §15）。

### 一、马克思主义原理

#### （一）物质世界的二重化　【必背考点·实践】

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>两个"分化"</nobr></b> | 世界分化为<b><nobr>自然界与人类社会</nobr></b>；分化为<b><nobr>客观世界与主观世界</nobr></b> |
| <b><nobr>分化的关键</nobr></b> | 人的劳动（在从猿到人的转变中起决定性作用）；人类社会是最高级的物质存在形态 |
| <b><nobr>客观世界的构成</nobr></b> | 客观世界 ＝ 自然界 + 人类社会（主观世界不在其列） |
| <b><nobr>主观世界的性质</nobr></b> | 从客观世界分化出来，有相对独立性，但不能脱离、从属于客观世界 |
| <b><nobr>自然界与人类社会之别</nobr></b> | 自然界一切自发产生；人类社会一切打着人的意识的印记，是人有目的的实践活动的结果 |
| <b><nobr>分化与统一的关键</nobr></b> | 都是人的实践活动 |

#### （二）物质与意识的辩证关系

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>物质与意识的关系</nobr></b> | 物质决定意识，意识依赖于物质并反作用于物质 |
| <b><nobr>意识的本质</nobr></b> | 意识是人脑的机能和属性，是客观世界的主观映象 |
| <b><nobr>意识的内容与形式</nobr></b> | 内容上是客观的、形式上是主观的，是客观内容和主观形式的统一；是物质的产物，但又不是物质本身 |
| <b><nobr>意识起源三阶段</nobr></b> | 一切物质所具有的反应特性 → 低等生物的刺激感应性 → 高等动物的感觉和心理 → 人类意识 |
| <b><nobr>意识产生的决定因素</nobr></b> | 社会实践特别是劳动；劳动和交往中形成的语言促进意识发展 |
| <b><nobr>能动作用四条</nobr></b> | 目的性和计划性／创造性／指导实践改造客观世界／调控人的行为和生理活动（口诀：<b><nobr>目创指调</nobr></b>） |

#### （三）主观能动性和客观规律性的辩证统一　【必背考点·前提 & 基础】

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>规律的定义</nobr></b> | 事物变化发展过程中本身所<b><nobr>固有的、内在的、本质的、必然的联系</nobr></b> |
| <b><nobr>二者的关系</nobr></b> | 尊重客观规律是正确发挥主观能动性的前提；只有充分发挥主观能动性，才能正确认识和利用客观规律 |
| <b><nobr>二者统一的基础</nobr></b> | 实践 |
| <b><nobr>正确发挥能动性三条</nobr></b> | 从实际出发（前提）／实践（基本途径）／一定的物质条件和物质手段（依赖） |
| <b><nobr>历史主动精神</nobr></b> | 基于对历史发展规律的深刻认识和把握而表现出的一种积极、能动、进取的精神状态 |

#### （四）分析题答题方法　【总结考点·"实践"是四对关系统一的基础】

#### （五）唯物辩证法总框架　【两大特征·三大规律·五对范畴·思维方法】

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>总特征（两大）</nobr></b> | 联系、发展 |
| <b><nobr>三大规律</nobr></b> | 对立统一规律（<b><nobr>实质与核心</nobr></b>）、质量互变规律、否定之否定规律 |
| <b><nobr>五对基本范畴</nobr></b> | 原因与结果、必然与偶然、可能与现实、现象与本质、形式与内容 |
| <b><nobr>辩证思维方法</nobr></b> | 归纳与演绎、分析与综合、抽象与具体、逻辑与历史相统一 |
| <b><nobr>根本认识方法</nobr></b> | 矛盾分析法 |
| <b><nobr>总特征与三大规律的关系</nobr></b> | 联系和发展是总特征；三大规律是联系和发展的<b><nobr>展开与深化</nobr></b> |

#### （六）联系　【唯物辩证法的总特征之一】

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>联系的定义</nobr></b> | 事物内部各要素之间和事物之间相互影响、相互制约、相互作用的关系（记忆点：<b><nobr>两个"之间" + 三个"相互"</nobr></b>） |
| <b><nobr>四大特征</nobr></b> | 客观性、普遍性、多样性、条件性 |
| <b><nobr>客观性</nobr></b> | 事物的联系是事物本身所固有的，不是主观臆想的；方法论要求从事物固有联系中去把握事物，切忌主观随意性 |
| <b><nobr>普遍性（三层）</nobr></b> | 其一，任何事物内部的不同部分和要素是相互联系的（内部联系）；其二，任何事物都不能孤立存在，都同其他事物处于一定的联系之中（外部联系）；其三，整个世界是相互联系的统一整体（整体联系） |
| <b><nobr>多样性</nobr></b> | 世界上的事物是多样的，因而事物的联系也是多样的（直接与间接、内部与外部、本质与非本质、必然与偶然） |
| <b><nobr>条件性（三点）</nobr></b> | ①条件对事物发展和人的活动具有支持或制约作用；②条件是可以改变的；③改变和创造条件<b><nobr>不是任意的</nobr></b>，必须尊重事物发展的客观规律 |
| <b><nobr>条件论反对什么</nobr></b> | 坚持唯物辩证法的条件论，就要反对唯心主义的<b><nobr>无条件论</nobr></b>和<b><nobr>唯条件论</nobr></b>——既善用有利条件，又善化不利条件为有利条件 |
| <b><nobr>方法论意义</nobr></b> | 要善于分析事物的具体联系，确立<b><nobr>整体性、开放性</nobr></b>观念，从动态中考察事物的普遍联系 |

#### （七）发展　【唯物辩证法的总特征之二】

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>发展的定义与实质</nobr></b> | 发展是<b><nobr>前进上升</nobr></b>的运动；实质是<b><nobr>新事物的产生和旧事物的灭亡</nobr></b> |
| <b><nobr>新事物与旧事物</nobr></b> | 新事物是合乎历史前进方向、具有远大前途的东西；旧事物是丧失历史必然性、日趋灭亡的东西 |
| <b><nobr>新事物不可战胜（就本质而言）</nobr></b> | 新事物符合事物发展的必然趋势，具有强大生命力和远大前途 |
| <b><nobr>新事物不可战胜（就新旧关系而言）</nobr></b> | 新事物是在旧事物基础上产生的，否定了旧事物中消极腐朽的东西，保留了其中合理的、仍适合新条件的因素，并添加了旧事物所不能容纳的新内容 |
| <b><nobr>新事物不可战胜（社会领域）</nobr></b> | 新事物符合<b><nobr>人民群众的根本利益和要求</nobr></b>，得到人民群众的拥护和支持 |
| <b><nobr>过程论</nobr></b> | 任何事物的发展都是一个过程 |

#### （八）对立统一规律　【唯物辩证法的实质与核心】

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>地位</nobr></b> | 揭示了事物发展的<b><nobr>源泉和动力</nobr></b>，是唯物辩证法的<b><nobr>实质与核心</nobr></b> |
| <b><nobr>矛盾的同一性</nobr></b> | 矛盾双方相互依存、相互贯通（在一定条件下相互转化） |
| <b><nobr>矛盾的斗争性</nobr></b> | 矛盾双方相互排斥、相互分离（相互对立、相互限制、相互否定） |
| <b><nobr>同一性与斗争性的关系</nobr></b> | 同一性是<b><nobr>有条件的、相对的</nobr></b>；斗争性是<b><nobr>无条件的、绝对的</nobr></b>；二者相结合构成事物的矛盾运动，推动事物发展 |
| <b><nobr>矛盾的普遍性（共性）</nobr></b> | 矛盾存在于一切事物中，存在于事物发展过程的始终（矛盾无处不在、无时不有） |
| <b><nobr>矛盾的特殊性（个性）</nobr></b> | ①不同事物的矛盾各有其特点；②同一事物的矛盾在不同发展阶段各有不同特点；③构成事物的诸多矛盾以及每一矛盾的不同方面各有不同的性质、地位和作用 |
| <b><nobr>普遍性与特殊性的关系</nobr></b> | 共性与个性、一般与个别的关系；<b><nobr>共性寓于个性之中</nobr></b>，个性比共性丰富 |
| <b><nobr>方法论（活的灵魂）</nobr></b> | <b><nobr>具体问题具体分析</nobr></b>——马克思主义活的灵魂 |
| <b><nobr>矛盾发展不平衡性</nobr></b> | 主要矛盾与次要矛盾、矛盾的主要方面与次要方面 ⟹ <b><nobr>两点论与重点论的统一</nobr></b> |
| <b><nobr>同一性在事物发展中的作用（三条）</nobr></b> | ①同一性是事物存在和发展的<b><nobr>前提</nobr></b>（一方的发展以另一方的发展为条件）；②使矛盾双方<b><nobr>相互吸取有利于自身的因素</nobr></b>，在相互作用中各自得到发展；③<b><nobr>规定着事物转化的可能和发展的趋势</nobr></b> |
| <b><nobr>斗争性在事物发展中的作用（两条）</nobr></b> | ①促进矛盾双方<b><nobr>力量的变化</nobr></b>，造成力量发展不平衡，为对立面的转化、事物的质变<b><nobr>创造条件</nobr></b>；②是一种矛盾统一体向另一种矛盾统一体<b><nobr>过渡的决定性力量</nobr></b> |
| <b><nobr>二者关系的方法论</nobr></b> | 善于把二者结合起来——<b><nobr>在斗争中把握同一性，在同一性中把握斗争性</nobr></b> |
| <b><nobr>人的认识一般规律</nobr></b> | <b><nobr>个别 → 一般 → 个别</nobr></b>（由认识个别上升到认识一般，再由一般到个别） |
| <b><nobr>"两个结合"的哲学基础</nobr></b> | 矛盾的<b><nobr>普遍性和特殊性辩证关系原理</nobr></b>——马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合 |

#### （九）质量互变规律

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>度</nobr></b> | 度是保持事物质的稳定性的<b><nobr>数量界限</nobr></b>；认识度才能确切把握事物的质，才能提出指导实践活动的正确准则 |
| <b><nobr>量变与质变的关系</nobr></b> | ①量变是质变的<b><nobr>必要准备</nobr></b>；②质变是量变的<b><nobr>必然结果</nobr></b>；③量变与质变相互渗透 |
| <b><nobr>方法论四条</nobr></b> | ①重视量的积累；②抓住时机，促成质变；③坚持适度原则；④事物发展是<b><nobr>连续性与阶段性</nobr></b>的统一 |

#### （十）否定之否定规律

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>辩证否定观四条</nobr></b> | ①否定是事物的<b><nobr>自我否定</nobr></b>；②否定是事物发展的环节；③否定是事物联系的环节；④辩证否定的实质是<b><nobr>"扬弃"</nobr></b>，即既克服又保留 |
| <b><nobr>否定之否定</nobr></b> | 两次否定、三个阶段（肯定 → 否定 → 否定之否定） |
| <b><nobr>发展道路</nobr></b> | 前进性与曲折性的统一（<b><nobr>螺旋式上升、波浪式前进</nobr></b>） |
| <b><nobr>方法论</nobr></b> | 对事物采取科学分析的态度，反对肯定一切或否定一切；正确对待前进中的挫折 |

#### （十一）五对基本范畴

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>原因与结果</nobr></b> | ①两者的区分既是确定的又是不确定的；②相互作用；③相互渗透；④因果关系复杂多样 |
| <b><nobr>必然与偶然</nobr></b> | ①必然性存在于偶然性之中，通过大量的偶然性表现出来；②偶然性背后隐藏着必然性、受必然性支配；③二者在一定条件下相互转化 |
| <b><nobr>可能与现实</nobr></b> | ①相互区别；②相互联系、相互转化（可能 → 现实，现实又产生新的可能） |
| <b><nobr>现象与本质</nobr></b> | ①现象是外部联系与表面特征，本质是内在联系与根本性质；②现象是个别的、片面的、多变易逝的，本质是一般的、共同的、相对稳定的；③现象是本质的表现，本质通过现象表现出来；④现象有<b><nobr>真象与假象</nobr></b>之分，<b><nobr>假象也是本质的表现</nobr></b> |
| <b><nobr>形式与内容</nobr></b> | ①内容决定形式，形式反作用于内容；②二者在一定条件下相互转化 |
| <b><nobr>原因与结果的铁律</nobr></b> | 原因在前、结果在后，<b><nobr>不能混淆和颠倒</nobr></b>（"倒因为果""倒果为因"必歪曲事实）；没有"无果之因""无因之果"，二者可相互转化 |
| <b><nobr>现象与本质的任务</nobr></b> | 科学任务＝<b><nobr>准确辨别真象和假象，透过现象把握本质</nobr></b>（去粗取精、去伪存真，由此及彼、由表及里） |
| <b><nobr>现实与可能的方法论</nobr></b> | 一方面<b><nobr>立足现实</nobr></b>，对可能性作全面分析预判；另一方面<b><nobr>着眼长远</nobr></b>，防止坏的可能变为现实、促使好的可能获得实现 |

#### （十二）辩证思维方法

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>四种方法</nobr></b> | 归纳与演绎、分析与综合、抽象与具体、逻辑与历史相统一 |
| <b><nobr>归纳与演绎</nobr></b> | 归纳是从个别到一般，演绎是从一般到个别；二者相互依存、相互补充 |
| <b><nobr>分析与综合</nobr></b> | 分析是在思维中把认识对象分解为不同部分来考察；综合是把分解出的各部分按内在联系组合为整体 |
| <b><nobr>抽象与具体</nobr></b> | 从<b><nobr>感性具体</nobr></b>到<b><nobr>思维抽象</nobr></b>，再从思维抽象上升到<b><nobr>思维具体</nobr></b> |
| <b><nobr>逻辑与历史相统一</nobr></b> | 历史是逻辑的基础，逻辑是历史在思维中的再现；逻辑与历史在<b><nobr>总趋势上</nobr></b>一致 |

#### （十三）六种思维能力　【学习唯物辩证法，不断增强思维能力】

| 提示 | 必背内容 |
|:---|:---|
| <b><nobr>六种思维</nobr></b> | 辩证、历史、系统、战略、底线、创新（口诀：<b><nobr>辩历系战底创</nobr></b>） |
| <b><nobr>辩证思维能力</nobr></b> | 用<b><nobr>批判的和革命的精神</nobr></b>、联系和发展的观点、唯物辩证法基本规律和范畴、辩证思维方法分析解决问题的能力；一言以蔽之——<b><nobr>发现矛盾、分析矛盾、解决矛盾，把握本质、遵循规律、指导实践</nobr></b> |
| <b><nobr>历史思维能力</nobr></b> | 辩证思维<b><nobr>与历史眼光的结合</nobr></b>，是马克思主义科学历史观的具体表现和实践运用；<b><nobr>以史为鉴、知古鉴今</nobr></b>，认识发展规律、把握前进方向、指导现实工作 |
| <b><nobr>历史·现实·未来</nobr></b> | 三者相通——历史是过去的现实，现实是未来的历史 |
