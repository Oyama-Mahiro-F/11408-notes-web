> 算法题注意事项：
>
> 1. 对需要操作的变量用 `&` 引用（或 `*` 指针）作为参数，才能把结果带回调用处（如 `int &value`、`SqList &L`）
> 2. for 循环的三个表达式之间用分号 `;` 分隔，不要误写成逗号 `,`（应写 `for(k=0; k<L.length; k++)`）。写成逗号后循环条件会变成最后一个表达式（如 `k++`），导致死循环（题 3、6、7 均犯此错）
> 3. 判断相等用 `==`，不要写成赋值 `=`：`if(L.length = 0)` 条件恒为假，还会把表长误改成 0（题 7）
> 4. 循环边界注意是否取等：`i <= c` 在偶数长度逆置时会多交换一次、把结果又换回去（题 4）；`data[i] <= s` 会漏删等于 s 的元素（题 6）。统一写成 `i < L.length` 更安全
> 5. 更新 `L.length` 的语句放在循环外，且值必须是新表的实际元素个数：删除全部 x 后是 k（题 5）、去重后是 j+1 而不是 j（题 7）
> 6. 需要把结果带回调用处的参数用引用（题 3 的 value 漏了 `&`），并且所有分支都要写 return（题 6 漏了 `return true;`）
> 7. 内层 while 要加越界保护 `while(i < j && ...)`：全是奇数/全是偶数时 i、j 会越界（题 8）
> 8. 删除一段连续区间 [i, j] 后，新表长 = 原表长 - (j - i + 1)（题 2、6）；移动循环结束后变量值已改变，长度要用原来的 i、j 计算或直接取移动后的 i
>
> 说明：每题给出**批改标注后的代码**——原错误行以注释形式保留（`// ✗` 标注错误原因），正确代码保留为可运行的语句，整段代码可直接编译验证；其后附**错误解释**。5~8 题原题缺失题干，已根据伪代码补全。

##### 3. 删除顺序表中最小的元素，返回删除值，并用最后一个元素填补空出的位置，若顺序表为空，则报错并退出

```c++

// bool DeleteMIN(SqList &L,int value){
bool DeleteMin(SqList &L,int &value){

        return false;
    }
    // ✗ 错误 2：int min; 声明后从未使用（多余变量），已删除
    int p=0;                         // ✓ 记录最小值下标
    // ✗ 错误 3：① k 未声明（编译错误）；② 逗号应为分号，否则条件变成 k++，恒真 → 死循环；
```

**错误解释**：

1. **返回值丢失**：`value` 必须用引用 `int &value` 才能把最小值带回调用处（对应注意事项 1、6）。
2. **多余变量**：`int min;` 从未使用，应删除。
3. **for 语句三处错误**：`k` 未声明；两个分隔符误写成逗号（条件变成 `k++`，永远为真 → 死循环）；边界可简化为 `k < L.length`。

##### 4. 逆置顺序表 L 中的所有元素，要求复杂度为O(1)

```c++
// ✗ 题目表述有误：逆置至少需要 O(n) 时间，题中“复杂度为 O(1)”应指空间复杂度 O(1)
void Reverse(SqList &L){
    int c=L.length/2;
    int temp,i;
    // ✗ 错误：i<=c 取等，偶数长度时会多交换一次、把已换好的元素又换回去（长度 4 时 (1,2) 被换两次）；
    //   应为 i < c
    // for(i=0;i<=c;i++){
    for(i=0;i<c;i++){                // ✓
        temp=L.data[i];
        L.data[i]=L.data[L.length-i-1];
        L.data[L.length-i-1]=temp;
    }
}
```

**错误解释**：

1. **边界多取一次等号**：`i <= c` 在偶数长度时出错。例：长度 4，c=2，执行 i=0、1、2 三次交换：先换 (0,3)、(1,2)，i=2 时换 (2,1) 又撤销了 (1,2)，最终未完全逆置。奇数长度时 i=c 是中间元素自交换（无害但多余），所以必须改为 `i < c`。
2. **题目复杂度表述**：应改为“时间复杂度 O(n)、空间复杂度 O(1)”（辅助空间只有 temp）。

##### 5. 删除顺序表中所有值等于 x 的元素（原题缺失题干，已根据伪代码补全）

```c++
// 原代码其余部分正确，仅 L.length 更新位置有误：

        // L.length=k;
    }
```

##### 6. 从有序顺序表中删除其值在 s 与 t 之间（含 s、t，s<t）的所有元素，若 s>t 或表空则返回 false（原题缺失题干，已根据伪代码补全）

```c++
bool Delete_s_t(SqList &L,int s,int t){
    if(L.length==0||s>t){
        return false;
    }
    int i=0,j=L.length-1;
    // ✗ 错误 1：原条件 L.data[i]<=s 会让 i 停在第一个大于 s 的元素，等于 s 的元素漏删；
    //   应为 L.data[i]<s（i 停在第一个 >=s 的元素）；另需加越界保护（表内元素全部 <s 时）
    // for(i=0;L.data[i]<=s;i++);
    while(i<L.length&&L.data[i]<s){  // ✓ i：第一个 >=s 的元素（区间起点）
        i++;
    }
    // ✗ 错误 2（原第二行）：① 逗号应为分号；② 条件引用了 i，应为 j；③ 比较方向错。
    //   应从表尾向前找最后一个 <=t 的元素，条件为 L.data[j]>t
    // for(j=L.length-1,L.data[i]>=s,j--);
    while(j>=0&&L.data[j]>t){        // ✓ j：最后一个 <=t 的元素（区间终点）
        j--;
    }
    if(i>j){                         // ✓ 新增：表中没有值在 [s,t] 内的元素
        return false;
    }
    // ✗ 错误 3：原移动循环从 j 开始复制，而 j 自己指向的是待删除区间内的元素，
    //   不应被复制上移；应从 j+1 开始
    // for(;j<L.length;i++,j++){ L.data[i]=L.data[j]; }
    for(int k=j+1;k<L.length;k++){   // ✓ 从 j+1 开始，区间后面的元素整体前移
        L.data[i++]=L.data[k];
    }
    // ✗ 错误 4：移动循环结束后 i、j 的值已改变，原公式不能再用来计算长度
    // L.length=L.length-j+i-1;
    L.length=i;                      // ✓ 正确：新表长 = 移动完成后的 i
    // ✗ 错误 5：原代码缺少成功返回
    return true;                     // ✓
}
```

**错误解释**：

1. **区间起点定位错误**：`data[i] <= s` 漏删等于 s 的元素；要求删闭区间 [s,t]（含 s、t），应写 `data[i] < s`。
2. **第二个 for 完全写错**：分隔符写成了逗号；条件里用错变量（应为 `j`）；方向也错——应从表尾向前找最后一个 ≤ t 的元素，条件为 `L.data[j] > t`。
3. **移动起点错误**：j 停在区间 [i,j] 内（值在 [s,t] 中），区间后的元素从 j+1 开始前移；原代码从 j 开始复制，把应删的元素又复制上来了。
4. **长度计算时机错误**：移动循环结束后 i、j 已改变，原公式失效；正确做法是移动完成后 `L.length = i`（i 恰好是新表长）。
5. **缺少成功返回**：删除成功路径没有 return，应补 `return true;`（对应注意事项 6）。

##### 7. 从有序顺序表中删除所有值重复的元素，使表中各元素值均不同（原题缺失题干，已根据伪代码补全）

```c++

bool DeleteSame(SqList &L){
    // ✗ 错误 1：赋值号 = 应为比较 ==。写成赋值后：先把 L.length 误改成 0（破坏数据），
    //   再把 0 当条件（恒为假）→ 空表不会返回 false
    // if(L.length=0){
    if(L.length==0){                 // ✓
```

##### 8. 将顺序表 L 中的所有奇数移动到所有偶数之前（原题缺失题干，已根据伪代码补全）

```c++
void Switch(SqList &L){              // 奇数在前、偶数在后，O(n) 时间、O(1) 空间
    int i=0;
    int j=L.length-1;
    while(i<j){
        // ✗ 错误 1、2：内层 while 无越界保护——全是奇数时 i 会一直加到 L.length 之外越界；
        //   全是偶数时 j 会减到 -1 越界；应加 i<j 条件
        // while(L.data[i]%2!=0){ i++; }
        while(i<j&&L.data[i]%2!=0){  // ✓ 跳过奇数，找第一个偶数
            i++;
        }
        // while(L.data[j]%2==0){ j--; }
        while(i<j&&L.data[j]%2==0){  // ✓ 跳过偶数，找第一个奇数
            j--;
        }
        // ✗ 错误 3：内层循环因 i>=j 退出时（已没有可交换的“左偶右奇”），原代码仍会交换一次，
        //   把已排好的位置弄乱。例：[1,3,2,4]——i 停在 2、j 停在 1（i>j），交换后变成 [1,2,3,4]，
        //   偶数反而跑到奇数前面了。应加 if(i<j) 判断再交换
        if(i<j){                     // ✓
            int temp=L.data[i];
            L.data[i]=L.data[j];
            L.data[j]=temp;
            i++;
            j--;                     // ✗ 错误 4：原代码这里漏了 j--（写成孤立的“j”，什么都不做），
        }                            //   交换后右指针没有收缩
    }
}
```

**错误解释**：

1. **内层 while 越界**：全为奇数时 `L.data[i]%2!=0` 恒真，i 一直加到越界；全为偶数时 j 一直减到 -1 越界。应写成 `while(i < j && L.data[i]%2!=0)`（对应注意事项 7）。
2. **交换缺少保护**：内层循环因 i ≥ j 退出时本应结束，却仍执行交换（例见注释）。
3. **缺少 `j--`**：交换后 `i++` 了但 `j` 没减，两个指针没有同时向中间收缩。
