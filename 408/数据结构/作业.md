> 算法题注意事项：
>
> 1. 对需要操作的变量用 `&` 引用（或 `*` 指针）作为参数，才能把结果带回调用处（如 `int &value`、`SqList &L`）
> 2. for 循环的三个表达式之间用分号 `;` 分隔，不要误写成逗号 `,`（应写 `for(k=0; k<L.length; k++)`）。写成逗号后循环条件会变成最后一个表达式（如 `k++`），导致死循环（题 3、6、7 均犯此错）
> 3. 判断相等用 `==`，不要写成赋值 `=`：`if(L.length = 0)` 条件恒为假，还会把表长误改成 0（题 7）
> 4. 循环边界注意是否取等：`i <= c` 在偶数长度逆置时会多交换一次、把结果又换回去（题 4）；`data[i] <= s` 会漏删等于 s 的元素（题 6）。统一写成 `i < L.length` 更安全
> 5. 更新 `L.length` 的语句放在循环外，且值必须是新表的实际元素个数：删除全部 x 后是 k（题 5）、去重后是 j+1 而不是 j（题 7）
> 6. 需要把结果带回调用处的参数用引用（题 3 的 value 漏了 `&`），并且所有分支都要写 return（题 6 漏了 `return true;`）
> 7. 内层 while 要加越界保护 `while(i < j && ...)`：全是奇数/全是偶数时 i、j 会越界（题 8）
> 8. 删除一段连续区间 [i, j] 后，新表长 = 原表长 - (j - i + 1)（题 2、6）；移动循环结束后变量值已改变，长度要用原来的 i、j 计算或直接取移动后的 i
> 9. 函数定义不能只有返回类型和参数表，必须写函数名：`bool(char A[])` 缺函数名，编译不过（栈题 3(2)）；关键字别拼错（`wehile` → `while`）
> 10. 数组作函数参数会退化为指针，**没有 `.length` 成员**（栈题 3(2) 编译不过）；遍历一维数组要么另传长度 n，要么用结束符 `'\0'` 判断
> 11. 判定合法性的循环条件必须与"序列是否扫描完"挂钩，写成 `while(A[k]!='\0')`；`while(sum>=0)` 只约束"栈不空"，序列末尾入栈多于出栈时会死循环且下标越界（栈题 3(2)）
> 12. 合法性/最终结论一律放在**扫描结束后**判断（`return sum==0;`）；`return` 之后不要再写 `break`（不可达语句），并确保所有分支都有返回值
>
> 说明：每题给出**批改标注后的代码**——原错误行以注释形式保留（`// ✗` 标注错误原因），正确代码保留为可运行的语句，整段代码可直接编译验证；其后附**错误解释**。5~8 题原题缺失题干，已根据伪代码补全；栈部分题 3(2)、题 5 出自《考研计算机题型精练（数据结构）》第一部分 3、栈·综合应用题。

##### 6. 从有序顺序表中删除其值在 s 与 t 之间（含 s、t，s<t）的所有元素，若 s>t 或表空则返回 false（原题缺失题干，已根据伪代码补全）

```c++
bool Delete_s_t(SqList &L,int s,int t){
    if(L.length==0||s>t){
        return false;
    }
    int i=0,j=L.length-1;
    // ✗ 错误 1：原条件 L.data[i]<=s 会让 i 停在第一个大于 s 的元素，等于 s 的元素漏删；
    //   应为 L.data[i]<s（i 停在第一个 >=s 的元素）；另需加越界保护（表内元素全部 <s 时）
    // for(i=0;L.data[i]<=s;i++);
    while(i<L.length&&L.data[i]<s){  // ✓ i：第一个 >=s 的元素（区间起点）
        i++;
    }
    // ✗ 错误 2（原第二行）：① 逗号应为分号；② 条件引用了 i，应为 j；③ 比较方向错。
    //   应从表尾向前找最后一个 <=t 的元素，条件为 L.data[j]>t
    // for(j=L.length-1,L.data[i]>=s,j--);
    while(j>=0&&L.data[j]>t){        // ✓ j：最后一个 <=t 的元素（区间终点）
        j--;
    }
    if(i>j){                         // ✓ 新增：表中没有值在 [s,t] 内的元素
        return false;
    }
    // ✗ 错误 3：原移动循环从 j 开始复制，而 j 自己指向的是待删除区间内的元素，
    //   不应被复制上移；应从 j+1 开始
    // for(;j<L.length;i++,j++){ L.data[i]=L.data[j]; }
    for(int k=j+1;k<L.length;k++){   // ✓ 从 j+1 开始，区间后面的元素整体前移
        L.data[i++]=L.data[k];
    }
    // ✗ 错误 4：移动循环结束后 i、j 的值已改变，原公式不能再用来计算长度
    // L.length=L.length-j+i-1;
    L.length=i;                      // ✓ 正确：新表长 = 移动完成后的 i
    // ✗ 错误 5：原代码缺少成功返回
    return true;                     // ✓
}
```

**错误解释**：

1. **区间起点定位错误**：`data[i] <= s` 漏删等于 s 的元素；要求删闭区间 [s,t]（含 s、t），应写 `data[i] < s`。
2. **第二个 for 完全写错**：分隔符写成了逗号；条件里用错变量（应为 `j`）；方向也错——应从表尾向前找最后一个 ≤ t 的元素，条件为 `L.data[j] > t`。
3. **移动起点错误**：j 停在区间 [i,j] 内（值在 [s,t] 中），区间后的元素从 j+1 开始前移；原代码从 j 开始复制，把应删的元素又复制上来了。
4. **长度计算时机错误**：移动循环结束后 i、j 已改变，原公式失效；正确做法是移动完成后 `L.length = i`（i 恰好是新表长）。
5. **缺少成功返回**：删除成功路径没有 return，应补 `return true;`（对应注意事项 6）。

##### 8. 将顺序表 L 中的所有奇数移动到所有偶数之前（原题缺失题干，已根据伪代码补全）

```c++
void Switch(SqList &L){              // 奇数在前、偶数在后，O(n) 时间、O(1) 空间
    int i=0;
    int j=L.length-1;
    while(i<j){
        // ✗ 错误 1、2：内层 while 无越界保护——全是奇数时 i 会一直加到 L.length 之外越界；
        //   全是偶数时 j 会减到 -1 越界；应加 i<j 条件
        // while(L.data[i]%2!=0){ i++; }
        while(i<j&&L.data[i]%2!=0){  // ✓ 跳过奇数，找第一个偶数
            i++;
        }
        // while(L.data[j]%2==0){ j--; }
        while(i<j&&L.data[j]%2==0){  // ✓ 跳过偶数，找第一个奇数
            j--;
        }
        // ✗ 错误 3：内层循环因 i>=j 退出时（已没有可交换的“左偶右奇”），原代码仍会交换一次，
        //   把已排好的位置弄乱。例：[1,3,2,4]——i 停在 2、j 停在 1（i>j），交换后变成 [1,2,3,4]，
        //   偶数反而跑到奇数前面了。应加 if(i<j) 判断再交换
        if(i<j){                     // ✓
            int temp=L.data[i];
            L.data[i]=L.data[j];
            L.data[j]=temp;
            i++;
            j--;                     // ✗ 错误 4：原代码这里漏了 j--（写成孤立的“j”，什么都不做），
        }                            //   交换后右指针没有收缩
    }
}
```

**错误解释**：

1. **内层 while 越界**：全为奇数时 `L.data[i]%2!=0` 恒真，i 一直加到越界；全为偶数时 j 一直减到 -1 越界。应写成 `while(i < j && L.data[i]%2!=0)`（对应注意事项 7）。
2. **交换缺少保护**：内层循环因 i ≥ j 退出时本应结束，却仍执行交换（例见注释）。
3. **缺少 `j--`**：交换后 `i++` 了但 `j` 没减，两个指针没有同时向中间收缩。

##### 3.（2）判定所给的操作序列是否合法，合法返回 true，否则返回 false

> **题干**（题型精练·第一部分 3、栈·综合应用题 3(2)）：以 I 和 O 分别表示入栈和出栈操作，栈的初态和终态均为空，入栈和出栈的操作序列可表示为仅由 I、O 组成的序列，能顺利操作的序列称为**合法序列**，否则称为非法序列。写出一个算法判定所给的操作序列是否合法：合法返回 `true`，否则返回 `false`（假定被判定的操作序列已存入一维数组 A 中）。
>
> **判据**：把序列看作一串 $+1$（入栈）/ $-1$（出栈），合法 $\iff$ **任意前缀和 $\ge 0$**（不能空栈出栈）且**总和 $=0$**（终态栈空）。

```c++
// ✗ 错误 1：函数定义缺少函数名，只剩返回类型和参数表，编译不过；应补上函数名
// bool(char A[]){
bool Judge(char A[]){
    int sum=0;                       // ✓ 栈内元素个数：入栈 +1、出栈 -1（教材"另解"的思路，与 +1/-1 序列判定等价）
    int k=0;                         // ✓ 扫描下标
    // ✗ 错误 2：wehile 拼写错误，应为 while（编译不过）
    // ✗ 错误 3：循环条件与"序列是否扫描完"无关——sum>=0 只说明"此刻栈没空"：
    //   若序列末尾入栈多于出栈（如 III），sum 恒 ≥0，循环永不退出、k 一直自增 → 数组越界。应以"未扫描到序列结尾"为条件
    // wehile(sum>=0){
    while(A[k]!='\0'){               // ✓ 扫描到序列结束（题目约定序列以 '\0' 收尾）
        // ✗ 错误 4：① 赋值号 = 误写成比较 ==，会把 A[k] 改写成 1，且赋值表达式恒为真 →
        //   所有操作都被当成"入栈"，sum 只增不减，合法性判定彻底失效；
        //   ② 字符数组元素是 'I'/'O'，不能与整数 1 比较
        // if(A[k]=1){
        if(A[k]=='I'){               // ✓ 入栈
            sum++;
        }else{                       // 'O'：出栈
            sum--;
        }
        k++;
        // ✗ 错误 5：出栈后若 sum<0，说明"栈空还要出栈"，序列非法，应立即返回
        if(sum<0){
            return false;
            // ✗ 错误 6：return 之后的 break 永远执行不到（不可达语句），冗余，删除
            // break;
        }
        // ✗ 错误 7：① A 作参数会退化为指针，没有 .length 成员（编译不过）；
        //   ② 判定放在循环内、还用"最后一个下标"作条件，逻辑错：若最后一步是入栈，
        //   此时 sum=1，该分支不成立，循环会带着 sum>0 继续 → 越界。合法性应在扫描结束后统一判定
        // if((k==A.length-1)&&(sum==0)){
        //     return true
        // }
    }
    // ✗ 错误 8：原代码没有覆盖全部路径的返回值，且 return true 漏了分号（编译不过）
    return sum==0;                   // ✓ 扫描结束：入栈次数 == 出栈次数（终态栈空）才合法
}
```

**错误解释**：

1. **缺少函数名**：`bool(char A[])` 只有返回类型与参数表，编译器无法识别（对应注意事项 9），应写 `bool Judge(char A[])`。
2. **关键字拼写**：`wehile` → `while`。
3. **循环条件错**：合法序列的判定必须**遍历完整个序列**。`while(sum>=0)` 只约束"栈不空"，与扫描进度无关；序列末尾若入栈多于出栈（如 `III`），`sum` 恒 ≥0，循环不终止、`k` 越界读取（对应注意事项 11）。应改为 `while(A[k]!='\0')`。
4. **`=` 与 `==`**：`if(A[k]=1)` 先把 `A[k]` 赋成 1、再以 1 作条件（恒真），于是全部操作都按入栈处理；且字符数组元素是 `'I'`/`'O'`，与整数 1 比较无意义。正确写法 `if(A[k]=='I')`（对应注意事项 3）。
5. **判定时机错**：原代码在循环内用 `k==A.length-1` 判定，既依赖不存在的 `A.length`，又漏掉"最后一步是入栈（此时 sum=1）"的情形 → 越界。正确做法是循环外统一判定（对应注意事项 12）。
6. **不可达语句**：`return false;` 之后的 `break;` 永远不会执行，应删除。
7. **返回值缺失**：`return true` 少了分号；函数在所有路径上都应有返回值。

> **说明**：以上按教材口径改写（数组存字符 `'I'`/`'O'`，以 `'\0'` 结尾）。若题目约定数组存整数 1（入栈）/ 0（出栈），只需两处对应替换——`while(A[k]!='\0')` → `while(k<n)`（把序列长度 n 一并传入）、`A[k]=='I'` → `A[k]==1`；算法结构与上述错误点完全相同。
>
> **考点**：合法序列 $\iff$ 任意前缀和 $\ge 0$ 且总和 $=0$，即"任意时刻入栈次数 $\ge$ 出栈次数"且"结束时栈空"。
> **易错点**：① 循环条件写成 `sum>=0`，末尾入栈多时死循环 + 越界；② 把最终判定塞在循环内而不是扫描结束后；③ 数组参数无 `.length`。

##### 5. 证明：输出序列中不可能出现 $i<j<k$ 使 $P_j<P_k<P_i$

> **题干**（题型精练·第一部分 3、栈·综合应用题 5）：试证明若借助栈可由输入序列 $1,2,3,\dots,n$ 得到一个输出序列 $P_1,P_2,P_3,\dots,P_n$（它是输入序列的某一种排列），则在输出序列中不可能出现以下情况：存在 $i<j<k$，使得 $P_j<P_k<P_i$。（提示：用反证法）

**证明**：记 $x=P_i$、$y=P_j$、$z=P_k$，题设即 **$y<z<x$**，且三者在输出序列中的先后顺序为 **$x\to y\to z$**（$x$ 最先出栈，$z$ 最后出栈）。用反证法，假设这样的 $i<j<k$ 存在。

1. 输入序列按值递增进栈，故三者的**入栈顺序为 $y\to z\to x$**（$y$ 最小先入栈，$x$ 最大后入栈）。
2. $x$ 最后入栈；且 $y$、$z$ 此刻都还没出栈（它们分别在位置 $j$、$k$ 出栈，都不早于位置 $i$ 的 $x$），因此 $x$ 入栈时 **$y$、$z$ 都已在栈中**。又因 $y$ 早于 $z$ 入栈，栈内自底向上为 $y,z$，$x$ 再压在 $z$ 之上。
3. 输出序列中 $x$ 最先出栈（$P_i$ 在位置 $i$），与"$x$ 位于栈顶"一致，这一步可以做到。
4. $x$ 出栈后，栈顶是 **$z$**（$z$ 压在 $y$ 之上），按后进先出（LIFO），下一个能出栈的只能是 $z$。
5. 但题设要求紧接着出栈的是 **$y$**（$P_j$ 在位置 $j$，早于 $P_k$）。$y$ 被 $z$ 压在下面，**不可能先于 $z$ 出栈**，矛盾。

故假设不成立，命题得证。∎

> **直观记忆**：合法的栈输出序列中不允许出现 **"大、小、中"（312 模式）**——较大的数先出栈时，比它小的数都在栈内被"降序"压着，只能按后进先出的逆序出栈，不可能再冒出一对递增的。
>
> **例**：$n=3$ 时序列 $3,1,2$ 违反命题（取 $i=1$、$j=2$、$k=3$：$P_j=1<P_k=2<P_i=3$）。$1,2,3$ 的合法出栈序列只有 $123$、$132$、$213$、$231$、$321$ 共 $5$ 种（卡特兰数 $C_3=\dfrac{1}{3+1}\dbinom{6}{3}=5$），不含 $312$。
