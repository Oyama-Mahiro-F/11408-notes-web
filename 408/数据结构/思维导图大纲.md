## 一、基本概念（笔记：第1章 绪论）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC1%E7%AB%A0%20%E7%BB%AA%E8%AE%BA.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 【25新增】数据结构的基本概念：三要素 = 逻辑结构 + 存储结构 + 数据的运算
  - 数据项 < 数据元素（基本单位）< 数据对象（相同性质数据元素的集合）
  - 逻辑结构四类：集合、线性、树形、图形；存储结构四类：顺序、链式、索引、散列
  - 运算的定义针对逻辑结构，运算的实现针对存储结构（高频判断题）
- 【25新增】算法的基本概念：算法是对特定问题求解步骤的描述
  - 五个特性：有穷性、确定性、可行性、输入、输出（程序可以不满足有穷性）
  - 设计目标：正确性、可读性、健壮性、高效性（时间高效 + 存储低耗）
  - 算法与程序的区别：程序可以无限循环，算法必须有穷
- 时间复杂度：大 $O$ 记号是渐进上界，只保留最高阶、忽略常数
  - 单层看执行次数：`i=1; while(i<=n) i*=3;` → $O(\log_3 n) = O(\log n)$
  - 双层内层依赖外层：$\sum_{i=1}^{n} i \approx n^2/2$ → $O(n^2)$
  - 递归式：$T(n)=T(n-1)+O(1)$ → $O(n)$；$T(n)=T(n-1)+O(n)$ → $O(n^2)$；$T(n)=2T(n/2)+O(n)$ → $O(n\log n)$
- 空间复杂度：只统计辅助空间，与 $n$ 无关即 $O(1)$
  - 原地工作 $O(1)$；递归算法空间 = 递归栈深度，不是调用总次数
  - 顺序表插入删除、链表操作的空间开销各有来源，比较时先明确口径
- 最好、最坏与平均时间复杂度
  - 平均复杂度常按等概率假设计算，考试先写清假设
  - $O(n)$ 的算法不一定比 $O(n^2)$ 的算法快（$n$ 小或常数因子大时相反）
- 常用复杂度增长阶比较
  - $O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$
  - 折半、平衡树、堆操作是 $O(\log n)$ 级；排序下界 $O(n\log n)$ 只对基于比较的排序成立

## 二、线性表（笔记：第2章 线性表）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC2%E7%AB%A0%20%E7%BA%BF%E6%80%A7%E8%A1%A8.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 线性表的基本概念：$n$ 个数据元素的有限序列，元素类型相同、有唯一前驱与后继
  - 逻辑结构是线性结构，可用顺序存储或链式存储实现
  - 常见运算：初始化、求表长、按位查找、按值查找、插入、删除
- 顺序存储（顺序表）：逻辑相邻即物理相邻，支持随机存取
  - 按位查找 $O(1)$；按值查找 $O(n)$（有序时可折半到 $O(\log n)$）
  - 静态分配（定长数组）vs 动态分配（malloc/realloc 扩容）；位序与数组下标差 1
- 顺序表插入与删除的移动次数
  - 长度 $n$ 的表第 $i$ 位插入移动 $n-i+1$ 个，等概率平均 $n/2$
  - 删除第 $i$ 位移动 $n-i$ 个，等概率平均 $(n-1)/2$；插入删除平均时间均 $O(n)$
- 链式存储（单链表）：结点 = 数据域 + 指针域，只能顺序存取
  - 头结点的作用：首位置插入删除与中间统一、空表与非空表处理统一；头指针 vs 头结点 vs 首元结点
  - 头插法建表（逆序）vs 尾插法建表（顺序，需尾指针）
  - 按序号查找 $O(n)$，定位后插入删除 $O(1)$；$O(1)$ 删除结点 $*p$ 需把后继值复制到 p（尾结点不适用）
- 双链表、循环链表与静态链表
  - 双链表插入四步顺序：`s->next=p->next; s->prior=p; p->next->prior=s; p->next=s;`
  - 循环单链表判空 `L->next==L`；只设**尾指针**时找头找尾都 $O(1)$，两表合并 $O(1)$
  - 静态链表：数组 + 游标（next 存数组下标），容量固定，适合不支持指针的语言
- 顺序表与链表的选型
  - 存取方式：顺序表随机存取，链表顺序存取；链表不改变查找效率，只改变插入删除的代价
  - 空间：链表每结点多一个指针域；顺序表需预分配、扩容有搬移代价
  - 频繁按位查找、表长可预估 → 顺序表；频繁插入删除、表长变化大 → 链表
- 线性表的应用：有序表合并 $O(n+m)$；删除重复结点；就地逆置；求并集与交集

## 三、栈、队列和数组（笔记：第3章 栈 / 第4章 队列 / 第9章 数组）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC3%E7%AB%A0%20%E6%A0%88.md)（第3章 栈） · [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC4%E7%AB%A0%20%E9%98%9F%E5%88%97.md)（第4章 队列） · [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC9%E7%AB%A0%20%E6%95%B0%E7%BB%84.md)（第9章 数组） · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 栈的基本概念与顺序存储：后进先出，只在栈顶插入删除
  - top 指向栈顶元素（初值 −1）：入栈 `S[++top]=x`，空 `top==-1`，满 `top==MaxSize-1`
  - top 指向栈顶下一空位（初值 0）：入栈 `S[top++]=x`，空 `top==0`——先看清题目约定
- 共享栈与链栈
  - 共享栈：两栈底在数组两端、栈顶相向增长，满条件 `top1+1==top2`，只有整体满才溢出
  - 链栈：头插法入栈，无栈满问题；出栈即删除首元结点
- 出栈序列与卡特兰数
  - $n$ 个元素依次入栈的合法出栈序列数 $= \frac{C_{2n}^{n}}{n+1}$（$n=3$ 时为 5）
  - 判合法：任意时刻出栈的元素必须是当前栈顶——1,2,3 入栈时 **312 非法、321 合法**
- 栈的典型应用
  - 括号匹配、进制转换、递归与函数调用栈（保存返回地址、参数、局部变量）
  - 中缀转后缀：栈顶运算符优先级不低于当前则先弹出；后缀求值：弹两个数，**先弹的是右操作数**
- 队列的基本概念与循环队列：先进先出
  - 顺序队列"假溢出" → 循环队列 `rear=(rear+1)%MaxSize`
  - 牺牲一格法：队空 `front==rear`，队满 $(\text{rear}+1) \bmod \text{MaxSize} = \text{front}$，元素数 $(\text{rear}-\text{front}+\text{MaxSize}) \bmod \text{MaxSize}$
  - 另有增设 size、增设 tag 两种判满方案，看清题目用哪种
- 链式队列与双端队列
  - 链式队列 front 指头结点、rear 指尾结点；出队到只剩一个元素时要**把 rear 也指回**
  - 只设尾指针的循环单链表可同时作队列（尾进头出）
  - 双端队列：输入受限与输出受限，给定序列判断能否得到（两侧模拟插入）
- 栈、队列和数组的应用
  - 栈：括号匹配、表达式求值、进制转换、递归消除
  - 队列：二叉树层序遍历、图的 BFS、缓冲区、页面置换 FIFO
- 【21增】多维数组的存储：行优先与列优先的地址计算
  - 二维行优先：$\text{LOC}(i,j) = \text{LOC}(0,0) + (i \times n + j) \times L$（$n$ 列、下标从 0）；列优先改为 $(j \times m + i)$
  - 三维按行优先线性化：$(i,j,k)$ 的偏移 $= i \times n \times p + j \times p + k$（$n$ 行、$p$ 页）
  - 数组是随机存取结构，压缩存储不改变其"给定下标算地址 $O(1)$"的性质
- 特殊矩阵的压缩存储
  - 对称矩阵按行存下三角（含对角线、$i \ge j$）：$i,j$ 与 $k$ 同从 0 起 $k = \frac{i(i+1)}{2} + j$；同从 1 起 $k = \frac{i(i-1)}{2} + j$；**笔记口径**（$i,j$ 从 1 起、一维数组 $B$ 下标从 0 起）$k = \frac{i(i-1)}{2} + j - 1$——下标起法决定公式
  - 上三角元素利用对称性 $a_{ij} = a_{ji}$ 换算；三对角矩阵（1 起）$a_{ij} \to k = 2i + j - 3$
  - 对称矩阵、三角矩阵、三对角矩阵压缩后仍能 $O(1)$ 随机存取
- 稀疏矩阵的存储与转置
  - 三元组表（行、列、值）与十字链表（行头结点 + 列头结点循环链表）；三元组表失去随机存取
  - 转置：按列序转置 $O(\text{列数} \times \text{非零元数})$；快速转置用 num/cpot 辅助数组 $O(\text{列数} + \text{非零元数})$

## 四、树与二叉树（笔记：第5章 树）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC5%E7%AB%A0%20%E6%A0%91.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 树的基本概念与性质
  - 结点数 = 总度数 + 1 = 边数 + 1；度为 $m$ 的树至少有 $m+1$ 个结点
  - $m$ 叉树第 $i$ 层最多 $m^{i-1}$ 个结点；高 $h$ 最多 $\frac{m^h-1}{m-1}$ 个结点
  - $n_0 = 1 + \sum_{i \ge 2}(i-1)n_i$；树没有中根遍历
- 二叉树定义及其主要特征
  - $n_0 = n_2 + 1$；第 $i$ 层最多 $2^{i-1}$ 个结点；高 $h$ 最多 $2^h - 1$ 个结点
  - 完全二叉树 $n$ 个结点高度 $= \lceil \log_2(n+1)\rceil$；$i$ 的双亲 $\lfloor i/2 \rfloor$，孩子 $2i$、$2i+1$
  - 满二叉树、完全二叉树、真二叉树（无度 1 结点）的判定与相互关系
- 二叉树的顺序存储与链式存储
  - 顺序存储适合完全二叉树（不浪费）；一般二叉树最坏需 $2^h - 1$ 个单元
  - 二叉链表（2 个指针域）与三叉链表（3 个，便于找双亲）；$n$ 个结点共 $n+1$ 个空链域
- 二叉树的遍历
  - 先序、中序、后序（递归与非递归，中序非递归一路向左入栈）；层序用队列
  - 中序 +（先序 或 后序 或 层序）可唯一还原；**先序 + 后序不能**（真二叉树可以）
  - 叶结点在前、中、后序中的相对次序相同；会由两种序列手推树形与第三种序列
- 线索二叉树的基本概念和构造
  - 用 $n+1$ 个空链域：左空指前驱、右空指后继，另加 ltag/rtag 标志
  - 中序线索化后找中序前驱/后继 $O(1)$，是"无栈遍历"的基础
  - 先序线索找先序前驱、后序线索找后序后继困难（需双亲信息或从根出发）
- 树的存储结构
  - 双亲表示法：找双亲 $O(1)$，找孩子要扫全表；适合并查集
  - 孩子表示法：顺序存结点 + 孩子链表；孩子兄弟表示法：左孩子右兄弟，是树与二叉树转换的桥梁
- 森林与二叉树的转换
  - 树转二叉树：左孩子右兄弟，转换后根结点**无右子树**
  - 森林转二叉树：各树根视为兄弟（互为右孩子）；二叉树转森林：根有右孩子则沿右链拆分
- 树和森林的遍历
  - 树的先根遍历 = 对应二叉树的先序；树的后根遍历 = 对应二叉树的中序
  - 森林的先序遍历 = 二叉树先序；森林的中序遍历 = 二叉树中序
- 哈夫曼树和哈夫曼编码
  - $n$ 个叶结点的哈夫曼树共 $2n-1$ 个结点、无度 1 结点；$WPL = \sum w_i l_i$ 最小
  - 构造：每次合并权值最小的两棵子树；权值相同时树形可不唯一，WPL 唯一
  - 编码是前缀码（左 0 右 1），总编码长度 = WPL，频率高的字符编码短
- 【22增】并查集及其应用
  - 双亲表示法用数组存储，Find 沿双亲向上直到根；Union 可让一棵树根指向另一棵树根
  - 按大小或按高度合并，树高 $\le \lfloor \log_2 n \rfloor + 1$；路径压缩后单次操作接近 $O(\alpha(n))$
  - 应用：Kruskal 判环、动态连通性与等价类统计
- 【25新增】堆及其应用：堆 = 完全二叉树 + 堆序性质
  - 大根堆 $k_i \ge k_{2i}, k_{2i+1}$，小根堆反之；**兄弟之间没有大小关系**
  - 顺序存储（1 起下标）双亲 $\lfloor i/2 \rfloor$、孩子 $2i$、$2i+1$，故堆只适合顺序存储
  - 自下而上建堆：从 $\lfloor n/2 \rfloor$ 起逐个向前下沉，时间 $O(n)$；自上而下逐个插入建堆是 $O(n\log n)$
  - 插入：新元素放末尾后**上浮** $O(\log n)$；删除堆顶：末尾元素补顶再**下沉** $O(\log n)$
- 【25新增】堆的典型应用：优先队列
  - 优先队列出队总是当前优先级最高的元素，堆实现插入与删除都是 $O(\log n)$
  - Top-K：维护大小为 $k$ 的堆（前 $k$ 大用小根堆），时间 $O(n\log k)$、空间 $O(k)$
  - 合并 $m$ 个有序表：堆中放各表当前最小元素，取一个补一个，$O(N\log m)$
  - 其他：定时器与任务调度、哈夫曼树构造、Dijkstra 取最小 dist、堆排序（衔接第七章堆排序）

## 五、图（笔记：第6章 图）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC6%E7%AB%A0%20%E5%9B%BE.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 图的基本概念
  - 完全图：无向 $\frac{n(n-1)}{2}$ 条边，有向 $n(n-1)$ 条弧
  - 握手定理 $\sum \deg = 2e$；有向图 $\sum \text{入度} = \sum \text{出度} = e$
  - $n$ 顶点连通图至少 $n-1$ 条边，有向强连通至少 $n$ 条边；连通分量、强连通分量、生成树与生成森林
- 邻接矩阵法
  - 空间 $O(n^2)$，适合稠密图；无向图矩阵对称，第 $i$ 行元素之和 = 该顶点度
  - 有向图行和 = 出度、列和 = 入度；判两顶点是否相邻 $O(1)$
  - 适合频繁判边存在性与增删边，不适合稀疏图
- 邻接表法
  - 空间 $O(n+e)$（无向图 $2e$ 个边结点）；同一图的邻接表**不唯一**（边结点次序）
  - 有向图邻接表求入度需遍历全表，或另建逆邻接表
  - 找某顶点的所有邻接点方便，判任意两点是否相邻不便
- 邻接多重表与十字链表
  - 十字链表（有向图）：弧结点含 tail/head 指针 + 同头链与同尾链，求入度出度都方便
  - 邻接多重表（无向图）：一条边只存一个结点，便于删边与标记访问
- 深度优先搜索（DFS）
  - 递归或显式栈 + visited 数组；邻接表 $O(n+e)$、邻接矩阵 $O(n^2)$
  - 非连通图调用遍历的次数 = 连通分量数；DFS 生成树与生成森林
  - 邻接表存储时 DFS 序列不唯一，邻接矩阵唯一
- 广度优先搜索（BFS）
  - 队列 + visited + 层次标记；空间 $O(n)$，可非递归实现
  - 可求**无权图**单源最短路径（最少边数）；同一连通图中 BFS 生成树高度 $\ge$ DFS 生成树高度
- 最小（代价）生成树
  - MST 的权值和唯一，树形可不唯一（边权互异时唯一）
  - Prim：从顶点出发，每步选横跨已选/未选顶点集的最小边，$O(n^2)$，适合稠密图
  - Kruskal：按边权升序 + 并查集判环，$O(e\log e)$，适合稀疏图；会手推每一步选边
- 最短路径
  - Dijkstra：单源、贪心，每轮确定一个顶点的最终距离，$O(n^2)$，**不能处理负权边**
  - Floyd：所有顶点对、动态规划、$k$ 在最外层 $O(n^3)$，允许负权边但不允许负权回路
  - 会手推 dist/path 数组变化与 $A^{(k)}$ 矩阵
- 拓扑排序
  - AOV 网：反复输出入度为 0 的顶点并删除其出边，$O(n+e)$；用栈或队列存放 0 入度顶点
  - 拓扑序列不唯一；存在长度为 $n$ 的拓扑序列 ⇔ 图中无环
  - 逆拓扑排序：出度法，或 DFS 完成时入栈再弹出
- 关键路径
  - AOE 网：事件最早 $ve$（源点 0，取 $\max(ve+w)$）、最迟 $vl$（汇点 = $ve$，取 $\min(vl-w)$）
  - 活动最早开始 $e = ve(\text{弧尾})$、最迟开始 $l = vl(\text{弧头}) - w$；$e = l$ 的是关键活动（时间余量 0）
  - 关键路径 = 最长路径；缩短工期必须压缩所有关键路径共有的关键活动，压缩过度会改变关键路径

## 六、查找（笔记：第7章 查找 / 第10章 串）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC7%E7%AB%A0%20%E6%9F%A5%E6%89%BE.md)（第7章 查找） · [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC10%E7%AB%A0%20%E4%B8%B2.md)（第10章 串） · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 查找的基本概念
  - ASL（平均查找长度）$= \sum p_i c_i$，成功与失败两种 ASL 都要会算
  - 静态查找（顺序、折半、分块）与动态查找（BST、AVL、红黑树、B 树、散列）
- 顺序查找法
  - 等概率成功 $ASL = \frac{n+1}{2}$；失败 $ASL = n+1$（无序表）
  - 有序表顺序查找失败可比到确定位置提前终止；哨兵 `ST[0]=key` 免去越界判断，链表也适用
- 分块查找法
  - 索引表有序、块内无序；先查索引定块，再在块内顺序查找
  - 索引顺序查找 $ASL = \frac{b+1}{2} + \frac{s+1}{2}$，$s = \sqrt{n}$ 时最优 $ASL = \sqrt{n} + 1$
  - 索引折半查找 $ASL = \lceil \log_2(b+1)\rceil + \frac{s+1}{2}$
- 折半查找法
  - 只适用**有序顺序表**；链表不能折半（不支持随机存取）
  - 判定树是平衡二叉树：失败结点 $n+1$ 个，树高 $= \lceil \log_2(n+1)\rceil$，成功最多比较 $\lceil \log_2(n+1)\rceil$ 次
  - $\text{mid} = \lfloor (low+high)/2 \rfloor$；会画判定树并算成功/失败 ASL
- 二叉搜索树（BST）
  - 定义：左子树所有结点 < 根 < 右子树所有结点；中序序列递增
  - 查找与插入 $O(h)$；删除度 2 的结点用中序前驱或后继替补
  - 相同关键字不同插入次序得到不同树形，ASL 不同（最好 $O(\log n)$、最坏退化为单支 $O(n)$）
- 平衡二叉树（AVL）
  - 平衡因子 $\in \{-1, 0, 1\}$；四种失衡：LL 右单旋、RR 左单旋、LR 先左后右双旋、RL 先右后左双旋
  - 插入后至多一次（单/双）旋转恢复平衡；删除后可能 $O(\log n)$ 次旋转
  - 高 $h$ 的 AVL 最少结点 $N(h) = N(h-1) + N(h-2) + 1$（$N(1)=1$、$N(2)=2$）
- 【22增】红黑树
  - 五条性质：结点非红即黑、根黑、叶（NULL）黑、红结点的孩子必黑、任一结点到各叶的黑高相同
  - 高度 $\le 2\log_2(n+1)$，查找最坏 $O(2\log n)$
  - 插入时新结点染红：叔结点红则变色并上溢，叔结点黑则旋转 + 变色；增删旋转次数少于 AVL，综合性能更好
- B 树及其基本操作、B+ 树的基本概念
  - $m$ 阶 B 树：根至少 2 棵子树，非根非叶至少 $\lceil m/2 \rceil$ 棵；子树数 = 关键字数 + 1
  - 关键字数范围 $[\lceil m/2 \rceil - 1, m-1]$；所有叶结点（失败结点）在同一层；$n$ 个关键字对应 $n+1$ 个失败结点
  - 插入到最底层终端结点，超上限从 $\lceil m/2 \rceil$ 处分裂；删除借兄弟或与兄弟 + 父关键字合并，可级联回溯
  - B+ 树：$n$ 棵子树 $n$ 个关键字；叶结点含全部关键字且链表串联；非叶只作索引，成功查找一定走到叶层
- 散列（Hash）表
  - 装填因子 $\alpha = \frac{\text{记录数}}{\text{表长}}$；散列函数：除留余数（$p$ 取 $\le m$ 的最大素数）、直接定址、数字分析、平方取中
  - 冲突处理：开放定址（线性探测会堆积、平方探测 $\pm j^2$ 需表长为 $4k+3$ 型素数、双散列）与拉链法
  - 开放定址删除只能**懒惰删除**（做标记）；失败 ASL 按 $0..p-1$ 个地址统计，不是全表长 $m$
  - 效率只取决于散列函数、冲突处理方法与 $\alpha$，与表长无直接关系
- 字符串模式匹配
  - 大纲归入"查找"（六(八)）：模式串即关键字，在主串中查找其出现位置
  - 朴素（BF）匹配：最坏 $O(nm)$，失配后主串指针回溯；KMP：失配时 $i$ 不回溯、$j$ 滑动到 $\text{next}[j]$，$O(n+m)$
  - nextval 优化与手算过程见 [📖 第10章 串](%E7%AC%94%E8%AE%B0/%E7%AC%AC10%E7%AB%A0%20%E4%B8%B2.md) 与第4章 KMP 自查
- 查找算法的分析及其应用
  - 表小或无序、插入删除频繁 → 顺序查找；有序顺序表且静态 → 折半查找
  - 块间有序、块内无序、插入删除受限 → 分块查找；只需等值查找、能控制 $\alpha$ → 散列表（最坏退化为 $O(n)$）
  - 需动态插入删除且保持高效：内存中选 AVL / 红黑树；外存海量数据选 B 树 / B+ 树（B+ 更适合范围查询与顺序遍历）

## 七、排序（笔记：第8章 排序）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC8%E7%AB%A0%20%E6%8E%92%E5%BA%8F.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 排序的基本概念
  - 稳定性：排序前后关键字相同元素的相对次序不变；稳定 = 直接插入、冒泡、归并、基数（口诀"插冒归基"）
  - 不稳定 = 希尔、快速、简单选择、堆；内部排序 vs 外部排序（是否需内外存交换数据）
- 直接插入排序
  - 每趟把一个元素插入前面已有序的子序列；最好 $O(n)$（基本有序）、最坏 $O(n^2)$（逆序）
  - 稳定；空间 $O(1)$；适合 $n$ 小或基本有序；顺序与链式存储都能用
- 折半插入排序
  - 用折半查找定位插入位置：**比较次数 $O(n\log n)$ 与初态无关**，但移动次数不变
  - 总时间复杂度仍 $O(n^2)$；稳定；只适用顺序存储
- 起泡（冒泡）排序
  - 相邻逆序即交换，每趟把当前最大元素沉底；设交换标志后最好 $O(n)$
  - 稳定；空间 $O(1)$；每对逆序元素恰好交换一次，可用来数逆序对
- 简单选择排序
  - 每趟选最小元素与第 $i$ 位交换；**比较次数恒为 $\frac{n(n-1)}{2}$，与初态完全无关**
  - 移动次数 $\le 3(n-1)$；不稳定（交换可能跨过相等元素）
- 希尔排序
  - 按增量分组做插入排序，增量逐次缩小最后为 1；复杂度依赖增量序列（约 $O(n^{1.3})$，最坏 $O(n^2)$）
  - 不稳定；只能顺序存储（分组需按增量跳跃访问）
- 快速排序
  - 一趟划分后枢轴就位；平均 $O(n\log n)$ 且常数最小，内部排序平均性能最优
  - 最坏 $O(n^2)$（基本有序或逆序且枢轴取端点）；空间 = 递归栈 $O(\log n)$（最坏 $O(n)$）
  - 不稳定；$n$ 很大时优势明显；一次划分可求第 $k$ 大（平均 $O(n)$）
- 堆排序
  - 大根堆用于升序：从 $\lfloor n/2 \rfloor$ 逐个下沉建堆 $O(n)$，再反复"堆顶与末尾交换 + 下沉" $O(n\log n)$
  - 空间 $O(1)$、不稳定、只适合顺序存储；比较次数与初态基本无关
  - 与第四章【25新增】堆的建堆、插入、删除共用同一下沉/上浮机制
- 二路归并排序
  - 相邻两段归并，段长由 1 翻倍到 $n$；$O(n\log n)$，比较次数与初态基本无关
  - 稳定；空间 $O(n)$（辅助数组）——内部排序中空间开销最大
- 基数排序
  - LSD 最低位优先：$d$ 趟"分配 + 收集"，$r$ 个队列；$O(d(n+r))$、空间 $O(r)$
  - 不基于比较（可突破比较排序 $O(n\log n)$ 下界），要求 $d$ 小、$n$ 大；每趟子排序必须稳定
- 外部排序
  - 多路归并：趟数 $S = \lceil \log_k r \rceil$（$r$ 个初始归并段、$k$ 路）；时间大头在外存读写，减少趟数最有效
  - 败者树使每次选最小只需 $\lceil \log_2 k \rceil$ 次比较；置换-选择排序生成平均长度为 $2 \times$ 内存容量的初始归并段
  - 最佳归并树（哈夫曼思想）安排归并顺序；$u = (r-1) \bmod (k-1) \ne 0$ 时补 $k-1-u$ 个虚段
- 排序算法的分析与应用：按场景选型
  - $n$ 小或基本有序 → 直接插入 / 冒泡；$n$ 大且关键字随机 → 快速排序
  - 要求最坏 $O(n\log n)$ 且空间 $O(1)$ → 堆排序；要求稳定 → 归并 / 基数 / 插入 / 冒泡
  - 关键字位数 $d$ 小、$n$ 大且可分解为多关键字 → 基数排序；数据量超出内存 → 外部排序
