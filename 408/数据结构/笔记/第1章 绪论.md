> **408 高频考点提醒**：
> - **数据元素/数据项**：数据元素是数据的基本单位，数据项是构成数据元素的**不可分割的最小单位**
> - **数据结构三要素**：**逻辑结构、存储结构、数据的运算**
> - **逻辑结构四类型**：集合、线性 **1:1**、树形 **1:n**、图状 **n:n**
> - **存储结构**：顺序/链式/索引/散列
> - **算法五特性**：有穷性、确定性、可行性、输入、输出
> - **算法 ≠ 程序**：算法必须**可终止**，程序可以是无穷的
> - **时间复杂度**：加法规则**保留最高阶**、乘法规则直接相乘，阶排序**常对幂指阶**
> - **空间复杂度**：一般指**辅助空间**（输入数据外额外占用），原地 $S(n)=O(1)$
> - **逻辑结构独立于存储结构**：存储是逻辑结构在计算机上的**映射**；存储时要存**元素的值 + 元素间的关系**
> - **频度 vs 复杂度**：$i \times = 2$ → $O(\log_2 n)$；问"执行次数"直接求和（如 $n(n+1)$），问"复杂度"取最高阶去系数

### （一）数据结构的基本概念

* **数据**：是信息的载体，是描述客观事物属性的数、字符及所有能输入到计算机中并被计算机程序识别和处理的符号的集合 。


* **数据元素与数据项**：数据元素是数据的基本单位，通常作为一个整体进行考虑和处理 。一个数据元素可由若干数据项组成，数据项是构成数据元素的不可分割的最小单位，对客观事物某一方面的数据描述 。


* **数据对象**：数据对象则是具有相同性质的数据元素的集合，是数据的一个子集 。


* **数据类型**：是一个值的集合和定义在此集合上的一组操作的总称 。
    * 原子类型：其值不可再分的类型
    * 结构类型：由若干个数据项组成的类型
* **抽象数据类型 (ADT)**：是抽象数据组织及与之相关的操作，它用数学化的语言定义数据的逻辑结构和运算，与具体的实现无关。**可以用 ADT 定义一个完整的数据结构**——即用（数据对象，数据关系，基本操作集）三元组给出完整定义。

    * ADT=(D,S,P)

        * D：数据对象
        * S：D上的关系集
        * P：对D的基本操作集

* **数据结构**：是指相互之间存在一种或多种特定关系的数据元素的集合，它是数据类型及其相互关系的集合 。包含**逻辑结构、存储结构和数据的运算**。


### （二）数据结构的三要素

数据结构主要由以下三个要素构成：

1. #### **逻辑结构**（数据元素之间的逻辑关系）：

* **集合**：各个元素同属一个集合，别无其他关系 。
* **线性结构**：数据元素之间是一对一的关系 。
* **树形结构**：数据元素之间是一对多的关系 。
* **图状结构（网状结构）**：数据元素之间是多对多的关系 。

* **两大类划分**：按元素之间的逻辑关系，逻辑结构可归为**线性结构**与**非线性结构**两大类（集合、树形、图状均属**非线性结构**）。

2. #### **物理结构 / 存储结构**（数据元素的表示及其相互的关系）：

* **顺序存储**：逻辑上相邻的元素存储在物理位置上也相邻的存储单元中 。
* **链式存储**：逻辑上相邻的元素在物理位置上可以不相邻，借助指示元素存储地址的指针来表示元素之间的逻辑关系 。
* **索引存储**：在存储元素信息的同时，还建立附加的索引表 。
* **散列存储**：根据元素的关键字直接计算出该元素的存储地址，又称哈希 (Hash) 存储 。

3. #### **数据的运算**：

* 包括运算的**定义**和**实现**。运算的定义针对逻辑结构，指出运算的功能；运算的实现针对存储结构，指出运算的具体操作步骤 。

**逻辑结构与存储结构的关系**（高频辨析）：

* **逻辑结构独立于存储结构**：逻辑结构从实际问题出发、只作抽象表达；存储结构是逻辑结构在计算机上的**映射**，**不能独立于逻辑结构而存在**。
* 同一逻辑结构可以有多种存储结构（如线性表可用顺序、链式、索引、散列存储）；数据结构三要素**缺一不可**。

> **易错点**：存储数据时不仅要存储各**数据元素的值**，还要存储**数据元素之间的关系**——只存值不存关系，不构成完整的数据存储。

### （三）算法的基本概念

* **核心理念**：程序 = 数据结构 + 算法 。算法是对特定问题求解步骤的一种描述，它是指令的有限序列，其中的每条指令表示一个或多个操作 。

* **描述算法的方法**：**伪代码（伪语言）**、**自然语言**、**程序设计语言**、**流程图**（传统流程图与 N-S 结构图）；考试中多用伪代码或程序设计语言 。（教材 1.2.1）

- **算法的五个特性**：

  1. **有穷性**：一个算法必须总在执行有穷步之后结束，且每一步都可在有穷时间内完成（注：程序可以是无穷的） 。

  2. **确定性**：算法中每条指令必须有确切的含义，相同的输入只会产生相同的输出 。

  3. **可行性**：算法中描述的操作都可以通过已经实现的基本运算执行有限次来实现 。
  
  
     4. **输入**：一个算法有零个或多个输入 。
  
  
     5. **输出**：一个算法有一个或多个输出 。
  

> **易错点**（算法 vs 程序辨析，选择题高频）：
> - **算法是问题求解步骤的描述**，程序是算法在计算机上的**特定实现**——两者不是同一概念；算法也不**必须**由计算机程序实现（手工执行同样可以）。
> - 程序不一定满足**有穷性**（如死循环、操作系统），而算法必须有穷。
> - "满足五个基本特性"只是算法的**必要条件**，不能作为算法的定义。
> - "指令不能有二义性"是对**确定性**的要求，与**可行性**无关。

* **“好”算法的特质**：
  
    1. **正确性**：能够正确地解决求解问题 。
    
    2. **可读性**：具有良好的可读性，以帮助人们理解 。
    
    3. **健壮性**：输入非法数据时，算法能适当地做出反应或进行处理 。
    
     4. **通用性**：算法的处理结果对于一般的数据都成立
    
     5. **高效率与低存储量需求**：即算法执行省时、省内存（时间复杂度低、空间复杂度低） 。

### （四）算法的复杂度度量

#### 一、时间复杂度

衡量算法时间开销 $T(n)$与问题规模 $n$的关系 。

* **影响因素**：问题规模、数据初始状态、选用策略、程序设计语言、编译产码质量、机器速度（后四者归类为**软/硬件因素**）；撇开软硬件因素，算法运行工作量只依赖**问题规模 $n$** 。（教材 1.2.2）同一算法，实现语言的级别越**高**，执行效率通常越**低**（严蔚敏教材口径，选择题考过）。

* **计算规则**：
    * **加法规则**（保留最高阶）：$T(n) = O(f(n)) + O(g(n)) = O(max(f(n), g(n)))$。
    
    - **乘法规则**：$T(n) = O(f(n)) \times O(g(n)) = O(f(n) \times g(n))$。


* **杂度排序（常对幂指阶）**：$O(1) < O(log_2 n) < O(n) < O(n log_2 n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$。

* **大 O 记号（形式化定义）**：若存在正常量 $M$ 与 $n_0$，当 $n \ge n_0$ 时恒有 $|f(n)| \le M\cdot g(n)$，则记 $f(n)=O(g(n))$（教材 1.2.2）。它给出算法时间的**渐进上界**，只关心 $n$ 充分大后的增长趋势（低阶项与常数系数忽略）。如 $T(n)=O(n^2)$ 表明执行时间与 $n^2$ **成正比**（$T(n) \le cn^2$，$c$ 为比例常数），**问题规模仍是 $n$** 而不是 $n^2$。阶排序口诀仍为"**常对幂指阶**"。

**（1）常见循环结构的频度与复杂度（选择题高频）**：

| 程序段形态 | 分析 | 结果 |
|:---|:---|:---|
| `i=1; while(i<=n) i=i*2;` | 设执行 $t$ 次，$2^t \le n$ → $t \le \log_2 n$ | $O(\log_2 n)$ |
| `while(i*i*i<=n) i++;` | 设执行 $t$ 次，$t^3 \le n$ → $t \le \sqrt[3]{n}$ | $O(n^{1/3})$ |
| 双重循环（内外层都与 $n$ 有关，如 `++x`） | 内层 $n$ 次 × 外层 $n$ 次 | $O(n^2)$ |
| 内层依赖外层：`for(i=1;i<=n;i++) for(j=1;j<=2*i;j++) m++;` | 精确频度 $\sum_{i=1}^{n} 2i = n(n+1)$ | 频度 $n(n+1)$，复杂度 $O(n^2)$ |
| 冒泡型：`for(i=n-1;i>1;i--) for(j=1;j<i;j++) 交换;` | 最坏（全部逆序）每次都交换，频度 $\sum_{i=2}^{n-1}(i-1)=\frac{(n-1)(n-2)}{2}$ | $O(n^2)$ |

> **易错点**：区分**精确执行次数（频度）**与**大 O 复杂度**——问"执行次数"要直接求和给精确值（如 $n(n+1)$）；问"复杂度"才取最高阶、去系数。

* **三种时间复杂度**：
    * **最好时间复杂度**：考虑输入数据“最好”的情况 。
    
    
    * **最坏时间复杂度**：考虑输入数据“最坏”的情况（它给出执行时间的**上界**，保证算法运行时间不会比它更长；通常就以最坏情况复杂度作为算法的时间复杂度） 。
    
    
    * **平均时间复杂度**：考虑所有输入数据都等概率出现的情况下的期望运行时间 。
    

#### 二、空间复杂度

衡量算法空间开销（内存开销）与问题规模 $n$之间的关系 $S(n)$。

* **辅助空间**：程序运行所需存储空间一般包括指令/常数/变量、输入数据、辅助空间三方面；**一般地，算法的空间复杂度指的是辅助空间**，即除输入数据外**额外占用的空间**（王道/教材口径）。（教材 1.2.3）

* **算法原地工作**：无论问题规模怎么变，算法运行所需的内存空间都是固定的常量，即 $S(n) = O(1)$。

> **易错点**："原地工作"**不是**指不需要任何额外的辅助空间，而是指**辅助空间为常量** $O(1)$（仍可申请有限个辅助变量）。


* **内存分析**：只需关注与问题规模相关的变量（如一维数组 $O(n)$，二维数组 $O(n^2)$） 。


* **函数递归调用**：递归程序的空间复杂度通常等于递归调用的深度 。
