## 数据结构

### 2.3 线性表的链式结构

错题：3、6、7、9、11、12、14、16、17、18、19、20、21

**① 静态链表 = 数组外壳 + 链表灵魂（错题 3、9、11）**

- 静态链表的"指针"是**游标**：存放后继元素**在数组中的下标**，不是内存地址（第 3 题，"下一元素在数组中的地址"是干扰项）
- 双重身份：需要分配**较大的连续空间**（数组的一面）＋ 插入删除**不需要移动元素**（链表的一面），两边都答上才是完整特点（第 11 题）
- 与顺序表相比的优点：**便于插入和删除**（第 9 题）；注意它恰恰**需要连续空间**，"便于利用零散的存储空间"说反了；也不能随机存取

>
> A. 内存地址　B. 数组下标　C. 链表中下一元素在数组中的地址　D. 左、右孩子地址
>
> 答案：**B**
>
> **原题 9**：线性表的静态链表存储结构与顺序存储结构相比，其优点是（　）。
>
> A. 所有的操作算法实现简单　B. 便于随机存取　C. 便于插入和删除　D. 便于利用零散的存储空间
>
> 答案：**C**
>
> **原题 11**：需要分配较大的连续空间，插入和删除不需要移动元素的线性表，其存储结构为（　）。
>
> A. 单链表　B. 静态链表　C. 顺序表　D. 双链表
>
> 答案：**B**

**② 单链表操作复杂度的判断口诀（错题 6、7、21；第 21 题原文见 ④）**

- **删除结点必须知道其前驱**，插入结点必须知道前驱（或指定结点本身）：
  - 删首结点：前驱 = 头结点，地址已知 → O(1)，与表长无关
  - 删尾结点：尾的前驱未知，须从头遍历 → O(n)，**与表长有关**（第 7 题）
  - 表尾后插入：尾结点地址已知（有尾指针 r）→ O(1)
- 有序单链表插入并保持有序 = **查找位置 O(n) + 修改指针 O(1) = O(n)**——链表操作的瓶颈永远在"定位"而非"操作"（第 6 题）
- 循环单链表**即使带尾指针**，删尾结点仍要找前驱 O(n)；要频繁"删除最后一个结点"只能上循环双链表（第 21 题 A、D 项的死因）

> **原题 6**：在一个具有 n 个结点的有序单链表中插入一个新结点仍然保持有序的时间复杂度是（　）。
>
> A. O(1)　B. O(n)　C. O(n²)　D. O(nlog₂n)
>
> 答案：**B**
>
> **原题 7**：在一个长度为 n（n>1）的带头结点的单链表 h 上，另设有尾指针 r（指向尾结点），执行（　）操作与链表的长度有关。
>
> A. 删除单链表中的第一个结点
>
> B. 删除单链表中的最后一个结点
>
> C. 在单链表第一个元素前插入一个新结点
>
> D. 在单链表最后一个元素后插入一个新结点
>
> 答案：**B**

**③ 按位序访问是顺序表的主场（错题 12、17、19；第 19 题原文见 ⑤）**

- 取第 i 个元素 / 第 i 个元素的前驱：顺序表 O(1)，链表（含双链表）O(n)（第 12 题）
- 陷阱：看到"前驱"别条件反射选双链表——双链表的优势是"**给定某个结点**后访问其前后相邻结点"，不是"按位序"定位
- 删除所有值为 x 的元素：两者都要 O(n) 遍历，但顺序表每次删除要移动大量元素（最坏累计 O(n²)），单链表只改指针 → **单链表效率更高**（第 17 题，2n 个元素同理）

> **原题 12**：如果最常用的操作是取第 i 个元素的前驱结点，则采用（　）存储方式最节省时间。
>
> A. 单链表　B. 双链表　C. 单循环链表　D. 顺序表
>
> 答案：**D**
>

>
> D. 交换第 i 个元素和第 2n-i-1 个元素的值（i=0, …, n-1）
>

**④ 存储结构选型：按"最常用操作"倒推（错题 14、16、21；第 16 题原文见 ⑤；对照第 2、15 题）**

| 最常用操作 | 最优结构 | 关键原因 |
|:---|:---|:---|
| 表尾插入 + 表头删除 | 仅设尾指针的循环单链表（对照第 2、15 题；16-V 即队列场景） | rear 后插 O(1)；rear->next 即头结点，头删 O(1)——**用链表实现队列的标准答案** |
| 表尾插入 + **表尾删除** | 带头结点的循环双链表（错题 14） | 删尾必须找前驱，只有双链表的 prior 指针直达前驱 |
| 删首、删尾、插首、插尾全都要 | 只有头指针（无尾指针）的**循环双链表**（错题 21） | 头结点的 prior 即尾结点、尾结点的 next 即头结点，**一个头指针两端全 O(1)**，尾指针是冗余 |

- 第 21 题各选项死因：A（仅尾指针循环单链表）删尾 O(n)；B（仅尾指针非循环双链表）删首须沿 prior 一路回退 O(n)；D（带头尾指针的循环单链表）删尾仍 O(n)

> **原题 14**：若某链表最常用的操作是在最后一个结点之后插入一个结点或删除最后一个结点，则采用（　）存储结构最节省运算时间。

>
> 答案：**D**
>
> **原题 21**：设对 n（n>1）个元素的线性表的运算只有 4 种：删除第一个元素；删除最后一个元素；在第一个元素之前插入新元素；在最后一个元素之后插入新元素，则最好使用（　）。

**⑤ 概念纠偏集（错题 16、18、19、20；对照第 1、13 题）**

- "顺序存储只能存储线性结构" ×——顺序方式也能存树（堆）、图（邻接矩阵）（16-I）
- "取第 i 个元素的时间与 i 的大小有关" ×——顺序表 O(1) 与 i 无关；此说法只在链式存储下成立（16-II、19-D）
- 头结点的作用 = **方便运算的实现**：① 首结点的插删与其他位置算法统一，无需特判；② 空表与非空表处理统一（头指针恒指向头结点，永为非空指针）。头结点不是数据元素、不是"首结点的标识"（第 18 题）
- 双链表 vs 单链表：优点**只有**"访问前后相邻结点更灵活"；插删都不移动元素、双链表指针修改反而更复杂，"插删更简单/方便" ×；都不能随机访问；不能省略头/尾指针（第 13、20 题）
- "线性表中每个元素都有直接前驱和直接后继" ×——首元素无前驱、尾元素无后继（19-B）
- 链表结点地址：连续与否均可以（一般分散，连续申请也可以）

**⑥ 遗留疑问解答：为什么单循环链表设尾指针优于头指针（综合应用题 2-1）**

- 设尾指针 rear（带头结点）：终端结点 = rear 所指结点，O(1)；开始结点 = `rear->next->next`，O(1) → **两端操作都是 O(1)**
- 设头指针：开始结点 O(1)，但终端结点须遍历全表，O(n)
- 推广：这就是"带尾指针的循环单链表可高效实现队列"的原因（表尾插入、表头删除均 O(1)），对应选择题 2、15、16-V

### 3 栈

错题：6、22、23、25

**① 链栈选型的真门槛：能否 O(1) 找到"开始结点的前驱"（错题 6、25）**

- 链栈**不带头结点、所有操作都在表头**（栈顶 = 开始结点）：压栈 `s->next=top; top=s`、弹栈 `top=top->next` 本身都是 O(1)，四种候选结构找"表头"也都不难——**所以考点不在栈顶定位**，而在**循环链表必须维护"尾结点的 next 指回开始结点"**：插入/删除后要能 O(1) 拿到**开始结点的前驱（即尾结点）**
- 四种结构死因对照：

| 候选结构（均无头结点） | 表头插删 O(1)? | 关键原因 |
|:---|:---|:---|
| 只有**表头**指针的双向循环链表 | ✓ | 开始结点的 prior 就是尾结点，直达 |
| 只有**表尾**指针的双向循环链表 | ✓ | 尾结点的 next 就是开始结点，且可双向回退 |
| 只有**表尾**指针的单向循环链表 | ✓ | 开始结点 = 尾->next，改 `尾->next` 即完成插删 |
| 只有**表头**指针的单向循环链表 | ✗ O(n) | 尾结点（开始结点的前驱）无指针直达，只能从头遍历 |

- 第 6 题选 C、第 25 题选 D——两题只是选项顺序互换，**答案指向同一个结构：只有表头指针的循环单链表**（"单向 + 只有头指针 + 循环"三条同时成立才不合格）
- 关联 §2.3 ④：与"删除结点必须知道其前驱""带头结点的循环双链表凭一个头指针两端全 O(1)"是**同一条规律**——链式结构选型先问：要动的那个位置，它的**前驱/后继能不能 O(1) 拿到**
- 口诀：**单循环只给头指针 = 最差链栈**；给尾指针、或换成双链表（prior 直达）都是 O(1)

**② 共享栈：只省空间、只降上溢（错题 23；对照第 24 题）**

- 共享栈 = 两个顺序栈共用一片连续空间 `Share[0..n-1]`，两栈顶从两端向中间生长
- 好处**只有两条**：① **节省存储空间**（两栈按需互补，不必各按最大可能预留）；② **降低发生上溢的可能**（两栈顶相遇才算满，一个栈能"借用"另一个的空闲单元）
- "减少存取时间" ×：进出栈永远是栈顶操作 O(1)，共享与否都一样
- "降低下溢可能" ×：栈只在栈顶插删 → 只会**上溢**（栈满再进栈）；**下溢 = 空栈上出栈**，共享不改变任一栈为空的条件
- 对照第 24 题：`top1` 初值 -1、`top2` 初值 n 时，**栈满条件 `top1+1 == top2`**（两栈顶相遇，但**不能相等**——相等意味着两栈共用同一单元，不合理）；栈顶指针的定义不唯一，务必先按题干定义推判定式

> **原题 23**：采用共享栈的好处是（　）。

> A. 减少存取时间，降低发生上溢的可能
>
> B. 节省存储空间，降低发生上溢的可能
>
> C. 减少存取时间，降低发生下溢的可能
>
> D. 节省存储空间，降低发生下溢的可能
>
> 答案：**B**

**③ 出栈序列题要过两道筛子：先枚举，再套规则（错题 22）**

- 第一步**枚举全部合法出栈序列**：n、1、`_` 三个字符按此序进栈，出栈序列共 Catalan 数 `C(2n,n)/(n+1) = 5` 种——`n1_`、`n_1`、`1_n`、`1n_`、`_1n`
- 第二步**套筛子**：C 语言标识符要求**首字符是字母或下划线、不能是数字** → 剔除 `1_n`、`1n_`，剩 **3 个**（`n1_`、`n_1`、`_1n`），选 C
- 最易漏的是反向筛子：`_n1` **满足标识符规则，却不是栈的合法输出**（要首个出 `_`，则 n、1 已按序入栈，出栈只能 1 在 n 之前）——**两道筛子缺一不可**
- 注：C 标识符命名规则属语言/组成原理常识，本题主体仍是栈的输出序列枚举，两条都要用上（对应便签"22：C 语言语法规范，属于计算机组成原理内容"）
- 口诀：**先列全（卡特兰计数兜底）+ 再筛条件；满足条件的未必是合法出栈序列，合法出栈序列未必满足条件**

> **原题 22**：设栈的初始状态为空，当字符序列"n1_"作为栈的输入时，输出长度为 3，且可用做 C 语言标识符的序列有（　）个。
>
> A. 4　B. 5　C. 3　D. 6
>
> 答案：**C**

### 4 队列

错题：7、8、15、16

**① 链队出队：常态只改队头指针，删到"队空"时队尾指针也必须改（错题 7、8；对照第 9 题）**

- 出队 = 从**表头**删除：只要队中还剩 ≥2 个元素，改动队头指针（带头结点时即 `front->next`）就完事，尾指针不动
- 唯一的例外 = **删掉最后一个元素、队列变空**：尾指针仍指着刚被释放的结点 → 必须同步归位（带头结点 `rear = front`；不带头结点则头、尾两指针都置 NULL）
- 所以正确答案是"头尾指针**可能**都要修改"（第 7、8 题均选 D）；"仅修改头指针"的死因就是漏掉这个**队空临界点**（对照第 9 题，不带头结点时同样是 D）
- 口诀：**删空要收尾**——链表队列里，凡"删到空"的操作都得顺手把尾指针归位（与 §3 ①"链栈要能 O(1) 拿到开始结点的前驱"同属"边界情形决定成败"）

**② 链队选型：入队要 O(1) 找到队尾、出队要 O(1) 找到队头（错题 15、16；对照第 18 题）**

- 链队的两个动作**分居链表两端**：入队在队尾、出队在队头 → 选型判据 = **两头都要能 O(1) 拿到**（栈只需管一头，所以链栈的门槛比链队低）
- 各选项死因逐条对照：

| 候选结构（均带头结点） | 入队（需队尾） | 出队（需队头） | 判定 |
|:---|:---|:---|:---|
| 只带队尾指针的循环单链表（第 15 题 B；与第 16 题 D 为同一结构） | ✓ 尾已知 | ✓ 队头 = rear->next->next | **最适合**（第 15 题答案 B） |
| 只带队首指针的循环单链表（第 15 题 A） | ✗ 须遍历找尾 O(n) | ✓ | 不合格 |
| 只带队首指针的非循环单链表（第 15 题 C） | ✗ 须遍历找尾 O(n) | ✓ | 不合格 |
| 只带队尾指针的非循环单链表（第 15 题 D） | ✓ | ✗ 非循环摸不到头结点 | **连出队都做不了** |
| 只带队首指针的非循环双链表（第 16 题 A） | ✗ 非循环时 prior 不指向尾 | ✓ | **最不适合**（第 16 题答案 A） |
| 只带队首指针的循环双链表（第 16 题 B） | ✓ 尾 = 头结点->prior | ✓ | O(1)，合格 |
| 只带队尾指针的循环双链表（第 16 题 C） | ✓ | ✓ 队头 = rear->next->next | O(1)，合格 |

- 第 15 题问"最适合"选 B（两端都 O(1)）；第 16 题问"最不适合"选 A（该题四个选项里只有它入队 O(n)）——**"最…"题的答案随选项集合变化**，务必按自己那道题的选项逐一验算，别把上题的结论搬过来
- ⚠️ 双链表的 prior 只有在**循环**表中才指向终端结点；一旦非循环（第 16 题 A），头结点的 prior 是空/废指针，照样得遍历找尾——"双链表"三个字不等于"两头都能 O(1)"
- 关联 §3 ①：**栈看头端、队看两端**；循环/双链的作用就是把"另一端"从 O(n) 变成 O(1)。另对照第 12、13 题——栈与队列的**共同点是"受限的线性表、只允许在端点插入删除"**，差别在端口数（栈一口 LIFO、队两口 FIFO），这正是"链栈只要管一头、链队必须管两头"的根源；对照第 18 题——带头结点时**队尾就是链尾结点**
- 口诀：**入队找尾、出队找头，两头都要 O(1)；只给尾指针就必须循环（否则摸不到头）**

> **原题 15**：最适合用作链队的链表（链表有头结点，有队首指针则指向头结点，有队尾指针则指向终端结点）是（　）。
>
> A. 只带队首指针的循环单链表
>
> B. 只带队尾指针的循环单链表
>
> C. 只带队首指针的非循环单链表
>
> D. 只带队尾指针的非循环单链表
>
> 答案：**B**
>
> **原题 16**：最不适合用作队列的链表是（　）。
>
> A. 只带队首指针的非循环双链表
>
> B. 只带队首指针的循环双链表
>

>

### 5.2 二叉树的概念

错题：12、18

**① 度为 1 的结点数的奇偶性——"不可能存在"类题型的钥匙（错题 12）**

- 由 `n0 = n2 + 1` 推：设总结点数为 `T`，则 `T = n0 + n1 + n2 = 2n2 + n1 + 1` → **`n1 = T − 2n2 − 1`**
- ⚠️ 于是 **`n1` 与 `T − 1` 同奇偶**：总结点数为偶 ⟹ `n1` 为奇；总结点数为奇 ⟹ `n1` 为偶。**别背成"n1 恒为奇数"**——单结点树 T=1、n1=0 就是反例
- 本题 T = 2n 为偶 → `n1` 必为**奇数** → **偶数个（`2m` 个）度为 1 的结点不可能存在**，选 C
- 其余三个选项都能构造出来：`n0`、`n2` 的取值不受奇偶限制，只要配合 `n1 = T − 2n2 − 1 ≥ 0` 即可——所以"不可能"只能落在**奇偶矛盾**的那一项
- 口诀：**"n1 看奇偶"**——凡问"不可能有多少个度为 1 的结点"，先算总结点数的奇偶

> **原题 12**：设二叉树有 2n 个结点，且 m < n，则不可能存在（　）的结点。
>
> A. n 个度为 0　B. 2m 个度为 0　C. 2m 个度为 1　D. 2m 个度为 2
>
> 答案：**C**

**② 二叉链表的空指针数 = 结点数 + 1（错题 18）**

- 两条推导都要会：
  - **分支法**：非空指针数 = 分支数 = `n − 1`（每个非根结点恰被一条边指向）；指针域共 `2n` 个 → 空指针 = `2n − (n − 1) = n + 1`
  - **结点法**：空指针只来自叶子（2 个空）与单分支结点（1 个空）→ 空指针 = `2n0 + n1 = 2(n2 + 1) + n1 = (2n2 + n1) + 2 = (n − 1) + 2 = n + 1`
- 结论**与树形无关**：任何 n 个结点的二叉树用二叉链表存储，都有 **n+1 个空指针**
- 本节三个计数结论一起记：

| 结论 | 表达式 | 来源 |
|:---|:---|:---|
| 叶子数 = 双分支结点数 + 1 | n0 = n2 + 1 | 对照第 13、17 题 |
| 度为 1 的结点数 | n1 = T − 2n2 − 1（与 T−1 同奇偶） | 错题 12 |
| 二叉链表空指针数 | 2n0 + n1 = n + 1 | 错题 18 |

> **原题 18**：一棵有 n 个结点的二叉树采用二叉链存储结点，其中空指针数为（　）。
>
> A. n　B. n + 1　C. n − 1　D. 2n
>
> 答案：**B**

### 5.3 二叉树的遍历

错题：12、13、15

**① 先序 ↔ 入栈次序、中序 ↔ 出栈次序：序列题最快的检验法（错题 12）**

- 原理：先序遍历是**借助栈**实现的——把**先序序列当入栈次序、中序序列当出栈次序**，两者必须构成一对合法的栈操作序列
- 检验法：按先序逐个入栈，再看中序（= 出栈序列）是否合法——**某个元素要出栈时，它必须在栈顶**；"晚入栈却早出栈"不可能
- 本题以 1234567 入栈，逐项判：
  - A（3 开头）：3 第一个出栈说明 1、2、3 都已入栈，则 1 不可能早于 2 出栈 ✗
  - C（4 开头）：同理，1 不可能早于 3、2 出栈 ✗
  - D（1、4、6 开头）：1 出栈后要出 4 需再入 2、3、4，到 6 第三个出栈时栈内自底向上为 2、3、5，**栈顶是 5 不是 3** ✗
  - B（1234567）：每次进栈即出栈，全程合法 ✓ ——对应**右斜单支树**，此时先序 = 中序 = 1234567
- 另一条路（结构法）：**先序首元素是根**，把它放回中序里，左侧即左子树、右侧即右子树，再递归验证。如 A 中 1 的左子树含 3，则先序里 1 后面应紧跟 3（实际是 2）✗
- 口诀：**先序定根、中序分左右；两序互为"入栈 / 出栈"**

> **原题 12**：一棵二叉树的前序遍历序列为 1234567，它的中序遍历序列可能是（　）。
>
> A. 3124567　B. 1234567　C. 4135627　D. 1463572
>
> 答案：**B**

**② 唯一确定二叉树：必须"带中序"（错题 13）**

- 能唯一确定：**中序 + 先序**、**中序 + 后序**、**中序 + 层次**（第 13 题 A 项即"层次 + 中序"，成立）
- 不能唯一确定：**先序 + 后序**（选 D）——缺了"中序"这把划分左右子树的尺子
- 先序 + 后序能给出的唯一信息是**祖先关系**：若 X 在**先序**中出现在 Y 之前、又在**后序**中出现在 Y 之后，则 **X 是 Y 的祖先**
- 反例技巧：只要能画出**两棵不同**的树满足同一对（先序, 后序），就证明不唯一——别去猜答案，直接构造
- 口诀：**"有中序才定型"**

> **原题 13**：下列序列中，不能唯一地确定一棵二叉树的是（　）。
>
> A. 层次序列和中序序列
>
> B. 先序序列和中序序列
>
> C. 后序序列和中序序列
>
> D. 先序序列和后序序列
>
> 答案：**D**

**③ 二叉树的度可以小于 2（"二叉树"≠"度为 2 的树"）（错题 15）**

- 树的度 = **各结点度的最大值**；单个结点也算一棵二叉树 → 度为 **0**；只有一棵子树的单支树 → 度为 **1**
- 因此 A"二叉树的度为 2"、C"二叉树中至少有一个结点的度为 2"、D"任何一个结点的度都为 2"全错；正确说法是 **一棵二叉树的度可以小于 2**（0、1、2 都可能）
- 概念澄清："二叉树"不是"度为 2 的树"——二叉树的本质是**每个结点至多两棵子树、且左右子树有严格次序**（有序树，即使只有一棵子树也要区分左右）；而"度为 2 的树"只限制"最多两个分支"，不区分左右
- 口诀：**二叉树管"至多两棵 + 分左右"，不管"度为 2"**

> **原题 15**：有关二叉树下列说法正确的是（　）。
>
> A. 二叉树的度为 2
>
> B. 一棵二叉树的度可以小于 2
>
> C. 二叉树中至少有一个结点的度为 2
>
> D. 二叉树中任何一个结点的度都为 2
>
> 答案：**B**

**④ 遗留疑问解答：出栈序列 ↔ 二叉树形态的一一对应（综合应用题 3）**

- **原理**：二叉树的遍历都是**递归**的，递归要靠**系统栈**——所以**先序遍历序列 = 各结点"入栈时打印"**得到的序列，**中序遍历序列 = "出栈时打印"**得到的序列
- **映射方法**：把**入栈序列直接当作先序序列**（本题固定为 1, 2, …, n），把**任意一个出栈序列当作中序序列**；而先序 + 中序能唯一确定一棵二叉树 ⟹ **每种出栈序列 ↔ 一棵二叉树，一一对应**
- n = 3 时（出栈序列共 Catalan 数 `C(2n,n)/(n+1) = 5` 种，先序恒为 1、2、3）；原书此处配图，这里用文字给出五种树形：

| 出栈序列（= 中序） | 对应二叉树形态（先序恒为 1、2、3） |
|:---|:---|
| 3 2 1 | 左斜链：1 —左→ 2 —左→ 3 |
| 2 1 3 | 1 的左孩子 2、右孩子 3（左、右子树各一个结点） |
| 2 3 1 | 1 的左孩子 2；2 的右孩子 3 |
| 1 3 2 | 1 的右孩子 2；2 的左孩子 3 |
| 1 2 3 | 右斜链：1 —右→ 2 —右→ 3 |

- 顺带记两条（综合题 1、2，对照本节选择题第 14 题）：先序与后序正好**相反** ⟹ 每层只有一个结点、**高度 = 结点数**；先序与后序正好**相同** ⟹ 这棵非空二叉树**只有一个根结点**
- 口诀：**"入栈即先序、出栈即中序"**——"栈的出入序列"与"二叉树形态"两类题可以互相翻译

### 5.4 线索二叉树

错题：5、6、8

**① "先序难在前驱、后序难在后继"——线索不是万能钥匙（错题 5、6、8）**

- 二叉链表 n 个结点共 2n 个指针域，其中只有 `n − 1` 个真正指向孩子（同 §5.2 ②），剩下的 **n + 1 个空指针**正好用来存放"前驱/后继"线索；`ltag / rtag = 1` 表示该指针是**线索**，`= 0` 表示指向**左/右孩子**（教材 5.4）
- 但线索只能解决"**遍历顺序上紧挨着的那个方向**"，反向往往落空——二叉链表里**没有双亲指针**：
  - **中序线索树**：中序前驱、中序后继**都能 O(1)** 直达
  - **先序线索树**：先序**后继** O(1)，先序**前驱**必须知道**双亲** ✗
  - **后序线索树**：后序**前驱** O(1)，后序**后继**必须知道**双亲** ✗
- 三种线索树对照：

| 线索树 | 求前驱 | 求后继 | 遍历是否仍需栈 |
|:---|:---|:---|:---|
| 先序线索树 | ✗ 需双亲 | ✓ O(1) | 不需要 |
| 中序线索树 | ✓ O(1) | ✓ O(1) | 不需要 |
| 后序线索树 | ✓ O(1) | ✗ 需双亲 | **仍需要栈** |

- 三道错题就是这条规律的三次追问：第 5 题"**不正确**的是"D 项"每个结点通过线索都可以直接找到前驱和后继"（被上面这条否掉）；第 6 题"仍不能有效求解"→ **后序线索树求后序后继**（D）；第 8 题"遍历仍需栈支持"→ **后序线索树**（C）——**第 6、8 题是同一事实的两种问法**
- 第 6 题的死因举例：结点 E 的右指针指向右孩子，而后序序列中 E 的后继是 B，线索在这里完全帮不上忙，只能按常规回溯
- 口诀：**中序两头通，先序缺前驱，后序缺后继（所以后序线索遍历还得用栈）**

> **原题 5**：在线索二叉树中，下列说法不正确的是（　）。
>
> A. 在中序线索树中，若某结点有右孩子，则其后继结点是它的右子树的最左下结点
>
> B. 在中序线索树中，若某结点有左孩子，则其前驱结点是它的左子树的最右下结点
>
> C. 线索二叉树是利用二叉树的 n + 1 个空指针来存放结点的前驱和后继信息的
>
> D. 每个结点通过线索都可以直接找到它的前驱和后继
>
> 答案：**D**
>
> **原题 6**：二叉树在线索化后，仍不能有效求解的问题是（　）。
>
> A. 先序线索二叉树中求先序后继
>
> B. 中序线索二叉树中求中序后继
>
> C. 中序线索二叉树中求中序前驱
>
> D. 后序线索二叉树中求后序后继
>
> 答案：**D**
>
> **原题 8**：（　）的遍历仍需要栈的支持。
>
> A. 前序线索树　B. 中序线索树　C. 后序线索树　D. 所有线索树
>
> 答案：**C**

**② 中序线索树里"前驱/后继"到底是哪个结点（错题 5 的 A、B 项；对照第 7、9 题；题干见本节 ①）**

- 结点**有右孩子**时：中序后继 = **右子树中最左下的结点**（从右孩子出发，沿左指针一路走到底）
- 结点**有左孩子**时：中序前驱 = **左子树中最右下的结点**（从左孩子出发，沿右指针一路走到底）
- ⚠️ 最易错的是把"最右**下**结点"说成"最右**叶**结点"——**前驱不一定是叶子**（该结点自己还可以有左孩子）：对照第 7、9 题（同题异选项、答案都是 C"左子树中最右（边的）结点"），D 项"最右叶结点"就是那个干扰项
- 第 5 题 A、B 两项用的正是上面两条**正确**说法，所以本题只能选 D
- 口诀：**后继看右边最深、前驱看左边最深；只说"最右/最左"别说"叶"**
