# 408 · 数据结构 复习自查

> **用法**：逐条自测并勾选 —— ✅ 合上书能独立讲清 / ⚠️ 模糊（需翻笔记确认）/ ❌ 不会（重点回炉）。「自测问答」先遮住答案作答再核对；代码题（KMP、堆调整、快排一趟）务必**手算**，只看会 ≠ 会。配套 [思维导图大纲](思维导图大纲.md) 看全局。

## 第1章 绪论

### 1.1 自查清单

- [ ] 数据项 < 数据元素 < 数据对象 的层次关系；数据结构三要素：**逻辑结构、存储结构、数据的运算**
- [ ] 逻辑结构四类：集合、线性、树形、图形（网状）；存储（物理）结构四种：顺序、链式、索引、散列
- [ ] **运算的定义针对逻辑结构，运算的实现针对存储结构**（高频判断题）
- [ ] 算法五个特性：有穷性、确定性、可行性、输入、输出；设计目标：正确性、可读性、健壮性、高效性
- [ ] 会算循环的时间复杂度：单层累加、`i` 乘法增长（`i=1; while(i<=n) i*=3` → O(log₃n)）、两层嵌套（内层依赖外层：Σi ≈ n²/2 → O(n²)）
- [ ] 会算递归式复杂度：T(n)=T(n−1)+O(1) → O(n)；T(n)=T(n−1)+O(n) → O(n²)；T(n)=2T(n/2)+O(n) → O(n log n)
- [ ] 最好/最坏/平均时间复杂度的概念；空间复杂度：递归栈深度、原地工作 O(1)

### 1.2 易错点 · 高频陷阱

- O 记号是**渐进上界**；"时间复杂度为 O(n) 的算法一定比 O(n²) 快"**不对**（n 小或常数差异）。
- 顺序存储也支持"随机存取"，链式存储只能顺序存取——"存取方式"与"存取结构"区分。
- 循环里 `while(i<n) i=i*2;` 内再套常数循环是 O(n log n)，别只看层数。
- 递归算法空间复杂度 = **递归深度**（栈），不是调用总次数。

### 1.3 自测问答

**Q1. 求 `x=0; for(i=1;i<=n;i++) for(j=1;j<=2*i;j++) x++;` 的时间复杂度。**

<details><summary>▶ 展开答案</summary>

基本操作执行 2(1+2+…+n) = n(n+1) 次，T(n) = **O(n²)**。
</details>

**Q2. `int f(int n){ if(n<=1) return 1; return f(n/2)+1; }` 的时间与空间复杂度。**

<details><summary>▶ 展开答案</summary>

递归深度 log₂n，每次 O(1)：时间 **O(log n)**，空间 **O(log n)**（栈深）。
</details>

## 第2章 线性表

### 2.1 自查清单

- [ ] 顺序表：按位查找 O(1)；**插入平均移动 n/2 个元素，删除平均移动 (n−1)/2 个**（等概率）；插入删除平均时间 O(n)
- [ ] 静态分配 vs 动态分配（malloc/realloc 扩容）；位序与数组下标差 1
- [ ] 单链表：**头结点的作用**（首位置插入删除与中间统一、空表与非空表处理统一）；头指针 vs 头结点 vs 首元结点
- [ ] 单链表插入（p 后插）：`s->next=p->next; p->next=s;`；删除 p 后继：`q=p->next; p->next=q->next; free(q);`
- [ ] **O(1) 删除结点 \*p**（无前驱时）：把 p 的后继值复制到 p，再删后继（对尾结点不适用）
- [ ] 头插法建表（逆序）vs 尾插法建表（顺序，需尾指针）；两者对输入序列生成的链表顺序
- [ ] 双链表插入四步的**顺序**：`s->next=p->next; s->prior=p; p->next->prior=s; p->next=s;`（第一步必须在第四步前）
- [ ] 循环单链表：判空 `L->next==L`；**设尾指针（不设头指针）**的好处：找头尾都是 O(1)，**两表合并 O(1)**
- [ ] 静态链表：数组+游标（next 指针为数组下标），容量固定
- [ ] 顺序表 vs 链表：存取方式、插入删除、空间开销（链表指针额外开销）、是否支持随机存取——按场景选型

### 2.2 易错点 · 高频陷阱

- 双链表插入若先执行 `p->next=s`，会**丢失**后半段链——四步顺序是送分题也是坑。
- "带头结点"后：空表条件单链表为 `L->next==NULL`；循环单链表为 `L->next==L`。
- 删除单链表结点必须**先接后删**（free 之后指针失效）；操作前判断合法性（p 非空、p 非尾）。
- 顺序表插入的移动次数与**插入位置**有关：第 i 位插入移动 n−i+1 次；链表定位后插入 O(1)。
- 链表"按序号查找"仍是 O(n)——**链表不改变查找效率，只改变插入删除的代价**。

### 2.3 自测问答

**Q1. 长度 n 的顺序表在第 i 个位置前插入元素，需要移动多少个元素？平均移动次数？**

<details><summary>▶ 展开答案</summary>

第 i 位插入移动 n−i+1 个（第 i 到第 n 个后移）。等概率下平均 = (1/(n+1))·Σ_{i=1}^{n+1}(n−i+1) = **n/2**。
</details>

**Q2. 判断：带头结点的双循环链表 L 判空的条件是 `L->next==L`。**

<details><summary>▶ 展开答案</summary>

正确。头结点的 next、prior 都指向自己时为空表（也可写 `L->prior==L`）。若是**非循环**双链表则判 `L->next==NULL`。
</details>

## 第3章 栈、队列和数组（含压缩存储）

### 3.1 自查清单（栈）

- [ ] 顺序栈两种 top 约定：**top 指向栈顶元素**（初值 −1：入栈 `S[++top]=x`，空 `top==-1`，满 `top==MaxSize-1`，元素数 top+1）vs top 指向栈顶下一空位（初值 0）
- [ ] **共享栈**：两栈底在数组两端，栈顶相邻，满条件 `top1+1==top2`；共享栈更省空间且**不会发生上溢溢出丢失**（只有整体满才溢出）
- [ ] 链栈：头插法入栈，无栈满问题；多个顺序栈共享一个数组 vs 各自链栈的取舍
- [ ] n 个元素按某顺序入栈，出栈序列数 = **卡特兰数 C(2n,n)/(n+1)**；会判断出栈序列合法性（1,2,3 入栈：**312 非法，321 合法**）
- [ ] 中缀→后缀：操作数直接输出；运算符与栈顶比较优先级（**栈外先遇到高优先级的入栈，栈顶≥当前则弹栈输出**——左括号在栈内优先级最低）；括号处理
- [ ] 后缀表达式求值：遇操作数入栈，遇运算符弹**两个**数，**先弹的是右操作数**（减法除法顺序易错）
- [ ] 函数递归调用栈保存：返回地址、参数、局部变量；所有递归都可改用栈消除递归

### 3.2 自查清单（队列）

- [ ] 顺序队列"假溢出"原因 → 循环队列：`rear=(rear+1)%MaxSize`
- [ ] 循环队列三种判满方案：**牺牲一格**（队满 `(rear+1)%MaxSize==front`，队空 `front==rear`，元素数 `(rear−front+MaxSize)%MaxSize`）、增设 size 变量、增设 tag（上次删除 tag=0：`front==rear && tag==0` 为空；`&& tag==1` 为满）
- [ ] 链式队列：front 指头结点、rear 指尾结点；出队到只剩一个元素时要**把 rear 也指回**（或带头结点规避）
- [ ] 只设**尾指针的循环单链表**可以同时当队列（尾进头出）使用
- [ ] 双端队列：输入受限/输出受限——给定序列判断**能否**由某双端队列得到（逐个模拟两侧插入）
- [ ] 队列应用：二叉树层序遍历/BFS、操作系统缓冲区、页面置换 FIFO；栈应用：括号匹配、表达式求值、递归、进制转换

### 3.3 自查清单（数组与特殊矩阵）

- [ ] 二维数组行优先/列优先地址：**LOC(i,j) = LOC(0,0) + (i×n+j)×L**（行优先、n 列、下标从 0）；列优先换成 (j×m+i)
- [ ] 对称矩阵压缩（按行存下三角，含对角线，0 起）：a_ij（i≥j）存到 **k = i(i−1)/2 + j**（0 起）；上三角对称位置互换；不含对角线的变体看清题目约定
- [ ] 三对角矩阵（1 起下标）下三角存储：a_ij → **k = 2i+j−3**
- [ ] 稀疏矩阵：三元组表（行、列、值）与十字链表（行头结点+列头结点循环链表）；压缩后特殊矩阵仍可 O(1) 随机存取，**稀疏矩阵三元组不行**

### 3.4 易错点 · 高频陷阱

- 出栈序列合法性：**任意时刻出栈的元素必须是当前栈顶**——312 中出 3 后栈内是 1、2（1 在底），出 1 非法。
- 后缀求值弹出两数的顺序：`栈顶 − 次栈顶`（例：后缀 `3 4 −` = 3−4 = −1）。
- 循环队列元素个数公式必须 +MaxSize 再取模；题目若用"front/rear 指向"不同约定，公式要重推，**看清约定再套公式**。
- 对称矩阵压缩下标从 0 还是 1、是否含对角线，决定 ±1——考试先确认下标约定。
- 卡特兰数 n=3 时为 5：123 能产生的 5 种出栈序列里没有 312。

### 3.5 自测问答

**Q1. 循环队列 Q，MaxSize=6，front=2，rear=5（牺牲一格法）。队列中有几个元素？再入队 2 个后 front、rear 是多少？**

<details><summary>▶ 展开答案</summary>

元素数 = (5−2+6)%6 = **3**。再入队 2 个：rear=(5+2)%6=1；判满 (1+1)%6=2==front → 队满，实际**只能再入 1 个**（牺牲一格），所以"再入队 2 个"会先成功 1 个、第 2 个入队失败（队满）。
</details>

**Q2. 中缀式 `A+B*(C-D)-E/F` 的后缀表达式？**

<details><summary>▶ 展开答案</summary>

`A B C D - * + E F / -`。逐步：B*(C−D) 先括号后乘法，最后两个减法按从左到右。
</details>

**Q3. 数组 a[0..4][0..5]（6 列），行优先，首地址 1000，每元素 4 字节，求 a[2][3] 的地址。**

<details><summary>▶ 展开答案</summary>

前 2 整行共 2×6=12 个元素，再加本行 3 个：偏移 15×4=60 → **1060**。
</details>

**Q4. n 阶对称矩阵按行优先压缩下三角（含对角线，0 起下标），a[3][1]（3≥1）存在第几个单元？**

<details><summary>▶ 展开答案</summary>

k = 3×2/2 + 1 = **4**（第 5 个单元，若按 1 计数）。
</details>

## 第4章 串（KMP）

### 4.1 自查清单

- [ ] 串的三种存储：定长顺序存储、堆分配存储、块链存储（块大小与存储密度）
- [ ] 朴素模式匹配：最坏 O(nm)；失配后 **i 回溯到 i−j+2**（主串指针回退），下一趟从模式首字符重新比
- [ ] KMP 核心：失配时 **i 不回溯，j 滑动到 next[j]**；next[j] 的定义（王道 1 起下标）：`next[1]=0, next[2]=1`，其余 = 最长相等前后缀长度 + 1
- [ ] 会**手算**任意串的 next 数组（如 `ababaa`、`aaaab`）；理解"部分匹配值"
- [ ] nextval：若 `s[j] == s[next[j]]`，则 `nextval[j] = nextval[next[j]]`，否则等于 next[j]——会手算并解释为什么更快
- [ ] KMP 复杂度 O(n+m)；求 next 为 O(m)

### 4.2 易错点 · 高频陷阱

- 王道的 next 是 **1 起下标且 =匹配值+1**；LeetCode 式 0 起的 next 数组整体不同——看清教材约定。
- 求 next 时比较的是**真前缀与真后缀**（不含自身）。
- j=0（王道约定）时表示"本次从模式首字符重新开始且 i 也要 +1"——手推匹配过程时别死循环。
- nextval 只有在 `s[j]==s[next[j]]` 时才改写；否则照抄 next。

### 4.3 自测问答

**Q1. 求串 `abaabc`（1 起下标）的 next 数组与 nextval 数组。**

<details><summary>▶ 展开答案</summary>

next：j=1→0，j=2→1，j=3→1（a 前面无真前后缀相等），j=4→2（`ab`），j=5→3（`aba`），j=6→1（`abaab` 无相等前后缀）。
即 **0 1 1 2 3 1**。
nextval：j=3：s[3]=a，s[next[3]]=s[1]=a 相等 → nextval[3]=nextval[1]=0；j=4：s[4]=a == s[2]=b? 不等 → 照抄 2；j=5：s[5]=b == s[3]=a? 不等 → 3；j=6：s[6]=c == s[1]=a? 不等 → 1。
即 **0 1 0 2 3 1**。
</details>

**Q2. KMP 匹配中模式串在 j=5 失配（next[5]=3），下一步比什么？**

<details><summary>▶ 展开答案</summary>

主串指针 i 不动，模式指针滑到 j=3，继续比较主串当前字符与模式第 3 个字符；若再失配按 next 继续滑动，直到 j=0（王道约定）则 i+1、j=1 从头比。
</details>

## 第5章 树与二叉树

### 5.1 自查清单

- [ ] 结点数关系：**n = 边数+1 = 总度数+1**；二叉树 **n₀ = n₂ + 1**；m 叉树 n₀ = 1 + Σ(i−1)·nᵢ
- [ ] m 叉树第 i 层最多 m^(i−1) 个结点；高 h 最多 (m^h−1)/(m−1) 个；n 个结点 m 叉树最小高度 ⌈log_m(n(m−1)+1)⌉
- [ ] 完全二叉树：n 个结点高度 ⌈log₂(n+1)⌉（= ⌊log₂n⌋+1）；顺序编号性质：双亲 ⌊i/2⌋，孩子 2i、2i+1，**i≤⌊n/2⌋ 为分支结点**；n 为奇数时无度 1 结点
- [ ] 满二叉树/完全二叉树/真二叉树（无度 1 结点）的判定与互相关系
- [ ] 三种遍历（递归版）+ 层序遍历（队列）；**中序+（前序 或 后序 或 层序）可唯一还原二叉树，前序+后序不能**（真二叉树可以）
- [ ] 会手工还原二叉树并写出其他遍历序列（考题标配）
- [ ] 非递归遍历：前/中序用栈；后序非递归需要标记最近访问的结点
- [ ] 遍历序列的应用：前序+中序求后序；"叶结点相对次序在前/中/后序中相同"
- [ ] 线索二叉树：n 个结点有 **n+1 个空链域**；中序线索中找前驱/后继的规则；**先序线索难找先序前驱、后序线索难找后继**（需要双亲信息/从根出发）
- [ ] 树的存储：双亲表示法（找双亲 O(1)）、孩子表示法（顺序+链式）、**孩子兄弟表示法**（左孩子右兄弟，树→二叉树的桥梁）
- [ ] 树 ↔ 二叉树转换：左孩子右兄弟；**树转换后根无右子树**；森林 ↔ 二叉树（各树根互为右兄弟）
- [ ] 树的遍历对应：先根遍历 = 对应二叉树**先序**；后根遍历 = 对应二叉树**中序**；树没有中根遍历；森林先序 = 二叉树先序，森林中序 = 二叉树中序
- [ ] BST：定义（左<根<右）、中序序列递增；查找/插入；**删除度 2 结点用前驱或后继替补**；ASL 计算；相同关键字序列不同插入次序得到不同树形
- [ ] AVL：平衡因子 ∈{−1,0,1}；四种失衡的旋转：LL 右单旋、RR 左单旋、LR 先左后右双旋、RL 先右后左双旋——**每个失衡结点都要调整**
- [ ] AVL 插入后**至多一次（单/双）旋转**恢复平衡；删除后可能 O(log n) 次旋转；最少结点数递推 N(h)=N(h−1)+N(h−2)+1（N(1)=1, N(2)=2）
- [ ] 哈夫曼树：n 个叶结点的哈夫曼树**共 2n−1 个结点、无度 1 结点**；构造：每次取权值最小的两棵合并；WPL = Σ权×路径长 最小
- [ ] 哈夫曼编码：前缀码（任何编码不是另一编码前缀）；左 0 右 1；总编码长度 = WPL；频率高的字符编码短
- [ ] 并查集：双亲表示法存储；Find 沿双亲向上；Union 按大小/高度合并（树高 ≤ ⌊log₂n⌋+1）；路径压缩

### 5.2 易错点 · 高频陷阱

- "前序+后序不能唯一确定二叉树"的反例：只有左孩子的链（前 ab 后 ba 与只有右孩子链相同）。
- 先序线索二叉树中**先序前驱无法 O(1) 得到**（可能需要双亲）；后序线索中后序后继同理——考"在 X 线索树中找 X 序前驱/后继能否实现"。
- 树转二叉树后，树的**后根序列 = 二叉树的中序序列**（不是后序！）。
- AVL 双旋（LR/RL）先对**孩子**旋再对**自己**旋；旋转后新根的左右子树分配要准确——考手画。
- 完全二叉树用顺序存储**不浪费**；一般二叉树顺序存储有大量空间浪费（最坏单支深 h 需 2^h−1 单元）。
- 哈夫曼树中权值相同的不同构造方式 WPL 相同；哈夫曼编码长度可能不同（各叶深度不同）。
- 度为 m 的树至少有 m+1 个结点；m 叉树至少 1 个结点——"树"与"m 叉树"概念区分。

### 5.3 自测问答

**Q1. 一棵二叉树先序 ABDECF，中序 DBEACF，求后序序列。**

<details><summary>▶ 展开答案</summary>

先序首 A 为根；中序中 A 左侧 DBE 为左子树、CF 为右子树。左子树先序 BDE+中序 DBE：B 为根，D 左 E 右；右子树先序 CF+中序 CF：C 为根，F 为右孩子。
后序：**DEBFCA**。
</details>

**Q2. 一棵有 5 个结点且无度为 1 结点的二叉树（真二叉树）有几种不同形态？**

<details><summary>▶ 展开答案</summary>

由 n₀ = n₂+1 且 n₀+n₂=5 得 n₂=2、n₀=3。含 k=2 个内部结点的真二叉树形态数 = 卡特兰数 C(2k,k)/(k+1) = C(4,2)/3 = **2 种**（根的另一孩子为叶，含内部结点的那棵子树可挂左边或右边）。
</details>

**Q3. 依次插入 50, 30, 70, 20, 40, 35 构造 BST，再插入 38 后是否失衡？若插入 45, 46 呢（描述调整）？**

<details><summary>▶ 展开答案</summary>

插入 38：30→40→35→38 路径，最小失衡子树是 40（因子 2，LR 型）：对 40 左旋、再对 35? ——失衡结点为 40（|bf|=2），LR：先左旋 40 与 35 关系、后右旋，新子树根 38。
插入 45、46：46 使 35（或调整后相应结点）出现 RR 失衡 → 左单旋一次恢复。要点：**插入只引起一次旋转**。
</details>

**Q4. 权集 {7,5,2,4} 构造哈夫曼树，求 WPL 与各字符编码长度。**

<details><summary>▶ 展开答案</summary>

合并 2+4=6；6 与 5 合并 11；11 与 7 合并 18。

</details>

## 第6章 图

### 6.1 自查清单

- [ ] 基本概念：完全图边数（无向 n(n−1)/2，有向 n(n−1)）；连通（无向）vs 强连通（有向，任意两顶点双向可达）；子图/生成子图
- [ ] 度、入度、出度；握手定理：**Σ度 = 2e**；有向图 Σ入度 = Σ出度 = e
- [ ] 连通分量（无向极大连通子图）；有向图的强连通分量；n 顶点连通图至少 n−1 条边，强连通至少 n 条（环）
- [ ] 生成树：连通图含全部 n 顶点的 n−1 条边无环子图；非连通图得生成森林
- [ ] 邻接矩阵：无向图对称、第 i 行和 = 度；有向图行和=出度、列和=入度；空间 O(n²)，适合**稠密图**
- [ ] 邻接表：空间 O(n+e)（无向 2e）；**有向图邻接表求入度要遍历全表（或建逆邻接表）**；同一图的邻接表**不唯一**（边结点次序）
- [ ] 十字链表（有向图）与邻接多重表（无向图，方便同一条边的操作）
- [ ] BFS：队列实现、 visited 数组；空间 O(n)；邻接表 O(n+e)、邻接矩阵 O(n²)；**BFS 可解无权图单源最短路**；BFS 生成树高度 ≥ DFS 生成树高度
- [ ] DFS：栈/递归；邻接表表示时序列不唯一；对无向图判连通、找路径；非连通图调用遍历次数 = 连通分量数
- [ ] 最小生成树：**MST 权值和唯一，树形可不唯一**（权互异才唯一）；Prim（从点出发、适合稠密、O(n²)）vs Kruskal（按边贪心+并查集判环、适合稀疏、O(e log e)）——会手推每一步选边
- [ ] Dijkstra：单源最短路、贪心、**每轮确定一个顶点的最终距离**；不能处理负权边；邻接矩阵 O(n²)；会手推 dist/path 数组变化
- [ ] Floyd：所有顶点对、动态规划、三重循环（k 在最外层）O(n³)；允许负权边（不允许负权回路）；会手推 A^(k) 矩阵
- [ ] 拓扑排序：AOV 网；算法（反复输出入度 0 顶点+删除其出边）；**O(n+e)**；用栈或队列存 0 入度顶点；拓扑序列不唯一；**存在长度为 n 的拓扑序列 ⇔ 无环**；DFS 可得逆拓扑排序
- [ ] 逆拓扑排序：出度法（反复输出出度 0 顶点）或 DFS 完成时入栈再弹出
- [ ] 关键路径（AOE 网，带权有向无环）：事件最早 ve（源点 0，取 max(ve+权)）、最迟 vl（汇点 = ve，取 min(vl−权)）、活动最早开始 e = ve(弧尾)、最迟开始 l = vl(弧头) − 权；**关键活动 e=l、时间余量 0**
- [ ] 关键路径 = 最长路径；缩短工期：必须压缩**所有**关键路径共有的关键活动才有效；压缩过度可能使关键路径改变

### 6.2 易错点 · 高频陷阱

- 有向图邻接表里一个顶点的边表是"出边"；求入度必须扫全表——复杂度题常考。
- Dijkstra **不能用于含负权边的图**（贪心前提被破坏）；Floyd 可以（但不能有负权回路）。
- Kruskal 用**并查集**判断两端点是否已连通；Prim 每次加入一个**顶点**、选横跨已选/未选的最小边。
- "图 G 的 DFS 序列唯一吗"：邻接矩阵唯一，**邻接表不唯一**。
- 拓扑排序的存储结构通常说"栈"，其实队列也可以——结果都可能合法，考的是机制不是容器。
- 关键路径可能不止一条；**关键活动不延误则整个工期不延误**，但缩短单个关键活动不一定缩短总工期。
- 无向连通图 n 顶点至少 n−1 条边；**有向强连通**至少 n 条边（构成环）——两条结论分开记。

**Q1. 无向图 n=6，要保证图一定连通，至少需要几条边？**

<details><summary>▶ 展开答案</summary>

6 个顶点、5 条边只可能是一棵树才连通，"一定连通"要考虑最坏情形：5 条边全部浪费在 K₅（5 个点完全图需 10 条边）之内再加 1 条连出：10+1 = **11 条**。

**Q2. 用 Dijkstra 求下图 v0 到各点最短路（边：v0→v1=4, v0→v2=1, v2→v1=2, v1→v3=1, v2→v3=5）。给出确定顺序。**

<details><summary>▶ 展开答案</summary>

① 选 v2（dist=1）；更新 v1 = min(4, 1+2)=3，v3=6。
② 选 v1（dist=3）；更新 v3 = min(6, 3+1)=4。
③ 选 v3（dist=4）。
确定顺序 v2 → v1 → v3；v1 最短路 1+2=3，v3 最短路 v0→v2→v1→v3 = 4。若允许 v0→v3=6 直达对比，说明贪心逐步确定正确。
</details>

e = ve(弧尾) = 5；l = vl(弧头) − 历时 = 12−4 = 8。时间余量 l−e = 3 > 0，**不是**关键活动（可延迟 3）。

## 第7章 查找

### 7.1 自查清单

- [ ] ASL（平均查找长度）= Σ pᵢcᵢ；会算成功/失败两种 ASL
- [ ] 顺序查找：成功 (n+1)/2；**有序表顺序查找失败可不比到尾（有序可提前终止）**；哨兵的作用
- [ ] 折半查找：适用**有序顺序表**；判定树：mid=⌊(low+high)/2⌋；**判定树是平衡 BST，失败结点 n+1 个**；树高 = ⌈log₂(n+1)⌉；查找成功最多比较 ⌈log₂(n+1)⌉ 次
- [ ] 会画 n=11 的判定树并算成功 ASL（第 k 层结点数×k 求和除以 n）
- [ ] 分块查找：n 元素分 b 块每块 s 个；索引**顺序查找**时 ASL = (b+1)/2 + (s+1)/2，**最优 s=√n**，ASL=√n+1；索引折半查找 ASL = ⌈log₂(b+1)⌉ + (s+1)/2
- [ ] B 树（m 阶）五条性质：根 ≥2 棵子树；非根非叶 ≥⌈m/2⌉ 棵子树（⌈m/2⌉−1 个关键字）；子树数=关键字数+1；**所有叶结点（失败结点）在同一层**；关键字有序
- [ ] m 阶 B 树关键字数范围 [⌈m/2⌉−1, m−1]；n 个关键字的 B 树叶结点（失败）个数 = n+1
- [ ] B 树插入：插入到**最底层终端结点**，超上限从中间 ⌈m/2⌉ **分裂**（结点数 m 时）；B 树删除：兄弟够借（父关键字旋转下移）、不够借则与兄弟+父关键字**合并**，可能级联回溯到根
- [ ] B+ 树与 B 树差异：**n 棵子树 n 个关键字**（B 树 n+1 棵 n 个）；叶结点含全部关键字且**链表串联**支持顺序查找；非叶结点只作索引；m 阶 B+ 结点关键字数 [⌈m/2⌉, m]
- [ ] 红黑树（考纲新增）：五条性质（结点红/黑、根黑、叶(NULL)黑、红结点孩子必黑、任一结点到叶的每条路径黑高相同）；**高度 ≤ 2log₂(n+1)**；插入：新结点初始红色，叔红变色上溢、叔黑旋转+变色；为什么用红黑树代替 AVL（增删旋转次数少、综合性能好）
- [ ] 散列表：装填因子 α = 记录数/表长；散列函数：除留余数法（p 取 ≤m 的最大素数）、直接定址、数字分析、平方取中
- [ ] 冲突处理：开放定址（**线性探测**：堆积/一次聚集；**平方探测**：±j²，表长为 4k+3 型素数才能探完全表；双散列）、拉链法；开放定址删除只能**懒惰删除**（做标记）
- [ ] 会手算：给定散列函数和序列构造散列表，分别计算**成功 ASL**（每个元素的比较次数均值）与**失败 ASL**（从每个哈希地址出发到第一个空位的比较数均值，模 p 只算 0..p−1）
- [ ] 散列查找效率只取决于散列函数、冲突处理方法与 α（与 n 无直接关系）；α 越小效率越高

### 7.2 易错点 · 高频陷阱

- 折半查找判定树画法与取整方向绑定：mid 向下取整时左子树结点 ≥ 右子树；考试按题目约定画。
- B 树的"叶结点"指**失败结点（外部结点）**，不算关键字层——数层、算高度时先确认题目口径。
- B+ 树根结点至少 2 棵子树、其他结点至少 ⌈m/2⌉ 棵；**B+ 的成功查找一定走到叶层**（B 树可能在中间命中）。
- 散列"失败 ASL"：除留余数 mod p 时只需对 0..p−1 各地址统计，不是对全表长 m——经典扣分点。
- 线性探测删除后不能直接置空（截断探测链），要用标记。
- 顺序表才能折半；链表不能折半（不支持随机访问）——"对有序链表折半查找"必错。
- 红黑树查找最坏 O(2log n)，AVL 更矮但维护更贵；两树对比题答"增删多的场景用红黑树"。

## 第8章 排序

### 8.1 自查清单

- [ ] 稳定性表：稳定 = 直接插入、冒泡、归并、基数（口诀"插冒归基"）；不稳定 = 希尔、快排、简单选择、堆
- [ ] 直接插入：最好 O(n)（基本有序，只比不搬）、最坏 O(n²)（逆序，比较+移动都满）；适合**基本有序或 n 小**
- [ ] 折半插入：**比较次数 O(n log n) 与初始状态无关，移动次数不变** → 总仍 O(n²)
- [ ] 希尔排序：按增量分组做插入，增量逐次缩小最后为 1；复杂度依赖增量序列（约 O(n^1.3)，最坏 O(n²)）；不稳定；只能顺序存储
- [ ] 冒泡：设交换标志后最好 O(n)；第 i 趟结束后**最大的 i 个元素依次沉底**；移动次数与逆序对有关（每对逆序元素交换一次）
- [ ] 快排：划分（枢轴就位）；平均 O(n log n) **常数最小、内部排序平均性能最优**；最坏 O(n²)（基本有序/逆序+枢轴取端点）；空间 = 递归栈 O(log n)（最坏 O(n)）；不稳定；**n 很大时快排优势明显，n 小时插入排序更快**
- [ ] 简单选择：**比较次数恒为 n(n−1)/2 与初态无关**；移动 ≤3(n−1)；不稳定
- [ ] 堆：大根堆（升序）；`⌊n/2⌋..1` 依次下沉建堆 **O(n)**；排序每趟堆顶与末尾交换再下沉 O(log n)，总 O(n log n)；空间 O(1)；仅适合**顺序存储**；插入=上浮；删除堆顶=末尾补顶下沉
- [ ] 会手算：给序列建大根堆（画出过程）、给第 k 趟后的序列
- [ ] 归并：2 路归并 O(n log n)，比较次数与初态**基本无关**（除最后合并）；稳定；空间 O(n)（辅助数组）——内部排序里空间开销最大
- [ ] 基数排序（LSD 最低位优先）：d 趟"分配+收集"，r 个队列；每趟 O(n+r)，总 **O(d(n+r))**；空间 O(r)；不基于比较（突破 O(n log n) 下界）；要求 d 小、n 大；依赖**稳定的**子排序
- [ ] 外部排序：多路归并，归并趟数 S = ⌈log_k r⌉（r 个初始归并段、k 路）；增加 k 或减少 r 都能减趟数；**败者树**使每次选最小比较 ⌈log₂k⌉ 次；置换-选择排序生成平均长度 2×内存容量的初始段；**最佳归并树**（哈夫曼思想）安排归并顺序，u=(r−1)%(k−1)≠0 时补 k−1−u 个虚段；k 路归并需 2k 个输入缓冲、2 个输出缓冲
- [ ] 会做"给两个序列判断是哪种排序的第某趟"题型（快排/冒泡/插入/归并/堆/选择 各自趟特征：枢轴就位、后缀有序、前缀有序、归并段长翻倍、堆顶规律）

### 8.2 易错点 · 高频陷阱

- "比较次数与初始序列无关"的算法：**简单选择、折半插入（比较）、归并（次数基本无关）**；"移动次数无关"几乎没有。
- 堆排序前 k 大：O(n + k log n)——top-k 题的经典答案；快排一次划分也能求第 k 大（平均 O(n)）。
- 归并排序**比较次数与初态无关**（每趟固定 n−1 级别），但严格说最后一段可能不足 m——考题表述"基本无关/与初态无关"按教材口径答。
- 快排"每趟至少一个元素就位"——冒泡是"每趟一个最大值就位"、选择是"每趟一个最小值就位"、堆是"每趟堆顶就位"。
- 基数排序每趟用的分配收集必须是**稳定的**，否则前一位排序结果被破坏。
- 大根堆的兄弟之间**没有大小关系**；删除堆顶是"末尾元素补顶再下沉"，不是"右孩子上移"。
- 外部排序时间 = 内部排序(初始段) + 外存读写( dominated，趟数×段总数) + 内部归并；减少**趟数**最有效。
