## 一、计算机系统概述（笔记：第1章 计算机系统概述）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC1%E7%AB%A0%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%B3%BB%E7%BB%9F%E6%A6%82%E8%BF%B0.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- (一)1 计算机系统的基本组成：硬件 + 软件，主机 = CPU + 主存
  - 冯·诺依曼机核心思想：**存储程序**、指令与数据同等地位存放于存储器、按地址访问
  - 五大部件：运算器、控制器、存储器、输入设备、输出设备；CPU = 运算器 + 控制器
  - 软件分系统软件（OS、DBMS、编译程序）与应用软件；指令和数据都用二进制表示
- (一)2 计算机硬件的基本结构：冯·诺依曼结构 vs 哈佛结构
  - 冯·诺依曼结构：指令与数据**共用一个存储器**，早期以运算器为中心、现代以存储器为中心
  - 哈佛结构：指令存储器与数据存储器**分开**，可同时取指与取数
- (一)3 计算机软件和硬件的关系：逻辑功能上等价
  - 同一功能既可用硬件（快、贵、不灵活）实现，也可用软件（慢、便宜、灵活）实现
  - 固件（Firmware）= 固化在 ROM 中的微程序，是软硬件之间的折中
- (一)4 计算机系统的工作原理之一：高级语言程序 → 机器语言程序
  - 编译程序：把源程序**整体翻译**成等价的目标程序后再执行，执行期不再需要源程序
  - 解释程序：**逐句翻译并立即执行**，不生成目标程序
  - 程序与指令的执行过程：取指令 → 分析（译码）→ 执行，PC 取指后自动加 1
- (一)4 计算机系统的工作原理之二：计算机系统的层次结构
  - 微程序机器级 → 传统机器级（机器语言）→ 操作系统级 → 汇编语言级 → 高级语言级
  - 相邻层次由**翻译程序**衔接（汇编程序、编译程序）；下层是上层的基础
- 【21增】计算机性能指标之一：吞吐量、响应时间与 CPU 时间
  - 吞吐量 = 单位时间完成的任务数；响应时间 = 从发出请求到获得结果的时间
  - 时钟周期 $T$、主频 $f = \dfrac{1}{T}$、CPI（执行一条指令平均所需时钟周期数）
  - $T_{\text{CPU}} = \text{指令条数} \times CPI \times T = \dfrac{\text{指令条数} \times CPI}{f}$
- 【21增】计算机性能指标之二：MIPS 与浮点运算速度
  - $MIPS = \dfrac{\text{指令条数}}{T_{\text{CPU}} \times 10^6} = \dfrac{f}{CPI \times 10^6}$，与主频、CPI 都有关
  - MFLOPS $10^6$、GFLOPS $10^9$、TFLOPS $10^{12}$、PFLOPS $10^{15}$、EFLOPS $10^{18}$、ZFLOPS $10^{21}$
- 存储容量、字长与数据通路带宽
  - MAR 位数决定可寻址单元数 $2^n$，MDR 位数 = 存储字长：MAR 24 位 + MDR 16 位 → $2^{24} \times 2\text{B} = 32\text{MB}$
  - 数据通路带宽 = 数据总线一次并行传送的位数，**不是 CPU 字长**；机器字长 = CPU 一次能处理的位数
- 基准程序（benchmark）与性能评价
  - 比较性能必须用**同一程序的总执行时间**或同一基准程序，单比主频、单比 MIPS 都不严谨
  - 主频高不等于快：CPI、指令条数、访存速度都会影响实际性能

## 二、数据的表示和运算（笔记：第2章 数据的表示和计算）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC2%E7%AB%A0%20%E6%95%B0%E6%8D%AE%E7%9A%84%E8%A1%A8%E7%A4%BA%E5%92%8C%E8%AE%A1%E7%AE%97.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- (一)1 进位计数制及其相互转换
  - 二/八/十六进制互转以二进制为桥梁：每 3 位一组、每 4 位一组
  - 十进制整数：除基取余、逆序排列；十进制小数：乘基取整、顺序排列，**可能无限循环**
- (一)2 定点数的编码表示
  - 原码、反码（负数数值位取反）、补码（反码末位加 1）、移码（补码符号位取反）及互换
  - $n+1$ 位补码整数范围 $[-2^n,\ 2^n-1]$，比原码/反码**多表示一个最小负数**；定点小数补码范围 $[-1,\ 1-2^{-n}]$
  - 0 的表示：补码、移码唯一；原码、反码有 $+0$ 与 $-0$ 两种
- (二)1 基本运算部件：加法器与算术逻辑部件 ALU
  - 一位全加器：$S = A \oplus B \oplus C_i$，$C_o = AB + (A \oplus B)C_i$
  - 串行进位加法器延迟 $O(n)$；先行进位 CLA：$C_{i+1} = G_i + P_i C_i$（$G_i = A_i B_i$、$P_i = A_i \oplus B_i$），组内并行、组间可再串行
  - ALU 是**组合逻辑部件**，74181 的 M 位选择算术/逻辑运算，ALU 是运算器的核心
- (二)2 加减运算：补码加减运算器与标志位的生成
  - 减法用补码加法器实现：$[A-B]_补 = [A]_补 + [-B]_补$，$[-B]_补$ 为 $[B]_补$ 各位取反、末位加 1（由 $Sub$ 控制）
  - $CF$ 取最高位进位：加法 $CF = C_{out}$；减法 $CF = C_{out} \oplus 1$（不够减产生借位时 $CF = 1$）
  - $OF = C_n \oplus C_{n-1}$（最高位进位异或次高位进位，只对带符号数有意义）；$ZF = \overline{F_{n-1} + \cdots + F_0}$（结果全 0）；$SF = F_{n-1}$（结果符号位）
  - 溢出判别：单符号位用 $OF = C_n \oplus C_{n-1}$；双符号位（变形补码）**两符号位不同即溢出**，01 正溢、10 负溢
- (二)3 乘除运算的基本原理：一位乘
  - 原码一位乘：符号位**异或**单独求，数值位取绝对值相乘、每步**逻辑右移**（高位补 0），$n$ 次加法 + $n$ 次移位
  - 补码一位乘 Booth：符号位参与，按 $Y_iY_{i-1}$ 判断（01 加 $[X]_补$、10 加 $[-X]_补$、00/11 只移位）后**算术右移**，$n+1$ 次加法 + $n$ 次移位，**最后一步不移位**
- (二)3 乘除法电路的基本结构之一：一位乘电路与阵列乘法器
  - 原码一位乘硬件：部分积寄存器与乘数寄存器**联合右移**、一位加法器、乘数最低位控制"加被乘数/加 0"、计数器控制循环次数
  - 阵列乘法器：$n \times n$ 个**与门**并行产生 $n^2$ 个位积 + **全加器阵列**按权重压缩求和，**纯组合逻辑、一个时钟周期出结果**（面积换时间），$n$ 位约 $2n-1$ 级全加器延迟
  - 进位保存加法器 CSA（3-2 压缩器）：把 3 个输入压缩成"和 + 进位"两个输出，**进位不在本级传播**而横向送入下一列的高位，只在最后一级用一次 CLA/行波加法器 CPA 求和
- (二)3 乘除法电路的基本结构之二：带符号阵列乘法器与阵列除法器
  - 带符号阵列乘法器：**算前求补**（补码 → 绝对值）→ 无符号阵列相乘 → **算后求补**，符号位由 $X_S \oplus Y_S$ 单独决定
  - 阵列除法器：用**可控加/减运算单元 CAS** 排成阵列逐行"减除数试商"，每行最左单元产生一位商并控制本行加/减除数，余数向下传递，纯组合逻辑
- (二)3 除法的实现：恢复余数法与加减交替法
  - 原码恢复余数法：余数为负时**加回除数**恢复，每步可能要两次加法
  - 不恢复余数法（加减交替）：余数为负时商 0 且**不恢复**，下一步直接加除数，每步固定 1 次加法，仅最后一步恢复一次
  - 补码加减交替除法：符号位参与运算、**商符由运算自然形成**；原码除法的商由绝对值运算、商符异或得到
- (三)1 无符号整数的表示与运算
  - $n$ 位无符号整数全部位都是数值位，范围 $0 \sim 2^n-1$；加减结果按模 $2^n$ 自动截断
  - **无符号溢出判据 = 最高位的进位（加法）/借位（减法）**，即 $CF = 1$；比较用 $CF$、$ZF$（无符号条件转移 JA/JAE/JB/JBE）
- (三)2 带符号整数的表示与运算
  - 补码 $n+1$ 位范围 $[-2^n,\ 2^n-1]$，符号位参与运算，最高位进位**自动丢弃**
  - **带符号溢出判据 = $OF = C_n \oplus C_{n-1}$**（双符号位 01 正溢、10 负溢）；比较用 $SF$、$OF$、$ZF$（带符号条件转移 JG/JGE/JL/JLE）
  - 无符号 ↔ 带符号转换：同宽转换**位串不变、只改变解释方式**；位宽提升时无符号**零扩展**、带符号**符号扩展**；C 语言中有符号与无符号混合运算会**隐式转为无符号**
- (四)浮点数的表示和运算
  - 格式 = 阶码（移码，便于比较大小）+ 尾数（原码，常用规格化）；左规（尾数左移、阶码减）、右规最多一次
  - IEEE 754：单精度 1 + 8 + 23（偏置 127）、双精度 1 + 11 + 52（偏置 1023）；规格化数有**隐藏的最高位 1**；阶码全 0（非规格化数、$\pm 0$）、全 1（$\pm\infty$、NaN）为特例
  - 浮点加减五步：**对阶（小阶向大阶）→ 尾数加减 → 规格化 → 舍入 → 溢出判断**（只有阶码溢出才算溢出）
- 教材常考：校验码（海明码与 CRC）
  - 海明码：$2^k \ge n + k + 1$（$k$ 位校验位、$n$ 位信息位），校验位放在 $2^i$ 位置，可**纠 1 位错**
  - CRC：模 2 除法，生成多项式最高 $r$ 次幂 → $r$ 位校验位，**只检错、不纠错**

## 三、存储器层次结构（笔记：第3章 存储器层次结构）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC3%E7%AB%A0%20%E5%AD%98%E5%82%A8%E5%99%A8%E5%B1%82%E6%AC%A1%E7%BB%93%E6%9E%84.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- (一)存储器的分类
  - 按存储介质（半导体/磁表面/光）、按存取方式（RAM、ROM、SAM、DAM、CAM）、按作用（主存/辅存/Cache/寄存器）分类
  - 磁盘属**直接存取存储器 DAM**（先定位区域再顺序搜索）；Cache 的标记存储器用**相联存储器 CAM**（按内容检索）
- (二)层次化存储器的基本结构
  - 层次：寄存器 → Cache → 主存 → 辅存；"Cache—主存"解决**速度**矛盾，"主存—辅存"解决**容量**矛盾
  - 越往上层速度越快、容量越小、单位价格越高，依据是**局部性原理**（时间局部性、空间局部性）
- (三)半导体随机存取存储器：SRAM、DRAM、Flash
  - SRAM 用触发器存储：快、贵、功耗大 → Cache；DRAM 用电容存储：需**刷新**、集成度高、便宜 → 主存
  - DRAM 刷新：集中刷新、分散刷新、异步刷新，**按行刷新**、对 CPU 透明（不占 CPU 时间但占用存储器周期）
  - Flash：NOR（可随机读、支持 XIP 就地执行）与 NAND（**按页读写、按块擦除**、密度高 → SSD/U 盘），改写必须先擦除
- (四)1 DRAM 芯片和内存条
  - DRAM 芯片地址线**行/列分时复用**：同一组地址引脚分两次送入行地址、列地址（由 $\overline{RAS}$、$\overline{CAS}$ 选通锁存），显著减少引脚；刷新只需行地址
  - 内存条（DIMM）：多颗 DRAM 芯片焊在小电路板上，各芯片**位扩展**并联成 64 位数据位宽，经内存插槽与主板连接
  - 条上的 **SPD**（小容量 EEPROM）保存容量与时序参数供 BIOS 读取；**DDR** 在时钟双沿各传一次，数据传输率 = 内存时钟频率 × 2
- (四)2 多模块存储器
  - 高位交叉编址：体号在地址**高位**，顺序编址、便于扩容，不能流水存取
  - 低位交叉编址：体号在地址**低位**，连续地址分布在不同的体上，可**流水线存取**
  - $m$ 体低位交叉连续读 $m$ 个字：$T + (m-1)r$（存取周期 $T$、总线传送周期 $r$，条件 $m r \ge T$）；双端口 RAM 冲突时由 $\overline{BUSY}$ 决定优先
- (四)3 主存和 CPU 之间的连接
  - 存储扩展：**位扩展**（多片共用片选、数据线拼接）、**字扩展**（高位地址译码产生片选）、字位同时扩展；芯片数 = 总容量 ÷ 单片容量
  - 片选译码：线选法（简单、地址不连续）与译码器法（如 74LS138，地址连续、无浪费）
- 【22增】外部存储器（磁盘/SSD）之一：磁盘存储器
  - 结构：盘片（记录面）→ **磁道** → **扇区**（读写最小单位，也称块）；不同记录面上**同号磁道构成柱面**；磁头数 = 记录面数
  - 磁盘地址 = **驱动器号 + 柱面（磁道）号 + 盘面号 + 扇区号**；容量 = 记录面数 × 每面磁道数 × 每道扇区数 × 扇区大小
  - 平均存取时间 = **寻道时间 + 平均旋转延迟（半圈 $\dfrac{60}{2r}$ 秒，转速 $r$ 转/分）+ 传输时间 + 控制器延迟**；数据传输率 = 转速(r/s) × 每道扇区数 × 扇区大小
- 【22增】外部存储器（磁盘/SSD）之二：固态硬盘 SSD
  - 组成：NAND Flash 阵列 + 主控制器 + DRAM 缓存；**FTL（闪存翻译层）**完成主机逻辑块地址 → 闪存物理页的映射，磨损均衡也由它实现
  - 读写特性：按页读写、按块擦除、**写前必须先擦**；改写已写页要整块擦除并搬移有效页（**垃圾回收**）→ **写放大**；随机读快、写（尤其随机写）慢
  - **磨损均衡**把擦写均摊到各块，避免热点块提前失效；**TRIM** 通知 SSD 回收无效页；寿命由每块的 **P/E（编程/擦除）次数**决定
  - 磁盘 vs SSD：SSD **无寻道与旋转延迟**、随机访问快、抗震低功耗；但**写入寿命有限、单位容量成本高**，磁盘在大容量顺序读写与成本上仍有优势
- (六)1 高速缓冲存储器 Cache 的基本工作原理
  - 命中率 $H = \dfrac{N_c}{N_c + N_m}$；平均访问时间 $t = H t_c + (1-H) t_m$（并行口径）或 $t = H t_c + (1-H)(t_c + t_m)$（顺序口径），看清题目假设
  - 块（行）大小的影响：太小则空间局部性利用不足，太大则行数减少、冲突率上升
- (六)2 Cache 和主存之间的映射方式
  - **直接映射**：主存块 → 唯一行，行号 = 主存块号 $\bmod$ 行数（地址 = tag | 行号 | 块内），无替换问题但冲突率高
  - **全相联**：可放到任一行，tag 最长、比较器最多最贵；**组相联**：组间直接映射、组内全相联（地址 = tag | 组号 | 块内）
  - 会做地址划分与命中判断：块内位数 $= \log_2(\text{块大小})$，组数 $= \dfrac{\text{Cache 容量}}{\text{块大小} \times \text{路数}}$
- (六)3/4 替换算法与写策略
  - 替换算法：直接映射无需替换；全相联/组相联组内用 LRU（计数器法）、FIFO、LFU、随机，会推 LRU 计数器变化与命中替换过程
  - 写命中：**写直达 write-through**（同时写主存，配写缓冲）与**写回 write-back**（置换时才写回，需**脏位/修改位**）
  - 写不命中：**写分配**（调块入 Cache，常配写回）与**非写分配**（只写主存，常配写直达）；多级 Cache 有局部/全局命中率之分
- (七)虚拟存储器：页式、段式与段页式
  - 基本概念：主存与辅存统一编址，由**硬件（MMU）与操作系统**共同管理；虚存解决容量、Cache 解决速度
  - 页式虚拟存储器：虚地址（虚页号 + 页内偏移）→ 查**页表** → 实地址（页框号 + 页内偏移）；**TLB（快表）**存页表项副本，命中则免去访问页表；缺页时 OS 调页并更新页表
  - 段式（按逻辑功能分段、段长可变、便于共享与保护）与**段页式**（先分段再分页，地址转换需查段表 + 页表）

## 四、指令系统（笔记：第4章 指令系统）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC4%E7%AB%A0%20%E6%8C%87%E4%BB%A4%E7%B3%BB%E7%BB%9F.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 【22增】指令系统 (一)指令系统的基本概念
  - 指令 = 操作码 + 地址码；指令系统（指令集）是**软硬件之间的接口**，决定机器能直接执行的操作
  - 指令字长、机器字长、存储字长三者可以不同；指令字长取决于操作码长度与地址码个数/位数
- (二)指令格式
  - 四地址/三地址/二地址/一地址/零地址指令的语义与访存次数；零地址用于堆栈型机器或无需操作数（NOP、停机）
  - 定长操作码 vs **扩展操作码**（变长）：短码**不能**是长码的前缀，会算给定分层方案下各长度能表示的指令条数
- (三)寻址方式
  - 立即（操作数在指令中，取指后**不再访存**）、直接 $EA = A$、一次间接 $EA = (A)$、寄存器 $EA = R_i$（0 次访存）、寄存器间接（1 次访存）
  - 相对寻址 $EA = (PC) + A$：PC 是**取指完成后**的值（= 本指令地址 + 指令字长），便于程序浮动，偏移用补码
  - 基址寻址 $EA = (BR) + A$：BR 由**操作系统**管理，面向系统（重定位、多道程序）；变址寻址 $EA = (IX) + A$：IX **用户可改**，面向用户（数组、循环）
  - 堆栈寻址：由 SP 指示栈顶，硬堆栈（寄存器组）与软堆栈（主存），压栈/弹栈改变 SP
- (四)数据的对齐和大/小端存放方式
  - 大端：**高字节存低地址**；小端：**低字节存低地址**（x86 小端、网络字节序大端），0x12345678 在大端低地址放 0x12
  - 边界对齐：数据地址为自身长度的整数倍，可**一次访存取出**；不齐可能需两次访存，结构体需填充
- (五)CISC 和 RISC 的基本概念
  - RISC：指令少且**定长**、寻址方式少、**只有 Load/Store 访存**、通用寄存器多、**硬布线控制器**、便于流水线
  - CISC：指令多且变长、寻址方式多、指令功能复杂、多用**微程序控制器**、较难流水
- (六)1 编译器、汇编器和链接器的基本概念
  - 翻译链路：源程序 .c →（**编译器**）汇编程序 .s →（**汇编器**）目标文件 .o →（**链接器** + 库文件）可执行文件 →（加载器）装入内存
  - 编译程序（整体翻译、生成目标程序）与解释程序（逐句翻译执行、不生成目标程序）的区别；静态链接与动态链接
- (六)2 选择结构语句的机器级表示
  - if-else = CMP/TEST 置条件码 + 条件转移 Jcc + JMP 跳过 else 分支
  - switch = **跳转表**（用 case 值直接索引目标地址，与 case 个数无关、近似 O(1)），前提是 case 值较密集且需判断越界走 default
- (六)3 循环结构语句的机器级表示
  - while 先判断后执行（循环体可能一次都不执行）；do-while 先执行后判断（至少执行一次）；for = 判断 + 循环体 + 自增 + JMP 回跳
  - 条件码 CF/ZF/SF/OF：**OF、SF 对无符号数无意义，CF 对带符号数无意义**；带符号比较用 Jg/Jge/Jl/Jle，无符号比较用 Ja/Jae/Jb/Jbe
- (六)4 过程（函数）调用对应的机器级表示
  - 调用约定：cdecl（参数**从右向左**入栈、**调用者**清栈）、stdcall（被调用者清栈）；x86-64 System V 前 6 个整数参数走 RDI、RSI、RDX、RCX、R8、R9，返回值放 RAX
  - CALL 自动压入**返回地址**（下一条指令的地址），RET 弹出并转移；栈由高地址向低地址增长
  - 栈帧：局部变量在 $[ebp]-n$（低地址侧）、入口参数在 $[ebp]+n$（高地址侧）、$[ebp]$ 存调用者的 EBP、$[ebp]+4$ 是返回地址；leave = movl %ebp,%esp + popl %ebp
- 常用 x86 指令与乘除的隐含寄存器约定
  - AT&T 格式**源在前、目的在后**、寄存器加 %、立即数加 $、内存写 disp(base,index,scale)；Intel 格式相反，用 dword ptr 等说明长度
  - 乘法被乘数隐含 AX、结果在 (DX:AX)；除法被除数 (DX:AX)、**商 → AX、余数 → DX**；MUL/DIV 无符号，IMUL/IDIV 带符号
  - CMP 行为同 SUB、TEST 行为同 AND，**只设置条件码、不改变目的寄存器**；MOV 有五种操作数组合但不能内存到内存

## 五、中央处理器（笔记：第5章 中央处理器）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC5%E7%AB%A0%20%E4%B8%AD%E5%A4%AE%E5%A4%84%E7%90%86%E5%99%A8.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- (一)CPU 的功能和基本结构
  - 五大功能：指令控制、操作控制、时间控制、数据加工、异常和中断处理；CPU = 运算器 + 控制器
  - 寄存器：用户可见（通用寄存器、PSW 的标志位）；**用户不可见**（PC、IR、MAR、MDR、暂存器），对汇编程序员透明
- (二)指令执行过程
  - 四个工作周期：**取指周期 → 间址周期 → 执行周期 → 中断周期**，取指后 PC 自动加 1（(PC)+1→PC）
  - 取指微操作：M(MAR)→MDR→IR；执行方案有单周期、多周期、流水线三种，各指令周期不等长
- (三)数据通路的功能和基本结构
  - 数据通路 = 指令执行时数据流经的路径与部件，ALU、寄存器、异常中断处理逻辑都属于数据通路
  - 单总线结构冲突多、一次加法需 3 步微操作；多总线、专用数据通路可并行更快；内部总线 vs 系统总线
- (四)1 硬布线控制器
  - 微操作控制信号 = 指令译码输出 & 节拍（时钟）& 状态条件 的**组合逻辑**
  - 速度快、RISC 常用；设计复杂、修改与扩充困难
- (四)2 微程序控制器
  - 一条机器指令 → 一段**微程序** → 若干**微指令** → 若干**微命令**；控制存储器 CM（ROM）存微程序，配 CMAR/μIR/地址转移逻辑，取指微程序各指令公用
  - 水平型微指令：一条可并行控制多个微命令，微程序短、字长长、执行快；垂直型：类似机器指令、需译码，字短但微程序长
  - 微指令编码：直接编码、字段直接编码（**互斥微命令分到同一字段**，每字段留全 0 表示"无操作"，$n$ 位字段最多表示 $2^n-1$ 个微命令）、字段间接编码
  - 后继微地址形成：增量计数器法（μPC+1）与断定方式（下址字段 + 转移条件 + 地址转移逻辑）
- (五)1 异常和中断的基本概念
  - 异常（Exception）= CPU **内部**、与当前指令**同步**的意外事件；中断（Interrupt）= CPU **外部**（I/O 设备）、**异步**的请求
  - 两者都使 CPU 暂停当前程序、保存现场后转入处理程序，处理完恢复现场返回原程序
- (五)2 异常和中断的分类
  - 异常三类：**故障（Fault）**——指令执行前/中检出、纠正后**重执行**当前指令（缺页、除零、非法指令）；**自陷（Trap）**——有意触发、处理后**执行下一条**（系统调用 int 0x80/syscall、断点）；**终止（Abort）**——不可恢复、**终止进程**（硬件故障、校验错）
  - 中断两类：**可屏蔽中断（INTR）**（可由关中断屏蔽，I/O 设备请求）与**不可屏蔽中断（NMI）**（必须立即响应，电源故障、内存校验错）
- (五)3 异常和中断的检测与响应
  - 检测时机：异常在**指令执行过程中**由硬件检出（译码/执行/访存阶段）；中断在**一条指令执行结束后**的中断检查点检测
  - **中断隐指令**（硬件自动执行、**不属于指令系统**）做三件事：**关中断、保存断点（PC/PSW 压栈）、引出中断服务程序入口**
  - 服务程序（软件）流程：保护现场 → 设备服务 → 恢复现场 → 开中断 → 返回；响应优先级（硬件排队、不可变）与处理优先级（屏蔽字、可变）及多重中断细节见第7章
- (六)1/2 指令流水线的基本概念与基本实现
  - 五段式：IF 取指 → ID 译码 → EX 执行 → MEM 访存 → WB 写回；时钟周期取决于**最慢的一段**
  - $n$ 条指令 $m$ 段流水：总时间 $T = (m + n - 1)\Delta t$；实际吞吐率 $\dfrac{n}{(m+n-1)\Delta t}$；最大吞吐率 $\dfrac{1}{\Delta t}$；加速比 $\dfrac{nm}{m+n-1}$；效率 $\dfrac{nm}{m(m+n-1)}$
- (六)3 结构冒险、数据冒险和控制冒险的处理
  - **结构冒险**：部件冲突（IF 与 MEM 同时访存）→ 停顿一拍、指令存储器与数据存储器分开
  - **数据冒险**：RAW（写后读）→ 转发/旁路；load-use 即使有转发也必须停 1 拍，可配合编译调度
  - **控制冒险**：转移指令 → 静态/动态分支预测（BHT）、延迟分支；预测错误要**冲刷已取的指令**，代价 = 惩罚周期
- (六)4 超标量和动态流水线的基本概念
  - 超标量：一个时钟周期**发射多条**指令（横向、多条流水线）；超流水：把段**再细分**（纵向）以提高主频
  - 动态调度：乱序执行、按序完成（记分牌、Tomasulo）；超长指令字 VLIW 由编译器静态打包
- 【22增】多处理器基本概念之一：Flynn 分类与向量处理器
  - Flynn 分类（按指令流/数据流）：**SISD**（传统单核冯·诺依曼机）、**SIMD**（一条指令同时处理多个数据，向量处理器/GPU/SSE/AVX）、**MISD**（理论模型、极少）、**MIMD**（多核/多处理器/集群）
  - **SPMD（单程序多数据）是 MIMD 的编程模型**：多处理器运行同一程序、处理不同数据，不属于 Flynn 的四种结构
  - 向量处理器：SIMD 的典型实现（Cray-1、现代 GPU），一条向量指令对整组数据运算，用并行功能部件/流水线喂饱运算单元
- 【22增】多处理器基本概念之二：硬件多线程
  - **细粒度多线程**：每个时钟周期轮转切换线程，切换代价最小、隐藏延迟最好，但单线程性能下降
  - **粗粒度多线程**：只在**长延迟事件**（如 Cache 缺失）时才切换，切换（保存/恢复上下文）代价大，流水线气泡多
  - **同时多线程 SMT**：同一时钟周期内发射多个线程的指令（如 Intel 超线程），要求超标量发射槽有余量，硬件成本最高
- 【22增】多处理器基本概念之三：多核处理器与共享内存多处理器 SMP
  - 多核处理器：一个芯片集成多个**独立核心**，**共享 L3/内存控制器/I/O，各自独立 L1/L2 与寄存器组**；核间通过共享 Cache/总线通信与同步
  - 共享内存多处理器 SMP：多个**同构**处理器经**总线或交叉开关**共享同一物理主存，由 OS 统一调度（MIMD 的实现）
  - **UMA**（统一存储访问，访存时间与处理器、字无关）与 **NUMA**（非统一存储访问，访存时间与之相关）；组织方式分**主/从**与**对称**
  - Cache 一致性：**监听（snooping）协议**（各 Cache 在总线上偷听写操作并作废/更新副本，如 MESI，适合总线型 SMP）与**目录（directory）协议**（目录记录块的副本位置、定向发无效化消息，可扩展性好），同步靠原子指令 + 锁 + 屏障

## 六、总线（笔记：第6章 总线系统）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC6%E7%AB%A0%20%E6%80%BB%E7%BA%BF%E7%B3%BB%E7%BB%9F.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- (一)1 总线的基本概念
  - 总线是连接多个部件、由各部件**分时共享**的一组公共信号线及协议，同一时刻只能有一对部件通信
  - 总线是**共享**（分时）的，其结构直接影响整机性能与可扩展性
- (一)1 总线的分类
  - 按功能分：片内总线、系统总线（数据总线、地址总线、控制总线）、通信总线
  - **数据总线双向、地址总线单向（CPU → 外部）**、控制总线中每根线单向；按传输方式分串行总线与并行总线
  - 系统总线结构：单总线（简单但同一时刻只能一对部件通信、易成瓶颈）→ 双总线（主存总线 + I/O 总线）→ 三总线（增加 DMA 总线）
- (一)2 总线的组成及性能指标
  - 性能指标：总线宽度（位数）、工作频率、**总线带宽 = 工作频率 × 每次传送的字节数**、总线复用、信号线数
  - 例：32 位宽、100MHz、每周期传 1 次 → $4\text{B} \times 100\text{M} = 400\text{MB/s}$；DDR 双沿再 ×2
- (一)2 总线带宽的典型计算
  - 看清"每几个时钟周期传送一次"：每 2 个时钟传一次则带宽减半（$1.6\text{GB/s} \to 800\text{MB/s}$）
  - 分清总线带宽（B/s）与总线频率（Hz），计算前先把宽度换算成字节
- (一)3 总线事务和总线周期
  - 一次总线事务的四个阶段：**申请分配 → 寻址 → 传输 → 结束**
  - 总线周期指完成一次总线操作所需的时间；突发传送在一个地址后可连续传送多个数据
- (一)3 总线定时方式
  - **同步通信**：统一时钟、速度快、控制简单，但须迁就最慢设备（强制同步）
  - **异步通信**：应答方式，分不互锁、半互锁、全互锁，可靠性依次提高、速度依次变慢
  - 半同步通信：在同步基础上加 WAIT 应答信号；**分离式通信**把一个总线周期拆成两个，让出总线给其他主设备，**总线利用率最高**
- 总线仲裁
  - 集中式三种：**链式查询**（BG 串行、优先级由物理位置固定、线最少，但某设备故障会阻断其后设备）、**计数器定时查询**（设备地址计数、优先级可改）、**独立请求**（每设备一对 BR/BG、响应最快、优先级可编程、线最多）
  - 分布式仲裁：无中央仲裁器，各设备按仲裁号/自举方式竞争总线
- 总线标准
  - 常见标准：ISA、EISA、PCI（并行、共享）、PCIe（**串行、点对点**、x1/x4/x8/x16）、AGP、USB（**通用串行、支持热插拔**、最多 127 个设备）、SATA
  - 总线标准从物理特性、功能特性、电气特性、时间特性四个方面作出规定

## 七、输入输出系统（笔记：第7章 输入输出系统）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC7%E7%AB%A0%20%E8%BE%93%E5%85%A5%E8%BE%93%E5%87%BA%E7%B3%BB%E7%BB%9F.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- (二)1 I/O 接口（I/O 控制器）的功能和基本结构
  - 功能：数据缓冲、错误与状态检测、控制与定时、数据格式转换、与主机和设备通信
  - 组成：数据缓冲寄存器 DBR、状态/控制寄存器、端口地址译码、控制逻辑；**接口 ≠ 端口 ≠ 设备**（一个接口可含多个端口）
- (二)2 I/O 端口及其编址
  - **统一编址**：与主存共用地址空间、可用访存指令、译码慢、占用内存空间
  - **独立编址**：地址空间独立、需专用 I/O 指令与控制线区分是访存还是 I/O
- (三)1 程序查询方式
  - CPU 不断轮询设备状态、**忙等**，CPU 与设备**完全串行**，接口最简单、CPU 利用率最低
  - 会算查询方式的 CPU 时间开销与利用率（一次查询的开销 × 查询次数）
- (三)2 程序中断方式
  - 流程：中断请求 → 中断判优 → 响应条件（CPU 允许中断、有请求、**一条指令执行完**）→ 中断隐指令 → 服务程序（保护现场 → 设备服务 → 恢复现场 → 开中断 → 返回）
  - 单重中断 vs **多重中断**（服务过程中开中断才能嵌套）；**响应优先级由硬件排队器决定、不可变，处理优先级由屏蔽字决定、可变**
  - 中断向量：由中断类型号查中断向量表得到**服务程序入口地址**；"向量地址"是表项地址，与入口地址不同
- (三)3 DMA 方式
  - 特点：以**数据块**为单位、主存与设备之间直接传送、**不经过 CPU**，CPU 只在预处理/后处理介入
  - DMA 控制器组成：主存地址计数器、传送长度计数器、数据缓冲寄存器、中断逻辑、控制/状态逻辑
  - 三种传送方法：停止 CPU 访存、**周期挪用（周期窃取）**、交替访存；三阶段：预处理 → 数据传送（硬件完成）→ 后处理（以中断方式报告 CPU）
- DMA 与中断方式的对比
  - 响应时机：**DMA 在存取周期结束时响应，中断在一条指令执行结束时响应**；优先级 DMA 高于中断（不挪用会丢数据）
  - 数据通路：DMA 不经过 CPU 寄存器；中断方式的数据经 CPU 中转（每字都要执行服务程序）
  - 适用对象：中断适合中低速设备按字传送；DMA 适合磁盘等高速块设备，CPU 开销最小
- 通道方式与外部设备
  - 通道（概念级）：执行通道程序、独立于 CPU 管理 I/O；字节多路通道（低速多设备）、数组选择通道（高速独占）、数组多路通道（高速多设备分时）
