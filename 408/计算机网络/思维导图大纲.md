## 一、计算机网络体系结构（笔记：第1章 计算机网络体系结构）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC1%E7%AB%A0%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C%E4%BD%93%E7%B3%BB%E7%BB%93%E6%9E%84.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 计算机网络概述：定义、组成与功能
  - 定义：自治的计算机互连的集合（自治 + 互连 + 交换信息，缺一不可）
  - 组成：硬件（主机/链路/设备）+ 软件（OS/协议）+ 协议；也可按"资源子网 + 通信子网"划分
  - 功能：数据通信、资源共享、分布式处理、提高可靠性
- 网络的分类：按范围、使用者、交换技术、拓扑
  - 按范围：WAN（广域网）> MAN（城域网）> LAN（局域网）> PAN（个人区域网）
  - 按交换技术：电路交换、报文交换、分组交换；按拓扑：总线/星形/环形/网状；按传输技术：广播式、点对点
  - 按使用者：公用网、专用网（如军队/铁路网）
- 性能指标：速率、带宽、时延、时延带宽积、RTT、利用率
  - 四种时延：发送 $= \dfrac{\text{分组长度}}{\text{带宽}}$、传播 $= \dfrac{\text{距离}}{\text{传播速率}}$、处理、排队
  - 时延带宽积 $= \text{传播时延} \times \text{带宽}$（单位 bit，即"以比特为单位的链路长度"）
  - 发送时延只与带宽和分组长度有关，与距离无关；利用率越高时延越大（$D = \dfrac{D_0}{1-U}$）
- 交换方式：电路交换 / 报文交换 / 分组交换
  - 电路交换：建立连接→通话→释放，独占线路、时延最小、利用率最低；适合大量持续实时通信
  - 报文交换：整报文存储转发，时延最大；分组交换：拆分为分组，时延小、利用率高（首部开销增 5%-10%）
  - 分组交换总时间 ≈ 总发送时延 + 一个传播时延（最后一个分组流水到达）
- 体系结构与分层：协议、接口、服务
  - 分层好处：各层独立、灵活、易实现维护、促进标准化；对等层通信靠协议，相邻层靠接口（服务访问点 SAP）
  - **协议三要素**：语法（格式）、语义（含义）、同步/时序（事件顺序）
  - 服务是"下层向上层提供的能力"，协议是"同层之间的规则"——服务是垂直的、协议是水平的
- ISO/OSI 参考模型与 TCP/IP 模型：分层与对应关系
  - OSI 七层：物理、数据链路、网络、传输、会话、表示、应用（自下而上），理论完备但复杂、先于实现
  - TCP/IP 四层：网络接口层、网际层、传输层、应用层；**教学五层** = 物理 + 链路 + 网络 + 传输 + 应用
  - TCP/IP 赢在实现先行、免费开放、可扩展（会话层/表示层功能并入应用层）
- OSI 七层各层功能与对应 PDU / 设备（强化条目）
  - 物理层：比特流透明传输（比特）+ 中继器、集线器；数据链路层：成帧/差错/流量控制（帧）+ 网桥、交换机
  - 网络层：分组转发与路由选择（分组/数据报）+ 路由器；传输层：端到端进程通信（报文段）+ 网关
  - 会话层：会话管理与同步；表示层：格式转换、加密、压缩；应用层：用户服务（报文）——后两层在五层模型并入应用层
- 数据封装与解封装：逐层加首部
  - 发送方自上而下每层加首部（链路层还要加尾部 FCS）；接收方自下而上逐层剥去
  - 名称随层变化：报文 → 报文段 → 分组/数据报 → 帧 → 比特；PDU 就是"该层的数据单元"

## 二、物理层（笔记：第2章 物理层）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC2%E7%AB%A0%20%E7%89%A9%E7%90%86%E5%B1%82.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 通信基础概念：信源、信宿、信道、信号、码元、波特
  - 信道：单工 / 半双工 / 全双工；信号：模拟（连续）与数字（离散）
  - 码元：承载信息的信号基本波形；波特率 = 码元/秒，比特率 $= \text{波特率} \times \log_2 V$（$V$ = 码元状态数）
  - 速率 = 比特率，带宽 = 最高频率与最低频率之差；信源发、信宿收，信道承载信号
- 奈奎斯特定理与香农定理：两个极限速率公式
  - 奈氏（无噪声）：$C = 2W\log_2 V$——限制波特率上限，提高电平数可提速
  - 香农（有噪声）：$C = W\log_2(1 + S/N)$——与 $V$ 无关，只由带宽和信噪比决定
  - 30dB → $S/N = 10^{30/10} = 1000$；实际速率取两者较小值
- 编码与调制：数字数据/模拟数据的变换
  - 编码：不归零（NRZ，无自同步）、归零（RZ）、曼彻斯特（比特中间跳变，自同步、数据率是码率一半）、差分曼彻斯特（看起始有无跳变）、4B/5B
  - 调制：ASK / FSK / PSK / QAM（幅相联合，QAM-16 每码元 4 bit）
  - 以太网 10Mb/s 用曼彻斯特 → 20M 波特；100BASE-T 用 4B/5B + NRZI 才不必 200M 波特
- 电路交换、报文交换与分组交换：三种交换方式
  - 时延大小：报文交换 > 分组交换（虚电路）> 电路交换；电路交换时延小而固定，适合语音
  - 电路交换独占线路、利用率低；报文/分组交换都是存储转发
  - 会算"分组交换最后一个小分组的到达时间 ≈ 总发送时延 + 一个传播时延"
- 数据报与虚电路：分组交换的两种实现（网络层提供的两种服务）
  - 数据报（无连接）：每个分组独立选路、路由器逐跳决策、可能乱序/丢失/重复；健壮灵活，**因特网采用**
  - 虚电路（面向连接）：先建立虚电路、所有分组沿同一路径、分组只需携带**虚电路号**、按序到达；节点失效影响大
  - 与电路交换/分组交换的关系：虚电路是**分组交换**的一种实现（不是电路交换，线路不独占）；差错控制：虚电路由网络层负责、数据报由传输层负责
  - 适用场景：长时间大量持续通信、需按序与服务质量选虚电路；突发、短事务、需健壮性选数据报
- 传输介质：导向与非导向
  - 导向：双绞线（便宜、短距）、同轴电缆（抗干扰、有线电视）、光纤（多模用 LED 便宜短距 / 单模用激光贵长距）
  - 非导向：无线电波、微波（直线传播、需中继）、红外；传输介质不属于物理层（"第 0 层"）
  - 双绞线按屏蔽分 UTP/STP；光纤带宽大、抗电磁干扰、保密性好
- 物理层接口的特性：机械、电气、功能、规程
  - **机械特性**：接口形状、引线数目、引脚数量与排列；**电气特性**：电压范围、阻抗匹配、速率与距离限制
  - **功能特性**：某条线上一电平表示何种意义、各信号线的用途；**规程特性**：事件出现顺序与工作时序
  - 判据口诀：电气看"电平取值范围"，功能看"电平表示什么含义"
- 物理层设备：中继器与集线器
  - 中继器：对数字信号**再生还原**（不累积噪声），连接两个网段、两端必须同协议、不存储转发；5-4-3 规则
  - 集线器 Hub：多端口中继器；物理拓扑星形、逻辑拓扑总线形；共享带宽（各主机 = 总带宽 ÷ 主机数）
  - 两者都属同一冲突域、不隔离广播域，只能半双工

## 三、数据链路层（笔记：第3章 数据链路层）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC3%E7%AB%A0%20%E6%95%B0%E6%8D%AE%E9%93%BE%E8%B7%AF%E5%B1%82.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 数据链路层的功能与组帧：帧定界、透明传输
  - 功能：组帧、差错控制、流量控制、传输管理（链路管理）
  - 四种组帧：字符计数法（出错连锁）、字节填充（SOH/EOT + ESC 转义）、**比特填充（HDLC：5 个连续 1 后插 0）**、物理编码违例（以太网）
  - 帧 = 首部 + 数据 + 尾部（FCS）；"透明传输"就是数据里出现定界符也能正确传送
- 差错控制：检错编码与纠错编码
  - CRC：信息位后补 $r$ 个 0 做模 2 除，余数为 FCS（$r$ = 生成多项式最高次幂）；只检错不纠错
  - 海明码：$2^r \ge m + r + 1$，可纠 1 位错、检 2 位错；校验位放在 $2^i$ 位置
  - 奇偶校验只能检出奇数个错；纠错编码开销大于检错编码（故链路层多用 CRC + 重传）
- 流量控制、可靠传输与滑动窗口机制（总括）
  - 发送窗口 = 已发送未确认帧的上限；接收窗口 = 可接收的失序帧范围；窗口按确认向前**滑动**
  - **窗口与序号位数关系**：GBN $W \le 2^n - 1$；SR $W_{\text{发}} = W_{\text{收}} \le 2^{n-1}$（序号空间要够区分新旧帧）
  - 确认：累积确认（GBN）与逐帧/选择确认（SR）；停等是窗口为 1 的特例
- 停止-等待、GBN、SR：三种可靠传输协议
  - 停等：利用率 $U = \dfrac{T_D}{T_D + RTT + T_A}$；长肥管道利用率极低
  - GBN：接收窗口 = 1、累计确认，出错后重传**全部已发未确认帧**（顺序号 $n$ 位时发送窗口 $\le 2^n - 1$）
  - SR：设缓存、逐帧确认、只重传出错帧（$W \le 2^{n-1}$）；代价是缓存与复杂度
- 介质访问控制之一：信道划分（FDM/TDM/WDM/CDMA）
  - FDM 按频率划分（同时使用、频段不重叠）；TDM 按时间划分（轮流使用全部带宽），STDM 统计时分按需分配
  - WDM 是光波版的 FDM；CDMA 按正交码片划分，各站同时同频
  - CDMA 分离：$S \cdot X / n = +1$（发 1）/ $-1$（发 0）/ $0$（未发）；$S \cdot S = n$、$S \cdot T = 0$
- 介质访问控制之二：随机访问（ALOHA / CSMA / CSMA-CD / CSMA-CA）
  - 纯 ALOHA 效率 $S = G\mathrm{e}^{-2G}$（最大 18.4%）；时隙 ALOHA $S = G\mathrm{e}^{-G}$（最大 36.8%，效率翻倍）
  - CSMA：1-坚持（空闲即发、冲突概率大）、非坚持（随机等待、时延大）、p-坚持（折中）
  - CSMA/CD：先听后发、边发边听、**冲突后停发 + 发强化干扰信号 + 截断二进制指数退避**（第 $i$ 次 $r \in [0, 2^{\min(i,10)}-1]$，16 次放弃）
- CSMA/CD 争用期与最短帧长：会算
  - **争用期 $2\tau$**：发送方在 $2\tau$ 内未检测到冲突即确认成功；$\tau$ 为单程端到端传播时延
  - **最短帧长 $L_{\min} = 2\tau \times \text{数据率}$**：10Mb/s、$2\tau = 51.2\mu\text{s}$ → 512bit = 64B；不足则填充
  - 速率提高后 $L_{\min}$ 要重算（100Mb/s 同距离需加大帧长或缩小网段）；不能用于无线（无法边发边检测）
- CSMA/CA 与无线局域网：把冲突"避免"掉
  - 802.11 用 IFS（SIFS/DIFS）+ 随机退避 + **ACK 确认**；不能用冲突检测（隐蔽站、无法边发边听）
  - RTS/CTS 信道预约解决**隐蔽站**问题；可选 PC 点协调功能；无线帧要 ACK 才可靠
- 介质访问控制之三：轮询访问——令牌传递协议
  - 令牌 = 特殊短控制帧；各站组成**逻辑环**，**只有持有令牌的站才能发数据**，发完或超时即释放——**无冲突、各站公平**
  - 令牌持有时间 **THT** 限制单站占用；IEEE 802.5 令牌环、IEEE 802.4 令牌总线（物理总线 + 逻辑环）；802.5 有早期令牌释放与延迟释放
  - 令牌帧（空闲令牌，如 802.5 的 3 字节）与数据帧（忙标志 + 数据）；支持优先级预约机制（预约位/Priority/Reservation）
  - 监控站（Active Monitor）检测令牌丢失/多令牌/帧格式错误，清除残留数据并重新生成空闲令牌；FDDI 用双环冗余解决链路故障
  - 与 CSMA/CD 对比：令牌环**延迟确定、可精确计算最坏等待**（前面各站的令牌与帧时间之和），重负载效率高；但低负载不如 CSMA/CD，实现复杂、不支持全双工、不适应无线
- 局域网：IEEE 802 体系与以太网
  - IEEE 802 家族：802.3 以太网、802.11 无线局域网、802.5 令牌环；链路层分 LLC（802.2）与 MAC 子层
  - 以太网 V2 帧：目的 MAC 6B + 源 MAC 6B + 类型 2B + 数据 **46-1500B** + FCS 4B；MAC 地址 48 位；无连接不可靠
  - 10BASE-T（双绞线、星形、曼彻斯特）与网卡：网卡过滤（单播/广播/多播/混杂模式）；高速以太网演进（100BASE-T / 千兆 / 万兆）
- 局域网技术：【22增】VLAN
  - 划分 VLAN 后**隔离广播域**、提高安全性与管理灵活性；按端口/ MAC / 协议划分（动态 VLAN）
  - IEEE 802.1Q 标签 **4 字节**（TPID 0x8100 + 优先级 + CFI + VLAN ID 12 位 → 4094 个可用 VLAN）
  - 同一 VLAN 跨交换机通信需 Trunk 链路；不同 VLAN 间通信需路由器或三层交换机
- 广域网：基本概念与 PPP 协议
  - 广域网物理上由节点交换机与长距离链路构成，使用点对点信道；PPP 是点对点协议
  - PPP 帧：标志 7E + 地址 FF + 控制 03 + 协议 + 信息 + FCS + 标志 7E；异步链路用**字节填充**、同步用**零比特填充**
  - PPP 不需要的功能：纠错、流量控制、序号、多点线路；只提供无差错接收 + 不可靠交付，用 LCP/NCP 协商
- 数据链路层设备：以太网交换机
  - 交换机 = 多端口网桥：**自学习**（登记帧的源 MAC + 端口）、转发表**老化**机制
  - 转发/过滤：已知单播按表转发、未知单播与广播**泛洪**；每个端口**独立冲突域**、可全双工、独享带宽
  - 冲突域 vs 广播域：集线器都不隔离；交换机隔离冲突域不隔离广播域（VLAN 才隔离）；路由器两者都隔离

## 四、网络层（笔记：第4章 网络层）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC4%E7%AB%A0%20%E7%BD%91%E7%BB%9C%E5%B1%82.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 网络层的功能：异构互连、路由转发、SDN、拥塞控制
  - 异构网络互连：用统一 IP 编址与数据报格式屏蔽下层差异；路由选择（全局、算法）vs 分组转发（本地、查表）
  - 【22增】SDN：**控制平面与数据平面分离**，控制平面集中（SDN 控制器），南向接口 OpenFlow、北向接口给应用
  - 拥塞控制是**全局性**的（网络资源不够用），流量控制是**点到点**的——两者别混
- 路由算法：静态/动态、距离-向量、链路状态、层次路由
  - 静态路由手工配置、适合小网；动态路由由协议自动适应拓扑变化
  - 距离-向量：每个路由器向邻居通告"我到各网的距离"，坏消息传得慢（计数到无穷）
  - 链路状态：洪泛 LSA 使全网拓扑一致，各路由器用 Dijkstra 独立算最短路径；收敛快、开销大
  - 层次路由：AS 内用 IGP、AS 间用 EGP，减小路由表与更新流量
- IPv4 分组格式与分片：会算
  - 首部固定 20B：首部长度 ×4B、总长度 ×1B、**片偏移 ×8B**、TTL、协议（6=TCP / 17=UDP / 1=ICMP / 89=OSPF）、首部校验和（只校验首部、逐跳重算）
  - 分片：以 MTU=1500B 为例每片数据最多 1480B；除最后一片外每片数据必须是 **8B 的倍数**；中间路由器不重组，只在目的主机重组
  - DF 禁止分片、MF 还有分片；TTL 防环 + traceroute 原理
- IPv4 地址与 NAT：分类编址与地址转换
  - A 类 1-126、B 类 128-191、C 类 192-223、D 类组播、E 类保留；特殊地址：网络地址（主机号全 0）、广播（全 1）、127 环回、0.0.0.0、169.254 链路本地
  - NAT：私网地址 10/8、172.16/12、192.168/16；NAPT 改写 IP + 端口并建映射表
  - NAT 的代价：外网无法主动访问内网、破坏端到端透明性（需配置端口映射）
- 子网划分、子网掩码、CIDR 与路由聚集：地址规划重点
  - 子网划分：借主机位做子网位；可用主机数 $2^h - 2$；会算子网掩码、网络地址、广播地址
  - CIDR：a.b.c.d/n 前缀记法，消除分类；路由聚合取**最长公共前缀**（如 192.168.4.0/24 + 192.168.5.0/24 → /23）
  - 转发用**最长前缀匹配**（优先于默认路由 0.0.0.0/0）；直接交付 vs 间接交付
- ARP、DHCP 与 ICMP：三个配套协议
  - ARP：IP → MAC，同网段直接解析、跨网段解析**默认网关**的 MAC；**请求广播、应答单播**；有 ARP 缓存
  - DHCP：应用层协议、**UDP**（服务器 67 / 客户端 68）；Discover → Offer → Request → ACK；支持即插即用与移动
  - ICMP：差错报告（终点不可达/超时/参数问题/改变路由）+ 询问（回送请求与应答 = ping）；封装在 IP 数据报中；traceroute 靠 TTL 递增
- IPv6：主要特点与地址
  - **128 位**地址、基本首部 **40B 固定**、取消首部校验和与分片字段（只在源端分片）、支持扩展首部
  - 地址表示：冒号十六进制 + 零压缩（:: 只能出现一次）；无广播，用多播/任播
  - IPv4 → IPv6 过渡：**双协议栈**与**隧道技术**
- 路由协议：RIP、OSPF、BGP 对比
  - 自治系统 AS：域内路由（IGP）与域间路由（EGP）的边界；AS 内部统一管理、对外单一策略
  - RIP：距离向量、跳数度量（$\le 15$，16 = 不可达）、**UDP 520**、30s 周期交换，坏消息传得慢
  - OSPF：链路状态、**直接用 IP（协议号 89）**、洪泛 LSA + Dijkstra、划分区域（ABR/ASBR）、收敛快
  - BGP：路径向量、**TCP 179**、AS 级策略路由，只求"较好路由"不追求最优
- IP 组播与移动 IP：概念与通信过程
  - IP 组播：D 类地址为组播地址；IGMP 让主机加入/退出组；组播 MAC 映射 01-00-5E + IP 低 23 位（**32 个 IP 对应 1 个 MAC**）
  - 移动 IP 概念：**归属代理**（归属网）、**外地代理**（外地网）、**归属地址**（永久）、**转交地址 COA**（临时）
  - 通信过程：移动站到外地网 → 获 COA → 向归属代理**注册** → 归属代理**隧道封装**转发 → 外地代理/移动站解封装
  - 三角路由问题：通信对端仍发给归属地址，报文绕行归属代理造成额外时延（优化靠通信对端直接发 COA）
- 网络层设备：路由器的组成与转发
  - 组成：输入端口、交换结构、输出端口、路由选择处理机；输入/输出排队会丢包
  - 路由表 vs 转发表：路由表由协议维护，转发表是查表的优化结构；逐跳转发只看目的 IP
  - 转发流程：解封装 → 查表（最长前缀匹配）→ TTL 减 1 → 重算首部校验和 → 重新封装发出

## 五、传输层（笔记：第5章 传输层）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC5%E7%AB%A0%20%E4%BC%A0%E8%BE%93%E5%B1%82.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 传输层的功能与服务：进程间通信、端口、套接字
  - 端到端（进程到进程）逻辑通信、复用与分用、差错检测；屏蔽下层网络差异
  - 端口 0-65535：熟知 0-1023、登记 1024-49151、短暂 49152-65535；套接字 = IP:端口
  - 面向连接（TCP）与无连接（UDP）服务并存；"TCP/UDP 都是端到端进程通信"
- UDP 协议：数据报与校验
  - 首部 **8B**：源端口、目的端口、长度、校验和；无连接、尽最大努力、面向报文（保留边界）、无拥塞控制
  - 校验和计算含 **伪首部**（IP 层信息参与，仅用于计算不传输）；IPv4 中校验和可选
  - 适用：实时音视频、DNS、一次性短事务、广播/组播
- TCP 报文段与连接管理：首部、三次握手、四次挥手
  - 首部 20-60B：序号、确认号（= 期望收到的下一字节序号）、数据偏移 ×4B、标志位 SYN/ACK/FIN/RST/PSH/URG、窗口、校验和
  - 三次握手：SYN=1,seq=x → SYN=1,ACK=1,seq=y,ack=x+1 → ACK=1,seq=x+1,ack=y+1；**SYN 消耗一个序号**
  - 四次挥手：FIN → ACK → FIN → ACK；**主动方最后进 TIME-WAIT 等 2MSL**；FIN 也消耗一个序号，状态图要能画
- TCP 可靠传输与流量控制：序号确认、超时重传、rwnd
  - 可靠传输 = 序号 + 确认 + 重传；RTO 由 RTT 加权平均 + RTT 偏差估计；Karn 算法（重传段不采样）
  - 流量控制：接收方用 **rwnd** 通告可接收窗口，发送窗口 $\le \min(\text{rwnd}, \text{cwnd})$
  - **零窗口**死锁 → **持续计时器** + 零窗口探测报文；糊涂窗口综合征（概念级）
- TCP 拥塞控制：慢开始、拥塞避免、快重传、快恢复
  - 慢开始：cwnd 从 1 MSS 起**每个 RTT 翻倍**（指数），到 ssthresh 转拥塞避免（每 RTT +1，线性）
  - 超时：$\text{ssthresh} = \text{cwnd}/2$，cwnd = **1**，重新慢开始
  - 快重传：收到 **3 个冗余 ACK** 立即重传该段；快恢复：$\text{ssthresh} = \text{cwnd}/2$，cwnd = 新 ssthresh，进入拥塞避免（不回 1）
  - 目的不同：**流量控制防"接收方溢出"（rwnd）**，**拥塞控制防"网络过载"（cwnd）**

## 六、应用层（笔记：第6章 应用层）
- [📖 本章笔记](%E7%AC%94%E8%AE%B0/%E7%AC%AC6%E7%AB%A0%20%E5%BA%94%E7%94%A8%E5%B1%82.md) · [🧭 本章自查](%E5%A4%8D%E4%B9%A0%E8%87%AA%E6%9F%A5.md)
- 网络应用模型：C/S 与 P2P
  - C/S：服务器常驻、客户请求，集中管理但可扩展性差、易成瓶颈
  - P2P：对等节点既是客户又是服务器，自扩展、成本分摊、健壮（如 BitTorrent）
  - 对比维度：流量分布、扩展性、管理成本、可靠性
- DNS 系统：层次域名空间、域名服务器、解析过程
  - 层次域名空间：根 → 顶级域 → 权限域 → 主机；域名与 IP 是多对多关系
  - 四类服务器：根、顶级、权限、本地域名服务器（本地不属于层次结构，是查询入口）
  - 解析过程：主机→本地**递归**，本地→根/顶级/权限**迭代**；DNS 用 **UDP 53**（区域传送用 TCP）；高速缓存
- FTP：工作原理、控制连接与数据连接
  - 两条 TCP 连接：**控制连接 21**（整个会话保持）、**数据连接 20**（按需建立、传完即关）
  - 主动模式（PORT，服务器 20 连回客户端）vs 被动模式（PASV，客户端连服务器随机端口）
  - 控制信息带外传送；FTP 用 ASCII 或二进制传输模式
- 电子邮件：组成结构、格式与 MIME、SMTP 与 POP3
  - 组成：用户代理 UA + 邮件服务器 + 协议；邮件服务器之间用 SMTP
  - **SMTP（TCP 25，推）**只传 7 位 ASCII，二进制/非英文字符靠 **MIME** 扩展编码
  - **POP3（110，拉）**下载到本地（可保留），**IMAP** 在服务器上在线管理邮件；基于万维网时"网页 → HTTP → 服务器 → SMTP → 对方 → HTTP"
- WWW 与 HTTP：概念、组成结构、HTTP 协议
  - WWW 组成结构：URL + HTML + HTTP；浏览器/服务器结构，也可经代理服务器与 Web 缓存
  - HTTP/1.0 非持久连接（每对象 2RTT）vs HTTP/1.1 持久连接（首对象 2RTT、后续 1RTT，流水线可连发）
  - 报文：请求行/状态行 + 首部 + 实体；GET/POST；无状态 → **Cookie** 维持会话；条件 GET 支持缓存
